Big-O / Ω / Θ 7
ALG-U1-Q01MCQeasy

Consider f(n) = 3n² + 5n log n + 7. Which of the following is TRUE?

  1. f(n) = Θ(n²)
  2. f(n) = Θ(n log n)
  3. f(n) = Θ(n³)
  4. f(n) = Θ(n)
Show answer & solution

Detailed solution

Concept. Growth of a sum is governed by its fastest-growing term (the dominant term).

Step by step.

  1. The three terms grow as n², n log n and a constant.
  2. n log n = o(n²), because (n log n)/n² = (log n)/n → 0.
  3. So f(n) is squeezed between 3n² and (3+ε)n² for large n.
  4. Hence f(n) = Θ(n²).

Answer: 0

Common misconception. Adding a lower-order term such as 5n log n never changes the Θ-class. Students who sum the exponents or pick the largest coefficient by eye get B or C.

ALG-U1-Q02MCQeasy

If f(n) = Θ(g(n)) and g(n) = Θ(h(n)), which statement is necessarily TRUE?

  1. f(n) = Θ(h(n))
  2. f(n) = O(h(n)) but f(n) ≠ Θ(h(n))
  3. f(n) = o(h(n))
  4. Nothing can be concluded about f and h
Show answer & solution

Detailed solution

Concept. Θ is an equivalence relation: it is reflexive, symmetric and transitive.

Step by step.

  1. f = Θ(g) gives constants c₁, c₂, n₀ with c₁g(n) ≤ f(n) ≤ c₂g(n) for n ≥ n₀.
  2. g = Θ(h) gives d₁h(n) ≤ g(n) ≤ d₂h(n) for n ≥ n₁.
  3. Chain them for n ≥ max(n₀, n₁): c₁d₁h(n) ≤ f(n) ≤ c₂d₂h(n).
  4. That is exactly f(n) = Θ(h(n)).

Answer: 0

Common misconception. f = o(h) is strictly stronger than f = Θ(h) and does not follow. Θ gives a two-sided constant-factor sandwich, so it can never collapse to a little-o relation.

ALG-U1-Q03MCQmedium

Which is the correct increasing order of growth (slowest first) for large n?

  1. log log n < log n < √n < n/log n < n
  2. log n < log log n < √n < n < n/log n
  3. log log n < √n < log n < n/log n < n
  4. log log n < log n < n/log n < √n < n
Show answer & solution

Detailed solution

Concept. Compare functions by taking ratios (or logs of both sides) as n → ∞.

Step by step.

  1. log log n = o(log n): log log n / log n → 0.
  2. log n = o(√n): with n = 2^m, m / 2^(m/2) → 0.
  3. √n = o(n/log n): (n/log n)/√n = √n / log n → ∞.
  4. n/log n = o(n) since 1/log n → 0.
  5. Chaining gives log log n < log n < √n < n/log n < n.

Answer: 0

Common misconception. n/log n is easy to misplace. It sits *above* √n but *below* n; treating the /log n factor as making it slower than √n is the usual error. Verify with a concrete value: at n = 2^20, n/log₂n ≈ 52428 while √n = 1024.

ALG-U1-Q04MCQmedium

Which of the following statements is FALSE?

  1. n! = O(nⁿ)
  2. log(n!) = Θ(n log n)
  3. 2ⁿ⁺¹ = O(2ⁿ)
  4. 2²ⁿ = O(2ⁿ)
Show answer & solution

Detailed solution

Concept. Exponential bases cannot be changed by a constant factor, and log(n!) is sandwiched by Stirling's bounds.

Step by step.

  1. n! = 1·2···n ≤ n·n···n = nⁿ, so A is true.
  2. Stirling gives n! ≥ (n/e)ⁿ, so log(n!) = Θ(n log n); B is true.
  3. 2ⁿ⁺¹ = 2·2ⁿ, a constant multiple, so C is true.
  4. 2²ⁿ = 4ⁿ and 4ⁿ/2ⁿ = 2ⁿ → ∞, so 2²ⁿ ≠ O(2ⁿ); D is false.

Answer: 3

Common misconception. A constant added to the *exponent* is a constant factor in the value (2ⁿ⁺¹ = 2·2ⁿ), but a constant multiplying the exponent is an exponential factor (2²ⁿ = 4ⁿ). Mixing these two up is the standard trap.

ALG-U1-Q15MCQhard

Let f(n) = n^(log₂ n) and g(n) = n^1000. Which of the following is TRUE?

  1. f(n) = O(g(n))
  2. f(n) = Ω(g(n)) and f(n) ≠ O(g(n))
  3. f(n) = Θ(g(n))
  4. f(n) = o(g(n))
Show answer & solution

Detailed solution

Concept. Both are n raised to a power; compare the exponents log₂n and 1000.

Step by step.

  1. Write both as n^(exponent): f has exponent log₂n, g has exponent 1000.
  2. log₂n > 1000 once n > 2^1000.
  3. Beyond that point f(n) > g(n), so f is not O(g).
  4. f(n)/g(n) = n^(log₂n − 1000) → ∞, so f(n) = Ω(g(n)) and f(n) ≠ O(g(n)).

Answer: 1

Common misconception. A fixed polynomial n^1000 looks enormous but any polylog exponent eventually overtakes a constant exponent. The other classic trap is assuming n^(log n) is still polynomial — it is quasi-polynomial, growing faster than every n^k.

ALG-U1-Q16MSQmedium

Which of the following statements are TRUE?

  1. If f(n) = O(g(n)) then g(n) = Ω(f(n)).
  2. If f(n) = Θ(g(n)) then 2^(f(n)) = Θ(2^(g(n))).
  3. n^(1/2) = O(n^(2/3)).
  4. log(n!) = O(n log n).
Show answer & solution

Detailed solution

Concept. Definitions of O, Ω, Θ, and Stirling's bound for log(n!).

Step by step.

  1. A: f = O(g) means f(n) ≤ c·g(n) eventually; dividing by c gives g(n) ≥ (1/c)f(n), i.e. g = Ω(f). TRUE.
  2. B: take f(n) = n, g(n) = 2n. Then 2^(f(n)) = 2ⁿ and 2^(g(n)) = 4ⁿ, and 4ⁿ/2ⁿ = 2ⁿ → ∞, so they are not Θ of each other. FALSE.
  3. C: 1/2 < 2/3, so n^(1/2)/n^(2/3) = n^(−1/6) → 0. TRUE.
  4. D: log(n!) ≤ log(nⁿ) = n log n. TRUE.

Answer: [0, 2, 3]

Common misconception. B is the classic failure: Θ is preserved by addition and multiplication but **not** by exponentiation. Equal growth of f and g allows a multiplicative gap, which exponentiation turns into an unbounded ratio.

ALG-U1-Q20MSQeasy

Which of the following functions are O(n log n)?

  1. 5n log n + 100n
  2. n²/log n
  3. log(n!)
  4. 2^(log₂ n)
Show answer & solution

Detailed solution

Concept. Check whether each function is bounded above by a constant multiple of n log n.

Step by step.

  1. 5n log n + 100n ≤ 105 n log n for n ≥ 2. YES.
  2. (n²/log n)/(n log n) = n/(log n)² → ∞, so it is NOT O(n log n). NO.
  3. log(n!) = Θ(n log n) by Stirling, hence O(n log n). YES.
  4. 2^(log₂n) = n ≤ n log n for n ≥ 2. YES.

Answer: [0, 2, 3]

Common misconception. n²/log n is larger than n log n even though the log n sits in the denominator — dividing by a log does not bring a quadratic down to n log n.

Master Theorem Cases 8
ALG-U1-Q05MCQeasy

The recurrence T(n) = 2T(n/2) + n, with T(1) = 1, has the solution

  1. Θ(n log n)
  2. Θ(n²)
  3. Θ(n)
  4. Θ(log n)
Show answer & solution

Detailed solution

Concept. Master Theorem with a = 2, b = 2: compare f(n) against n^(log_b a).

Step by step.

  1. a = 2, b = 2, so n^(log₂2) = n¹.
  2. f(n) = n = Θ(n¹): this is Case 2 (equal growth).
  3. Case 2 gives T(n) = Θ(n^(log_b a) · log n) = Θ(n log n).
  4. Check by recursion tree: log₂n levels each costing n.

Answer: 0

Common misconception. Do not report Θ(n) just because the per-level cost is n; there are log n such levels.

ALG-U1-Q06MCQeasy

Using the Master Theorem, the solution of T(n) = 9T(n/3) + n is

  1. Θ(n²)
  2. Θ(n² log n)
  3. Θ(n log n)
  4. Θ(n)
Show answer & solution

Detailed solution

Concept. Master Theorem Case 1: f(n) is polynomially smaller than n^(log_b a).

Step by step.

  1. a = 9, b = 3, so n^(log₃9) = n².
  2. f(n) = n = O(n^(2−ε)) for any 0 < ε ≤ 1.
  3. Case 1 gives T(n) = Θ(n^(log_b a)) = Θ(n²).
  4. The +n work is negligible against the n² splitting cost.

Answer: 0

Common misconception. Case 1 needs a *polynomial* gap, not just f(n) = O(n^(log_b a)). Here n is smaller by a full factor of n, so the gap is genuine.

ALG-U1-Q07MCQmedium

Using the extended form of the Master Theorem, the solution of T(n) = 2T(n/2) + n log n is

  1. Θ(n log² n)
  2. Θ(n log n)
  3. Θ(n²)
  4. Θ(n log n log log n)
Show answer & solution

Detailed solution

Concept. Extended Case 2: if f(n) = Θ(n^(log_b a) · log^k n) with k ≥ 0, then T(n) = Θ(n^(log_b a) · log^(k+1) n).

Step by step.

  1. a = 2, b = 2, so n^(log₂2) = n.
  2. f(n) = n log n = Θ(n¹ · log¹ n), so k = 1.
  3. Extended Case 2 adds one extra logarithm: T(n) = Θ(n · log^(1+1) n).
  4. Hence T(n) = Θ(n log² n).

Answer: 0

Common misconception. Plain Case 2 would give Θ(n log n), which is *below* the actual cost — the n log n work per level already forces one extra log factor. Always check whether f(n) carries a log^k n.

ALG-U1-Q08MCQmedium

The solution of T(n) = 4T(n/2) + n² is

  1. Θ(n² log n)
  2. Θ(n²)
  3. Θ(n³)
  4. Θ(n log n)
Show answer & solution

Detailed solution

Concept. Master Theorem Case 2 when f(n) matches n^(log_b a) exactly.

Step by step.

  1. a = 4, b = 2, so n^(log₂4) = n².
  2. f(n) = n² = Θ(n^(log_b a)): Case 2 applies.
  3. Case 2 gives T(n) = Θ(n² log n).
  4. Recursion tree: each of the log₂n levels costs n².

Answer: 0

Common misconception. Reporting Θ(n²) omits the log n factor contributed by the number of levels; the per-level cost being exactly n² is the signal for Case 2, not Case 3.

ALG-U1-Q09MCQhard

The solution of T(n) = 3T(n/4) + n log n is

  1. Θ(n log n)
  2. Θ(n^0.792)
  3. Θ(n^1.585)
  4. Θ(n² log n)
Show answer & solution

Detailed solution

Concept. Master Theorem Case 3: f(n) polynomially dominates n^(log_b a) and satisfies the regularity condition.

Step by step.

  1. a = 3, b = 4, so n^(log₄3) ≈ n^0.7925.
  2. f(n) = n log n = Ω(n^(0.7925+ε)) for ε < 0.2, so Case 3 is in play.
  3. Regularity: a·f(n/b) = 3·(n/4)log(n/4) = (3/4)·n log(n/4) ≤ (3/4)·n log n = (3/4)f(n), and 3/4 < 1 holds.
  4. Case 3 gives T(n) = Θ(f(n)) = Θ(n log n).

Answer: 0

Common misconception. Option B tempts you to answer with n^(log_b a) (Case 1's answer) even though Case 3 applies here. Case 1 returns the *homogeneous* term; Case 3 returns f(n).

ALG-U1-Q17MSQmedium

Which of the following recurrences have the solution Θ(n log n)?

  1. T(n) = 2T(n/2) + n
  2. T(n) = 2T(n/2) + n²
  3. T(n) = 4T(n/4) + n
  4. T(n) = 8T(n/2) + n²
Show answer & solution

Detailed solution

Concept. Apply the Master Theorem case analysis to each recurrence separately.

Step by step.

  1. A: n^(log₂2) = n = f(n) → Case 2 → Θ(n log n). YES.
  2. B: n^(log₂2) = n, f(n) = n² polynomially larger, regularity 2·(n/2)² = n²/2 ≤ c·n² with c = 1/2 → Case 3 → Θ(n²). NO.
  3. C: n^(log₄4) = n = f(n) → Case 2 → Θ(n log n). YES.
  4. D: n^(log₂8) = n³, f(n) = n² polynomially smaller → Case 1 → Θ(n³). NO.

Answer: [0, 2]

Common misconception. b does not have to equal 2, and a does not have to equal b; only the comparison between f(n) and n^(log_b a) matters. Option C is missed by people who assume the a = b pattern.

ALG-U1-Q21NATeasy

For T(n) = 8T(n/2) + n², the solution is T(n) = Θ(n^k). Find k.

Show answer & solution

Detailed solution

Concept. Master Theorem Case 1: the homogeneous term n^(log_b a) wins when f(n) is polynomially smaller.

Step by step.

  1. a = 8, b = 2, so n^(log₂8) = n³.
  2. f(n) = n² = O(n^(3−ε)) with ε = 1, so Case 1 applies.
  3. Case 1 gives T(n) = Θ(n^(log_b a)) = Θ(n³).
  4. Matching Θ(n^k) gives k = 3.

Answer: 3

Common misconception. Adding the exponents of a and b (8 + 2) or answering 2 from f(n) = n² are the usual slips. The exponent is log_b a = log₂8 = 3.

ALG-U1-Q23NATmedium

For T(n) = 2T(n/4) + √n, the solution is T(n) = Θ(√n · log^k n). Find k.

Show answer & solution

Detailed solution

Concept. Master Theorem Case 2: f(n) matches n^(log_b a) exactly, adding one logarithmic factor.

Step by step.

  1. a = 2, b = 4, so n^(log₄2) = n^(1/2) = √n.
  2. f(n) = √n = Θ(n^(1/2)), exactly matching the homogeneous term.
  3. Case 2 gives T(n) = Θ(√n · log n).
  4. Matching Θ(√n · log^k n) gives k = 1.

Answer: 1

Common misconception. Because b = 4 and a = 2, log₄2 = 1/2, not 2. Getting the exponent wrong makes the comparison look like Case 1 or Case 3 and the extra log n disappears.

Recursion Tree Method 6
ALG-U1-Q10MCQmedium

For T(n) = T(n/3) + T(2n/3) + n, the recursion tree has total cost n at every level down to the deepest level. The solution is

  1. Θ(n log n)
  2. Θ(n²)
  3. Θ(n)
  4. Θ(n log² n)
Show answer & solution

Detailed solution

Concept. Unbalanced recursion trees: add the per-level cost over the tree height.

Step by step.

  1. Level 0 costs n.
  2. Level 1 costs n/3 + 2n/3 = n.
  3. In general level k costs n as long as subproblems have not hit the base case.
  4. The shortest root-to-leaf path has length log₃n; the longest has length log_(3/2) n.
  5. The tree has Θ(log n) fully-charged levels, so total cost is Θ(n log n).

Answer: 0

Common misconception. The two branch depths differ (log₃n vs log_(3/2)n), but they differ only by a constant factor 1/log₂(3/2) ≈ 1.71. Constant-factor height differences do not change the Θ-class, so the answer stays Θ(n log n).

ALG-U1-Q11MCQeasy

In the recursion tree for T(n) = 3T(n/4) + cn², the number of leaves is

  1. n^(log₄3)
  2. 3n
  3. n^(log₃4)
  4. 4^(log₃ n)
Show answer & solution

Detailed solution

Concept. A tree with branching factor a and shrink factor b has a^(log_b n) leaves.

Step by step.

  1. Each node has a = 3 children and the argument shrinks by b = 4.
  2. The depth is log₄n.
  3. Number of leaves = 3^(log₄ n).
  4. Rewrite: 3^(log₄n) = n^(log₄3) ≈ n^0.792.

Answer: 0

Common misconception. n^(log₃4) is the reciprocal exponent (it equals 4^(log₃n)); the base of the logarithm is b = 4 and the mantissa is a = 3, never the other way round.

ALG-U1-Q12MCQeasy

The solution of T(n) = T(n−1) + n, with T(1) = 1, is

  1. Θ(n²)
  2. Θ(n log n)
  3. Θ(n)
  4. Θ(2ⁿ)
Show answer & solution

Detailed solution

Concept. A subtract-and-conquer recurrence unrolls into a sum of the per-call costs.

Step by step.

  1. T(n) = n + T(n−1).
  2. Unrolling: T(n) = n + (n−1) + (n−2) + ··· + 1.
  3. That is n(n+1)/2.
  4. So T(n) = Θ(n²).

Answer: 0

Common misconception. A single recursive call does not mean linear time. The recursion depth is n and the per-call cost is also Θ(n), so the product is quadratic.

ALG-U1-Q18MSQhard

For T(n) = 2T(n/2) + n with T(1) = 1, consider its recursion tree. Which statements are TRUE?

  1. Every level, up to the deepest, contributes a total cost of n.
  2. The tree has exactly n leaves.
  3. The tree has exactly n − 1 internal nodes.
  4. The total cost of the tree is Θ(n²).
Show answer & solution

Detailed solution

Concept. Structure of a full binary recursion tree: level costs, leaf count and internal-node count.

Step by step.

  1. Level i has 2^i nodes, each doing n/2^i work → level cost 2^i · n/2^i = n. TRUE (for n a power of two).
  2. Depth is log₂n, so leaves = 2^(log₂n) = n. TRUE.
  3. A full binary tree with L leaves has L − 1 internal nodes; with L = n that is n − 1. TRUE.
  4. Total cost = n × (log₂n + 1) = Θ(n log n), not Θ(n²). FALSE.

Answer: [0, 1, 2]

Common misconception. The tempting error is D, obtained by adding the leaf count n to the level cost n. Leaves do constant work at the base case, so their contribution is Θ(n), which is dominated by the Θ(n log n) internal cost.

ALG-U1-Q22NATeasy

For T(n) = T(n−1) + n with T(1) = 1, the value of T(10) is ____.

Show answer & solution

Detailed solution

Concept. Unrolling a subtract-and-conquer recurrence produces an arithmetic series.

Step by step.

  1. T(n) = n + T(n−1).
  2. Unrolling to the base: T(n) = n + (n−1) + ··· + 2 + T(1).
  3. With T(1) = 1, T(n) = n(n+1)/2.
  4. T(10) = 10·11/2 = 55.

Answer: 55

Common misconception. Dropping the base term gives 54; the sum 10 + 9 + ··· + 1 already includes T(1) = 1, so 55 is correct.

ALG-U1-Q25NAThard

In the recursion tree for T(n) = 4T(n/2) + n² with base case T(1) = 1, how many leaves does the tree have when n = 32?

Show answer & solution

Detailed solution

Concept. Leaf count of a recursion tree is a^(log_b n), evaluated exactly at the given n.

Step by step.

  1. Branching factor a = 4, shrink factor b = 2.
  2. n = 32 = 2⁵, so the tree depth is log₂32 = 5.
  3. Level i has 4^i nodes; the leaves sit at level 5.
  4. Leaves = 4⁵ = 1024.
  5. Equivalently n^(log₂4) = 32² = 1024, which agrees.

Answer: 1024

Common misconception. Using 2⁵ = 32 (the depth) instead of 4⁵ is the standard slip — the leaf count is a^depth, not b^depth.

Substitution Method 4
ALG-U1-Q13MCQmedium

To prove T(n) = 2T(n/2) + n satisfies T(n) ≤ cn log₂ n by substitution, assume T(n/2) ≤ c(n/2) log₂(n/2). The inductive step requires

  1. c ≥ 1
  2. c ≥ 2
  3. any c > 0
  4. no condition on c
Show answer & solution

Detailed solution

Concept. Substitution: substitute the hypothesis, then find the constant condition that makes the target inequality hold.

Step by step.

  1. T(n) ≤ 2·[c(n/2) log₂(n/2)] + n.
  2. = cn (log₂n − 1) + n.
  3. = cn log₂ n − cn + n.
  4. We need cn log₂n − cn + n ≤ cn log₂n, i.e. n ≤ cn, i.e. c ≥ 1.
  5. So any c ≥ 1 works; the smallest integer choice is c = 1.

Answer: 0

Common misconception. The −cn term is what makes the induction tight. Beginners assume the induction is automatically satisfied and forget that the residual n − cn must be non-positive.

ALG-U1-Q14MCQeasy

The solution of T(n) = T(n/2) + 1, with T(1) = 0, is

  1. Θ(log n)
  2. Θ(n)
  3. Θ(1)
  4. Θ(n log n)
Show answer & solution

Detailed solution

Concept. Repeated halving with constant work per level gives a logarithmic number of levels.

Step by step.

  1. T(n) = 1 + T(n/2).
  2. Unroll: T(n) = 1 + 1 + ··· + 1 for log₂n terms.
  3. So T(n) = Θ(log n).
  4. Substitution check: guess T(n) ≤ c log₂n; then T(n) ≤ c log₂(n/2) + 1 = c log₂n − c + 1 ≤ c log₂n provided c ≥ 1.

Answer: 0

Common misconception. Θ(1) looks plausible because each call does constant work, but the number of calls grows with log n. The constant is per level, not per problem.

ALG-U1-Q19MSQhard

Which statements about the substitution method for solving recurrences are TRUE?

  1. A correct guess can always be verified by induction.
  2. If an induction attempt fails, the guess must be wrong.
  3. Subtracting a lower-order term from the guess, e.g. guessing T(n) ≤ cn − d instead of T(n) ≤ cn, can make an otherwise failing induction succeed.
  4. The substitution method can be used to prove tight Θ bounds.
Show answer & solution

Detailed solution

Concept. Substitution is a proof technique for a *guessed* bound; the guess supplies the constant, induction certifies it.

Step by step.

  1. A: substitution is precisely the inductive verification of a guess, so a correct guess with suitable constants always verifies. TRUE.
  2. B: the induction can fail purely because the guessed form is too weak, not because the bound is false — loosening the guess often fixes it. FALSE.
  3. C: with T(n) ≤ cn − d, the residual term can absorb the extra additive work, which is exactly how T(n) = 2T(n/2) + 1 is proved O(n). TRUE.
  4. D: proving both O and Ω with substitution yields Θ. TRUE.

Answer: [0, 2, 3]

Common misconception. A failed induction is evidence about the *guess*, not about the truth of the bound. The standard repair is to strengthen the hypothesis by subtracting a lower-order term.

ALG-U1-Q24NATmedium

To prove T(n) = 2T(n/2) + n ≤ cn log₂ n for all n ≥ 2 (with T(2) = 2) by substitution, what is the smallest integer value of c for which the inductive step goes through?

Show answer & solution

Detailed solution

Concept. Substitution: substitute the hypothesis into the recurrence and require the residual to be non-positive.

Step by step.

  1. Assume T(n/2) ≤ c(n/2) log₂(n/2).
  2. T(n) ≤ 2 · c(n/2)(log₂n − 1) + n = cn log₂n − cn + n.
  3. Require cn log₂n − cn + n ≤ cn log₂n, i.e. n ≤ cn, i.e. c ≥ 1.
  4. Base case n = 2: T(2) = 2 ≤ c·2·log₂2 = 2c, again requiring c ≥ 1.
  5. Both conditions are satisfied from c = 1 onwards, so the smallest integer is c = 1.

Answer: 1

Common misconception. The inductive step is *tight*: at c = 1 the residual n − cn is exactly zero. Students often answer 2 by assuming slack is needed; here the bound holds with equality at every level.
