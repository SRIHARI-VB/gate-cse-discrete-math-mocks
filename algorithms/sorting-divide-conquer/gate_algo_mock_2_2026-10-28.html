ALG-U1-Q01MCQeasy

Consider f(n) = 3n² + 5n log n + 7. Which of the following is TRUE?

  1. f(n) = Θ(n²)
  2. f(n) = Θ(n log n)
  3. f(n) = Θ(n³)
  4. f(n) = Θ(n)
Show answer & solution

Detailed solution

Concept. Growth of a sum is governed by its fastest-growing term (the dominant term).

Step by step.

  1. The three terms grow as n², n log n and a constant.
  2. n log n = o(n²), because (n log n)/n² = (log n)/n → 0.
  3. So f(n) is squeezed between 3n² and (3+ε)n² for large n.
  4. Hence f(n) = Θ(n²).

Answer: Option (A)

Common misconception. Adding a lower-order term such as 5n log n never changes the Θ-class. Students who sum the exponents or pick the largest coefficient by eye get B or C.

ALG-U1-Q02MCQeasy

If f(n) = Θ(g(n)) and g(n) = Θ(h(n)), which statement is necessarily TRUE?

  1. f(n) = Θ(h(n))
  2. f(n) = O(h(n)) but f(n) ≠ Θ(h(n))
  3. f(n) = o(h(n))
  4. Nothing can be concluded about f and h
Show answer & solution

Detailed solution

Concept. Θ is an equivalence relation: it is reflexive, symmetric and transitive.

Step by step.

  1. f = Θ(g) gives constants c₁, c₂, n₀ with c₁g(n) ≤ f(n) ≤ c₂g(n) for n ≥ n₀.
  2. g = Θ(h) gives d₁h(n) ≤ g(n) ≤ d₂h(n) for n ≥ n₁.
  3. Chain them for n ≥ max(n₀, n₁): c₁d₁h(n) ≤ f(n) ≤ c₂d₂h(n).
  4. That is exactly f(n) = Θ(h(n)).

Answer: Option (A)

Common misconception. f = o(h) is strictly stronger than f = Θ(h) and does not follow. Θ gives a two-sided constant-factor sandwich, so it can never collapse to a little-o relation.

ALG-U1-Q03MCQmedium

Which is the correct increasing order of growth (slowest first) for large n?

  1. log log n < log n < √n < n/log n < n
  2. log n < log log n < √n < n < n/log n
  3. log log n < √n < log n < n/log n < n
  4. log log n < log n < n/log n < √n < n
Show answer & solution

Detailed solution

Concept. Compare functions by taking ratios (or logs of both sides) as n → ∞.

Step by step.

  1. log log n = o(log n): log log n / log n → 0.
  2. log n = o(√n): with n = 2^m, m / 2^(m/2) → 0.
  3. √n = o(n/log n): (n/log n)/√n = √n / log n → ∞.
  4. n/log n = o(n) since 1/log n → 0.
  5. Chaining gives log log n < log n < √n < n/log n < n.

Answer: Option (A)

Common misconception. n/log n is easy to misplace. It sits *above* √n but *below* n; treating the /log n factor as making it slower than √n is the usual error. Verify with a concrete value: at n = 2^20, n/log₂n ≈ 52428 while √n = 1024.

ALG-U1-Q04MCQmedium

Which of the following statements is FALSE?

  1. n! = O(nⁿ)
  2. log(n!) = Θ(n log n)
  3. 2ⁿ⁺¹ = O(2ⁿ)
  4. 2²ⁿ = O(2ⁿ)
Show answer & solution

Detailed solution

Concept. Exponential bases cannot be changed by a constant factor, and log(n!) is sandwiched by Stirling's bounds.

Step by step.

  1. n! = 1·2···n ≤ n·n···n = nⁿ, so A is true.
  2. Stirling gives n! ≥ (n/e)ⁿ, so log(n!) = Θ(n log n); B is true.
  3. 2ⁿ⁺¹ = 2·2ⁿ, a constant multiple, so C is true.
  4. 2²ⁿ = 4ⁿ and 4ⁿ/2ⁿ = 2ⁿ → ∞, so 2²ⁿ ≠ O(2ⁿ); D is false.

Answer: Option (D)

Common misconception. A constant added to the *exponent* is a constant factor in the value (2ⁿ⁺¹ = 2·2ⁿ), but a constant multiplying the exponent is an exponential factor (2²ⁿ = 4ⁿ). Mixing these two up is the standard trap.

ALG-U1-Q15MCQhard

Let f(n) = n^(log₂ n) and g(n) = n^1000. Which of the following is TRUE?

  1. f(n) = O(g(n))
  2. f(n) = Ω(g(n)) and f(n) ≠ O(g(n))
  3. f(n) = Θ(g(n))
  4. f(n) = o(g(n))
Show answer & solution

Detailed solution

Concept. Both are n raised to a power; compare the exponents log₂n and 1000.

Step by step.

  1. Write both as n^(exponent): f has exponent log₂n, g has exponent 1000.
  2. log₂n > 1000 once n > 2^1000.
  3. Beyond that point f(n) > g(n), so f is not O(g).
  4. f(n)/g(n) = n^(log₂n − 1000) → ∞, so f(n) = Ω(g(n)) and f(n) ≠ O(g(n)).

Answer: Option (B)

Common misconception. A fixed polynomial n^1000 looks enormous but any polylog exponent eventually overtakes a constant exponent. The other classic trap is assuming n^(log n) is still polynomial — it is quasi-polynomial, growing faster than every n^k.

ALG-U1-Q16MSQmedium

Which of the following statements are TRUE?

  1. If f(n) = O(g(n)) then g(n) = Ω(f(n)).
  2. If f(n) = Θ(g(n)) then 2^(f(n)) = Θ(2^(g(n))).
  3. n^(1/2) = O(n^(2/3)).
  4. log(n!) = O(n log n).
Show answer & solution

Detailed solution

Concept. Definitions of O, Ω, Θ, and Stirling's bound for log(n!).

Step by step.

  1. A: f = O(g) means f(n) ≤ c·g(n) eventually; dividing by c gives g(n) ≥ (1/c)f(n), i.e. g = Ω(f). TRUE.
  2. B: take f(n) = n, g(n) = 2n. Then 2^(f(n)) = 2ⁿ and 2^(g(n)) = 4ⁿ, and 4ⁿ/2ⁿ = 2ⁿ → ∞, so they are not Θ of each other. FALSE.
  3. C: 1/2 < 2/3, so n^(1/2)/n^(2/3) = n^(−1/6) → 0. TRUE.
  4. D: log(n!) ≤ log(nⁿ) = n log n. TRUE.

Answer: Options (A), (C) and (D)

Common misconception. B is the classic failure: Θ is preserved by addition and multiplication but **not** by exponentiation. Equal growth of f and g allows a multiplicative gap, which exponentiation turns into an unbounded ratio.

ALG-U1-Q20MSQeasy

Which of the following functions are O(n log n)?

  1. 5n log n + 100n
  2. n²/log n
  3. log(n!)
  4. 2^(log₂ n)
Show answer & solution

Detailed solution

Concept. Check whether each function is bounded above by a constant multiple of n log n.

Step by step.

  1. 5n log n + 100n ≤ 105 n log n for n ≥ 2. YES.
  2. (n²/log n)/(n log n) = n/(log n)² → ∞, so it is NOT O(n log n). NO.
  3. log(n!) = Θ(n log n) by Stirling, hence O(n log n). YES.
  4. 2^(log₂n) = n ≤ n log n for n ≥ 2. YES.

Answer: Options (A), (C) and (D)

Common misconception. n²/log n is larger than n log n even though the log n sits in the denominator — dividing by a log does not bring a quadratic down to n log n.

ALG-U1-Q26MCQeasy

Which of the following is the formal definition of f(n) = O(g(n)) for asymptotically positive functions?

  1. There exist constants c > 0 and n₀ ≥ 0 such that f(n) ≤ c·g(n) for all n ≥ n₀.
  2. For every constant c > 0 there exists n₀ such that f(n) ≤ c·g(n) for all n ≥ n₀.
  3. There exist constants c > 0 and n₀ ≥ 0 such that f(n) ≥ c·g(n) for all n ≥ n₀.
  4. limn→∞ f(n)/g(n) = 0.
Show answer & solution

Detailed solution

Concept. Big-O is an upper bound that is allowed to be off by a fixed constant factor, and it only has to hold from some point onwards. One pair (c, n₀) that works is enough — the constant does not have to be beaten by every possible choice.

Step by step.

  1. Option A is exactly that statement: ∃c > 0, ∃n₀ such that f(n) ≤ c·g(n) beyond n₀.
  2. Option B quantifies c universally, so it demands f(n) ≤ c·g(n) even for c = 0.001. That is little-o, f(n) = o(g(n)), a strictly stronger claim.
  3. Option C has the inequality reversed, which defines f(n) = Ω(g(n)).
  4. Option D is the ratio test for little-o. It implies big-O but is not equivalent to it: f(n) = 2n is O(n) while f(n)/g(n) = 2 does not tend to 0.

Answer: Option (A)

Common misconception. Reading the ∃c of big-O as ∀c, which silently upgrades the claim to little-o, or reversing the inequality and landing on Ω. The constant is a witness you are free to choose, not a quantity you must satisfy for all values.

ALG-U1-Q27MCQeasy

Let f(n) = n^(3/2) and g(n) = n (log₂ n)². Which of the following is TRUE?

  1. f(n) = Θ(g(n))
  2. f(n) = O(g(n)) but f(n) ≠ Θ(g(n))
  3. g(n) = o(f(n))
  4. f(n) = o(g(n))
Show answer & solution

Detailed solution

Concept. Two functions are compared by the limit of their ratio. A ratio that blows up means the numerator grows faster; a ratio that tends to 0 means the denominator does.

Step by step.

  1. Form the ratio f(n)/g(n) = n^(3/2) / (n (log₂ n)²) = √n / (log₂ n)².
  2. Every polynomial in n beats every power of a logarithm: for n = 2^(m) the ratio is 2^(m/2)/m² → ∞.
  3. So f(n)/g(n) → ∞, which is precisely g(n) = o(f(n)).
  4. Consequently f(n) = ω(g(n)) and the two functions are not within a constant factor of each other.

Answer: Option (C)

Common misconception. Treating (log₂ n)² as if it were a polynomial factor comparable with √n. A logarithm squared is still far smaller than any positive power of n, so option (A) and option (D) both fail; option (B) reverses the direction.

ALG-U1-Q28MCQmedium

For every integer n ≥ 2 define f(n) = n^(1 + 1/log₂ n). Then

  1. f(n) = Θ(n)
  2. f(n) = Θ(n log n)
  3. f(n) = Θ(n²)
  4. f(n) = Θ(2^(n))
Show answer & solution

Detailed solution

Concept. A power of n whose exponent depends on n is best read in base 2: write n = 2^(log₂ n) and push the exponent through.

Step by step.

  1. Split the exponent: n^(1 + 1/log₂ n) = n · n^(1/log₂ n).
  2. Now n^(1/log₂ n) = 2^((log₂ n)·(1/log₂ n)) = 2^(1) = 2, a constant.
  3. Hence f(n) = 2n for every n ≥ 2.
  4. A constant multiple of n is Θ(n).

Answer: Option (A)

Common misconception. Assuming that an exponent containing 1/log₂ n must produce sub-linear or super-linear growth and guessing Θ(n log n) or Θ(n²). The exponent is not a fixed power: it shrinks exactly fast enough to cancel the log₂ n in the base change, leaving the constant 2.

ALG-U1-Q29MCQmedium

Which of the following statements is FALSE?

  1. n^(0.1) = O(log₂ n)
  2. log₂(n³) = Θ(log₂ n)
  3. 3^(n) = ω(n^(100))
  4. √n = O(n/log₂ n)
Show answer & solution

Detailed solution

Concept. Each claim is settled by the limit of the ratio of the two sides. Anything with a positive power of n outgrows any power of log n, and any exponential outgrows any polynomial.

Step by step.

  1. (A) n^(0.1)/log₂ n → ∞ because a polynomial dominates a logarithm. So n^(0.1) is ω(log n), never O(log n). FALSE.
  2. (B) log₂(n³) = 3 log₂ n, a constant multiple of log₂ n. TRUE.
  3. (C) 3^(n)/n^(100) → ∞, so n^(100) = o(3^(n)). TRUE.
  4. (D) √n / (n/log₂ n) = log₂ n / √n → 0, so √n = O(n/log₂ n). TRUE.

Answer: Option (A)

Common misconception. Judging by a few small values: at n = 10^(6) the ratio n^(0.1)/log₂ n is still below 1, which tempts a "yes" for (A). Asymptotics is about the limit, not about the first million values — the ratio eventually climbs without bound.

ALG-U1-Q30MCQhard

Which of the following functions grows fastest as n → ∞?

  1. 2^(n)
  2. n^(log₂ n)
  3. (log₂ n)^(n)
  4. n!
Show answer & solution

Detailed solution

Concept. When the bases differ and the exponents contain n, compare the base-2 logarithms of the four functions. A larger logarithm means a faster-growing function.

Step by step.

  1. (A) log₂ 2^(n) = n.
  2. (B) log₂ n^(log₂ n) = (log₂ n)².
  3. (C) log₂ (log₂ n)^(n) = n · log₂ log₂ n.
  4. (D) Stirling: log₂(n!) = n log₂ n − O(n), i.e. Θ(n log₂ n).
  5. Order the logarithms: (log₂ n)² is the smallest, then n, then n log₂ log₂ n, and n log₂ n is the largest.
  6. So n! is the fastest-growing of the four.

Answer: Option (D)

Common misconception. Picking 2^(n) because "exponential beats everything", or n^(log₂ n) because it has a power of n in the exponent. Both are beaten by n!, whose logarithm n log₂ n exceeds n log₂ log₂ n and (log₂ n)².

ALG-U1-Q41MSQeasy

Which of the following functions are Ω(n²)?

  1. n²/1000
  2. n (log₂ n)³
  3. 2^(n)
  4. n^(5/2)
Show answer & solution

Detailed solution

Concept. A function is Ω(n²) when it is bounded below by a constant multiple of n² from some point on. A small constant multiplier does not matter; what matters is the growth rate.

Step by step.

  1. (A) n²/1000 = (1/1000)·n² is a constant multiple of n²: Ω(n²). TRUE.
  2. (B) n (log₂ n)³ / n² = (log₂ n)³/n → 0, so it grows strictly slower: NOT Ω(n²).
  3. (C) 2^(n)/n² → ∞: TRUE.
  4. (D) n^(2.5)/n² = √n → ∞: TRUE.

Answer: Options (A), (C) and (D)

Common misconception. Rejecting (A) because of the tiny constant 1/1000. Asymptotic bounds ignore constant factors; only the growth rate counts.

ALG-U1-Q42MSQmedium

Which of the following statements are TRUE for asymptotically positive functions?

  1. f(n) = Θ(g(n)) if and only if f(n) = O(g(n)) and g(n) = O(f(n)).
  2. If f(n) = o(g(n)) then f(n) = O(g(n)) and f(n) ≠ Ω(g(n)).
  3. For every pair of functions f and g, either f(n) = O(g(n)) or g(n) = O(f(n)).
  4. If f(n) = O(g(n)) and g(n) = O(h(n)) then f(n) = O(h(n)).
Show answer & solution

Detailed solution

Concept. The asymptotic relations are preorders on functions. Θ is the symmetric part of O, O is transitive, and O is not a total order because two functions can be incomparable.

Step by step.

  1. (A) Θ means bounded above and below by constant multiples, which is exactly f = O(g) together with g = O(f). TRUE.
  2. (B) f = o(g) means f/g → 0, which gives f = O(g) at once and rules out f = Ω(g) (that would need f/g bounded below). TRUE.
  3. (C) Fails: take f(n) = n and g(n) = n^(1 + sin n). The ratio g/f = n^(sin n) oscillates between 1/n and n, so neither f = O(g) nor g = O(f) holds. FALSE.
  4. (D) Chaining the two constants gives f(n) ≤ c₁g(n) ≤ c₁c₂h(n) eventually. TRUE.

Answer: Options (A), (B) and (D)

Common misconception. Assuming O behaves like ≤ on numbers, which would make it a total order. It is only a preorder: transitivity and reflexivity hold, but two functions with wildly oscillating ratio are incomparable.

ALG-U1-Q45MSQhard

Which of the following statements are TRUE?

  1. n^(log₂ 3) = O(n^(1.6))
  2. 3^(n) = O(2^(n))
  3. 2^(3n) = Θ(8^(n))
  4. If f(n) = ω(g(n)) then f(n)/g(n) → ∞.
Show answer & solution

Detailed solution

Concept. Compare by ratio, and remember that two exponentials with different bases are never within a constant factor of each other, while two exponentials that differ only by rewriting the same expression are identical functions.

Step by step.

  1. (A) log₂ 3 ≈ 1.585 < 1.6, so n^(log₂ 3)/n^(1.6) = n^(−0.015) → 0. TRUE.
  2. (B) 3^(n)/2^(n) = (3/2)^(n) → ∞, so 2^(n) = o(3^(n)) and the claimed direction is reversed. FALSE.
  3. (C) 2^(3n) = (2³)^(n) = 8^(n), the very same function. TRUE.
  4. (D) That is the definition of little-omega: for every c > 0, f(n) > c g(n) eventually, which forces the ratio to diverge. TRUE.

Answer: Options (A), (C) and (D)

Common misconception. Reading O(2^(n)) as "exponential, so anything exponential is fine". A constant factor in the exponent is not a constant factor in the function: 3^(n) and 2^(n) differ by (3/2)^(n), which is unbounded.

ALG-U1-Q05MCQeasy

The recurrence T(n) = 2T(n/2) + n, with T(1) = 1, has the solution

  1. Θ(n log n)
  2. Θ(n²)
  3. Θ(n)
  4. Θ(log n)
Show answer & solution

Detailed solution

Concept. Master Theorem with a = 2, b = 2: compare f(n) against n^(log_b a).

Step by step.

  1. a = 2, b = 2, so n^(log₂2) = n¹.
  2. f(n) = n = Θ(n¹): this is Case 2 (equal growth).
  3. Case 2 gives T(n) = Θ(n^(log_b a) · log n) = Θ(n log n).
  4. Check by recursion tree: log₂n levels each costing n.

Answer: Option (A)

Common misconception. Do not report Θ(n) just because the per-level cost is n; there are log n such levels.

Using the Master Theorem, the solution of T(n) = 9T(n/3) + n is

  1. a = 9, b = 3, so n^(log₃9) = n².
  2. f(n) = n = O(n^(2−ε)) for any 0 < ε ≤ 1.
  3. Case 1 gives T(n) = Θ(n^(log_b a)) = Θ(n²).

Concept. Quickselect partitions once and recurses into the one side that contains the k-th element. The expected sum of the subproblem sizes is n + n/2 + n/4 + … = 2n, which is Θ(n); the worst case is still the degenerate chain of partitions, Θ(n²).

Step by step.

  1. One partition of a subarray of size m costs Θ(m).
  2. With a random pivot the expected size of the surviving side is at most 3m/4, so the expected total work satisfies E(n) ≤ n + E(3n/4) = Θ(n).
  3. If every pivot is extreme, the sizes fall by one each time and the total is Θ(n²).

Answer: Option (A)

Common misconception. Assuming that "select instead of sort" automatically means worst-case linear. Only the median-of-medians pivot gives that guarantee.

Which of the following statements about selection algorithms are TRUE? (Select all that apply.)

  1. Quickselect's expected Θ(n) time follows from the expected subproblem sizes forming a decreasing geometric series.
  2. The median-of-medians algorithm attains Θ(n) in the worst case by using a pivot that is guaranteed to lie between the 30th and 70th percentile.
  3. Sorting first and indexing costs Θ(n log n), which is asymptotically worse than the Θ(n) worst case of median-of-medians.
  4. Any comparison-based algorithm that finds the k-th smallest of n distinct keys needs Ω(n log n) comparisons in the worst case.
Show answer & solution

Detailed solution

Concept. Selection is a weaker problem than sorting, so it has a weaker lower bound: Ω(n), not Ω(n log n). The two ways to reach Θ(n) are randomisation (expected) and a guaranteed-fraction pivot (worst case).

Step by step.

  1. (A) True. With a random pivot the surviving side has expected size at most 3m/4, so the expected work is n + (3/4)n + (3/4)²n + … = 4n.
  2. (B) True. Each block of five contributes three keys on each side of its median, so the median of medians has at least 3n/10 keys below and at least 3n/10 above it.
  3. (C) True. Θ(n log n) dominates Θ(n).
  4. (D) False. Median-of-medians finds the k-th smallest in Θ(n) comparisons, so the lower bound is Ω(n).

Answer: Options (A), (B) and (C)

Common misconception. Quoting Ω(n log n) for selection. That bound is for producing the whole sorted order; a single order statistic costs only Ω(n).

Detailed solution

Concept. Finding the maximum alone needs n − 1 comparisons, and doing the two searches independently costs 2n − 2. Comparing pairs first makes each key lose at most once as a maximum candidate and win at most once as a minimum candidate, which brings the total down to ⌈3n/2⌉ − 2.

  1. Pair the 10 keys into 5 pairs and compare within each pair: 5 comparisons. Call the larger element the pair maximum and the smaller the pair minimum.
  2. The overall maximum is one of the 5 pair maxima, so 4 more comparisons find it.
  3. The overall minimum is one of the 5 pair minima, so 4 more comparisons find it.
  4. Total = 5 + 4 + 4 = 13, which equals ⌈3n/2⌉ − 2 = 15 − 2.

Common misconception. Answering 18 = 2n − 2 by running two independent scans, which wastes the information each comparison already gives about both extremes.

Which of the following statements about linear-time selection are TRUE? (Select all that apply.)

  1. With blocks of five, the recurrence T(n) ≤ T(n/5) + T(7n/10) + O(n) solves to Θ(n) because 1/5 + 7/10 < 1.
  2. Grouping into blocks of three instead of five still gives a linear-time algorithm, because the fraction of keys discarded at each step stays positive.
  3. Quickselect with a random pivot is Θ(n) in expectation even though its worst case is Θ(n²).
  4. Every comparison-based selection algorithm needs Ω(n) comparisons in the worst case, since a key that is never examined could be the answer.
Show answer & solution

Detailed solution

Concept. The block size controls how much the pivot guarantees. Blocks of five discard 3n/10 on each side, giving the 9/10 recurrence that solves to linear time. Blocks of three discard only n/3, and the recurrence then sums to Θ(n log n).

Step by step.

  1. (A) True. The fractions 1/5 (the recursive median-of-medians call) and 7/10 (the surviving side) add to 9/10 < 1, so the level costs form a decreasing geometric series.
  2. (B) False. With blocks of three the pivot only guarantees n/3 on each side, so the recurrence is T(n) ≤ T(n/3) + T(2n/3) + O(n), and 1/3 + 2/3 = 1 makes the sum Θ(n log n).
  3. (C) True. Randomisation gives a geometric expected decrease in subproblem size while leaving the adversarial worst case intact.
  4. (D) True. An unexamined key could be the k-th smallest, so every key must be touched at least once.

Answer: Options (A), (C) and (D)

Common misconception. Thinking that any constant block size works. The guarantee needs a block size of at least five, because only then is the recursive fraction sum below 1.

ALG-U2-Q19NAThard

Sixteen distinct keys are stored in an array. Both the largest and the second largest key must be determined. What is the minimum number of comparisons needed in the worst case? (Enter an integer.)

Show answer & solution

Detailed solution

Concept. Finding the maximum costs n − 1 comparisons, and only the keys that lost directly to the winner can be second largest. A tournament makes each key lose at most once, so the winner has beaten exactly ⌈log₂n⌉ opponents, and the second largest is the maximum of those.

Step by step.

  1. Run a knockout tournament on 16 keys: 8 + 4 + 2 + 1 = 15 comparisons identify the largest key.
  2. The largest key played exactly 4 matches, one per round, so exactly 4 keys lost directly to it.
  3. The second largest must be among those 4 losers, because every other key lost to some key that is itself smaller than the maximum.
  4. Finding the maximum of 4 keys costs 3 comparisons. Total = 15 + 3 = 18, that is n + ⌈log₂n⌉ − 2.

Answer: 18

Common misconception. Answering 16 + 15 = 31 by finding the maximum and then rescanning the array, which redoes comparisons that the tournament already made.

ALG-U2-Q21MCQeasy

Insertion sort is run on an array of n keys that contains exactly I inversions. Which statement is TRUE?

  1. It performs exactly I adjacent exchanges and runs in Θ(n + I) time.
  2. It runs in Θ(n log n) time regardless of I.
  3. It performs exactly I key comparisons in total.
  4. It cannot be used to count inversions, because it destroys them as it runs.
Show answer & solution

Detailed solution

Concept. Insertion sort moves a key left by swapping it with its immediate predecessor, and each swap removes exactly one inversion. The number of swaps is therefore exactly the inversion count, and the work is one pass over n keys plus one swap per inversion.

Step by step.

  1. Each inner-loop exchange swaps two adjacent keys that are out of order, which removes exactly one inversion and creates none.
  2. The process stops when no inversion remains, so exactly I exchanges are performed.
  3. The outer loop still visits all n keys, so the time is Θ(n + I).

Answer: Option (A)

Common misconception. Concluding that because insertion sort is Θ(n²) in the worst case, it is useless for counting. It is exactly linear in the number of inversions, which is the worst case n(n − 1)/2.

ALG-U2-Q22MCQmedium

In the merge-sort based inversion count, the left and right runs are being merged and the current key of the right run is smaller than the current key of the left run. How many new inversions are counted at that moment?

  1. Exactly one.
  2. As many as the number of keys still remaining in the left run, including the current one.
  3. As many as the number of keys still remaining in the right run.
  4. As many as the number of keys already written to the merged output.
Show answer & solution

Detailed solution

Concept. Within each run the keys are already sorted, so an inversion can only pair a left-run key with a right-run key. When the current right key r is smaller than the current left key, r is smaller than every key still in the left run, and all of them precede r in the original array.

Step by step.

  1. Both runs are sorted, so no inversion lies inside either run; only cross pairs matter.
  2. Let L[i..] be the remaining left run and R[j] the current right key, with R[j] < L[i].
  3. Since the left run is sorted, R[j] < L[i] ≤ L[i+1] ≤ …, so R[j] forms an inversion with each of them.
  4. The count added is therefore the number of keys left in the left run, that is len(L) − i.

Answer: Option (B)

Common misconception. Adding one inversion per comparison. The merge step must add a whole block of inversions, which is what makes the counting Θ(n log n) rather than Θ(n²).

ALG-U2-Q23MCQmedium

A permutation of n distinct keys is drawn uniformly at random. What is the expected number of inversions?

  1. n(n − 1)/2
  2. n(n − 1)/4
  3. n²/2
  4. (n − 1)/2
Show answer & solution

Detailed solution

Concept. Use linearity of expectation over pairs. For any fixed pair of positions, the two keys are equally likely to appear in either order, so the pair is inverted with probability 1/2, independently of all other pairs for the purpose of the sum.

Step by step.

  1. There are C(n,2) = n(n − 1)/2 pairs of positions.
  2. For a uniformly random permutation each pair is ordered one way or the other with probability 1/2, so the indicator of that pair being an inversion has expectation 1/2.
  3. By linearity of expectation the expected total is C(n,2) × 1/2 = n(n − 1)/4.
  4. For n = 4 the formula gives 4·3/4 = 3, and the 24 permutations of four keys do average exactly three inversions.

Common misconception. Assuming the expectation must be a whole number. Expectations need not be integers; n(n − 1)/4 is 1.5 for n = 4.

ALG-U2-Q24MSQmedium

Which of the following statements about inversions are TRUE? (Select all that apply.)

  1. The maximum possible number of inversions in an array of n distinct keys is n(n − 1)/2.
  2. Two different permutations of the same n distinct keys can have the same number of inversions.
  3. If an array has exactly one inversion, a single adjacent exchange sorts it.
  4. The number of inversions of a permutation equals the minimum number of arbitrary element exchanges needed to sort it.
Show answer & solution

Detailed solution

Concept. Inversions measure disorder in the adjacent-swap metric. Each adjacent exchange changes the count by exactly one, which is why inversions equal the adjacent-transposition distance. Exchanging arbitrary pairs is a different metric, governed by cycle structure.

Step by step.

  1. (A) True. There are C(n,2) pairs, and the decreasing order inverts every one of them.
  2. (B) True. For three keys, [2,3,1] and [3,1,2] both have two inversions.
  3. (C) True. Exactly one inversion means exactly one adjacent pair is out of order, and swapping it sorts the array.
  4. (D) False. The minimum number of arbitrary exchanges is n − (number of cycles), for example 1 for [2,3,1], which has two inversions.

Answer: Options (A), (B) and (C)

Common misconception. Treating every measure of disorder as the inversion count. Inversions count adjacent swaps only.

Detailed solution

Concept. With duplicates, an inversion is still a strict inequality on values but a strict inequality on positions. Equal keys never count, so the array is not simply "disordered everywhere".
