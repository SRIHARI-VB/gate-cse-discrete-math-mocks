Hardwired control 7
CO-U2-Q01MCQeasy

In a hardwired control unit, the control signals are generated by

  1. a control store that holds microinstructions
  2. combinational logic fed by the instruction register, the status flags and the timing signals
  3. an interrupt vector table indexed by the interrupt number
  4. a microprogram counter together with a mapping ROM
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. A control unit is hardwired when its output signals are produced by a fixed combinational network. The inputs to that network are the instruction opcode, the condition flags and the timing (T-state) signals.

Step by step.

  1. The instruction register supplies the opcode bits that identify which instruction is executing.
  2. The status flags supply the conditions on which conditional operations depend.
  3. A sequence counter and decoder supply the timing state, so the same opcode yields different signals in T0, T1 and so on.
  4. The network ANDs and ORs these inputs into the individual control lines, so no memory is consulted while the instruction executes.

Answer: combinational logic driven by opcode, flags and timing signals (option B).

Common misconception. Options A and D describe a microprogrammed unit, where the control word is read from a control store. The two designs differ precisely in whether a memory lookup sits on the control path.

CO-U2-Q02MCQeasy

Which property of a hardwired control unit makes it preferable to a microprogrammed one?

  1. Its control logic can be changed by rewriting the contents of a control store
  2. It needs no clock signal
  3. It supports long, complex instruction sets with less hardware
  4. Its control signals come from fast combinational logic, so the control path is short
Show answer & solution

Answer: Option (D)

Detailed solution

Concept. The trade-off between the two control designs is speed against flexibility. Combinational logic answers in gate delays; a microprogrammed unit must first read a microinstruction from the control store.

Step by step.

  1. A hardwired unit evaluates a fixed Boolean function of opcode, flags and timing state, so its delay is a few gate levels.
  2. A microprogrammed unit adds the control-store access time to every step, which is what makes it slower per control word.
  3. The price of that speed is rigidity: any change to the instruction set means redesigning the logic.
  4. Hence speed, not modifiability or hardware economy, is the hardwired advantage.

Answer: a short, fast combinational control path (option D).

Common misconception. Option A is the microprogrammed advantage, not the hardwired one; option C is also false, because long complex instruction sets are exactly where microprogramming saves hardware. Every control unit still needs a clock.

CO-U2-Q03NATeasy

A hardwired control unit must generate 6 distinct timing states, one per clock cycle. What is the minimum number of bits in its sequence counter?

    Show answer & solution

    Answer: 3

    Detailed solution

    Concept. A sequence counter with k bits drives a decoder with 2k outputs, so it can distinguish at most 2k timing states.

    Step by step.

    1. Two bits give 4 states, which is fewer than the 6 required.
    2. Three bits give 8 states, and 8 ≥ 6.
    3. So the counter needs ⌈log2 6⌉ = 3 bits, leaving two decoder outputs unused.

    Answer: 3 bits.

    Common misconception. Writing 6, the number of states, instead of the number of bits needed to encode them. A counter stores a code, not the count of states.

    CO-U2-Q04MCQmedium

    An instruction set has 12 instructions and its longest instruction needs 9 timing states. The control unit decodes the opcode with an instruction decoder and steps through the states with a sequence counter. What is the minimum width of the opcode field and of the sequence counter?

    1. 4 bits opcode and 4 bits sequence counter
    2. 3 bits opcode and 3 bits sequence counter
    3. 4 bits opcode and 3 bits sequence counter
    4. 12 bits opcode and 9 bits sequence counter
    Show answer & solution

    Answer: Option (A)

    Detailed solution

    Concept. Both fields hold a binary code, so each needs ⌈log2 n⌉ bits for n distinct values.

    Step by step.

    1. Opcode: 3 bits address only 8 instructions, so 12 instructions need 4 bits (16 codes, 4 unused).
    2. Timing states: 3 bits address only 8 states, so 9 states need 4 bits (16 states, 7 unused).
    3. Both fields are therefore 4 bits wide.

    Answer: 4-bit opcode and 4-bit sequence counter (option A).

    Common misconception. Rounding 9 states down to 3 bits because 8 feels close enough, or sizing the opcode by the number of instructions rather than by the number of codes needed to name them.

    CO-U2-Q05MSQmedium

    Which of the following statements about hardwired control are TRUE? (Select all that apply.)

    1. It is faster than microprogrammed control because the control signals come from combinational logic rather than from a control store.
    2. It is easy to extend when the instruction set changes, because a new instruction only needs new microcode.
    3. It uses a sequence counter and a decoder to generate the timing states of the instruction cycle.
    4. A single combinational network can generate every control signal, so no control store is needed.
    Show answer & solution

    Answer: Options (A), (C), (D)

    Detailed solution

    Concept. Hardwired control is a fixed Boolean network: fast, rigid, and driven by opcode, flags and timing state.

    Step by step.

    1. (A) No memory access sits on the control path, so the control signals settle in gate delays. True.
    2. (B) Adding an instruction means redesigning the logic and rewiring the network; new microcode is the microprogrammed route. False.
    3. (C) The sequence counter produces T0, T1, ... and its decoder output is ANDed into the signal equations. True.
    4. (D) That absence of a control store is exactly what defines the design. True.

    Answer: (A), (C) and (D).

    Common misconception. Believing hardwired control is also the flexible option. Speed and modifiability pull in opposite directions here, and microprogramming is the answer to the second.

    CO-U2-Q06NATmedium

    A hardwired control unit sequences 7 timing states, T0 to T6, from a 3-bit sequence counter feeding a 3-to-8 decoder. How many decoder outputs are never used?

      Show answer & solution

      Answer: 1

      Detailed solution

      Concept. A k-bit counter decodes into 2k outputs; if the machine uses fewer states than that, the surplus outputs stay idle.

      Step by step.

      1. A 3-bit counter produces 23 = 8 codes, so the decoder has 8 outputs.
      2. States T0 to T6 use 7 of them.
      3. 8 − 7 = 1 output, the code 111, is never asserted.

      Answer: 1 unused output.

      Common misconception. Counting the states as the decoder size, or assuming the spare code is harmless. An unused state must still be handled, since a glitch on the counter can land the machine there.

      CO-U2-Q07MCQhard

      An instruction needs 20 distinct timing states, and the design decodes every state directly from a binary sequence counter. What is the minimum counter width, and why is a narrower counter unsafe here?

      1. 4 bits, because states can be reused under different flag conditions
      2. 5 bits, because 4 bits decode to only 16 states while 20 distinct states are required
      3. 20 bits, one bit per state
      4. 4 bits plus a 2-to-1 multiplexer on the decoder output
      Show answer & solution

      Answer: Option (B)

      Detailed solution

      Concept. A counter of width k can name 2k distinct states. If every state must be decoded uniquely from the counter alone, the width is forced by the state count.

      Step by step.

      1. Four bits decode to 16 codes, and 16 < 20, so two states would share a code and the control signals of the two would be asserted together.
      2. Five bits decode to 32 codes, and 32 ≥ 20, so every state gets its own code and 12 codes remain spare.
      3. Hence the minimum width is 5 bits.

      Answer: 5 bits (option B).

      Common misconception. Option A describes a real but different technique: reusing a state under different flag conditions requires extra decision logic and a branch, which the question excludes by fixing the decoding to the counter alone. Without that extra logic, 4 bits silently merges states.

      Microprogrammed control 6
      CO-U2-Q08MCQeasy

      In a microprogrammed control unit, the microinstructions are held in

      1. the main memory, alongside the program being executed
      2. the control store, also called the control memory
      3. the data cache
      4. the general-purpose register file
      Show answer & solution

      Answer: Option (B)

      Detailed solution

      Concept. A microprogrammed control unit replaces the control logic with a small memory whose words are control words; each word is a microinstruction that asserts a set of control signals for one step.

      Step by step.

      1. The control store is addressed by the microprogram counter.
      2. Each location holds the control word for one micro-operation.
      3. The sequencer decides the next address, so the microprogram walks through the steps of the current instruction.
      4. Main memory and cache hold program and data, never control words.

      Answer: the control store / control memory (option B).

      Common misconception. Confusing the control store with main memory. It is a separate, usually read-only array inside the control unit, and its width is the number of control lines rather than the machine word size.

      CO-U2-Q09MCQeasy

      A microinstruction format that assigns one bit to each control line, with no encoding of mutually exclusive signals, is called

      1. a horizontal microinstruction
      2. a vertical microinstruction
      3. a diagonal microinstruction
      4. a two-level or nano microinstruction
      Show answer & solution

      Answer: Option (A)

      Detailed solution

      Concept. Horizontal and vertical microcode sit at opposite ends of the width-versus-decoding trade-off. A horizontal word is wide and fully decoded; a vertical word is narrow and encoded.

      Step by step.

      1. One bit per control line means no decoder is needed and every signal can be asserted independently.
      2. That independence lets many micro-operations run in parallel within one microinstruction, which is the horizontal advantage.
      3. The cost is a very wide control word, since the word must carry a bit for every control line.

      Answer: a horizontal microinstruction (option A).

      Common misconception. Assuming wider always means faster in a way that makes vertical code useless. Vertical code trades parallelism for a small control store and is often preferred when the store is a bottleneck.

      CO-U2-Q10NATeasy

      A control store holds 1024 microinstructions addressed by the microprogram counter. How many bits must the microprogram counter have?

        Show answer & solution

        Answer: 10

        Detailed solution

        Concept. The microprogram counter supplies the address of the next microinstruction, so its width must span every location of the control store.

        Step by step.

        1. 1024 = 210.
        2. Ten bits name 1024 distinct addresses, exactly the number of locations.
        3. No spare code remains, so every address is a legal microinstruction.

        Answer: 10 bits.

        Common misconception. Answering 1024, the number of locations, instead of the logarithm. Also watch the power-of-two boundary: 1023 locations would still need 10 bits.

        CO-U2-Q11MCQmedium

        A microinstruction consists of 40 control bits and a 10-bit sequencing field. The control store holds 512 microinstructions. What is the total capacity of the control store in bits?

        1. 25,600 bits
        2. 20,480 bits
        3. 51,200 bits
        4. 22,528 bits
        Show answer & solution

        Answer: Option (A)

        Detailed solution

        Concept. Control-store capacity is the word width multiplied by the number of words, and the word width includes every field, not only the control bits.

        Step by step.

        1. Word width = 40 + 10 = 50 bits.
        2. Number of words = 512.
        3. Capacity = 512 × 50 = 25,600 bits.
        4. Cross-check: 512 × 40 = 20,480 control bits, and 512 × 10 = 5,120 sequencing bits; the sum is 25,600.

        Answer: 25,600 bits (option A).

        Common misconception. Option B counts only the control field and forgets the sequencing field, which is part of every stored word.

        CO-U2-Q12MSQmedium

        Which of the following statements about microprogrammed control are TRUE? (Select all that apply.)

        1. Vertical microprogramming encodes mutually exclusive control signals into fields that a decoder expands, giving a narrow control word at the cost of decoding delay.
        2. A horizontal microinstruction is wide and can assert many control signals in parallel within a single microinstruction.
        3. A new instruction can be added by writing new microcode, without redesigning the control logic.
        4. A microprogrammed control unit always executes an instruction faster than a hardwired unit.
        Show answer & solution

        Answer: Options (A), (B), (C)

        Detailed solution

        Concept. Microprogramming buys flexibility with time: the control word comes from a memory, and encoding it narrowly adds a decoder in series.

        Step by step.

        1. (A) Encoded fields shrink the word, and the decoder adds delay. True.
        2. (B) One bit per signal allows simultaneous assertion, which is the horizontal strength. True.
        3. (C) The instruction set is defined by the control store contents, so microcode changes are enough. True.
        4. (D) The control-store access time makes the microprogrammed unit slower per control word, not faster. False.

        Answer: (A), (B) and (C).

        Common misconception. Treating microprogramming as a pure improvement. It is a trade: flexibility and simplicity in exchange for speed and, in the horizontal case, control-store width.

        CO-U2-Q13MCQhard

        A control word has three encoded fields, each of which selects exactly one of 10 mutually exclusive control signals, plus 6 control lines that each require their own bit. What is the minimum width of the control word?

        1. 18 bits
        2. 24 bits
        3. 30 bits
        4. 36 bits
        Show answer & solution

        Answer: Option (A)

        Detailed solution

        Concept. An encoded field holding n mutually exclusive choices needs ⌈log2 n⌉ bits and a decoder to expand it; a signal that must be controlled independently needs a bit of its own.

        Step by step.

        1. Each encoded field must name one of 10 signals: ⌈log2 10⌉ = 4 bits.
        2. Three such fields take 3 × 4 = 12 bits.
        3. The 6 independent lines take 6 bits.
        4. Total = 12 + 6 = 18 bits.
        5. Cross-check the encoding capacity: each 4-bit field has 16 codes for 10 signals, so 6 codes per field are spare, which is acceptable.

        Answer: 18 bits (option A).

        Common misconception. Option C comes from adding 10 + 10 + 10 instead of encoding, i.e. from using one bit per signal and forgetting that the field is decoded. Option B comes from dropping the 6 independent lines altogether.

        ALU & datapath timing 6
        CO-U2-Q14MCQeasy

        An ALU has 3 function-select inputs. How many distinct operations can it select?

        1. 3
        2. 6
        3. 9
        4. 8
        Show answer & solution

        Answer: Option (D)

        Detailed solution

        Concept. Select lines form a binary code, so k of them name 2k distinct operations.

        Step by step.

        1. Three select bits produce codes 000 through 111.
        2. That is 23 = 8 codes.
        3. Each code routes one ALU function to the output, so eight operations can be selected.

        Answer: 8 operations (option D).

        Common misconception. Answering 3, the number of select lines, or 9 by counting 3 × 3. The select lines are a code, not a count.

        CO-U2-Q15MCQeasy

        In an n-bit ALU, the zero flag is normally produced by

        1. ANDing all the result bits
        2. ORing all the result bits
        3. NORing all the result bits
        4. XORing all the result bits
        Show answer & solution

        Answer: Option (C)

        Detailed solution

        Concept. The zero flag must be 1 exactly when every result bit is 0, which is the definition of a NOR over all bits.

        Step by step.

        1. If any bit is 1, the OR of all bits is 1 and the result is not zero.
        2. So “all bits zero” is the complement of the OR, that is the NOR.
        3. In hardware an n-input NOR is usually built as an OR tree followed by an inverter, which keeps the delay logarithmic.

        Answer: NOR of all result bits (option C).

        Common misconception. ANDing the bits detects the all-ones case, not zero. A zero-detector must react to the OR being 0, so the flag is the inverse of an OR, not an AND.

        CO-U2-Q16NATmedium

        In a single-bus CPU, a register-to-register ADD traverses: source register output 2 ns, bus 1 ns, ALU 5 ns, bus again 1 ns, and destination register setup 2 ns. What is the minimum clock period in ns?

          Show answer & solution

          Answer: 11

          Detailed solution

          Concept. The clock period must cover the longest combinational path between two registers, plus the setup time of the register at the end of that path.

          Step by step.

          1. Register output to bus: 2 + 1 = 3 ns.
          2. Through the ALU: 3 + 5 = 8 ns.
          3. ALU output back onto the bus: 8 + 1 = 9 ns.
          4. Destination setup: 9 + 2 = 11 ns.
          5. The bus is used twice because a single bus carries one value at a time, so the two transfers cannot overlap.

          Answer: 11 ns.

          Common misconception. Adding only one bus delay because the bus is one physical wire. It is one wire used twice, so both uses cost time in the same cycle.

          CO-U2-Q17MCQmedium

          A 32-bit ripple-carry adder is built from full adders in which the carry takes 2 ns per stage, and the sum bit of a stage takes a further 3 ns after its carry-in has settled. What is the worst-case delay to the final sum bit S31, measured from the arrival of the operands?

          1. 62 ns
          2. 64 ns
          3. 65 ns
          4. 96 ns
          Show answer & solution

          Answer: Option (C)

          Detailed solution

          Concept. In a ripple-carry adder the carry propagates serially, and each sum bit needs one more delay after its own carry-in is valid.

          Step by step.

          1. Carry into bit i is valid at 2i ns, since each stage adds 2 ns.
          2. Bit 31 needs carry C31, valid at 31 × 2 = 62 ns.
          3. The sum bit then takes a further 3 ns: 62 + 3 = 65 ns.
          4. The final carry-out C32 would be valid at 64 ns, which is why 64 is the answer only if the question asks for the carry.

          Answer: 65 ns (option C).

          Common misconception. Reporting 64 ns, the carry-out time, instead of the sum time; or multiplying the sum delay by 32, which would wrongly assume the sum bits also ripple.

          CO-U2-Q18MSQhard

          Which of the following statements about datapath timing are TRUE? (Select all that apply.)

          1. The clock period must be at least the longest register-to-register combinational delay plus the destination register setup time.
          2. Inserting a pipeline register can shorten the clock period, at the cost of more cycles of latency for the same instruction.
          3. A single-bus datapath executes an ADD in fewer clock cycles than a three-bus datapath.
          4. A pipeline register placed between the ALU and the destination register shortens the combinational path that fixes the clock period.
          Show answer & solution

          Answer: Options (A), (B), (D)

          Detailed solution

          Concept. The clock period is set by the worst register-to-register path. Pipeline registers cut that path into shorter pieces; buses and their sharing decide how many transfers a step needs.

          Step by step.

          1. (A) That inequality is the definition of a valid clock period. True.
          2. (B) Each register halves the logic between two registers, so the period falls while the instruction needs extra cycles to traverse the added stage. True.
          3. (C) A single bus must be reused for each operand and for the result, so it needs more cycles, not fewer. False.
          4. (D) Placing the register at the ALU output ends the ALU-to-register path there, so only the shorter segments bound the period. True.

          Answer: (A), (B) and (D).

          Common misconception. Believing pipelining reduces the total work of an instruction. It reduces the clock period and raises throughput, but a single instruction takes more cycles than before.

          CO-U2-Q19MCQhard

          A datapath register has a clk-to-Q delay of 3 ns, the ALU takes 6 ns, the result multiplexer takes 2 ns, and the destination register needs 2 ns of setup time. What is the minimum clock period?

          1. 11 ns
          2. 13 ns
          3. 15 ns
          4. 8 ns
          Show answer & solution

          Answer: Option (B)

          Detailed solution

          Concept. A register-to-register path is bounded by four delays in series: clk-to-Q of the launching register, the combinational logic, any multiplexer on the result path, and the setup time of the capturing register.

          Step by step.

          1. Launch: 3 ns.
          2. ALU: 3 + 6 = 9 ns.
          3. Result multiplexer: 9 + 2 = 11 ns.
          4. Setup: 11 + 2 = 13 ns.
          5. 13 ns is therefore the shortest safe period, giving a clock of about 76.9 MHz.

          Answer: 13 ns (option B).

          Common misconception. Option A drops the multiplexer, and option D drops both the clk-to-Q and the setup time. Every element on the path between the two register edges must be counted.

          Bus architectures 6
          CO-U2-Q20MCQeasy

          The width of a system bus is conventionally quoted as the number of

          1. address lines
          2. data lines
          3. control lines
          4. interrupt request lines
          Show answer & solution

          Answer: Option (B)

          Detailed solution

          Concept. A bus is described as an 8-bit, 32-bit or 64-bit bus according to how many bits it can carry in one transfer, which is the data-line count.

          Step by step.

          1. The data lines move the operand itself, so their number sets the transfer granularity.
          2. The address lines set the addressable range instead: n address lines reach 2n locations.
          3. Control lines carry timing and command signals and are counted separately.

          Answer: data lines (option B).

          Common misconception. Confusing bus width with address width. A machine may have 32 data lines and 40 address lines; only the first is called the bus width.

          CO-U2-Q21MCQeasy

          In a synchronous bus, every transfer is timed with respect to

          1. a handshake between the master and the slave
          2. the ready signal of the slowest device on the bus
          3. a common clock shared by all devices on the bus
          4. the interrupt acknowledge cycle of the CPU
          Show answer & solution

          Answer: Option (C)

          Detailed solution

          Concept. Synchronous buses include a clock line and fix every event to a clock edge; asynchronous buses replace the clock with request and acknowledge handshakes.

          Step by step.

          1. All devices derive their timing from the same clock, so protocol steps take a known number of cycles.
          2. That makes the bus simple and fast for devices that can meet the timing.
          3. Its weakness is that the cycle must be long enough for the slowest device, or a ready/wait line must stretch it.

          Answer: a common clock (option C).

          Common misconception. Options A and B describe the asynchronous bus, where handshaking lets each device take the time it needs. A ready line can appear in a synchronous bus, but only as an exception to the fixed timing.

          CO-U2-Q22NATmedium

          A synchronous bus has a 32-bit data path and a 100 MHz clock, and completes one transfer per clock cycle. What is its maximum bandwidth in MB/s? (Use 1 MB = 106 bytes.)

            Show answer & solution

            Answer: 400

            Detailed solution

            Concept. Bus bandwidth is the bytes moved per transfer multiplied by the number of transfers per second.

            Step by step.

            1. 32 bits = 4 bytes per transfer.
            2. 100 MHz gives 100 × 106 transfers per second.
            3. 4 × 100 × 106 = 400 × 106 bytes per second.
            4. That is 400 MB/s in decimal megabytes.

            Answer: 400 MB/s.

            Common misconception. Reporting 3200 by using 32 bytes instead of 4, or 419 by dividing by 220 when the question specifies decimal megabytes. Also watch the cycle count: one transfer per cycle is given here, and a multi-cycle transfer halves or quarters the figure.

            CO-U2-Q23MCQmedium

            A bus has a 64-bit data path, a 66 MHz clock, and requires 2 clock cycles per data transfer. What is its effective bandwidth?

            1. 264 MB/s
            2. 528 MB/s
            3. 132 MB/s
            4. 4224 MB/s
            Show answer & solution

            Answer: Option (A)

            Detailed solution

            Concept. Effective bandwidth is the transfer size divided by the time one transfer occupies, so a multi-cycle transfer must divide the raw clock rate.

            Step by step.

            1. 64 bits = 8 bytes per transfer.
            2. Two cycles per transfer means 66 × 106 / 2 = 33 × 106 transfers per second.
            3. 8 × 33 × 106 = 264 × 106 bytes per second.
            4. So the effective bandwidth is 264 MB/s.

            Answer: 264 MB/s (option A).

            Common misconception. Option B ignores the two-cycle transfer, and option C halves twice by also treating the 64-bit path as 4 bytes. Divide the clock once for the cycle count, and use the full data width.

            CO-U2-Q24MSQmedium

            Which of the following statements about bus organisation are TRUE? (Select all that apply.)

            1. A three-bus datapath can read both operands and write the result within one clock cycle without an intermediate temporary register.
            2. In a single-bus organisation each transfer occupies the whole bus for a clock cycle, so the micro-operations of an instruction are serialised.
            3. A wider data bus shortens the transfer time of a single word even when that word already fits in one transfer.
            4. A bus with several potential masters needs an arbitration mechanism to decide which one drives it.
            Show answer & solution

            Answer: Options (A), (B), (D)

            Detailed solution

            Concept. The number of buses fixes how many values can move at once; bus width fixes how much one value can be; arbitration fixes who may drive.

            Step by step.

            1. (A) Two source buses feed the ALU and a third carries the result back, so no operand has to wait for the bus to be freed. True.
            2. (B) One bus means one value per cycle, so operands and result are moved one after another. True.
            3. (C) Once the word fits in a single transfer, extra width cannot shorten that transfer; it only helps wider operands or block transfers. False.
            4. (D) Contention must be resolved, whether by daisy chain, polling or independent requests. True.

            Answer: (A), (B) and (D).

            Common misconception. Treating bus width as a universal speed-up. Beyond the width of the data being moved, extra lines buy nothing on a single-word transfer.

            CO-U2-Q25MSQhard

            Which of the following statements about bus arbitration are TRUE? (Select all that apply.)

            1. Daisy-chain arbitration grants the bus by physical position on the chain, so a device nearer the arbiter wins a tie.
            2. Independent-request arbitration gives each master its own request and grant line, and any priority policy can be implemented.
            3. Polling arbitration uses a counter to select masters in turn and needs no separate grant line for each master.
            4. Daisy-chain arbitration gives every master the same worst-case access latency.
            Show answer & solution

            Answer: Options (A), (B), (C)

            Detailed solution

            Concept. Three standard schemes resolve contention: daisy chain (grant propagates physically), independent requests (one grant per master), and polling (the arbiter asks masters in turn).

            Step by step.

            1. (A) The grant signal passes through each device in order, so the nearest device sees it first and captures it. True.
            2. (B) With a grant line per master the arbiter may use fixed priority, rotating priority or any other rule. True.
            3. (C) Polling drives a common select code from a counter, so one set of lines serves all masters. True.
            4. (D) In a daisy chain a far device must wait for every nearer device to pass the grant along, so latency depends on position. False.

            Answer: (A), (B) and (C).

            Common misconception. Assuming daisy chaining is fair because the grant is passed down the line. It is a fixed priority scheme, and the last device in the chain can be starved indefinitely.
