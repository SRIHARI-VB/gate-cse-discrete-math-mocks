Hardwired control 13
CO-U2-Q01MCQeasy

In a hardwired control unit, the control signals are generated by

  1. a control store that holds microinstructions
  2. combinational logic fed by the instruction register, the status flags and the timing signals
  3. an interrupt vector table indexed by the interrupt number
  4. a microprogram counter together with a mapping ROM
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. A control unit is hardwired when its output signals are produced by a fixed combinational network. The inputs to that network are the instruction opcode, the condition flags and the timing (T-state) signals.

Step by step.

  1. The instruction register supplies the opcode bits that identify which instruction is executing.
  2. The status flags supply the conditions on which conditional operations depend.
  3. A sequence counter and decoder supply the timing state, so the same opcode yields different signals in T0, T1 and so on.
  4. The network ANDs and ORs these inputs into the individual control lines, so no memory is consulted while the instruction executes.

Answer: combinational logic driven by opcode, flags and timing signals (option B).

Common misconception. Options A and D describe a microprogrammed unit, where the control word is read from a control store. The two designs differ precisely in whether a memory lookup sits on the control path.

CO-U2-Q02MCQeasy

Which property of a hardwired control unit makes it preferable to a microprogrammed one?

  1. Its control logic can be changed by rewriting the contents of a control store
  2. It needs no clock signal
  3. It supports long, complex instruction sets with less hardware
  4. Its control signals come from fast combinational logic, so the control path is short
Show answer & solution

Answer: Option (D)

Detailed solution

Concept. The trade-off between the two control designs is speed against flexibility. Combinational logic answers in gate delays; a microprogrammed unit must first read a microinstruction from the control store.

Step by step.

  1. A hardwired unit evaluates a fixed Boolean function of opcode, flags and timing state, so its delay is a few gate levels.
  2. A microprogrammed unit adds the control-store access time to every step, which is what makes it slower per control word.
  3. The price of that speed is rigidity: any change to the instruction set means redesigning the logic.
  4. Hence speed, not modifiability or hardware economy, is the hardwired advantage.

Answer: a short, fast combinational control path (option D).

Common misconception. Option A is the microprogrammed advantage, not the hardwired one; option C is also false, because long complex instruction sets are exactly where microprogramming saves hardware. Every control unit still needs a clock.

CO-U2-Q03NATeasy

A hardwired control unit must generate 6 distinct timing states, one per clock cycle. What is the minimum number of bits in its sequence counter?

    Show answer & solution

    Answer: 3

    Detailed solution

    Concept. A sequence counter with k bits drives a decoder with 2k outputs, so it can distinguish at most 2k timing states.

    Step by step.

    1. Two bits give 4 states, which is fewer than the 6 required.
    2. Three bits give 8 states, and 8 ≥ 6.
    3. So the counter needs ⌈log2 6⌉ = 3 bits, leaving two decoder outputs unused.

    Answer: 3 bits.

    Common misconception. Writing 6, the number of states, instead of the number of bits needed to encode them. A counter stores a code, not the count of states.

    CO-U2-Q04MCQmedium

    An instruction set has 12 instructions and its longest instruction needs 9 timing states. The control unit decodes the opcode with an instruction decoder and steps through the states with a sequence counter. What is the minimum width of the opcode field and of the sequence counter?

    1. 4 bits opcode and 4 bits sequence counter
    2. 3 bits opcode and 3 bits sequence counter
    3. 4 bits opcode and 3 bits sequence counter
    4. 12 bits opcode and 9 bits sequence counter
    Show answer & solution

    Answer: Option (A)

    Detailed solution

    Concept. Both fields hold a binary code, so each needs ⌈log2 n⌉ bits for n distinct values.

    Step by step.

    1. Opcode: 3 bits address only 8 instructions, so 12 instructions need 4 bits (16 codes, 4 unused).
    2. Timing states: 3 bits address only 8 states, so 9 states need 4 bits (16 states, 7 unused).
    3. Both fields are therefore 4 bits wide.

    Answer: 4-bit opcode and 4-bit sequence counter (option A).

    Common misconception. Rounding 9 states down to 3 bits because 8 feels close enough, or sizing the opcode by the number of instructions rather than by the number of codes needed to name them.

    CO-U2-Q05MSQmedium

    Which of the following statements about hardwired control are TRUE? (Select all that apply.)

    1. It is faster than microprogrammed control because the control signals come from combinational logic rather than from a control store.
    2. It is easy to extend when the instruction set changes, because a new instruction only needs new microcode.
    3. It uses a sequence counter and a decoder to generate the timing states of the instruction cycle.
    4. A single combinational network can generate every control signal, so no control store is needed.
    Show answer & solution

    Answer: Options (A), (C), (D)

    Detailed solution

    Concept. Hardwired control is a fixed Boolean network: fast, rigid, and driven by opcode, flags and timing state.

    Step by step.

    1. (A) No memory access sits on the control path, so the control signals settle in gate delays. True.
    2. (B) Adding an instruction means redesigning the logic and rewiring the network; new microcode is the microprogrammed route. False.
    3. (C) The sequence counter produces T0, T1, ... and its decoder output is ANDed into the signal equations. True.
    4. (D) That absence of a control store is exactly what defines the design. True.

    Answer: (A), (C) and (D).

    Common misconception. Believing hardwired control is also the flexible option. Speed and modifiability pull in opposite directions here, and microprogramming is the answer to the second.

    CO-U2-Q06NATmedium

    A hardwired control unit sequences 7 timing states, T0 to T6, from a 3-bit sequence counter feeding a 3-to-8 decoder. How many decoder outputs are never used?

      Show answer & solution

      Answer: 1

      Detailed solution

      Concept. A k-bit counter decodes into 2k outputs; if the machine uses fewer states than that, the surplus outputs stay idle.

      Step by step.

      1. A 3-bit counter produces 23 = 8 codes, so the decoder has 8 outputs.
      2. States T0 to T6 use 7 of them.
      3. 8 − 7 = 1 output, the code 111, is never asserted.

      Answer: 1 unused output.

      Common misconception. Counting the states as the decoder size, or assuming the spare code is harmless. An unused state must still be handled, since a glitch on the counter can land the machine there.

      CO-U2-Q07MCQhard

      An instruction needs 20 distinct timing states, and the design decodes every state directly from a binary sequence counter. What is the minimum counter width, and why is a narrower counter unsafe here?

      1. 4 bits, because states can be reused under different flag conditions
      2. 5 bits, because 4 bits decode to only 16 states while 20 distinct states are required
      3. 20 bits, one bit per state
      4. 4 bits plus a 2-to-1 multiplexer on the decoder output
      Show answer & solution

      Answer: Option (B)

      Detailed solution

      Concept. A counter of width k can name 2k distinct states. If every state must be decoded uniquely from the counter alone, the width is forced by the state count.

      Step by step.

      1. Four bits decode to 16 codes, and 16 < 20, so two states would share a code and the control signals of the two would be asserted together.
      2. Five bits decode to 32 codes, and 32 ≥ 20, so every state gets its own code and 12 codes remain spare.
      3. Hence the minimum width is 5 bits.

      Answer: 5 bits (option B).

      Common misconception. Option A describes a real but different technique: reusing a state under different flag conditions requires extra decision logic and a branch, which the question excludes by fixing the decoding to the counter alone. Without that extra logic, 4 bits silently merges states.

      CO-U2-Q26MCQeasy

      A hardwired control unit is designed from a control step matrix. What do the rows and the columns of that matrix represent?

      1. one row per instruction; one column per control signal
      2. one row per microinstruction; one column per micro-operation
      3. one row per timing state (T-state); one column per control signal
      4. one row per control signal; one column per condition flag
      Show answer & solution

      Answer: Option (C)

      Detailed solution

      Concept. The control step matrix is a two-dimensional table of the control function: one row for each timing state and one column for each control signal, with a 1 in cell (Ti, Sj) meaning that Sj is asserted while the unit is in state Ti.

      Step by step.

      1. The unit steps through one timing state per clock, so the number of rows equals the number of T-states.
      2. Each column corresponds to one control signal that the datapath needs, such as PCout or MARin.
      3. A 1 in a cell means the signal is asserted in that state; a 0 means it is not.
      4. Instructions do not form the rows: they are decoded separately into instruction lines that gate the rows.

      Final answer. one row per timing state (T-state); one column per control signal (option C)

      Common trap. Swapping the axes, as in option A, is the usual slip. Microinstructions (option D) belong to microprogrammed control, where the control word is stored rather than computed.

      CO-U2-Q27NATeasy

      A hardwired control unit sequences its 11 timing states with a one-hot ring counter that uses one flip-flop per state. How many flip-flops does the counter require?

        Show answer & solution

        Answer: 11

        Detailed solution

        Concept. A one-hot (ring) sequencer carries one flip-flop per state, so its width grows linearly with the number of states; a binary counter grows logarithmically but needs a decoder.

        Step by step.

        1. One flip-flop is needed for each state, because exactly one flip-flop is active at a time.
        2. With 11 states that is 11 flip-flops.
        3. A binary counter would need ⌈log2 11⌉ = 4 flip-flops plus a 4-to-16 decoder and 11 output gates.
        4. The one-hot form trades flip-flops for the absence of a decoder and of glitch-prone decoded lines.

        Final answer. 11

        Common trap. Answering 4 by recalling only the binary counter. The question fixes the one-hot design, where the count of flip-flops equals the count of states.

        CO-U2-Q28MCQmedium

        A control unit is implemented as a PLA with 12 inputs, 8 product terms and 10 outputs, where every input and every output has one programmable connection to every product term. How many programmable connections does the PLA contain?

        1. 80
        2. 96
        3. 176
        4. 216
        Show answer & solution

        Answer: Option (C)

        Detailed solution

        Concept. A PLA has two programmable planes: the AND plane forms the product terms from the inputs, and the OR plane sums selected product terms into each output.

        Step by step.

        1. AND plane: every one of the 12 inputs is connected (or not) to each of the 8 product-term lines, so 12 × 8 = 96 connections.
        2. OR plane: every one of the 8 product terms is connected (or not) to each of the 10 outputs, so 8 × 10 = 80 connections.
        3. Total = 96 + 80 = 176 programmable connections.

        Final answer. 176 (option C)

        Common trap. Counting only the AND plane and answering 96, or using the input count twice and answering 12 × 8 + 12 × 10 = 216. The OR plane is fed by product terms, not by inputs.

        CO-U2-Q29MSQmedium

        A hardwired control unit sequences its T-states with a counter feeding a decoder. Which of the following statements about that arrangement are TRUE? (Select all that apply.)

        1. An n-bit counter with an n-to-2n decoder can provide up to 2n timing states.
        2. If the END signal clears the counter at the end of every instruction, the next instruction restarts at T0.
        3. A one-hot ring counter produces the timing states directly and needs no decoder.
        4. A one-hot ring counter needs fewer flip-flops than a binary counter for the same number of states.
        Show answer & solution

        Answer: Options (A), (B) and (C)

        Detailed solution

        Concept. The sequencer is a counter plus a decoder, or a one-hot shift register that replaces both; either way the number of states is bounded by the hardware that generates them.

        Step by step.

        1. Option A is true: n flip-flops carry 2n codes and the decoder turns each code into one state line.
        2. Option B is true: clearing the counter on END is what makes the state sequence repeat for the next instruction.
        3. Option C is true: in a ring counter exactly one flip-flop is high at a time, and that flip-flop is the state.
        4. Option D is false: a ring counter uses one flip-flop per state, while a binary counter uses ⌈log2 n⌉, so the ring counter uses more.

        Final answer. Options (A), (B) and (C)

        Common trap. Reversing the flip-flop trade-off: the one-hot form needs more flip-flops, and buys its saving by removing the decoder and its decoded lines.

        CO-U2-Q30MCQhard

        A hardwired control unit decodes a 4-bit opcode into 16 instruction lines, but the instruction set defines only 9 instructions. The control functions are minimised treating the 7 undefined opcodes as don't-care conditions. Which statement is TRUE?

        1. The minimised functions may assert a control signal for an undefined opcode, which is harmless only because a correct program can never fetch one.
        2. Undefined opcodes must be treated as 1 so that the AND plane stays consistent.
        3. Using don't-cares cannot change the number of product terms in any control function.
        4. Leaving the 7 decoder outputs unconnected forces every control function to be 0 for those opcodes.
        Show answer & solution

        Answer: Option (A)

        Detailed solution

        Concept. A don't-care condition lets the minimiser choose either value for that input combination, so the resulting expression is free to be 1 there; the choice is only safe when the combination cannot occur.

        Step by step.

        1. Each undefined opcode is an input combination that the specification does not constrain, so the truth table entry is X.
        2. Karnaugh-map or Quine–McCluskey minimisation may then set that entry to 1 if doing so merges implicants, which yields a smaller network.
        3. The minimised function is therefore not guaranteed to be 0 for those opcodes: the hardware has no defined behaviour for them.
        4. That is acceptable precisely because a correct program never fetches an undefined opcode; a program that does reaches unspecified behaviour.
        5. Option C is false because don't-cares often, but not always, reduce the product count. Option D is false because an unconnected input does not constrain the function that the minimiser derives.

        Final answer. The minimised functions may assert a control signal for an undefined opcode (option A)

        Common trap. Reading 'don't care' as 'must be 0'. It means 'either value is acceptable', which is exactly why the minimised hardware may behave arbitrarily on that opcode.

        CO-U2-Q31MCQeasy

        The signal MARin must be asserted in timing state T0 of every instruction, and in T3 only when the instruction is a memory-reference instruction, for which the decoder produces the signal MR. Which expression implements MARin?

        1. T0 · MR + T3
        2. (T0 + T3) · MR
        3. T0 · T3 + MR
        4. T0 + T3 · MR
        Show answer & solution

        Answer: Option (D)

        Detailed solution

        Concept. Each clause of a control function is the AND of the state in which the signal is asserted with the instruction conditions under which it is asserted; the clauses are ORed.

        Step by step.

        1. The T0 clause is unconditional, so it contributes the single term T0.
        2. The T3 clause holds only for memory-reference instructions, so it contributes T3 · MR.
        3. OR the two clauses: MARin = T0 + T3 · MR.
        4. Check: in T0 the expression is 1 whatever MR is; in T3 it is 1 exactly when MR = 1.

        Final answer. T0 + T3 · MR (option D)

        Common trap. Writing T0 · MR, which drops the unconditional T0 clause, or T0 · T3, which asks for both states at once — impossible for a counter that is in one state at a time.

        Microprogrammed control 12
        CO-U2-Q08MCQeasy

        In a microprogrammed control unit, the microinstructions are held in

        1. the main memory, alongside the program being executed
        2. the control store, also called the control memory
        3. the data cache
        4. the general-purpose register file
        Show answer & solution

        Answer: Option (B)

        Detailed solution

        Concept. A microprogrammed control unit replaces the control logic with a small memory whose words are control words; each word is a microinstruction that asserts a set of control signals for one step.

        Step by step.

        1. The control store is addressed by the microprogram counter.
        2. Each location holds the control word for one micro-operation.
        3. The sequencer decides the next address, so the microprogram walks through the steps of the current instruction.
        4. Main memory and cache hold program and data, never control words.

        Answer: the control store / control memory (option B).

        Common misconception. Confusing the control store with main memory. It is a separate, usually read-only array inside the control unit, and its width is the number of control lines rather than the machine word size.

        CO-U2-Q09MCQeasy

        A microinstruction format that assigns one bit to each control line, with no encoding of mutually exclusive signals, is called

        1. a horizontal microinstruction
        2. a vertical microinstruction
        3. a diagonal microinstruction
        4. a two-level or nano microinstruction
        Show answer & solution

        Answer: Option (A)

        Detailed solution

        Concept. Horizontal and vertical microcode sit at opposite ends of the width-versus-decoding trade-off. A horizontal word is wide and fully decoded; a vertical word is narrow and encoded.

        Step by step.

        1. One bit per control line means no decoder is needed and every signal can be asserted independently.
        2. That independence lets many micro-operations run in parallel within one microinstruction, which is the horizontal advantage.
        3. The cost is a very wide control word, since the word must carry a bit for every control line.

        Answer: a horizontal microinstruction (option A).

        Common misconception. Assuming wider always means faster in a way that makes vertical code useless. Vertical code trades parallelism for a small control store and is often preferred when the store is a bottleneck.

        CO-U2-Q10NATeasy

        A control store holds 1024 microinstructions addressed by the microprogram counter. How many bits must the microprogram counter have?

          Show answer & solution

          Answer: 10

          Detailed solution

          Concept. The microprogram counter supplies the address of the next microinstruction, so its width must span every location of the control store.

          Step by step.

          1. 1024 = 210.
          2. Ten bits name 1024 distinct addresses, exactly the number of locations.
          3. No spare code remains, so every address is a legal microinstruction.

          CO-U2-Q11MCQmedium

          A microinstruction consists of 40 control bits and a 10-bit sequencing field. The control store holds 512 microinstructions. What is the total capacity of the control store in bits?

          1. 25,600 bits
          2. 20,480 bits
          3. 51,200 bits
          4. 22,528 bits
          Show answer & solution

          Answer: Option (A)

          Detailed solution

          Concept. Control-store capacity is the word width multiplied by the number of words, and the word width includes every field, not only the control bits.

          Step by step.

          1. Word width = 40 + 10 = 50 bits.
          2. Number of words = 512.
          3. Capacity = 512 × 50 = 25,600 bits.
          4. Cross-check: 512 × 40 = 20,480 control bits, and 512 × 10 = 5,120 sequencing bits; the sum is 25,600.

          CO-U2-Q12MSQmedium

          Which of the following statements about microprogrammed control are TRUE? (Select all that apply.)

          1. Vertical microprogramming encodes mutually exclusive control signals into fields that a decoder expands, giving a narrow control word at the cost of decoding delay.
          2. A horizontal microinstruction is wide and can assert many control signals in parallel within a single microinstruction.
          3. A new instruction can be added by writing new microcode, without redesigning the control logic.
          4. A microprogrammed control unit always executes an instruction faster than a hardwired unit.
          Show answer & solution

          Answer: Options (A), (B), (C)

          Detailed solution

          Concept. Microprogramming buys flexibility with time: the control word comes from a memory, and encoding it narrowly adds a decoder in series.

          Step by step.

          1. (A) Encoded fields shrink the word, and the decoder adds delay. True.
          2. (B) One bit per signal allows simultaneous assertion, which is the horizontal strength. True.
          3. (C) The instruction set is defined by the control store contents, so microcode changes are enough. True.
          4. (D) The control-store access time makes the microprogrammed unit slower per control word, not faster. False.

          Answer: (A), (B) and (C).

          Common misconception. Treating microprogramming as a pure improvement. It is a trade: flexibility and simplicity in exchange for speed and, in the horizontal case, control-store width.

          CO-U2-Q13MCQhard

          A control word has three encoded fields, each of which selects exactly one of 10 mutually exclusive control signals, plus 6 control lines that each require their own bit. What is the minimum width of the control word?

          1. 18 bits
          2. 24 bits
          3. 30 bits
          4. 36 bits
          Show answer & solution

          Answer: Option (A)

          Detailed solution

          Concept. An encoded field holding n mutually exclusive choices needs ⌈log2 n⌉ bits and a decoder to expand it; a signal that must be controlled independently needs a bit of its own.

          Step by step.

          1. Each encoded field must name one of 10 signals: ⌈log2 10⌉ = 4 bits.
          2. Three such fields take 3 × 4 = 12 bits.
          3. The 6 independent lines take 6 bits.
          4. Total = 12 + 6 = 18 bits.
          5. Cross-check the encoding capacity: each 4-bit field has 16 codes for 10 signals, so 6 codes per field are spare, which is acceptable.

          Answer: 18 bits (option A).

          Common misconception. Option C comes from adding 10 + 10 + 10 instead of encoding, i.e. from using one bit per signal and forgetting that the field is decoded. Option B comes from dropping the 6 independent lines altogether.

          CO-U2-Q32MCQeasy

          In a microinstruction format, which field supplies the address of the next microinstruction when control does not simply fall through to the next word?

          1. the control field
          2. the condition-select field
          3. the opcode field of the machine instruction
          4. the sequencing (next-address) field
          Show answer & solution

          Answer: Option (D)

          Detailed solution

          Concept. A microinstruction that can branch needs a sequencing field: a condition-select part names the flag to test, and a next-address part gives the target address.

          Step by step.

          1. The control field holds the bits that drive the datapath's control lines.
          2. The condition-select field only chooses which status flag is tested; it carries no address.

                                3. Optimal trace: on the miss for 4 the victim is 1 (never used again), and on the miss for 3 the victim is 4: misses fall to 6.
                                4. So the pair is (7, 6), and optimal is better by exactly one replacement.

                                Answer: (7, 6)

                                Common misconception. Swapping the order to (6, 7) by assuming LRU is the better policy, or answering (6, 6) by tracing optimal with LRU's victim choice.

                                Takeaway. Optimal is a bound, not an algorithm. Any online policy's miss count is at least the optimal one for the same string.

                                CO-U3-Q43MSQeasy

                                Which of the following statements about cache replacement are TRUE? Select all that apply.

                                1. LRU is a stack algorithm and therefore never exhibits Belady's anomaly.
                                2. Optimal replacement needs knowledge of future references, so it cannot be implemented online.
                                3. FIFO is a stack algorithm.
                                4. For a fixed reference string and frame count, LRU can never have fewer misses than optimal replacement.
                                Show answer & solution

                                Answer: Options (A), (B) and (D)

                                Detailed solution

                                Concept. A stack algorithm has the property that the set of blocks held with n frames is always a subset of the set held with n+1 frames, which forbids Belady's anomaly. LRU has that property because its ordering does not depend on the frame count; FIFO's does.

                                Step by step.

                                1. (A) True. LRU's victim choice depends only on the past reference order, so adding a frame can only add blocks to the resident set.
                                2. (B) True. Optimal picks the block whose next use is furthest away, which requires the future of the reference stream; it is a bound used for comparison.
                                3. (C) False. FIFO's resident set depends on the frame count, so a larger cache can hold a worse set; the classic 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5 string misses 9 times with 3 frames and 10 times with 4.
                                4. (D) True. Optimal minimises misses over all policies, so no other policy can beat it on the same string and frame count.

                                Answer: Options (A), (B) and (D)

                                Common misconception. Statement (C) is the standard error: FIFO looks like a stack algorithm because it is simple, but the anomaly on the classic string proves it is not.

                                Takeaway. Only stack algorithms are immune to Belady's anomaly. LRU and optimal are stack algorithms; FIFO and random are not.

                                CO-U3-Q48NATmedium

                                A cache with 3 frames uses LRU replacement and starts empty. For the reference string 4, 1, 2, 4, 5, 3, 4, 1, 2, 3, how many misses occur?(Enter an integer.)

                                  Show answer & solution

                                  Answer: 8

                                  Detailed solution

                                  Concept. Every first reference to a block misses, and every reference to a block that has been evicted misses again. Tracking the last-use order is what makes LRU decidable.

                                  Step by step.

                                  1. 4, 1, 2 miss and fill the cache; order of last use is 4, 1, 2.
                                  2. 4 hits and becomes most recent: order 1, 2, 4.
                                  3. 5 misses, evicting 1: order 2, 4, 5. Then 3 misses, evicting 2: order 4, 5, 3.
                                  4. 4 hits: order 5, 3, 4. Then 1 misses, evicting 5: order 3, 4, 1.
                                  5. 2 misses, evicting 3: order 4, 1, 2. Finally 3 misses, evicting 4.
                                  6. Misses = 8 (three cold misses plus five replacement misses) and hits = 3, accounting for all 11 references.

                                  Answer: 8 misses

                                  Common misconception. Answering 9 by evicting the most recently used block at one step, or 7 by forgetting that the final 3 was evicted earlier.

                                  Takeaway. Three cold misses are unavoidable with three distinct blocks; every further miss is a replacement you must justify.

                                  CO-U3-Q50NAThard

                                  A 3-frame cache starts empty. For the reference string 1, 2, 3, 4, 2, 1, 5, 6, 2, 1, 2, 3, 7, 6, 3, 2, 1, 2, 3, 6, what is the minimum number of misses that any replacement policy can achieve?(Enter an integer.)

                                    Show answer & solution

                                    Answer: 11

                                    Detailed solution

                                    Concept. The minimum is the optimal (MIN) count: on every miss, evict the resident block whose next use is furthest in the future, or one that is never used again. No policy can do better, because a miss is unavoidable whenever the requested block is absent.

                                    Step by step.

                                    1. 1, 2, 3 are cold misses: 3 misses, frames {1, 2, 3}.
                                    2. 4 misses. Next uses are 1 at position 6, 2 at position 5 and 3 at position 12, so 3 is furthest away and is evicted: 4 misses, frames {1, 2, 4}.
                                    3. 2 and 1 hit. 5 misses and evicts 4, which is never used again: 5 misses, frames {1, 2, 5}.
                                    4. 6 misses and evicts 5, also never used again: 6 misses, frames {1, 2, 6}.
                                    5. 2, 1 and 2 hit. 3 misses and evicts 1, whose next use is at position 17 against 13 for 6 and 16 for 2: 7 misses, frames {2, 6, 3}.
                                    6. 7 misses and evicts 2, whose next use is at position 16 against 14 for 6 and 15 for 3: 8 misses, frames {6, 3, 7}.
                                    7. 6 and 3 hit. 2 misses and evicts 7, never used again: 9 misses, frames {6, 3, 2}.
                                    8. 1 misses and evicts 6, whose next use is at position 20 against 18 for 2 and 19 for 3: 10 misses, frames {3, 2, 1}.
                                    9. 2 and 3 hit. The final 6 misses, and any frame may go: 11 misses.

                                    Answer: 11 misses

                                    Common misconception. Reporting the LRU count of 15, which is a property of LRU rather than a lower bound, or forgetting that the last reference to 6 is a miss because 6 was evicted at position 14.

                                    Takeaway. Optimal is a bound. Any implementable policy, including LRU and FIFO, can only do worse on the same string.

                                    CO-U3-Q14MCQeasy

                                    Which one of the following statements about write policies is correct?

                                    1. A write-back cache needs no dirty bit, because every store is sent to main memory immediately.
                                    2. A write-through cache cannot use write-allocate, because the block is already on its way to memory.
                                    3. A write-back cache sets a dirty bit on a store, so a block is written to memory only if it has been modified.
                                    4. A write-back cache sends every store to main memory and leaves the cached copy unchanged.
                                    Show answer & solution

                                    Answer: Option (C)

                                    Detailed solution

                                    Concept. The write policy decides when main memory is updated. Write-through updates memory on every store and keeps the cache clean; write-back updates memory only when a modified block is evicted, which requires one extra state bit per line, the dirty bit.

                                    Step by step.

                                    1. Option (A) describes write-through, not write-back, and its reason is backwards: write-back exists precisely so that memory is not written on every store.
                                    2. Write-through and write-allocate are independent choices; a write-through write-allocate cache is a common design.
                                    3. Write-back marks the line dirty on the first store to it and writes the block back on eviction, so an unmodified block never costs a memory write.
                                    4. Option (D) again describes write-through while keeping the cache stale, which is simply a wrong cache.

                                    Answer: Option (C).

                                    Common misconception. The frequent confusion is to think the dirty bit is an optimisation that can be dropped. Without it the cache cannot tell a clean block from a modified one and must write every evicted block back, which turns write-back into the worst of both policies.

                                    Takeaway. Dirty bit = one bit per line that licenses write-back on eviction.

                                    CO-U3-Q15MCQhard

                                    A cache uses write-back with write-allocate. A loop executes 800 one-word stores to addresses that all lie in the same 64-byte block. The block is not in the cache when the loop starts, and it is evicted exactly once, after the loop ends. How many main-memory write operations does the cache perform?

                                    1. 800
                                    2. 1
                                    3. 0
                                    4. 100
                                    Show answer & solution

                                    Answer: Option (B)

                                    Detailed solution

                                    Concept. Write-allocate fetches the block on the first write miss; write-back then absorbs all later stores in the cache and writes the block to memory once, on eviction, provided it is dirty.

                                    Step by step.

                                    1. First store: miss. Write-allocate brings the block in (one memory read) and applies the store, marking the line dirty.
                                    2. The remaining 799 stores hit the line in the cache; each updates the cached copy and leaves the dirty bit set.
                                    3. On eviction the dirty line is written back once.
                                    4. Main-memory writes = 1. (Memory reads = 1, so total block transfers = 2.)

                                    Answer: 1 write.

                                    Common misconception. 800 is the write-through answer, and it is the number to compare against: the same loop under write-through with no write-allocate would issue 800 memory writes. 0 ignores the write-back at eviction, which would leave memory stale forever.

                                    Takeaway. Write-back converts N stores to one block into 1 write-back, at the price of a dirty bit and a possible stale memory copy.

                                    CO-U3-Q19MSQhard

                                    Which of the following statements about write policies are TRUE? Select all that apply.

                                    1. With write-allocate, a store that misses first fetches the block into the cache and then applies the store.
                                    2. A write-through cache with no write-allocate issues one main-memory write for every store that misses.
                                    3. A block that is resident and clean in a write-back cache may hold data newer than main memory.
                                    4. Write-back generally reduces main-memory traffic when a workload rewrites the same block many times.
                                    Show answer & solution

                                    Answer: Options (A), (B) and (D)

                                    Detailed solution

                                    Concept. Two independent decisions make up a write policy. The update policy says when memory is written (write-through or write-back); the allocation policy says whether a write miss brings the block in (write-allocate or no-write-allocate). Write-back also needs a dirty bit to know which clean blocks may be discarded silently.

                                    Step by step.

                                    1. (A) is true: write-allocate brings the block in on a write miss, which is what makes the next store to the same block a hit.
                                    2. (B) is true: with no write-allocate the store is not cached, so it is passed straight to memory — one write per missing store.
                                    3. (C) is false: a clean block is by definition identical to memory, so it cannot be newer. Only a dirty block can differ from memory, and that is precisely what the dirty bit records.
                                    4. (D) is true: repeated stores to one block collapse into a single write-back at eviction, whereas write-through issues one write per store.

                                    Answer: Options (A), (B) and (D).

                                    Common misconception. Option (C) reverses the meaning of clean: 'clean' means the cached copy equals the memory copy, so memory is never stale for a clean block. The same sentence with 'dirty' in place of 'clean' would be true.

                                    Takeaway. Write-through/back is about when memory is written; write-allocate/no-write-allocate is about whether a write miss fetches the block.

                                    CO-U3-Q24NATmedium

                                    A write-back, write-allocate cache serves a program that performs 1000 four-byte stores, all falling in 16 distinct 64-byte blocks that are rewritten many times. None of the 16 blocks is in the cache at the start, and all 16 are evicted at the end. How many block write-backs to main memory occur?(Enter an integer.)

                                      Show answer & solution

                                      Answer: 16

                                      Detailed solution

                                      Concept. Write-back writes a block to memory when the block is evicted and only if it is dirty. Every block that received at least one store is dirty, so the number of write-backs equals the number of distinct dirty blocks that are evicted.

                                      Step by step.

                                      1. The 1000 stores touch 16 distinct blocks, so at most 16 blocks become dirty.
                                      2. Each block receives at least one store (the stores are spread over all 16), so all 16 are dirty.
                                      3. A dirty block is written back once, at eviction, no matter how many times it was modified in the cache.
                                      4. Write-backs = 16.
                                      5. For contrast, a write-through cache with no write-allocate would issue 1000 memory writes, one per store.

                                      Answer: 16 block write-backs.

                                      Common misconception. 1000 is the write-through answer. Answering 1000 / 16 = 63 assumes a write-back per store rather than per block. The whole benefit of write-back is that the write-back count depends on the number of distinct dirty blocks, not on the number of stores.

                                      Takeaway. Write-backs = number of distinct dirty blocks evicted.

                                      CO-U3-Q25NAThard

                                      A 32-bit byte-addressed machine has a 16 KB four-way set-associative write-back cache with 64-byte blocks. Each line stores its data, one tag, one valid bit and one dirty bit. How many bits of storage does the whole cache need, including data, tags, valid bits and dirty bits?(Enter an integer.)

                                        Show answer & solution

                                        Answer: 136704

                                        Detailed solution

                                        Concept. The storage of a cache is per line: the data array holds block size × 8 bits, and the tag array holds the tag width plus one valid bit and, for write-back, one dirty bit. The total is lines × bits per line.

                                        Step by step.

                                        1. Number of lines = 16 384 / 64 = 256.
                                        2. Number of sets = 256 / 4 = 64, so the index is log2 64 = 6 bits.
                                        3. Block offset = log2 64 = 6 bits.
                                        4. Tag width = 32 − 6 − 6 = 20 bits.
                                        5. Bits per line = 64 × 8 data + 20 tag + 1 valid + 1 dirty = 512 + 22 = 534.
                                        6. Total = 256 × 534 = 136 704 bits, which is 16.68 KB of storage for 16 KB of data.

                                        Answer: 136704 bits.

                                        Common misconception. 131 072 is the data alone (16 KB). Forgetting the dirty bit gives 256 × 533 = 136 448; forgetting both bits gives 136 192; computing the tag as 32 − 6 − 8 (using 256 sets as if the cache were direct-mapped) gives 18 tag bits and 256 × 532 = 136 192. The associativity is what sets the index at 6 bits, not 8.

                                        Takeaway. total bits = lines × (block size × 8 + tag + valid + dirty).

                                        CO-U3-Q38MCQeasy

                                        A write-through cache with no write-allocate serves a loop of 400 stores, each to a different word that is not in the cache. How many main-memory write operations does the loop cause?

                                        1. 0
                                        2. 100
                                        3. 400
                                        4. 800
                                        Show answer & solution

                                        Answer: Option (C)

                                        Detailed solution

                                        Concept. Write-through sends every store to memory immediately. No-write-allocate means a store that misses does not fetch the block, so a miss costs a write but no read.

                                        Step by step.

                                        1. Each of the 400 stores misses, because none of the words is resident.
                                        2. No-write-allocate suppresses the fetch, so no read is issued.
                                        3. Write-through issues one memory write per store, so there are 400 writes.
                                        4. Total memory transactions = 400 writes + 0 reads.

                                        Answer: 400 memory writes

                                        Common misconception. Answering 0 by confusing no-write-allocate with no-write-through, or 800 by charging a fill read for each miss.

                                        CO-U3-Q39MCQmedium

                                        A write-through cache with write-allocate serves 2000 stores of 4 bytes, all to 8 distinct 64-byte blocks that are not resident when the loop begins. Counting reads and writes together, how many main-memory accesses does the loop cause?

                                        1. 2000
                                        2. 8
                                        3. 16
                                        4. 2008
                                        Show answer & solution

                                        Answer: Option (D)

                                        Detailed solution

                                        Concept. Write-allocate turns the first store to a block into a read-modify-write: the block is fetched, and then every store in it writes through. The fetch happens once per block, not once per store.

                                        Step by step.

                                        1. Eight blocks are fetched, so there are 8 memory reads.
                                        2. All 2000 stores write through, so there are 2000 memory writes.
                                        3. Total accesses = 8 + 2000 = 2008.
                                        4. For contrast, write-back with write-allocate would issue 8 reads and 8 write-backs, that is 16 accesses.

                                        Answer: 2008 memory accesses

                                        Common misconception. Answering 2000 forgets the eight fills, and 16 is the write-back answer to the same workload. The policy, not the workload, decides which number applies.

                                        Takeaway. Count fills once per block and writes once per store for write-through, or once per block for write-back.

                                        CO-U3-Q40MCQhard

                                        A write-through cache has no write buffer, so every store waits 20 cycles for main memory. Stores are 12% of all instructions and every other instruction takes exactly 1 cycle. What is the effective CPI?

                                        1. 1.12
                                        2. 3.4
                                        3. 2.4
                                        4. 4.0
                                        Show answer & solution

                                        Answer: Option (B)

                                        Detailed solution

                                        Concept. Without a write buffer the processor stalls for the full memory write on every store, so the store cost enters the CPI as (fraction of stores) × (write time).

                                        Step by step.

                                        1. Stall cycles per instruction = 0.12 × 20 = 2.4.
                                        2. Base CPI for the remaining instructions = 1.0.
                                        3. Effective CPI = 1.0 + 2.4 = 3.4.
                                        4. With a four-entry write buffer the processor would continue until the buffer filled, so the stall would fall to roughly one store in twenty rather than every store.

                                        Answer: 3.4

                                        Common misconception. Answering 1.12 by adding 12% to the CPI as a fraction rather than as cycles, or 2.4 by dropping the base CPI. A store stalls the whole pipeline for 20 cycles here.

                                        Which of the following statements about write policies are TRUE? Select all that apply.

                                        1. A write-back cache may hold data that is newer than the corresponding main-memory contents.
                                        2. A write-through cache needs no dirty bit, because main memory is always up to date.
                                        3. With no write-allocate, a store that misses does not fetch the block into the cache.
                                        4. A write buffer removes every store stall, however long the loop of stores runs.
                                        Show answer & solution

                                        Answer: Options (A), (B) and (C)

                                        Detailed solution

                                        Concept. The dirty bit exists only to answer one question at replacement time: is the cached copy the newest one? Write-through never leaves a stale memory word, so the question never arises.

                                        Step by step.

                                        1. (A) True. A store to a resident line sets the dirty bit and memory keeps the old value until the line is evicted.
                                        2. (B) True. Every store has already reached memory, so eviction needs no write-back and no dirty state.
                                        3. (C) True. No-write-allocate writes around the cache, which is the usual partner of write-through because the block would not be reused soon.
                                        4. (D) False. A buffer absorbs bursts, but if stores arrive faster than memory drains it, it fills and the processor stalls again; its benefit depends on the drain rate.

                                        Answer: Options (A), (B) and (C)

                                        Common misconception. Statement (D) is the classic overstatement. A write buffer smooths bursts; it cannot exceed the memory bandwidth over a long run.

                                        Takeaway. Ask what each mechanism is for: dirty bit for eviction, allocate for reuse, buffer for burst absorption. None of them removes a bandwidth limit.

                                        CO-U3-Q45MSQhard

                                        Which of the following statements about write-back caches are TRUE? Select all that apply.

                                        1. Replacing a dirty block costs a write-back in addition to the fill that caused the replacement.
                                        2. In a write-back cache a read miss that evicts a dirty block needs two memory transactions.
                                        3. Write-back reduces memory traffic when a block is rewritten many times before it is evicted.
                                        4. For a read-only workload, write-through generates more main-memory write traffic than write-back.
                                        Show answer & solution

                                        Answer: Options (A), (B) and (C)

                                        Detailed solution

                                        Concept. A write-back cache defers memory writes until eviction, so its traffic is counted in dirty blocks rather than in stores. The price is paid on the replacement path, where a dirty victim must be written before the new block is filled.

                                        Step by step.

                                        1. (A) True. The victim's data must be saved before its frame is reused, so the replacement carries an extra write.
                                        2. (B) True. The dirty victim is written out and the requested block is read in, which is why write-back caches often need a write buffer on the eviction path.
                                        3. (C) True. Many stores to one block produce a single write-back, whereas write-through would produce one memory write per store.
                                        4. (D) False. A read-only workload never dirties a line, so write-through issues no writes either; both policies generate zero write traffic and the same read traffic.

                                        Answer: Options (A), (B) and (C)

                                        Common misconception. Statement (D) sounds like a general law but fails on the degenerate case: with no writes, there is nothing for either policy to write.

                                        Takeaway. Write-back trades write traffic for a more expensive miss path. Say which quantity is being compared before claiming one policy is better.
