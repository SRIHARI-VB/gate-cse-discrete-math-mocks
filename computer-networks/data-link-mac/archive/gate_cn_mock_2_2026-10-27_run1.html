CN-U1-Q01MCQeasy

In the OSI reference model, which layer is responsible for routing a packet from one network to another through intermediate routers?

  1. Physical layer
  2. Data link layer
  3. Network layer
  4. Transport layer
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. The OSI layers divide work by scope: the physical layer moves bits, the data link layer moves frames across a single link, the network layer moves packets across a sequence of links, and the transport layer moves data between processes.

Step by step.

  1. Routing means choosing the next hop for a packet whose source and destination lie in different networks.
  2. That decision needs a global (network-wide) address, which is exactly what the network layer provides.
  3. The data link layer only addresses the next machine on the same link; the transport layer does not see routers at all.

Answer: Option (C) — the network layer.

Common misconception. Many candidates choose the transport layer because it is the first ‘end-to-end’ layer. End-to-end delivery is transport; routing inside the network is network layer.

Takeaway. Fix the vocabulary early: routing and logical addressing → network layer; framing and MAC addressing → data link; process-to-process delivery → transport.

CN-U1-Q02MCQeasy

Which one of the following is NOT a layer of the TCP/IP reference model?

  1. Application
  2. Transport
  3. Session
  4. Internet
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. The TCP/IP reference model has four layers — application, transport, internet and network access (host-to-network).

Step by step.

  1. The application layer merges the OSI application, presentation and session functions.
  2. Transport and internet are layers in their own right.
  3. There is no separate session layer; session-style services (dialogue control, checkpointing) are either omitted or pushed into the application.

Answer: Option (C) — Session.

Common misconception. Candidates who memorise ‘seven layers’ often assume the session layer exists in every model. It is an OSI-only layer.

Takeaway. OSI = 7 layers (physical, data link, network, transport, session, presentation, application). TCP/IP = 4 (or 5 if the link layer is split into link and physical).

CN-U1-Q03MCQeasy

A switch that forwards frames by looking up 48-bit MAC addresses operates at which OSI layer?

  1. Physical layer
  2. Data link layer
  3. Network layer
  4. Transport layer
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Device class follows the header the device reads. A MAC address is a data link layer address, so a MAC-address switch is a layer-2 device.

Step by step.

  1. The switch receives a frame, reads its destination MAC address, and forwards it out of the port learned for that address.
  2. It does not modify or inspect the IP header, so it never reaches layer 3.
  3. A hub, by contrast, only repeats electrical signals and is a layer-1 device; a router reads IP addresses and is a layer-3 device.

Answer: Option (B) — the data link layer.

Common misconception. Switches are sometimes called ‘layer-3 switches’ when they also route, which makes candidates assume all switches are layer 3. Plain MAC forwarding is layer 2.

Takeaway. Hub → layer 1, switch/bridge → layer 2, router → layer 3, and a device is named after the highest header it actually processes.

CN-U1-Q04MSQmedium

Which of the following statements about layering and encapsulation are TRUE? (Select all that apply.)

  1. A router forwards a packet using the destination network-layer address and normally does not inspect the transport-layer header.
  2. The data link layer appends a trailer to the frame, while the network layer adds only a header.
  3. A hub regenerates and repeats bits, so it operates at the physical layer.
  4. A protocol converter that works at the application layer is, by definition, a layer-3 device.
Show answer & solution

Answer: Options (A), (B) and (C)

Detailed solution

Concept. Each layer adds its own control information and reads only its own header; a router is a layer-3 relay and is transparent to transport headers.

Step by step.

  1. (A) True — routing needs only the network-layer destination address; the transport header travels untouched.
  2. (B) True — a data link frame carries a trailer (the frame check sequence); the network header has no trailer.
  3. (C) True — a hub performs no frame parsing at all, so it is layer 1.
  4. (D) False — an application-layer converter works at layer 7; a ‘gateway’ in the general sense can operate at any layer.

Answer: Options (A), (B) and (C).

Common misconception. Statement (D) is the trap: the word ‘gateway’ is sometimes used for a router (layer 3), but an application-level converter is a layer-7 device. The definition in (D) is simply wrong.

Takeaway. Ask of any claim ‘which header does this entity have to read?’ — the answer fixes its layer.

Which of the following statements comparing the OSI and TCP/IP reference models are TRUE? (Select all that apply.)

  1. The TCP/IP application layer performs the functions that OSI splits across its session, presentation and application layers.
  2. The TCP/IP internet layer corresponds to the OSI network layer.

Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. OSI is a protocol-independent architecture written first; TCP/IP is a description of an already-working protocol suite.

Step by step.

  1. (A) True — presentation (encoding, compression, encryption) and session services are handled inside application protocols in TCP/IP.
  2. (B) True — the internet layer provides logical addressing and routing, exactly the OSI network layer's job.

CN-U1-Q06NATeasy

An application message of 600 bytes is passed down the stack. The transport layer adds a 20-byte header, the network layer adds a 20-byte header, and the data link layer adds a 14-byte header and a 4-byte trailer.
What is the total size, in bytes, of the frame handed to the physical layer?

Show answer & solution

Answer: 658

Detailed solution

Concept. Encapsulation adds one header at each layer (and a trailer at the data link layer), so the sizes simply add.

Step by step.

  1. Application data: 600 bytes.
  2. Transport segment: 600 + 20 = 620 bytes.
  3. Network datagram: 620 + 20 = 640 bytes.
  4. Data link frame: 640 + 14 + 4 = 658 bytes.

Answer: 658 bytes.

Common misconception. The common slip is to forget the 4-byte trailer, or to add the transport header twice because the segment is later called a payload. Overhead here is 58 bytes in total.

Takeaway. Layer overhead is cumulative: every header added below is carried by everything above it.

CN-U1-Q07MCQhard

A frame travels from a source host to a destination host through two routers. Which statement about error checking on this path is correct?

  1. Both the frame check sequence and the TCP checksum are verified only at the destination host.
  2. The frame check sequence is verified by every device that receives the frame, including each router; the TCP checksum is verified only at the destination host.
  3. The frame check sequence is verified only at the destination host; the TCP checksum is verified at every router.
  4. Both the frame check sequence and the TCP checksum are verified at every router along the path.
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Error detection is layered, and each layer's check has the scope of that layer: a data link check covers one hop, a transport check covers the whole end-to-end path.

Step by step.

  1. When a router receives a frame it recomputes the frame check sequence over the received bits; a bad frame is discarded on that hop.
  2. The router then strips the data link header and trailer, so the next hop gets a brand-new frame with a newly computed check sequence.
  3. The TCP header and its checksum travel end to end untouched, so only the destination transport layer can verify them — a router never even looks at them.

Answer: Option (B).

Common misconception. The tempting error is (D): students reason that ‘every device checks for errors’. A router cannot verify a TCP checksum without reassembling the transport segment, which it does not do.

Takeaway. Per-hop check ⇒ data link; end-to-end check ⇒ transport. This is the cleanest illustration of why both layers exist.

CN-U1-Q26MCQeasy

Which OSI layer is responsible for data compression and for converting between different data representations such as ASCII and EBCDIC?

  1. Session layer
  2. Application layer
  3. Data link layer
  4. Presentation layer
Show answer & solution

Answer: Option (D)

Detailed solution

Concept. The OSI model separates user-facing work from syntax work. The application layer offers the service the user asks for, the presentation layer fixes the form of the data (compression, encryption, character-set conversion), and the session layer manages the dialogue between two applications.

Step by step.

  1. Compression removes redundancy from a representation; it changes how the data is encoded, not what service is requested.
  2. Code conversion between ASCII and EBCDIC is the same kind of job: it rewrites the syntax of the data.
  3. Both are exactly the functions the presentation layer owns.
  4. The session layer manages dialogue control (checkpoints, synchronisation) and the application layer handles the user service itself.

Answer: Option (D) — the presentation layer.

Common misconception. Encryption and compression are often attributed to the application layer because an application often requests them. In the OSI reference model they belong to presentation, which is exactly the layer the TCP/IP model does not have.

Takeaway. Ask what is being changed: the service (application), the form of the data (presentation), or the dialogue (session).

CN-U1-Q27MCQeasy

The protocol data units (PDUs) of the transport, network and data link layers are, in that order, called:

  1. frame, packet, segment
  2. segment, datagram, frame
  3. datagram, segment, frame
  4. segment, frame, datagram
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Each layer names the unit it hands down: the transport layer produces a segment, the network layer a datagram (packet), and the data link layer a frame; the physical layer moves raw bits.

Step by step.

  1. The transport layer takes the byte stream and adds its header, producing a segment.
  2. The network layer wraps the segment in an IP header, producing a packet or datagram.
  3. The data link layer wraps the datagram with a header and a trailer, producing a frame.
  4. So the order transport → network → data link gives segment → datagram → frame.

Answer: Option (B) — segment, datagram, frame.

Common misconception. The pairs are easy to rotate. The trap is placing the frame before the packet; a frame is the outermost encapsulation, so it is produced last on the way down and removed first on the way up.

Takeaway. Anchor the order by encapsulation depth: segment inside datagram inside frame.

CN-U1-Q28MCQmedium

Flow control and error control appear at more than one layer. Which statement is correct?

  1. The data link layer controls flow and errors between two adjacent nodes on one link, while the transport layer controls them between the two end processes.
  2. Only the transport layer performs flow control; the data link layer has none.
  3. The network layer performs end-to-end flow control between processes.
  4. Flow control in the data link layer protects against errors introduced inside routers.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. OSI draws a scope line: the data link layer works link by link between adjacent nodes, the transport layer works end to end between processes. Both perform flow and error control, but over different spans.

Step by step.

  1. A frame exists only on one link, so its acknowledgement and window can only concern that link — that is link-by-link control.
  2. A segment survives every hop, so its window and acknowledgement concern the two end processes — that is end-to-end control.
  3. The network layer forwards packets; it does not run a window between processes.
  4. Errors introduced inside a router are exactly what the end-to-end transport checksum is there to catch, not the link-layer window.

Answer: Option (A).

Common misconception. Candidates read ‘flow control’ as a single function belonging to one layer. It is a family of mechanisms, and the same name at two layers means two different scopes.

Takeaway. Name the scope before naming the layer: adjacent nodes → data link, end processes → transport.

CN-U1-Q29MSQmedium

A router forwards an IPv4 packet that arrives on one Ethernet and leaves on another. Ignoring NAT, which of the following are TRUE? (Select all that apply.)

  1. The source and destination MAC addresses of the outgoing frame differ from those of the incoming frame.
  2. The source and destination IPv4 addresses in the packet are unchanged.
  3. The TTL field is decremented by one.
  4. The transport-layer checksum must be recomputed by the router because the frame addresses changed.
Show answer & solution

Answer: Options (A), (B) and (C)

Detailed solution

Concept. A router terminates the link layer on each interface and forwards at the network layer, so link-layer addresses are local to a link while network-layer addresses are end to end.

Step by step.

  1. MAC addresses identify a network card on one link. The outgoing frame is built for the next hop, so both MAC addresses are rewritten.
  2. The IPv4 addresses name the end hosts and are carried unchanged through every router (NAT aside).
  3. The TTL is decremented at each router so that packets cannot loop forever.
  4. The transport checksum covers a pseudo-header of IP addresses and the transport payload; neither changes here, so the router does not recompute it.

Answer: Options (A), (B) and (C).

Common misconception. ‘The router changes the addresses, so it must fix the checksum’ conflates the two address spaces. Only the MAC addresses change, and no transport checksum covers them.

Takeaway. Per hop: MAC addresses and TTL change. End to end: IP addresses and the transport checksum survive.

CN-U1-Q30NATeasy

A router forwards IPv4 packets between its attached links. It implements the physical and data link layers on each link and the network layer for forwarding; it runs no transport-layer or application-layer protocol of its own.
How many of the seven OSI layers does this router implement?

Show answer & solution

Answer: 3

Detailed solution

Concept. The number of OSI layers a device implements is the number of distinct layers whose functions it actually performs, not the number of headers it happens to read.

Step by step.

  1. Physical layer: it drives the line and moves bits on each interface.
  2. Data link layer: it frames and unframes, checks the frame check sequence and addresses the next hop.
  3. Network layer: it runs the routing table and forwards the packet.
  4. It runs no transport or application protocol, and OSI session and presentation functions are absent entirely, so the count stops at three.

Takeaway. Count the layers whose functions the device performs, and stop where its processing stops.

CN-U1-Q31MCQhard

Every link uses a frame check sequence that each router verifies and recomputes. Why does TCP nevertheless carry its own checksum?

  1. Because a frame check sequence cannot detect burst errors.
  2. Because a packet can be corrupted inside a router, after its incoming frame check sequence has been verified, and the outgoing link will then protect the corrupted packet with a fresh, valid frame check sequence.
  3. Because the frame check sequence covers only the frame header.
  4. Because routers strip the frame check sequence before forwarding the frame.
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. A hop-by-hop check protects a hop; it cannot protect the path. The end-to-end argument places a correctness check at the endpoints precisely because intermediate systems can introduce errors of their own.

Step by step.

  1. The incoming frame check sequence is verified when the frame arrives, so it says nothing about anything that happens afterwards.
  2. Inside a router the packet is held in memory, moved across a switching fabric and rewritten; any of these can corrupt it.
  3. The outgoing frame gets a newly computed check sequence over the corrupted bits, which therefore validates perfectly at the next hop.
  4. Only a check computed at the source and verified at the destination spans the whole path, which is what the TCP checksum provides.

Answer: Option (B).

Common misconception. The tempting answer is that the link check is somehow weak. It is strong; it is simply local. A correct hop check on a packet corrupted inside a router is a false reassurance, and that gap is exactly what the transport checksum closes.

Takeaway. A check protects the span over which it is computed and verified; hop-by-hop protection leaves the router itself uncovered.

CN-U1-Q08MCQeasy

A 1500-byte packet is placed on a 1 Mbps link. Ignoring propagation, processing and queueing delay, what is the transmission delay?

  1. 1.2 ms
  2. 12 ms
  3. 120 ms
  4. 0.12 ms
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Transmission delay is the time to push all the bits of the packet onto the link: L / R, with L in bits and R in bits per second.

Step by step.

  1. L = 1500 bytes = 1500 × 8 = 12000 bits.
  2. R = 1 Mbps = 10⁶ bits per second.
  3. L / R = 12000 / 10⁶ = 0.012 s = 12 ms.

Answer: Option (B) — 12 ms.

Common misconception. Forgetting the factor of 8 (bytes to bits) gives 1.5 ms or 1.2 ms, which is why those distractors are present.

Takeaway. Always convert to bits before dividing by a bit rate: delay = 8 × size_in_bytes / bandwidth.

CN-U1-Q09MCQeasy

Two links have the same length and the same propagation speed, but link 1 has twice the bandwidth of link 2. For the same packet, which of the following is TRUE?

  1. The propagation delay is the same on both links, and the transmission delay is smaller on link 1.
  2. Both delays are smaller on link 1.
  3. The transmission delay is the same on both links, and the propagation delay is smaller on link 1.
  4. Both delays are the same on both links.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Transmission delay depends on the link's bandwidth; propagation delay depends only on distance and signal speed.

Step by step.

  1. Propagation delay = distance / propagation speed, and both are identical, so the two links have equal propagation delay.
  2. Transmission delay = L / R; R is doubled on link 1, so its transmission delay is halved.
  3. Therefore only the transmission delay changes.

Answer: Option (A).

Common misconception. The frequent error is (B): assuming a ‘faster link’ shortens everything. Bandwidth cannot make a signal travel faster than the propagation speed of the medium.

Takeaway. Bandwidth governs how long the packet takes to enter the wire; distance governs how long it takes to cross it.

CN-U1-Q10NATmedium

A link has a bandwidth of 100 Mbps and a one-way propagation delay of 20 ms.
What is the bandwidth-delay product of the link, in kilobytes? Use 1 kB = 1000 bytes and enter a number.

Show answer & solution

Answer: 250

Detailed solution

Concept. Bandwidth-delay product = bandwidth × propagation delay. It is the number of bits that can be in flight on the link at one instant.

Step by step.

  1. R = 100 Mbps = 10⁸ bits/s; delay = 20 ms = 0.02 s.
  2. BDP = 10⁸ × 0.02 = 2 × 10⁶ bits.
  3. In bytes: 2 × 10⁶ / 8 = 250000 bytes.
  4. In kB (1000 bytes): 250000 / 1000 = 250 kB.

Answer: 250 kB.

Common misconception. Two errors dominate: dividing by 1024 instead of 1000, and using bits per byte wrongly, giving 244 or 2000. The question fixes 1 kB = 1000 bytes to remove the first ambiguity.

Takeaway. BDP answers ‘how much data must be outstanding to keep the pipe full?’ — the basis of the TCP window sizing question.

CN-U1-Q12MSQhard

Which of the following statements about delay, bandwidth and the bandwidth-delay product are TRUE? (Select all that apply.)

  1. The bandwidth-delay product of a link equals the maximum number of bits that can be in transit on that link at any instant.
  2. Doubling the propagation delay and halving the bandwidth leaves the bandwidth-delay product unchanged.
  3. The transmission delay of a packet depends on the distance between the two end hosts.
  4. The throughput of a path is limited by the slowest link on it, while the end-to-end delay is the sum of the per-link delays.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. BDP = R × Tprop is the ‘amount of pipe’; transmission delay is L / R; throughput of a path is set by the bottleneck link.

Step by step.

  1. (A) True — that is the definition: the bits that fit inside the link while the first bit is still travelling.
  2. (B) True — (R/2) × (2T) = R × T.
  3. (C) False — transmission delay is L / R and contains no distance term; it is the propagation delay that depends on distance.
  4. (D) True — for a single flow the sustained rate cannot exceed the minimum link rate, and the delays add up hop by hop.

Answer: Options (A), (B) and (D).

Common misconception. Statement (C) is the standard confusion between the two delays. A satellite link of huge length but high bandwidth still has a tiny transmission delay and a large propagation delay.

Takeaway. Transmission delay: packet size vs bandwidth. Propagation delay: distance vs signal speed. Never mix them.

Common misconception. Dropping the end-around carry gives 0xFC95, and forgetting the complement gives 0x0369; both are offered as options. Note that 0xFC96 is not the arithmetic negation in two's complement either.

Takeaway. Checksum routine: sum with wraparound, fold the carry in, then complement. Verify by adding the checksum back — the total must be 0xFFFF.

CN-U1-Q25NATmedium

A CRC is computed with the generator polynomial x³ + 1, whose bit pattern is 1001. The message bits are 1101 and three zeros are appended before division.
Enter the decimal value of the resulting 3-bit remainder.

Show answer & solution

Answer: 4

Detailed solution

Concept. CRC division is long division over GF(2): align the divisor under the leading 1 of the current remainder and XOR, with no borrows or carries.

Step by step.

  1. Append three zeros: 1101000.
  2. Leading 4 bits 1101 ⊕ 1001 = 0100; bring down 0 → 1000; 1000 ⊕ 1001 = 0001.
  3. Bring down the next 0 → 0010; the leading bit is 0, so XOR nothing. Bring down the last 0 → 0100; again nothing.
  4. The 3-bit remainder is 100, i.e. 4 in decimal.

Answer: 4 (remainder 100).

Common misconception. The trap is ordinary binary subtraction with borrows. In GF(2) there is no borrow: XOR is the only operation, so a step where the leading bit is 0 just shifts down the next bit.

Takeaway. For a degree-r generator the remainder is always r bits; read it as a plain binary number if the answer must be decimal.

CN-U1-Q44MCQeasy

Which of the following schemes can correct a single-bit error?

  1. A single parity bit per block
  2. A block code with minimum Hamming distance 2
  3. A Hamming code with minimum distance 3
  4. A 16-bit Internet checksum
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. Correction needs the received word to be nearer one codeword than any other, which requires minimum distance at least 3; distance 2 only guarantees detection.

Step by step.

  1. A code with minimum distance d corrects ⌊(d − 1)/2⌋ errors.
  2. A single parity bit gives d = 2, so it corrects 0 errors.
  3. A code with d = 2 also corrects 0 errors — it detects single errors only.
  4. A checksum is an arithmetic check with no distance guarantee, so it cannot locate an error at all.
  5. A Hamming code with d = 3 corrects ⌊2/2⌋ = 1 error.

Answer: Option (C) — a Hamming code with minimum distance 3.

Common misconception. Expecting a parity bit to point at the bad bit. Parity tells you that something is wrong; locating it needs several overlapping parity groups, which is exactly what a Hamming code builds.

Takeaway. Detect needs d ≥ e + 1; correct needs d ≥ 2t + 1.

CN-U1-Q45MCQeasy

A single parity bit is appended to a block of data. Which error pattern is guaranteed to be detected?

  1. Any single-bit error
  2. Any two-bit error
  3. Any odd number of bit errors
  4. Any burst of three consecutive bit errors
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. A single parity bit records the parity of the block, so it detects exactly those error patterns that change the parity, that is, patterns of odd weight.

Step by step.

  1. The parity bit is chosen so that the total number of 1s has a fixed parity.
  2. Flipping one bit changes that parity, so any single-bit error is detected — but that is a special case, not the general guarantee.
  3. Flipping two bits leaves the parity unchanged, so a two-bit error is undetected.
  4. Flipping any odd number of bits changes the parity, so every odd-weight pattern is detected.
  5. A burst of three flips the parity too, but a burst of two does not, so the burst statement is not a guarantee.

Answer: Option (C) — any odd number of bit errors.

Common misconception. Believing parity detects all single-bit errors and therefore all small errors. Parity is blind to every even-weight pattern, including the very common two-bit error.

Takeaway. Single parity detects odd weight, nothing else.

CN-U1-Q46NATmedium

A CRC uses the generator polynomial x3 + x + 1, whose bit pattern is 1011. The message bits are 1100 and three zeros are appended before division.
Enter the decimal value of the resulting 3-bit remainder.

Show answer & solution

Answer: 2

Detailed solution

Concept. CRC is polynomial division over GF(2): subtraction is XOR, the message is shifted left by the degree of the generator, and the remainder is the check bits.

Step by step.

  1. Degree of the generator is 3, so append three zeros: 1100000.
  2. XOR 1100000 with 1011 aligned at the left: 1100 ⊕ 1011 = 0111, giving 0111000.
  3. Bring the leading 1 into position and XOR again: 1110 ⊕ 1011 = 0101, leaving 010100.
  4. Once more: 1010 ⊕ 1011 = 0001, leaving 00010.
  5. No further leading 1 remains, so the 3-bit remainder is 010 = 2 in decimal.

Answer: 2 (remainder 010).

Common misconception. Subtracting in ordinary integer arithmetic. Over GF(2) there is no borrow: 1100 ⊕ 1011 = 0111, not 0001. The other slip is appending two zeros instead of three, which silently changes the remainder.

Takeaway. Append as many zeros as the generator's degree, then XOR-shift; never subtract.

CN-U1-Q47MCQmedium

A CRC generator polynomial has degree r. Which class of burst errors is it guaranteed to detect?

  1. Every burst error of length at most r
  2. Every burst error of length at most r + 1
  3. Every burst error of length exactly r + 1
  4. Every burst error, whatever its length
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A degree-r generator has a non-zero constant term, so any error polynomial of degree below r cannot be a multiple of it; that is the burst guarantee.

Step by step.

  1. A burst of length k is an error polynomial of the form xi(1 + … + xk−1).
  2. The generator G(x) of degree r divides such a polynomial only if it divides the bracket, which has degree k − 1.
  3. When k ≤ r the bracket has degree below r, so it cannot be a non-zero multiple of G(x) and the error is always detected.
  4. Bursts longer than r can slip through, so the guarantee stops exactly at r.

Answer: Option (A) — every burst of length at most r.

Common misconception. Extending the guarantee to r + 1 or claiming CRC detects everything. A CRC detects all single-bit errors, all odd numbers of errors when G has (x + 1) as a factor, and all bursts up to length r — and nothing more in general.

Takeaway. Degree r buys burst protection up to length r, full stop.

CN-U1-Q48MSQmedium

Which of the following statements about error-detecting and error-correcting codes are TRUE? (Select all that apply.)

  1. The Internet checksum adds the 16-bit words using two's complement arithmetic.
  2. A code with minimum Hamming distance d detects any pattern of at most d − 1 bit errors.
  3. A code with minimum Hamming distance d corrects any pattern of at most ⌊(d − 1)/2⌋ bit errors.
  4. Adding one parity bit to a block raises the minimum distance of the code from 1 to 2.
Show answer & solution

Answer: Options (B), (C) and (D)

Detailed solution

Concept. Minimum distance fixes both guarantees: detection up to d − 1, correction up to ⌊(d − 1)/2⌋. The Internet checksum is one's complement, not two's complement.

Step by step.

  1. Two codewords at distance d cannot be joined by an error of weight below d, so any such error lands off the code: (B) is true.
  2. Correcting t errors needs disjoint balls of radius t, which requires d ≥ 2t + 1, hence t = ⌊(d − 1)/2⌋: (C) is true.
  3. Without a parity bit any word is a codeword, so d = 1; one parity bit makes every pair differ in at least two places: (D) is true.
  4. The Internet checksum uses one's complement arithmetic with end-around carry: (A) is false.

Answer: Options (B), (C) and (D).

Common misconception. Option (A) is a favourite trap because two's complement is the arithmetic most programmers reach for. The Internet checksum predates that habit: it is one's complement, which is why the end-around carry exists and why there are two representations of zero.

Takeaway. Distance drives the guarantees; the Internet checksum is one's complement with end-around carry.

CN-U1-Q49MCQhard

A block code has minimum Hamming distance 6. Which of the following states the largest guaranteed detection and correction capability?

  1. Detect up to 5 bit errors, correct up to 2
  2. Detect up to 5 bit errors, correct up to 3
  3. Detect up to 6 bit errors, correct up to 2
  4. Detect up to 6 bit errors, correct up to 3
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Detection is guaranteed up to d − 1 and correction up to ⌊(d − 1)/2⌋; with d = 6 these are 5 and 2.

Step by step.

  1. d − 1 = 5, so every pattern of weight at most 5 is detected.
  2. ⌊(6 − 1)/2⌋ = ⌊2.5⌋ = 2, so up to 2 errors can be corrected.
  3. Correcting 3 errors would need d ≥ 2 × 3 + 1 = 7, which this code does not have.
  4. Detecting 6 errors would need d ≥ 7, and a weight-6 error can land exactly on another codeword at distance 6.

Answer: Option (A) — detect 5, correct 2.

Common misconception. Rounding (d − 1)/2 up, or assuming detection and correction capacities can both be pushed to the maximum at once. The two guarantees are separate budgets taken from the same distance.

Takeaway. With d = 6: detect 5, correct 2 — the floor, never the ceiling.

CN-U1-Q50NAThard

A single-error-correcting Hamming code uses r = 6 parity bits.
What is the largest number of data bits it can protect?

Show answer & solution

Answer: 57

Detailed solution

Concept. With r parity bits the syndrome has 2r values: one for ‘no error’ and one for each of the m + r single-bit positions. Hence m + r + 1 ≤ 2r.

Step by step.

  1. Write the Hamming condition: m + r + 1 ≤ 2r.
  2. Substitute r = 6: 26 = 64, so m + 6 + 1 ≤ 64.
  3. Therefore m ≤ 64 − 7 = 57.
  4. With m = 57 the code has 57 + 6 = 63 bit positions, and the 64th syndrome value is reserved for ‘no error’.

Answer: 57 data bits.

Common misconception. Using 2r ≥ m + r and answering 58, which forgets the all-zero syndrome that must mean ‘no error’. The +1 in the inequality is that reserved pattern.

Takeaway. A single-error-correcting Hamming code spends one syndrome value on ‘no error’: m ≤ 2r − r − 1.
