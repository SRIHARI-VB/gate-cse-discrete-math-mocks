CN-U1-Q01MCQeasy

In the OSI reference model, which layer is responsible for routing a packet from one network to another through intermediate routers?

  1. Physical layer
  2. Data link layer
  3. Network layer
  4. Transport layer
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. The OSI layers divide work by scope: the physical layer moves bits, the data link layer moves frames across a single link, the network layer moves packets across a sequence of links, and the transport layer moves data between processes.

Step by step.

  1. Routing means choosing the next hop for a packet whose source and destination lie in different networks.
  2. That decision needs a global (network-wide) address, which is exactly what the network layer provides.
  3. The data link layer only addresses the next machine on the same link; the transport layer does not see routers at all.

Answer: Option (C) — the network layer.

Common misconception. Many candidates choose the transport layer because it is the first ‘end-to-end’ layer. End-to-end delivery is transport; routing inside the network is network layer.

Takeaway. Fix the vocabulary early: routing and logical addressing → network layer; framing and MAC addressing → data link; process-to-process delivery → transport.

CN-U1-Q02MCQeasy

Which one of the following is NOT a layer of the TCP/IP reference model?

  1. Application
  2. Transport
  3. Session
  4. Internet
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. The TCP/IP reference model has four layers — application, transport, internet and network access (host-to-network).

Step by step.

  1. The application layer merges the OSI application, presentation and session functions.
  2. Transport and internet are layers in their own right.
  3. There is no separate session layer; session-style services (dialogue control, checkpointing) are either omitted or pushed into the application.

Answer: Option (C) — Session.

Common misconception. Candidates who memorise ‘seven layers’ often assume the session layer exists in every model. It is an OSI-only layer.

Takeaway. OSI = 7 layers (physical, data link, network, transport, session, presentation, application). TCP/IP = 4 (or 5 if the link layer is split into link and physical).

CN-U1-Q03MCQeasy

A switch that forwards frames by looking up 48-bit MAC addresses operates at which OSI layer?

  1. Physical layer
  2. Data link layer
  3. Network layer
  4. Transport layer
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Device class follows the header the device reads. A MAC address is a data link layer address, so a MAC-address switch is a layer-2 device.

Step by step.

  1. The switch receives a frame, reads its destination MAC address, and forwards it out of the port learned for that address.
  2. It does not modify or inspect the IP header, so it never reaches layer 3.
  3. A hub, by contrast, only repeats electrical signals and is a layer-1 device; a router reads IP addresses and is a layer-3 device.

Answer: Option (B) — the data link layer.

Common misconception. Switches are sometimes called ‘layer-3 switches’ when they also route, which makes candidates assume all switches are layer 3. Plain MAC forwarding is layer 2.

Takeaway. Hub → layer 1, switch/bridge → layer 2, router → layer 3, and a device is named after the highest header it actually processes.

CN-U1-Q04MSQmedium

Which of the following statements about layering and encapsulation are TRUE? (Select all that apply.)

  1. A router forwards a packet using the destination network-layer address and normally does not inspect the transport-layer header.
  2. The data link layer appends a trailer to the frame, while the network layer adds only a header.
  3. A hub regenerates and repeats bits, so it operates at the physical layer.
  4. A protocol converter that works at the application layer is, by definition, a layer-3 device.
Show answer & solution

Answer: Options (A), (B) and (C)

Detailed solution

Concept. Each layer adds its own control information and reads only its own header; a router is a layer-3 relay and is transparent to transport headers.

Step by step.

  1. (A) True — routing needs only the network-layer destination address; the transport header travels untouched.
  2. (B) True — a data link frame carries a trailer (the frame check sequence); the network header has no trailer.
  3. (C) True — a hub performs no frame parsing at all, so it is layer 1.
  4. (D) False — an application-layer converter works at layer 7; a ‘gateway’ in the general sense can operate at any layer.

Answer: Options (A), (B) and (C).

Common misconception. Statement (D) is the trap: the word ‘gateway’ is sometimes used for a router (layer 3), but an application-level converter is a layer-7 device. The definition in (D) is simply wrong.

Takeaway. Ask of any claim ‘which header does this entity have to read?’ — the answer fixes its layer.

CN-U1-Q05MSQmedium

Which of the following statements comparing the OSI and TCP/IP reference models are TRUE? (Select all that apply.)

  1. The TCP/IP application layer performs the functions that OSI splits across its session, presentation and application layers.
  2. The TCP/IP internet layer corresponds to the OSI network layer.
  3. The TCP/IP reference model has seven layers.
  4. The OSI model was designed before the protocols that implement it existed, whereas the TCP/IP model was written up after its protocols were already in use.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. OSI is a protocol-independent architecture written first; TCP/IP is a description of an already-working protocol suite.

Step by step.

  1. (A) True — presentation (encoding, compression, encryption) and session services are handled inside application protocols in TCP/IP.
  2. (B) True — the internet layer provides logical addressing and routing, exactly the OSI network layer's job.
  3. (C) False — TCP/IP has four layers (five if the link layer is split).
  4. (D) True — the classic historical distinction: OSI came from a model, TCP/IP came from running code.

Answer: Options (A), (B) and (D).

Common misconception. Statement (C) is the usual error, produced by carrying the OSI count over to TCP/IP. Also note (D) is a genuine, examinable distinction, not trivia.

Takeaway. Two facts to keep: TCP/IP = 4 layers and no session/presentation layer; OSI = 7 layers and model-first.

CN-U1-Q06NATeasy

An application message of 600 bytes is passed down the stack. The transport layer adds a 20-byte header, the network layer adds a 20-byte header, and the data link layer adds a 14-byte header and a 4-byte trailer. What is the total size, in bytes, of the frame handed to the physical layer?

Show answer & solution

Answer: 658

Detailed solution

Concept. Encapsulation adds one header at each layer (and a trailer at the data link layer), so the sizes simply add.

Step by step.

  1. Application data: 600 bytes.
  2. Transport segment: 600 + 20 = 620 bytes.
  3. Network datagram: 620 + 20 = 640 bytes.
  4. Data link frame: 640 + 14 + 4 = 658 bytes.

Answer: 658 bytes.

Common misconception. The common slip is to forget the 4-byte trailer, or to add the transport header twice because the segment is later called a payload. Overhead here is 58 bytes in total.

Takeaway. Layer overhead is cumulative: every header added below is carried by everything above it.

CN-U1-Q07MCQhard

A frame travels from a source host to a destination host through two routers. Which statement about error checking on this path is correct?

  1. Both the frame check sequence and the TCP checksum are verified only at the destination host.
  2. The frame check sequence is verified by every device that receives the frame, including each router; the TCP checksum is verified only at the destination host.
  3. The frame check sequence is verified only at the destination host; the TCP checksum is verified at every router.
  4. Both the frame check sequence and the TCP checksum are verified at every router along the path.
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Error detection is layered, and each layer's check has the scope of that layer: a data link check covers one hop, a transport check covers the whole end-to-end path.

Step by step.

  1. When a router receives a frame it recomputes the frame check sequence over the received bits; a bad frame is discarded on that hop.
  2. The router then strips the data link header and trailer, so the next hop gets a brand-new frame with a newly computed check sequence.
  3. The TCP header and its checksum travel end to end untouched, so only the destination transport layer can verify them — a router never even looks at them.

Answer: Option (B).

Common misconception. The tempting error is (D): students reason that ‘every device checks for errors’. A router cannot verify a TCP checksum without reassembling the transport segment, which it does not do.

Takeaway. Per-hop check ⇒ data link; end-to-end check ⇒ transport. This is the cleanest illustration of why both layers exist.

CN-U1-Q26MCQeasy

Which OSI layer is responsible for data compression and for converting between different data representations such as ASCII and EBCDIC?

  1. Session layer
  2. Application layer
  3. Data link layer
  4. Presentation layer
Show answer & solution

Answer: Option (D)

Detailed solution

Concept. The OSI model separates user-facing work from syntax work. The application layer offers the service the user asks for, the presentation layer fixes the form of the data (compression, encryption, character-set conversion), and the session layer manages the dialogue between two applications.

Step by step.

  1. Compression removes redundancy from a representation; it changes how the data is encoded, not what service is requested.
  2. Code conversion between ASCII and EBCDIC is the same kind of job: it rewrites the syntax of the data.
  3. Both are exactly the functions the presentation layer owns.
  4. The session layer manages dialogue control (checkpoints, synchronisation) and the application layer handles the user service itself.

Answer: Option (D) — the presentation layer.

Common misconception. Encryption and compression are often attributed to the application layer because an application often requests them. In the OSI reference model they belong to presentation, which is exactly the layer the TCP/IP model does not have.

Takeaway. Ask what is being changed: the service (application), the form of the data (presentation), or the dialogue (session).

CN-U1-Q27MCQeasy

The protocol data units (PDUs) of the transport, network and data link layers are, in that order, called:

  1. frame, packet, segment
  2. segment, datagram, frame
  3. datagram, segment, frame
  4. segment, frame, datagram
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Each layer names the unit it hands down: the transport layer produces a segment, the network layer a datagram (packet), and the data link layer a frame; the physical layer moves raw bits.

Step by step.

  1. The transport layer takes the byte stream and adds its header, producing a segment.
  2. The network layer wraps the segment in an IP header, producing a packet or datagram.
  3. The data link layer wraps the datagram with a header and a trailer, producing a frame.
  4. So the order transport → network → data link gives segment → datagram → frame.

Answer: Option (B) — segment, datagram, frame.

Common misconception. The pairs are easy to rotate. The trap is placing the frame before the packet; a frame is the outermost encapsulation, so it is produced last on the way down and removed first on the way up.

Takeaway. Anchor the order by encapsulation depth: segment inside datagram inside frame.

CN-U1-Q28MCQmedium

Flow control and error control appear at more than one layer. Which statement is correct?

  1. The data link layer controls flow and errors between two adjacent nodes on one link, while the transport layer controls them between the two end processes.
  2. Only the transport layer performs flow control; the data link layer has none.
  3. The network layer performs end-to-end flow control between processes.
  4. Flow control in the data link layer protects against errors introduced inside routers.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. OSI draws a scope line: the data link layer works link by link between adjacent nodes, the transport layer works end to end between processes. Both perform flow and error control, but over different spans.

Step by step.

  1. A frame exists only on one link, so its acknowledgement and window can only concern that link — that is link-by-link control.
  2. A segment survives every hop, so its window and acknowledgement concern the two end processes — that is end-to-end control.
  3. The network layer forwards packets; it does not run a window between processes.
  4. Errors introduced inside a router are exactly what the end-to-end transport checksum is there to catch, not the link-layer window.

Answer: Option (A).

Common misconception. Candidates read ‘flow control’ as a single function belonging to one layer. It is a family of mechanisms, and the same name at two layers means two different scopes.

Takeaway. Name the scope before naming the layer: adjacent nodes → data link, end processes → transport.

CN-U1-Q29MSQmedium

A router forwards an IPv4 packet that arrives on one Ethernet and leaves on another. Ignoring NAT, which of the following are TRUE? (Select all that apply.)

  1. The source and destination MAC addresses of the outgoing frame differ from those of the incoming frame.
  2. The source and destination IPv4 addresses in the packet are unchanged.
  3. The TTL field is decremented by one.
  4. The transport-layer checksum must be recomputed by the router because the frame addresses changed.
Show answer & solution

Answer: Options (A), (B) and (C)

Detailed solution

Concept. A router terminates the link layer on each interface and forwards at the network layer, so link-layer addresses are local to a link while network-layer addresses are end to end.

Step by step.

  1. MAC addresses identify a network card on one link. The outgoing frame is built for the next hop, so both MAC addresses are rewritten.
  2. The IPv4 addresses name the end hosts and are carried unchanged through every router (NAT aside).
  3. The TTL is decremented at each router so that packets cannot loop forever.
  4. The transport checksum covers a pseudo-header of IP addresses and the transport payload; neither changes here, so the router does not recompute it.

Answer: Options (A), (B) and (C).

Common misconception. ‘The router changes the addresses, so it must fix the checksum’ conflates the two address spaces. Only the MAC addresses change, and no transport checksum covers them.

Takeaway. Per hop: MAC addresses and TTL change. End to end: IP addresses and the transport checksum survive.

CN-U1-Q30NATeasy

A router forwards IPv4 packets between its attached links. It implements the physical and data link layers on each link and the network layer for forwarding; it runs no transport-layer or application-layer protocol of its own. How many of the seven OSI layers does this router implement?

Show answer & solution

Answer: 3

Detailed solution

Concept. The number of OSI layers a device implements is the number of distinct layers whose functions it actually performs, not the number of headers it happens to read.

Step by step.

  1. Physical layer: it drives the line and moves bits on each interface.
  2. Data link layer: it frames and unframes, checks the frame check sequence and addresses the next hop.
  3. Network layer: it runs the routing table and forwards the packet.
  4. It runs no transport or application protocol, and OSI session and presentation functions are absent entirely, so the count stops at three.

Answer: 3 layers.

Common misconception. Counting all seven because the router ‘sees’ the whole packet. Reading a header is not implementing a layer; the router never processes the transport header at all.

Takeaway. Count the layers whose functions the device performs, and stop where its processing stops.

CN-U1-Q31MCQhard

Every link uses a frame check sequence that each router verifies and recomputes. Why does TCP nevertheless carry its own checksum?

  1. Because a frame check sequence cannot detect burst errors.
  2. Because a packet can be corrupted inside a router, after its incoming frame check sequence has been verified, and the outgoing link will then protect the corrupted packet with a fresh, valid frame check sequence.
  3. Because the frame check sequence covers only the frame header.
  4. Because routers strip the frame check sequence before forwarding the frame.
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. A hop-by-hop check protects a hop; it cannot protect the path. The end-to-end argument places a correctness check at the endpoints precisely because intermediate systems can introduce errors of their own.

Step by step.

  1. The incoming frame check sequence is verified when the frame arrives, so it says nothing about anything that happens afterwards.
  2. Inside a router the packet is held in memory, moved across a switching fabric and rewritten; any of these can corrupt it.
  3. The outgoing frame gets a newly computed check sequence over the corrupted bits, which therefore validates perfectly at the next hop.
  4. Only a check computed at the source and verified at the destination spans the whole path, which is what the TCP checksum provides.

Answer: Option (B).

Common misconception. The tempting answer is that the link check is somehow weak. It is strong; it is simply local. A correct hop check on a packet corrupted inside a router is a false reassurance, and that gap is exactly what the transport checksum closes.

Takeaway. A check protects the span over which it is computed and verified; hop-by-hop protection leaves the router itself uncovered.

CN-U1-Q08MCQeasy

A 1500-byte packet is placed on a 1 Mbps link. Ignoring propagation, processing and queueing delay, what is the transmission delay?

  1. 1.2 ms
  2. 12 ms
  3. 120 ms
  4. 0.12 ms
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Transmission delay is the time to push all the bits of the packet onto the link: L / R, with L in bits and R in bits per second.

Step by step.

  1. L = 1500 bytes = 1500 × 8 = 12000 bits.
  2. R = 1 Mbps = 10⁶ bits per second.
  3. L / R = 12000 / 10⁶ = 0.012 s = 12 ms.

Answer: Option (B) — 12 ms.

Common misconception. Forgetting the factor of 8 (bytes to bits) gives 1.5 ms or 1.2 ms, which is why those distractors are present.

Takeaway. Always convert to bits before dividing by a bit rate: delay = 8 × size_in_bytes / bandwidth.

CN-U1-Q09MCQeasy

Two links have the same length and the same propagation speed, but link 1 has twice the bandwidth of link 2. For the same packet, which of the following is TRUE?

  1. The propagation delay is the same on both links, and the transmission delay is smaller on link 1.
  2. Both delays are smaller on link 1.
  3. The transmission delay is the same on both links, and the propagation delay is smaller on link 1.
  4. Both delays are the same on both links.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Transmission delay depends on the link's bandwidth; propagation delay depends only on distance and signal speed.

Step by step.

  1. Propagation delay = distance / propagation speed, and both are identical, so the two links have equal propagation delay.
  2. Transmission delay = L / R; R is doubled on link 1, so its transmission delay is halved.
  3. Therefore only the transmission delay changes.

Answer: Option (A).

Common misconception. The frequent error is (B): assuming a ‘faster link’ shortens everything. Bandwidth cannot make a signal travel faster than the propagation speed of the medium.

Takeaway. Bandwidth governs how long the packet takes to enter the wire; distance governs how long it takes to cross it.

CN-U1-Q10NATmedium

A link has a bandwidth of 100 Mbps and a one-way propagation delay of 20 ms. What is the bandwidth-delay product of the link, in kilobytes? Use 1 kB = 1000 bytes and enter a number.

Show answer & solution

Answer: 250

Detailed solution

Concept. Bandwidth-delay product = bandwidth × propagation delay. It is the number of bits that can be in flight on the link at one instant.

Step by step.

  1. R = 100 Mbps = 10⁸ bits/s; delay = 20 ms = 0.02 s.
  2. BDP = 10⁸ × 0.02 = 2 × 10⁶ bits.
  3. In bytes: 2 × 10⁶ / 8 = 250000 bytes.
  4. In kB (1000 bytes): 250000 / 1000 = 250 kB.

Answer: 250 kB.

Common misconception. Two errors dominate: dividing by 1024 instead of 1000, and using bits per byte wrongly, giving 244 or 2000. The question fixes 1 kB = 1000 bytes to remove the first ambiguity.

Takeaway. BDP answers ‘how much data must be outstanding to keep the pipe full?’ — the basis of the TCP window sizing question.

CN-U1-Q12MSQhard

Which of the following statements about delay, bandwidth and the bandwidth-delay product are TRUE? (Select all that apply.)

  1. The bandwidth-delay product of a link equals the maximum number of bits that can be in transit on that link at any instant.
  2. Doubling the propagation delay and halving the bandwidth leaves the bandwidth-delay product unchanged.
  3. The transmission delay of a packet depends on the distance between the two end hosts.
  4. The throughput of a path is limited by the slowest link on it, while the end-to-end delay is the sum of the per-link delays.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. BDP = R × Tprop is the ‘amount of pipe’; transmission delay is L / R; throughput of a path is set by the bottleneck link.

Step by step.

  1. (A) True — that is the definition: the bits that fit inside the link while the first bit is still travelling.
  2. (B) True — (R/2) × (2T) = R × T.
  3. (C) False — transmission delay is L / R and contains no distance term; it is the propagation delay that depends on distance.
  4. (D) True — for a single flow the sustained rate cannot exceed the minimum link rate, and the delays add up hop by hop.

Answer: Options (A), (B) and (D).

Common misconception. Statement (C) is the standard confusion between the two delays. A satellite link of huge length but high bandwidth still has a tiny transmission delay and a large propagation delay.

  3. So k ranges over 0, 1, ..., 7, that is eight choices.
  4. The range doubles with each further collision until the implementation's limit is reached.

Answer: Option (C) — 0 to 7.

Common misconception. “0 to 3” uses 2i−1 − 1, off by one collision; “0 to 15” is the range after the fourth. Note also that k = 0 is allowed, which is why the range is not 1 to 8.

Takeaway. Collision i gives 2i slots numbered from 0.

CN-U2-Q42MCQeasy

What does a CSMA/CD station transmit as soon as it detects a collision?

  1. A negative acknowledgement for the damaged frame.
  2. The frame again, immediately.
  3. A request-to-send frame.
  4. A jam signal, which reinforces the collision so that every station on the segment notices it.
Show answer & solution

Answer: Option (D)

Concept. A collision is detected by comparing the transmitted signal with the received one. Because the first station to notice may be far from the other participants, it must make the collision last long enough for everyone to see it.

Step by step.

  1. The detecting station stops sending the frame and sends a short jam signal instead.
  2. The jam guarantees that the collision energy persists for at least the slot time, so no station can miss it.
  3. Every station involved then aborts, enters binary exponential backoff and reschedules.
  4. Negative acknowledgements belong to error-control protocols at a higher layer, and an immediate retransmission would collide again.

Answer: Option (D) — a jam signal.

Common misconception. Assuming that everyone detects the collision at the same moment. Stations are spread along the cable, so the jam exists to equalise what they observe.

Takeaway. Detect → abort with a jam → back off → retry.

CN-U2-Q43MCQmedium

A CSMA/CD LAN has a slot time of 51.2 µs and signals that travel at 2 × 108 m/s. Treating the slot time as the maximum round-trip propagation delay, what is the greatest cable length the network can span?

  1. 5120 m
  2. 2560 m
  3. 10240 m
  4. 512 m
Show answer & solution

Answer: Option (A)

Concept. The slot time is twice the maximum one-way propagation delay, 2τ, because a collision must be able to travel from the far end back to the sender before the sender finishes transmitting.

Step by step.

  1. 2τ = 51.2 µs, so τ = 25.6 µs.
  2. length = speed × τ = 2 × 108 × 25.6 × 10−6.
  3. = 5120 m.
  4. Doubling the cable would double τ and break the guarantee that the sender is still transmitting when a distant collision is reported.

Answer: Option (A) — 5120 m.

Common misconception. Answering 10 240 m uses the slot time as a one-way delay. The slot time is a round trip, and the cable length is fixed by the one-way half of it.

Takeaway. slot time = 2 × length / speed; every one of the three quantities follows from the other two.

CN-U2-Q44MSQmedium

Which of the following statements about CSMA/CA in IEEE 802.11 are TRUE? (Select all that apply.)

  1. A data frame is positively acknowledged at the link layer, because a station cannot reliably detect a collision while it is transmitting.
  2. The RTS/CTS exchange reduces the damage caused by hidden terminals.
  3. A station that finds the medium busy must wait for it to become idle and then for a further backoff period before transmitting.
  4. The DIFS is shorter than the SIFS.
Show answer & solution

Answer: Options (A), (B) and (C)

Concept. CSMA/CA avoids collisions rather than detecting them, because a radio's own transmission drowns out any incoming signal and a hidden terminal is inaudible to the sender.

Step by step.

  1. (A) True — with detection impossible, the only way to learn that a frame was lost is to require an explicit acknowledgement and retransmit on its absence.
  2. (B) True — the short RTS reserves the medium and the CTS, sent by the receiver, is heard by stations that cannot hear the sender, which is exactly the hidden-terminal case.
  3. (C) True — after the medium goes idle a station still defers for a random backoff, so several waiting stations do not all start at the same instant.
  4. (D) False — the ordering is SIFS < PIFS < DIFS. The short interframe space gives acknowledgements priority over new frames, which is why it must be shorter.

Answer: Options (A), (B) and (C).

Common misconception. (D) reverses the two intervals. Making DIFS shorter than SIFS would let a new data frame jump ahead of the acknowledgement it is waiting for.

Takeaway. Shortest interval wins the contention: SIFS for control responses, DIFS for ordinary data.

CN-U2-Q45NAThard

After four consecutive collisions a CSMA/CD station draws k uniformly at random from 0 to 24 − 1 and waits k slot times.
What is its expected wait, in slot times?

Show answer & solution

Answer: 7.5

Concept. The backoff k is uniform over 0 .. 2i−1, so its expectation is the midpoint of the range, (2i − 1)/2.

Step by step.

  1. i = 4, so k is uniform over 0, 1, ..., 15, sixteen values.
  2. The sum is 0 + 1 + ... + 15 = 120.
  3. Expected value = 120/16 = 7.5.
  4. Equivalently (24 − 1)/2 = 15/2 = 7.5.

Answer: 7.5 slot times.

Common misconception. Answering 8 treats the range as 1 .. 16 or as 0 .. 16; the range is 0 .. 2i−1, which has an odd maximum and therefore a half-integer mean.

Takeaway. Expected backoff after collision i is (2i−1)/2 slot times — it doubles with every further collision.

CN-DL2-Q21MCQeasy

Which device learns source MAC addresses and then forwards a frame only to the port on which the destination address was last seen?

  1. A repeater
  2. A hub
  3. A transparent bridge (layer-2 switch)
  4. A router
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. A transparent bridge builds a forwarding table by watching the source address of every frame it receives, and uses the destination address to choose one output port.

Step by step.

  1. Repeaters and hubs are physical-layer devices: they regenerate or repeat every bit out of every other port, with no addresses at all.
  2. A bridge reads the frame header, records (source MAC, arrival port) in its table, and looks up the destination.
  3. If the destination is known, the frame leaves exactly one port; if not, it is flooded.
  4. A router works on network-layer addresses and does not switch on MAC addresses.

Answer: Option (C) — a transparent bridge (layer-2 switch).

Common misconception. Confusing a hub with a switch because both have several ports. A hub is a shared wire; a switch is a set of independent links joined by a table.

Takeaway. Layer 1 repeats, layer 2 switches, layer 3 routes. Ask which address the device reads to decide which it is.

CN-DL2-Q22MCQmedium

A switch receives a frame whose destination MAC address is not present in its forwarding table. What does it do?

  1. It discards the frame and waits for the address to be learned.
  2. It floods the frame out of every port except the one on which it arrived.
  3. It forwards the frame to the port with the lowest port number.
  4. It sends the frame back out of the port on which it arrived.
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. An unknown unicast address is handled exactly like a broadcast: the switch has no information, so it takes the only safe action and copies the frame to all other ports.

Step by step.

  1. The switch looks up the destination in its table and finds no entry.
  2. It cannot know which segment holds the host, so it floods to all ports except the arrival port.
  3. The destination host eventually replies, and that reply teaches the switch the correct port.
  4. Later frames to that address are switched to a single port.

Answer: Option (B).

Common misconception. Dropping the frame would make the network unusable until every address had been learned; sending it back out of the arrival port would be pointless.

Takeaway. Flooding is not an error path; it is how learning starts. The only traffic a switch never floods is a frame whose destination port equals its arrival port (which it filters).

CN-DL2-Q23MSQmedium

Which of the following statements about Ethernet and its interconnection devices are TRUE? (Select all that apply.)

  1. A layer-2 switch divides a collision domain but not a broadcast domain.
  2. A router divides both the collision domain and the broadcast domain.
  3. A hub forwards a frame only to the port on which the destination address was learned.
  4. 802.3 Ethernet uses 48-bit MAC addresses and a minimum frame size of 64 bytes.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. A collision domain is the set of stations whose transmissions can collide; a broadcast domain is the set that receives each other's broadcasts. Each device boundary removes one or both.

Step by step.

  1. (A) True. Each switch port is its own collision domain, but a broadcast is still flooded to all ports.
  2. (B) True. A router terminates both: it does not forward broadcasts and it regenerates the frame on each interface.
  3. (C) False. A hub has no table and no addresses; it repeats every bit out of every other port.
  4. (D) True. Both figures are part of the 802.3 standard.

Answer: Options (A), (B) and (D).

Common misconception. Assuming a switch also splits broadcast domains, which would make VLANs unnecessary. Only a router, or a VLAN boundary inside a switch, does that.

Takeaway. Count domains device by device: hub — nothing split; switch — collision split; router — both split.

CN-DL2-Q24NATeasy

A switch has 16 ports, and exactly one host is connected to each port. How many collision domains exist in this network?

Show answer & solution

Answer: 16

Detailed solution

Concept. A switch gives every port its own collision domain, because it stores and forwards frames instead of repeating bits.

Step by step.

  1. Each port is a separate link with exactly one host on it.
  2. Nothing transmitted on one port can collide with anything on another, so each port is one collision domain.
  3. 16 ports ⇒ 16 collision domains.

Answer: 16.

Common misconception. Answering 1, as if the switch were a hub. A 16-port hub would be a single collision domain shared by all 16 hosts.

Takeaway. With full-duplex links the collision domain is not merely separate but empty — which is why modern switched Ethernet needs no CSMA/CD.

CN-DL2-Q25MCQhard

Two transparent bridges are cabled so that they form a loop, and the spanning-tree protocol is disabled. What happens to a frame whose destination address is unknown to both bridges?

  1. It is flooded round the loop indefinitely and multiplies, because a layer-2 frame carries no hop count or time-to-live that a bridge could use to discard it.
  2. It is dropped as soon as it returns to the bridge that first forwarded it, because bridges detect duplicates by sequence number.
  3. It travels once round the loop and is then discarded when its time-to-live expires.
  4. Only broadcast frames loop; a unicast frame with an unknown address is returned to its source.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Bridging is transparent and stateless with respect to forwarding: a bridge floods unknown destinations every time it sees them. With a loop, each flooded copy is seen again and flooded again.

Step by step.

  1. Bridge 1 receives the frame, does not know the destination, and floods it to bridge 2.
  2. Bridge 2 also does not know the destination, so it floods the frame back to bridge 1 and to its own segments.
  3. Nothing in an 802.3 frame ages: there is no TTL field, and bridges do not keep a record of frames they have already forwarded.
  4. Each pass creates more copies, so the copies grow without bound and the loop saturates — a broadcast storm.
  5. Spanning tree protocol exists precisely to break the loop by blocking one port, keeping the topology a tree.

Answer: Option (A).

Common misconception. Options (B) and (C) assume layer-2 frames behave like IP packets. TTL, hop limits and duplicate detection are layer-3 and above; Ethernet has none of them.

Takeaway. A layer-2 network must be loop-free by construction, because the frame itself carries no defence against looping.

CN-U2-Q46MCQeasy

Which address in an arriving frame does a transparent bridge read in order to build its forwarding table?

  1. The destination MAC address
  2. The destination IP address
  3. The frame's sequence number
  4. The source MAC address
Show answer & solution

Answer: Option (D)

Concept. A transparent bridge learns by looking at where frames come from: if a frame with source address S arrived on port p, then S is reachable through p.

Step by step.

  1. The frame arrives on a port; the bridge records source → port in its table, refreshing the entry's age.
  2. It then looks up the destination address to decide where to forward the frame.
  3. So the source address is used for learning and the destination address for forwarding — two different reads for two different purposes.
  4. IP addresses are not examined at all by a layer-2 bridge.

Answer: Option (D) — the source MAC address.

Common misconception. Confusing the address used for learning with the address used for forwarding. Answering ‘destination’ describes the lookup, not the table construction.

Takeaway. Learn from the source, forward by the destination, and flood when the destination is unknown.

CN-U2-Q47MCQeasy

What does a hub do with a frame it receives?

  1. It forwards the frame only to the port on which the destination address was learned.
  2. It discards the frame if the destination address is unknown.
  3. It repeats the signal out of every other port, because it keeps no address table.
  4. It rewrites the source address before repeating the frame.
Show answer & solution

Answer: Option (C)

Concept. A hub is a physical-layer device: it regenerates and repeats electrical signals and has no notion of a frame, an address or a table.

Step by step.

  1. Bits arriving on one port are re-timed and sent out of all the others.
  2. There is no filtering, so every station in the collision domain sees every transmission.
  3. All ports of a hub therefore belong to a single collision domain and a single broadcast domain.
  4. Only a bridge or switch, which reads addresses, can forward selectively.

Answer: Option (C) — it repeats the signal out of every other port.

Common misconception. Option (A) describes a switch. Because a hub cannot read an address, it can neither filter nor learn, and it also cannot detect a collision per port — it merely repeats the collision to everyone.

Takeaway. Hub → repeat everything; switch → learn, filter and flood.

CN-U2-Q48MCQmedium

A switch receives a frame on port 1 whose destination MAC address is one that the switch has learned on port 1 itself. What does the switch do?

  1. It filters the frame, that is, drops it, because the destination lies on the same segment as the source.
  2. It floods the frame out of every other port.
  3. It forwards the frame out of port 1 as well.
  4. It returns the frame to the sender with an error indication.
Show answer & solution

Answer: Option (A)

Concept. A switch compares the port learned for the destination with the port the frame arrived on. Equal means the two hosts share a segment and no other segment needs the frame.

Step by step.

  1. The source address is learned on port 1, refreshing that entry.
  2. The destination address is looked up and also resolves to port 1.
  3. Because the frame is already on the segment where the destination lives, forwarding it anywhere would be wasted bandwidth.
  4. The switch therefore filters — drops — the frame.

Answer: Option (A) — it filters the frame.

Common misconception. Believing a switch always forwards or always floods. Filtering is the third action, and it is what makes a switch a bandwidth-saving device rather than a repeater.

Takeaway. Three actions: filter if the destination is on the incoming port, forward if it is on another known port, flood if it is unknown.

CN-U2-Q49MSQmedium

Which of the following statements about IEEE 802.3 Ethernet are TRUE? (Select all that apply.)

  1. A frame's payload must be at least 46 bytes for the frame to reach the 64-byte minimum.
  2. Ethernet delivers frames reliably by acknowledging each one at the data link layer.
  3. The preamble is seven bytes of alternating 1s and 0s followed by a one-byte start-frame delimiter.
  4. A switch forwards a broadcast frame out of every port except the one on which it arrived.
Show answer & solution

Answer: Options (A), (C) and (D)

Concept. Ethernet is a best-effort, connectionless LAN: it detects errors but does not recover from them, and its frame format is fixed by the standard.

Step by step.

  1. (A) True — the minimum frame is 64 bytes and the header plus trailer accounts for 18 bytes (6 + 6 + 2 + 4), so the payload floor is 46 bytes. Shorter payloads are padded.
  2. (B) False — there is no link-layer acknowledgement in 802.3. A lost frame is simply lost, and recovery is left to TCP or the application.
  3. (C) True — 7 bytes of preamble for clock recovery, then the 10101011 start-frame delimiter.
  4. (D) True — a broadcast address cannot be looked up, so the frame is flooded; the sending port is excluded.

Answer: Options (A), (C) and (D).

Common misconception. (B) is the usual error, often borrowed from Wi-Fi, where 802.11 does acknowledge every data frame. Wired Ethernet does not.

Takeaway. 64-byte minimum, 46-byte payload floor, 18 bytes of overhead, no acknowledgements.

CN-U2-Q50NAThard

Four switches are cabled so that every pair is joined by exactly one link. The spanning-tree protocol runs and reduces the network to a tree.
How many of those links are left in the blocking state?

Show answer & solution

Answer: 3

Concept. A spanning tree over n nodes has exactly n − 1 links. Every other link must be blocked, or a loop would remain.

Step by step.

  1. Four switches, every pair joined: the number of links is C(4,2) = 6.
  2. A tree on four nodes uses 4 − 1 = 3 links.
  3. Blocked links = 6 − 3 = 3.
  4. Each blocked port still receives bridge protocol data units but forwards no data, so the remaining three links form a loop-free path between every pair.

Answer: 3 links blocked.

Common misconception. Reporting 6 minus the number of switches, or blocking links until each switch has degree one. The tree requirement is n−1 links in total, not a star.

Takeaway. Blocked links = |E| − (|V| − 1) for a connected graph.
