OSI & TCP/IP models · 7
CN-U1-Q01MCQeasy

In the OSI reference model, which layer is responsible for routing a packet from one network to another through intermediate routers?

  1. Physical layer
  2. Data link layer
  3. Network layer
  4. Transport layer
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. The OSI layers divide work by scope: the physical layer moves bits, the data link layer moves frames across a single link, the network layer moves packets across a sequence of links, and the transport layer moves data between processes.

Step by step.

  1. Routing means choosing the next hop for a packet whose source and destination lie in different networks.
  2. That decision needs a global (network-wide) address, which is exactly what the network layer provides.
  3. The data link layer only addresses the next machine on the same link; the transport layer does not see routers at all.

Answer: Option (C) — the network layer.

Common misconception. Many candidates choose the transport layer because it is the first ‘end-to-end’ layer. End-to-end delivery is transport; routing inside the network is network layer.

Takeaway. Fix the vocabulary early: routing and logical addressing → network layer; framing and MAC addressing → data link; process-to-process delivery → transport.

CN-U1-Q02MCQeasy

Which one of the following is NOT a layer of the TCP/IP reference model?

  1. Application
  2. Transport
  3. Session
  4. Internet
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. The TCP/IP reference model has four layers — application, transport, internet and network access (host-to-network).

Step by step.

  1. The application layer merges the OSI application, presentation and session functions.
  2. Transport and internet are layers in their own right.
  3. There is no separate session layer; session-style services (dialogue control, checkpointing) are either omitted or pushed into the application.

Answer: Option (C) — Session.

Common misconception. Candidates who memorise ‘seven layers’ often assume the session layer exists in every model. It is an OSI-only layer.

Takeaway. OSI = 7 layers (physical, data link, network, transport, session, presentation, application). TCP/IP = 4 (or 5 if the link layer is split into link and physical).

CN-U1-Q03MCQeasy

A switch that forwards frames by looking up 48-bit MAC addresses operates at which OSI layer?

  1. Physical layer
  2. Data link layer
  3. Network layer
  4. Transport layer
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Device class follows the header the device reads. A MAC address is a data link layer address, so a MAC-address switch is a layer-2 device.

Step by step.

  1. The switch receives a frame, reads its destination MAC address, and forwards it out of the port learned for that address.
  2. It does not modify or inspect the IP header, so it never reaches layer 3.
  3. A hub, by contrast, only repeats electrical signals and is a layer-1 device; a router reads IP addresses and is a layer-3 device.

Answer: Option (B) — the data link layer.

Common misconception. Switches are sometimes called ‘layer-3 switches’ when they also route, which makes candidates assume all switches are layer 3. Plain MAC forwarding is layer 2.

Takeaway. Hub → layer 1, switch/bridge → layer 2, router → layer 3, and a device is named after the highest header it actually processes.

CN-U1-Q04MSQmedium

Which of the following statements about layering and encapsulation are TRUE? (Select all that apply.)

  1. A router forwards a packet using the destination network-layer address and normally does not inspect the transport-layer header.
  2. The data link layer appends a trailer to the frame, while the network layer adds only a header.
  3. A hub regenerates and repeats bits, so it operates at the physical layer.
  4. A protocol converter that works at the application layer is, by definition, a layer-3 device.
Show answer & solution

Answer: Options (A), (B) and (C)

Detailed solution

Concept. Each layer adds its own control information and reads only its own header; a router is a layer-3 relay and is transparent to transport headers.

Step by step.

  1. (A) True — routing needs only the network-layer destination address; the transport header travels untouched.
  2. (B) True — a data link frame carries a trailer (the frame check sequence); the network header has no trailer.
  3. (C) True — a hub performs no frame parsing at all, so it is layer 1.
  4. (D) False — an application-layer converter works at layer 7; a ‘gateway’ in the general sense can operate at any layer.

Answer: Options (A), (B) and (C).

Common misconception. Statement (D) is the trap: the word ‘gateway’ is sometimes used for a router (layer 3), but an application-level converter is a layer-7 device. The definition in (D) is simply wrong.

Takeaway. Ask of any claim ‘which header does this entity have to read?’ — the answer fixes its layer.

CN-U1-Q05MSQmedium

Which of the following statements comparing the OSI and TCP/IP reference models are TRUE? (Select all that apply.)

  1. The TCP/IP application layer performs the functions that OSI splits across its session, presentation and application layers.
  2. The TCP/IP internet layer corresponds to the OSI network layer.
  3. The TCP/IP reference model has seven layers.
  4. The OSI model was designed before the protocols that implement it existed, whereas the TCP/IP model was written up after its protocols were already in use.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. OSI is a protocol-independent architecture written first; TCP/IP is a description of an already-working protocol suite.

Step by step.

  1. (A) True — presentation (encoding, compression, encryption) and session services are handled inside application protocols in TCP/IP.
  2. (B) True — the internet layer provides logical addressing and routing, exactly the OSI network layer's job.
  3. (C) False — TCP/IP has four layers (five if the link layer is split).
  4. (D) True — the classic historical distinction: OSI came from a model, TCP/IP came from running code.

Answer: Options (A), (B) and (D).

Common misconception. Statement (C) is the usual error, produced by carrying the OSI count over to TCP/IP. Also note (D) is a genuine, examinable distinction, not trivia.

Takeaway. Two facts to keep: TCP/IP = 4 layers and no session/presentation layer; OSI = 7 layers and model-first.

CN-U1-Q06NATeasy

An application message of 600 bytes is passed down the stack. The transport layer adds a 20-byte header, the network layer adds a 20-byte header, and the data link layer adds a 14-byte header and a 4-byte trailer.
What is the total size, in bytes, of the frame handed to the physical layer?

Show answer & solution

Answer: 658

Detailed solution

Concept. Encapsulation adds one header at each layer (and a trailer at the data link layer), so the sizes simply add.

Step by step.

  1. Application data: 600 bytes.
  2. Transport segment: 600 + 20 = 620 bytes.
  3. Network datagram: 620 + 20 = 640 bytes.
  4. Data link frame: 640 + 14 + 4 = 658 bytes.

Answer: 658 bytes.

Common misconception. The common slip is to forget the 4-byte trailer, or to add the transport header twice because the segment is later called a payload. Overhead here is 58 bytes in total.

Takeaway. Layer overhead is cumulative: every header added below is carried by everything above it.

CN-U1-Q07MCQhard

A frame travels from a source host to a destination host through two routers. Which statement about error checking on this path is correct?

  1. Both the frame check sequence and the TCP checksum are verified only at the destination host.
  2. The frame check sequence is verified by every device that receives the frame, including each router; the TCP checksum is verified only at the destination host.
  3. The frame check sequence is verified only at the destination host; the TCP checksum is verified at every router.
  4. Both the frame check sequence and the TCP checksum are verified at every router along the path.
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Error detection is layered, and each layer's check has the scope of that layer: a data link check covers one hop, a transport check covers the whole end-to-end path.

Step by step.

  1. When a router receives a frame it recomputes the frame check sequence over the received bits; a bad frame is discarded on that hop.
  2. The router then strips the data link header and trailer, so the next hop gets a brand-new frame with a newly computed check sequence.
  3. The TCP header and its checksum travel end to end untouched, so only the destination transport layer can verify them — a router never even looks at them.

Answer: Option (B).

Common misconception. The tempting error is (D): students reason that ‘every device checks for errors’. A router cannot verify a TCP checksum without reassembling the transport segment, which it does not do.

Takeaway. Per-hop check ⇒ data link; end-to-end check ⇒ transport. This is the cleanest illustration of why both layers exist.

Delays & bandwidth-delay product · 6
CN-U1-Q08MCQeasy

A 1500-byte packet is placed on a 1 Mbps link. Ignoring propagation, processing and queueing delay, what is the transmission delay?

  1. 1.2 ms
  2. 12 ms
  3. 120 ms
  4. 0.12 ms
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Transmission delay is the time to push all the bits of the packet onto the link: L / R, with L in bits and R in bits per second.

Step by step.

  1. L = 1500 bytes = 1500 × 8 = 12000 bits.
  2. R = 1 Mbps = 10⁶ bits per second.
  3. L / R = 12000 / 10⁶ = 0.012 s = 12 ms.

Answer: Option (B) — 12 ms.

Common misconception. Forgetting the factor of 8 (bytes to bits) gives 1.5 ms or 1.2 ms, which is why those distractors are present.

Takeaway. Always convert to bits before dividing by a bit rate: delay = 8 × size_in_bytes / bandwidth.

CN-U1-Q09MCQeasy

Two links have the same length and the same propagation speed, but link 1 has twice the bandwidth of link 2. For the same packet, which of the following is TRUE?

  1. The propagation delay is the same on both links, and the transmission delay is smaller on link 1.
  2. Both delays are smaller on link 1.
  3. The transmission delay is the same on both links, and the propagation delay is smaller on link 1.
  4. Both delays are the same on both links.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Transmission delay depends on the link's bandwidth; propagation delay depends only on distance and signal speed.

Step by step.

  1. Propagation delay = distance / propagation speed, and both are identical, so the two links have equal propagation delay.
  2. Transmission delay = L / R; R is doubled on link 1, so its transmission delay is halved.
  3. Therefore only the transmission delay changes.

Answer: Option (A).

Common misconception. The frequent error is (B): assuming a ‘faster link’ shortens everything. Bandwidth cannot make a signal travel faster than the propagation speed of the medium.

Takeaway. Bandwidth governs how long the packet takes to enter the wire; distance governs how long it takes to cross it.

CN-U1-Q10NATmedium

A link has a bandwidth of 100 Mbps and a one-way propagation delay of 20 ms.
What is the bandwidth-delay product of the link, in kilobytes? Use 1 kB = 1000 bytes and enter a number.

Show answer & solution

Answer: 250

Detailed solution

Concept. Bandwidth-delay product = bandwidth × propagation delay. It is the number of bits that can be in flight on the link at one instant.

Step by step.

  1. R = 100 Mbps = 10⁸ bits/s; delay = 20 ms = 0.02 s.
  2. BDP = 10⁸ × 0.02 = 2 × 10⁶ bits.
  3. In bytes: 2 × 10⁶ / 8 = 250000 bytes.
  4. In kB (1000 bytes): 250000 / 1000 = 250 kB.

Answer: 250 kB.

Common misconception. Two errors dominate: dividing by 1024 instead of 1000, and using bits per byte wrongly, giving 244 or 2000. The question fixes 1 kB = 1000 bytes to remove the first ambiguity.

Takeaway. BDP answers ‘how much data must be outstanding to keep the pipe full?’ — the basis of the TCP window sizing question.

CN-U1-Q11MCQeasy

Two hosts are 3000 km apart on a link whose signal propagates at 3 × 10⁸ m/s. What is the one-way propagation delay?

  1. 1 ms
  2. 10 ms
  3. 100 ms
  4. 0.1 ms
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Propagation delay = distance / propagation speed.

Step by step.

  1. Distance = 3000 km = 3 × 10⁶ m.
  2. Speed = 3 × 10⁸ m/s.
  3. Delay = 3 × 10⁶ / 3 × 10⁸ = 10⁻² s = 10 ms.

Answer: Option (B) — 10 ms.

Common misconception. A kilometre-to-metre slip (using 3000 m) gives 0.01 ms, and a factor-of-ten slip gives 100 ms. Both appear as options.

Takeaway. Keep units consistent: convert km to m before dividing by m/s, and remember 10⁻³ s = 1 ms.

CN-U1-Q12MSQhard

Which of the following statements about delay, bandwidth and the bandwidth-delay product are TRUE? (Select all that apply.)

  1. The bandwidth-delay product of a link equals the maximum number of bits that can be in transit on that link at any instant.
  2. Doubling the propagation delay and halving the bandwidth leaves the bandwidth-delay product unchanged.
  3. The transmission delay of a packet depends on the distance between the two end hosts.
  4. The throughput of a path is limited by the slowest link on it, while the end-to-end delay is the sum of the per-link delays.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. BDP = R × Tprop is the ‘amount of pipe’; transmission delay is L / R; throughput of a path is set by the bottleneck link.

Step by step.

  1. (A) True — that is the definition: the bits that fit inside the link while the first bit is still travelling.
  2. (B) True — (R/2) × (2T) = R × T.
  3. (C) False — transmission delay is L / R and contains no distance term; it is the propagation delay that depends on distance.
  4. (D) True — for a single flow the sustained rate cannot exceed the minimum link rate, and the delays add up hop by hop.

Answer: Options (A), (B) and (D).

Common misconception. Statement (C) is the standard confusion between the two delays. A satellite link of huge length but high bandwidth still has a tiny transmission delay and a large propagation delay.

Takeaway. Transmission delay: packet size vs bandwidth. Propagation delay: distance vs signal speed. Never mix them.

CN-U1-Q13MCQmedium

A 1000-byte packet is sent from a source to a destination over three links in series, each of bandwidth 1 Mbps. The switches are store-and-forward and propagation delay is negligible. What is the total time from the first bit leaving the source to the last bit arriving at the destination?

  1. 8 ms
  2. 16 ms
  3. 24 ms
  4. 32 ms
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. Under store-and-forward, a switch must receive the whole packet before it can begin transmitting it on the next link, so each hop costs one full transmission time.

Step by step.

  1. One transmission time = 1000 × 8 / 10⁶ = 8 ms.
  2. The source pushes the packet onto link 1 in 8 ms; the packet then needs 8 ms on link 2 and 8 ms on link 3.
  3. Total = 3 × 8 = 24 ms.

Answer: Option (C) — 24 ms.

Common misconception. The popular wrong answer is 8 ms, from imagining that the bits flow continuously through all three links at once. That is cut-through switching, not store-and-forward.

Takeaway. Store-and-forward over k equal links: total = k × L/R (plus propagation). Only the first hop overlaps with nothing.

Framing: bit & byte stuffing · 6
CN-U1-Q14MCQeasy

Why is bit stuffing used in a bit-oriented framing protocol such as HDLC?

  1. To make sure the flag pattern 01111110 never appears inside the data.
  2. To detect bit errors introduced by the channel.
  3. To compress the data before transmission.
  4. To keep the receiver's clock synchronised with the sender's.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Framing needs an unambiguous delimiter. If the delimiter could occur in the payload, the receiver could not tell data from a frame boundary.

Step by step.

  1. HDLC uses the flag 01111110 at the start and end of every frame.
  2. A payload containing six consecutive 1s would imitate that flag.
  3. The sender therefore inserts a 0 after every five consecutive 1s, so six 1s can never occur inside a frame.
  4. The receiver deletes the inserted 0 again.

Answer: Option (A) — transparency of the flag.

Common misconception. Bit stuffing is often confused with error detection (option B). HDLC detects errors with the frame check sequence; stuffing only guarantees frame transparency.

Takeaway. Framing problems are solved by transparency mechanisms (stuffing, escaping), never by checksums.

CN-U1-Q15MCQeasy

In byte-oriented framing, FLAG = 0x7E and ESC = 0x7D, and the escape rule is to transmit ESC followed by the data byte XORed with 0x20. How is a data byte 0x7D transmitted?

  1. 0x7D 0x7D
  2. 0x7D 0x5D
  3. 0x5D
  4. 0x7E 0x7D
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Every occurrence of the flag byte and of the escape byte itself must be escaped, so the receiver never mistakes data for a delimiter.

Step by step.

  1. The data byte is 0x7D, which equals ESC.
  2. XOR with 0x20: 0x7D ⊕ 0x20 = 0x5D.
  3. Transmit ESC first, then the escaped byte: 0x7D 0x5D.

Answer: Option (B) — 0x7D 0x5D.

Common misconception. Many candidates escape only the flag. Forgetting that the escape byte itself must be escaped makes the receiver treat a data 0x7D as the start of an escape sequence.

Takeaway. Two bytes need escaping in byte stuffing: the flag and the escape byte itself. The XOR with 0x20 flips bit 5, which maps 0x7E→0x5E and 0x7D→0x5D.

CN-U1-Q16NATmedium

A frame uses byte stuffing with FLAG = 0x7E and ESC = 0x7D; an escape sequence is ESC followed by the data byte XORed with 0x20. The data to be transmitted is the six-byte sequence
41 7E 7D 42 7E 43 (hex).
How many bytes are transmitted between the two flags?

Show answer & solution

Answer: 9

Detailed solution

Concept. Byte stuffing replaces each occurrence of FLAG or ESC by a two-byte escape sequence; every other byte passes through unchanged.

Step by step.

  1. 0x41 is neither FLAG nor ESC → 0x41 (1 byte).
  2. 0x7E = FLAG → 0x7D 0x5E (2 bytes).
  3. 0x7D = ESC → 0x7D 0x5D (2 bytes).
  4. 0x42 → 0x42 (1 byte).
  5. 0x7E → 0x7D 0x5E (2 bytes).
  6. 0x43 → 0x43 (1 byte).
  7. Total = 1 + 2 + 2 + 1 + 2 + 1 = 9 bytes.

Answer: 9 bytes.

Common misconception. The usual mistakes are escaping only the two FLAG bytes (giving 8) or forgetting that the ESC byte must itself be escaped (giving 8 as well, but for a different reason).

Takeaway. Count the growth: each escaped byte adds exactly one byte to the frame, so the payload grows from 6 to 9.

CN-U1-Q17MCQmedium

The data bit stream 011111101111101111110 is to be transmitted with bit stuffing, where a 0 is inserted after every five consecutive 1s. How many bits are inserted?

  1. 2
  2. 3
  3. 4
  4. 5
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Scan the stream keeping a running count of consecutive 1s; whenever the count reaches five, insert a 0 and reset the counter.

Step by step.

  1. Group 1: the leading 0111111 has six consecutive 1s → one 0 inserted after the fifth 1.
  2. The inserted 0 resets the run, so the sixth 1 starts a new run of length 1.
  3. Group 2: 11111 → one 0 inserted.
  4. Group 3: 111111 → one 0 inserted after the fifth 1.
  5. Total insertions = 3.

Answer: Option (B) — 3 bits.

Common misconception. The trap is to treat a run of six 1s as a single insertion of two 0s, or to stop counting once a 0 has been inserted. Each insertion resets the counter, and each new run of five earns its own insertion.

Takeaway. Work left to right with a counter, never by eye: after inserting a 0 the run length is 0, and the next bit restarts it.

CN-U1-Q18MSQmedium

Which of the following statements about framing techniques are TRUE? (Select all that apply.)

  1. In byte-oriented framing, only the flag byte and the escape byte itself need to be escaped.
  2. In bit-oriented framing, the receiver removes a 0 that immediately follows five consecutive 1s.
  3. Character-count framing keeps synchronisation even if the count field of a frame is corrupted.
  4. In character-count framing, a corrupted count field destroys the framing of all the following frames in the stream.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. There are three standard framing methods: character count, flag bytes with stuffing, and flag bits with bit stuffing. Each has a different failure mode.

Step by step.

  1. (A) True — any other byte value can appear in the data without ambiguity, so only FLAG and ESC need escaping.
  2. (B) True — that is exactly the de-stuffing rule, and it is what makes six 1s impossible inside a frame.
  3. (C) False and (D) True — the count field tells the receiver where the frame ends, so a corrupted count shifts every subsequent boundary. This is the classic weakness of character-count framing.

Answer: Options (A), (B) and (D).

Common misconception. Statements (C) and (D) are contradictory, so one must be false: candidates who pick both have not modelled what the receiver does with the count.

Takeaway. Character count: simple, but one bad count desynchronises the stream. Flag-based methods recover because the receiver can rescan for the next flag.

CN-U1-Q19MCQhard

The data stream 01111101111110 is transmitted with bit stuffing (a 0 is inserted after every five consecutive 1s). Which is the transmitted stream?

  1. 0111110111111010
  2. 01111100111111010
  3. 0111110011111010
  4. 011111001111010
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. Bit stuffing is applied left to right with a counter of consecutive 1s; each insertion adds a 0 and resets the counter.

Step by step.

  1. Original: 0 1 1 1 1 1 0 1 1 1 1 1 1 0 (14 bits).
  2. Bits 2–6 are five 1s → insert 0 after bit 6.
  3. Bit 7 is 0; then bits 8–12 are five 1s → insert 0 after bit 12.
  4. Bit 13 is 1 (a new run of length 1) and bit 14 is 0, so no further insertion.
  5. Result: 0 1 1 1 1 1 0 0 1 1 1 1 1 0 1 0 = 0111110011111010 (16 bits).

Answer: Option (C) — 0111110011111010.

Common misconception. Option (A) is the original stream with two 0s appended, and option (B) has 17 bits because a 0 was inserted after a run of only four 1s. Both come from stuffing by eye rather than by counter.

Takeaway. Write the output bit by bit and keep the counter visible; the length grows by exactly the number of insertions.

CRC, checksum & Hamming · 6
CN-U1-Q20MCQeasy

What is the Hamming distance between the two 7-bit codewords 1011101 and 1001001?

  1. 1
  2. 2
  3. 3
  4. 4
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. The Hamming distance is the number of bit positions in which the two codewords differ.

Step by step.

  1. Align the words: 1 0 1 1 1 0 1 and 1 0 0 1 0 0 1.
  2. Position 1: 1 = 1. Position 2: 0 = 0. Position 3: 1 ≠ 0. Position 4: 1 = 1.
  3. Position 5: 1 ≠ 0. Position 6: 0 = 0. Position 7: 1 = 1.
  4. Two positions differ, so the distance is 2.

Answer: Option (B) — 2.

Common misconception. The slip is to compare the decimal values or to count matching positions instead of differing ones.

Takeaway. Distance = number of differing positions = weight of the XOR of the two words: 1011101 ⊕ 1001001 = 0010100, which has weight 2.

CN-U1-Q21MCQmedium

A block code has minimum Hamming distance 5. How many bit errors can it (i) detect and (ii) correct?

  1. Detect 4, correct 2
  2. Detect 2, correct 4
  3. Detect 5, correct 2
  4. Detect 2, correct 1
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. With minimum distance d: detection capability is d − 1 errors, correction capability is ⌊(d − 1)/2⌋ errors.

Step by step.

  1. d = 5, so up to d − 1 = 4 errors can be detected.
  2. Correction: ⌊4/2⌋ = 2 errors.
  3. Intuition: a received word with 2 errors is still strictly nearer its own codeword than any other (distance 2 against at least 3).

Answer: Option (A) — detect 4, correct 2.

Common misconception. Candidates often answer ‘detect 5’. With 5 errors a word can land exactly on another codeword, so 5 errors are not detectable.

Takeaway. Memorise the pair: detect ≤ d−1, correct ≤ ⌊(d−1)/2⌋. Every error-detection question reduces to these two.

CN-U1-Q22NATmedium

A single-error-correcting Hamming code is to be built for 16 data bits.
What is the minimum number of parity bits required?

Show answer & solution

Answer: 5

Detailed solution

Concept. With m data bits and r parity bits, the r check positions must be able to address every one of the m + r positions plus the ‘no error’ case: m + r + 1 ≤ 2r.

Step by step.

  1. Try r = 4: 16 + 4 + 1 = 21 > 16 = 2⁴, so 4 parity bits cannot address all error patterns.
  2. Try r = 5: 16 + 5 + 1 = 22 ≤ 32 = 2⁵, which works.
  3. So the minimum is 5 parity bits, giving a 21-bit codeword.

Answer: 5 parity bits.

Common misconception. The common error is to use 2r ≥ m only, which gives 4. The parity bits also occupy positions that must be addressable, and the all-zero syndrome must be reserved for ‘no error’.

Takeaway. For Hamming codes, solve the smallest r with m + r + 1 ≤ 2r. For m = 4, 7, 8, 16 the answers are 3, 4, 4, 5.

CN-U1-Q23MSQhard

Which of the following statements about CRC and checksums are TRUE? (Select all that apply.)

  1. A CRC whose generator polynomial has at least two non-zero terms detects every single-bit error.
  2. A CRC with a generator polynomial of degree r detects every burst error of length at most r.
  3. If the CRC remainder is zero, the received frame is guaranteed to be error-free.
  4. CRC arithmetic is polynomial division over GF(2), where addition and subtraction are both the XOR operation.
Show answer & solution

Answer: Options (A), (B) and (D)

Detailed solution

Concept. CRC treats the frame as a polynomial over GF(2); the properties follow from divisibility by the generator polynomial g(x).

Step by step.

  1. (A) True — a single-bit error is xi, and g(x) with two or more terms cannot divide a monomial.
  2. (B) True — a burst of length ≤ r has degree below r, so it cannot be a non-zero multiple of g(x).
  3. (C) False — a zero remainder only means the received polynomial is divisible by g(x); an error pattern that is itself a multiple of g(x) escapes detection.
  4. (D) True — coefficients are in GF(2), so +1 = −1 and both operations are XOR.

Answer: Options (A), (B) and (D).

Common misconception. Statement (C) is the classic over-claim. CRC is a detection scheme with a small, bounded probability of a missed error, not a guarantee — which is exactly why (D)'s algebraic view matters.

Takeaway. Learn the two guarantees (all single-bit errors; all bursts of length ≤ r) and the one non-guarantee (no error-free certification).

CN-U1-Q24MCQhard

A datagram header is to be protected by the 16-bit Internet checksum. The three 16-bit words to be summed are 0x1234, 0x5678 and 0x9ABC. Using one's complement arithmetic, what is the checksum field value?

  1. 0x0369
  2. 0xFC96
  3. 0xFC95
  4. 0xFC69
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. The Internet checksum adds the 16-bit words in one's complement arithmetic (end-around carry), then takes the one's complement of the result.

Step by step.

  1. 0x1234 + 0x5678 = 0x68AC.
  2. 0x68AC + 0x9ABC = 0x10368, which overflows 16 bits.
  3. End-around carry: 0x0368 + 1 = 0x0369.
  4. Checksum = one's complement of 0x0369 = 0xFFFF − 0x0369 = 0xFC96.

Answer: Option (B) — 0xFC96.

Common misconception. Dropping the end-around carry gives 0xFC95, and forgetting the complement gives 0x0369; both are offered as options. Note that 0xFC96 is not the arithmetic negation in two's complement either.

Takeaway. Checksum routine: sum with wraparound, fold the carry in, then complement. Verify by adding the checksum back — the total must be 0xFFFF.

CN-U1-Q25NATmedium

A CRC is computed with the generator polynomial x³ + 1, whose bit pattern is 1001. The message bits are 1101 and three zeros are appended before division.
Enter the decimal value of the resulting 3-bit remainder.

Show answer & solution

Answer: 4

Detailed solution

Concept. CRC division is long division over GF(2): align the divisor under the leading 1 of the current remainder and XOR, with no borrows or carries.

Step by step.

  1. Append three zeros: 1101000.
  2. Leading 4 bits 1101 ⊕ 1001 = 0100; bring down 0 → 1000; 1000 ⊕ 1001 = 0001.
  3. Bring down the next 0 → 0010; the leading bit is 0, so XOR nothing. Bring down the last 0 → 0100; again nothing.
  4. The 3-bit remainder is 100, i.e. 4 in decimal.

Answer: 4 (remainder 100).

Common misconception. The trap is ordinary binary subtraction with borrows. In GF(2) there is no borrow: XOR is the only operation, so a step where the leading bit is 0 just shifts down the next bit.

Takeaway. For a degree-r generator the remainder is always r bits; read it as a plain binary number if the answer must be decimal.
