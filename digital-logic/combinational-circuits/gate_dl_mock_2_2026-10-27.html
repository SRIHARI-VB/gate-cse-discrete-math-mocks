DL-U1-Q01MCQeasy

The octal number (756)8 is equal to which one of the following binary strings?

  1. 111101110
  2. 111110110
  3. 111101100
  4. 111011110
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Base 8 and base 2 are linked by 8 = 23, so each octal digit is replaced by exactly three bits, independently of its neighbours.

Step by step.

  1. Split the octal number into its digits: 7, 5, 6.
  2. Convert each digit on its own: 7 = 111, 5 = 101, 6 = 110.
  3. Concatenate without dropping zeros: 111 101 110.
  4. Check through decimal: (756)8 = 7×64 + 5×8 + 6 = 448 + 40 + 6 = 494, and 1111011102 = 256 + 128 + 64 + 32 + 8 + 4 + 2 = 494.

Answer: 1111011102

Common misconception. Converting through decimal and then writing the binary of each digit separately, which silently introduces decimal-to-binary errors; or grouping in four bits, which is the rule for hexadecimal, not octal.

Takeaway. Fix the group width before you start: 3 bits per octal digit, 4 bits per hex digit, and never drop a leading zero inside a group.

DL-U1-Q02MCQeasy

What is the minimum number of bits needed to represent the decimal number 1000 as an unsigned binary integer?

  1. 9
  2. 10
  3. 11
  4. 12
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. An unsigned binary number with n bits spans 0 to 2n − 1, so the requirement is 2n − 1 ≥ N, that is n ≥ ⌈log2(N + 1)⌉.

Step by step.

  1. Compute the powers around 1000: 29 = 512 and 210 = 1024.
  2. Nine bits reach only 511, which is below 1000.
  3. Ten bits reach 1023, and 1000 ≤ 1023, so ten bits suffice.

Answer: 10 bits

Common misconception. Answering 9 because 29 = 512 feels close to 1000, or using log10 instead of log2.

Takeaway. Count bits by the largest value the width can hold, not by the first power that looks large enough.

Which of the following represent the decimal value 255? (Select all that apply.)

  1. 0xFF in hexadecimal
  2. (377)8 in octal
  3. 11111111 in binary
  4. 0x1FF in hexadecimal
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. The same quantity has one representation per base, so each option must be converted to decimal and compared with 255.

Step by step.

  1. 0xFF = 15×16 + 15 = 255. True.
  2. (377)8 = 3×64 + 7×8 + 7 = 192 + 56 + 7 = 255. True.
  3. 111111112 = 28 − 1 = 255. True.
  4. 0x1FF = 1×256 + 15×16 + 15 = 511. False.

Common misconception. Treating 0x1FF as "FF plus a bit" and assuming it is still 255; in hexadecimal each extra digit multiplies the value by 16.

Takeaway. 0xFF is the largest 8-bit value; adding a hex digit pushes the number into the 9-bit range.

DL-U1-Q11MCQmedium

The binary fraction (0.1101)2 equals which decimal value?

  1. 0.8125
  2. 0.6875
  3. 0.875
  4. 0.625
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Bits to the right of the point carry the weights 2−1, 2−2, 2−3, and so on, so the digits are summed as fractions, not as integers.

Step by step.

  1. 1 × 2−1 = 0.5
  2. 1 × 2−2 = 0.25
  3. 0 × 2−3 = 0
  4. 1 × 2−4 = 0.0625
  5. Sum: 0.5 + 0.25 + 0 + 0.0625 = 0.8125.

Answer: 0.8125

Common misconception. Reading the four bits as the integer 13 and writing 0.13, or reversing the weight order and getting 0.6875.

Takeaway. Fractional bits halve as they move right; four bits can express only multiples of 1/16.

DL-U1-Q12MCQmedium

In which base b is the numeral (121)b equal to the decimal number 100?

  1. 9
  2. 8
  3. 10
  4. 11
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A positional numeral is evaluated by expanding its digits against powers of the base, which turns the question into an equation in b.

Step by step.

  1. Expand: (121)b = 1·b2 + 2·b + 1.
  2. Recognise the perfect square: b2 + 2b + 1 = (b + 1)2.
  3. Set (b + 1)2 = 100, so b + 1 = 10 and b = 9.
  4. Verify: (121)9 = 81 + 18 + 1 = 100.

Answer: b = 9

Common misconception. Trying bases by eye and stopping at 10 because 121 looks familiar in decimal; the digit 2 is legal in every base above 2, so legality alone does not identify the base.

Takeaway. Whenever the digits form a symmetric pattern, look for a perfect-square or perfect-cube structure before expanding.

  4. For any base b > 1, the numeral (1000)b equals b3.
Show answer & solution

Answer: Options (A), (B), (D)

Detailed solution

Concept. Conversion between base 2 and base 2k is mechanical because each digit of the larger base is exactly k bits.

Step by step.

The 8-bit two's complement pattern 1111 0000 represents which decimal integer?

  1. −16
  2. −15
  3. −112
  4. +240
Show answer & solution

Detailed solution

Concept. For an n-bit pattern whose leading bit is 1, the two's complement value is the unsigned value minus 2n.

DL-U1-Q13MCQmedium

In 8-bit two's complement arithmetic, the operation 0110 1001 − 1101 0110 produces which result, and does signed overflow occur?

  1. 1001 0011, and overflow occurs
  2. 1001 0011, and no overflow occurs
  3. 0100 1011, and overflow occurs
  4. 0011 0111, and no overflow occurs
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Subtraction is implemented as addition of the two's complement of the subtrahend, and signed overflow is decided by the signs of the operands and the result, not by the carry out.

Step by step.

  1. Interpret the operands: 0110 1001 = 105 and 1101 0110 = 214 − 256 = −42.
  2. The operation is 105 − (−42) = 105 + 42 = 147.
  3. The 8-bit signed range is −128 to +127, and 147 lies outside it, so signed overflow occurs.
  4. The bit pattern produced is 147 − 256 = −109, that is 1001 0011.
  5. Consistency check: both operands were positive after negation, and the result has its sign bit set, which is exactly the overflow signature.

Answer: 1001 0011, with overflow

Common misconception. Assuming that subtracting a negative number cannot overflow, or reading the carry out of the sign bit as an overflow flag; that carry detects unsigned wraparound only.

Takeaway. Overflow is a property of the operands' signs: two like-signed operands producing an unlike-signed result.

DL-U1-Q14MCQmedium

In 8-bit one's complement arithmetic, what is the value of (−5) + (−3) after the end-around carry is applied?

  1. −8
  2. −7
  3. +8
  4. −9
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. One's complement addition adds the patterns and folds the carry out of the sign position back into the least significant bit; the result is a one's complement pattern, so a leading 1 means a negative number whose magnitude is the bitwise complement.

Step by step.

  1. −5 in 8-bit one's complement: 0000 0101 inverted = 1111 1010.
  2. −3: 0000 0011 inverted = 1111 1100.
  3. Add: 1111 1010 + 1111 1100 = 1 1111 0110, a 9-bit intermediate.
  4. Fold the carry back: 1111 0110 + 1 = 1111 0111.
  5. Read the pattern: leading bit 1, so negate by inverting: 0000 1000 = 8, giving −8.

Answer: −8

Common misconception. Dropping the end-around carry, which leaves 1111 0110 and gives −9; that is the classic one-bit error in one's complement.

Takeaway. One's complement needs the carry folded back; two's complement simply discards the carry. That difference is why two's complement is used in hardware.

DL-U1-Q17MSQmedium

Which of the following statements about n-bit two's complement numbers are TRUE? (Select all that apply.)

  1. The negation of a value is obtained by inverting all its bits and adding 1.
  2. The most negative value −2n−1 has no positive counterpart in the same width.
  3. −1 is represented as all ones.
  4. For every value x, the n-bit sum x + (−x) is 0 without overflow.
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. Two's complement is a modular code: patterns are integers modulo 2n, with the upper half read as negative.

Step by step.

  1. Inverting and adding 1 computes the additive inverse modulo 2n, so statement A is true.
  2. The range is −2n−1 to 2n−1 − 1, which contains 2n−1 negatives but only 2n−1 − 1 positives, so −2n−1 is unmatched. Statement B is true.
  3. −1 is 2n − 1, whose n bits are all 1. Statement C is true.
  4. Take x = −2n−1. Its negation overflows, and the n-bit sum of the pattern with itself is 0 by wraparound but is not a valid result. Statement D is false.

Answer: Options (A), (B) and (C) only.

Common misconception. Believing every number has an opposite; the asymmetry of the range makes the most negative value its own negation.

Takeaway. The single exception at −2n−1 explains why negating the smallest value in a machine is a real and commonly hit bug.

DL-U1-Q23MCQhard

In an 8-bit two's complement system, the value stored in a register is 1000 0000. The negation operation (invert all bits, then add 1) is applied to it. What is the resulting pattern?

  1. 1000 0000, the same pattern
  2. 0000 0000, because the value is negated
  3. 0111 1111, the inverted pattern without the increment
  4. 1000 0001, because the operation adds one twice
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Negation is addition of the additive inverse modulo 2n; when the value is the most negative one, its inverse does not exist in the same width and the operation wraps onto itself.

Step by step.

  1. 1000 0000 has value −128, the most negative 8-bit two's complement number.
  2. Invert: 0111 1111.
  3. Add 1: 1000 0000.
  4. The pattern is unchanged and still decodes to −128, so the negation silently failed to change the value; +128 is not representable in 8 bits.

Answer: 1000 0000, unchanged

Common misconception. Assuming negation always flips the sign; it does so except at the single most negative value, where it overflows.

Takeaway. This is why the absolute value of the most negative integer is itself in C and Java; the fix is to widen before negating.

Answer: 8 gate delays (option C).

Common misconception. Counting the sum delay instead. The sum outputs settle later than the carry chain, but the question asks only about C4. A second error is multiplying 4 stages by 3 rather than by 2.

DL-U2-Q03NATeasy

A 4-bit parallel adder adds A3A2A1A0 and B3B2B1B0 and is built from the minimum number of half adders and full adders. How many full adders are required?

Show answer & solution

Answer: 3

Detailed solution

Concept. The least-significant bit position has no incoming carry, so it needs only a half adder; every higher position needs a full adder.

Step by step.

  1. Bit position 0 adds A0, B0 with Cin = 0. A half adder suffices: it has exactly the two inputs needed.
  2. Bit positions 1, 2 and 3 each add Ai, Bi and the carry from the position below, so each needs a full adder.
  3. Full adders required = 4 − 1 = 3.

Answer: 3 full adders (plus 1 half adder).

Common misconception. Answering 4 by assuming every stage is a full adder. Tying the LSB full adder's Cin to 0 wastes hardware; the minimum count is 3.

DL-U2-Q04MSQmedium

Which of the following statements about carry-lookahead adders (CLAs) are TRUE?

  1. A CLA reduces the carry propagation delay from O(n) to O(log n) compared with a ripple-carry adder.
  2. Generate and propagate are defined as Gi = Ai · Bi and Pi = Ai ⊕ Bi.
  3. The recurrence Ci+1 = Gi + Pi · Ci lets a single-level CLA derive every carry directly from the primary inputs rather than waiting stage by stage.
  4. A CLA of the same width needs less hardware than a ripple-carry adder.
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. Carry-lookahead trades hardware for delay: it computes generate and propagate signals in parallel and expands the carry recurrence in terms of the primary inputs.

Step by step.

  1. Statement A is true. Expanding the carry recurrence gives a two-level expression in the Gi and Pi signals, so the carry delay grows logarithmically rather than linearly.
  2. Statement B is true by definition: a stage generates a carry when both bits are 1, and propagates an incoming carry when exactly one bit is 1.
  3. Statement C is true. Ci+1 = Gi + Pi·Ci expanded recursively is a sum of products over the primary inputs, so no stage waits for its predecessor.
  4. Statement D is false. CLA needs extra AND/OR gates to build Gi, Pi and the expanded carry expressions; it is strictly larger than a ripple-carry adder of the same width.
  5. Correct set: A, B and C.

Answer: Options A, B and C are correct; D is false.

Common misconception. Assuming a faster adder must be a smaller adder. Lookahead buys delay with area — the two always move in opposite directions.

DL-U2-Q05MCQhard

An 8-bit two's-complement adder computes 0x7F + 0x01. Let Z, S, V and C be the zero, sign, overflow and carry-out flags respectively. Which set of flags is produced?

  1. Z = 0, S = 1, V = 1, C = 0
  2. Z = 0, S = 1, V = 0, C = 1
  3. Z = 1, S = 1, V = 1, C = 0
  4. Z = 0, S = 0, V = 1, C = 0
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. The four condition flags are independent: Z tests the whole result, S copies the MSB, V is the signed-overflow indicator and C is the carry out of the MSB.

Step by step.

  1. 0x7F = 0111 1111 and 0x01 = 0000 0001.
  2. Sum = 1000 0000 = 0x80. The result is non-zero, so Z = 0.
  3. The MSB of the result is 1, so S = 1.
  4. Both operands are positive (MSB 0) but the result is negative (MSB 1): a positive-plus-positive overflow, so V = 1.
  5. Bit 7 produces no carry out of the 8-bit word (0111 1111 + 1 stays inside), so C = 0.
  6. Hence Z = 0, S = 1, V = 1, C = 0.

Answer: Z = 0, S = 1, V = 1, C = 0 (option A).

Common misconception. Conflating overflow V with carry-out C. Signed overflow is detected by comparing operand and result signs (V = Cin ⊕ Cout at the MSB); the carry out of the word is a separate, unsigned quantity.

How many select lines does a 16-to-1 multiplexer require?

  2. 3
  3. 4
  4. 5
Show answer & solution

Answer: Option (C)

Detailed solution

Concept. An m-to-1 multiplexer needs ⌈log2 m⌉ select lines.

DL-U2-Q07MCQeasy

Using only an 8-to-1 multiplexer whose data inputs are tied to 0 or 1, any Boolean function of how many variables can be implemented?

  1. 2
  2. 3
  3. 4
  4. 8
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. A 2^n-to-1 multiplexer used with constants on its data inputs is a direct lookup table for any n-variable function.

Step by step.

  1. An 8-to-1 multiplexer has 8 data inputs and 3 select lines.
  2. Its truth table for a 3-variable function has 2^3 = 8 rows, one per data input.
  3. Tying each data input to 0 or 1 reproduces that truth table exactly, so any 3-variable function is realisable.

Common misconception. Answering 8 by reading the multiplexer size as the variable count. The variable count is the number of select lines, log2 8 = 3.

DL-U2-Q08NATmedium

What is the minimum number of 2-to-1 multiplexers required to construct a 16-to-1 multiplexer?

Show answer & solution

Answer: 15

Detailed solution

Concept. A 2^n-to-1 multiplexer built as a binary tree of 2-to-1 multiplexers needs 2^n − 1 of them.

Step by step.

  1. Level 1 combines the 16 data inputs into 8 outputs, using 8 multiplexers.
  2. Level 2 combines 8 into 4, using 4 multiplexers.
  3. Level 3 combines 4 into 2, using 2 multiplexers.
  4. Level 4 combines 2 into 1, using 1 multiplexer.
  5. Total = 8 + 4 + 2 + 1 = 15 = 16 − 1.

Answer: 15 multiplexers.

Common misconception. Answering 16 (one per data line) or 4 (one per level). A binary tree of N leaves always has exactly N − 1 internal nodes.

DL-U2-Q09MSQmedium

Which of the following statements about multiplexers are TRUE?

  1. A 4-to-1 multiplexer with data inputs tied to 0 or 1 can realise any Boolean function of two variables.
  2. A 2^n-to-1 multiplexer with n select lines can realise any Boolean function of n variables without extra gates.
  3. A 4-to-1 multiplexer has 4 select lines.
  4. A multiplexer can be used as a universal logic element.
Show answer & solution

Answer: Options (A), (B), (D)

Detailed solution

Concept. A multiplexer with constant data inputs is a truth-table lookup: the select lines are the variables and the data inputs are the function values.

Step by step.

  1. Statement A is true: a 2-variable truth table has 4 rows, matching the 4 data inputs of a 4-to-1 multiplexer.
  2. Statement B is true by the same argument: n select lines address 2^n data inputs, which is exactly the number of rows of an n-variable truth table.
  3. Statement C is false. A 4-to-1 multiplexer has log2 4 = 2 select lines and 4 data inputs.
  4. Statement D is true. Because it can realise any Boolean function with suitable data inputs, a multiplexer is a universal logic module.
  5. Correct set: A, B and D.

Answer: Options A, B and D are correct; C is false.

Common misconception. Believing the multiplexer size equals the number of select lines. The size counts data inputs; the select lines are log2 of that.

DL-U2-Q10MCQhard

The function f(A,B,C) = Σm(1,2,4,7) is implemented on an 8-to-1 multiplexer with A, B, C connected to S2, S1, S0 respectively and data inputs D0 … D7 tied to 0 or 1. Which assignment of D7 D6 D5 D4 D3 D2 D1 D0 is correct?

  1. 10010110
  2. 01101001
  3. 10101010
  4. 01011010
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. With A on the most significant select line, data input Di is selected when ABC = i, so Di must equal the function value at minterm i.

Step by step.

  1. The minterms present are 1 (001), 2 (010), 4 (100) and 7 (111). These are exactly the 3-bit patterns with an odd number of 1s, so f = A ⊕ B ⊕ C.
  2. The select inputs are S2 = A, S1 = B, S0 = C, so Di is chosen when ABC equals the binary value i.

Concept. A decoder asserts the output line whose index equals the binary value on its inputs.

DL-U2-Q12NATeasy

What is the minimum number of 3-to-8 decoders with enable inputs required to build a 5-to-32 decoder?

Show answer & solution

Answer: 4

Detailed solution

Concept. A larger decoder is built by using the extra input bits to select among smaller decoders through their enable inputs.

Step by step.

  1. The 5 inputs split into 2 high-order bits and 3 low-order bits.
  2. The 3 low-order bits address one of the 8 outputs inside a single 3-to-8 decoder.
  3. The 2 high-order bits must choose among 2^2 = 4 such decoders, each producing 8 outputs, giving 4 × 8 = 32 outputs.
  4. So 4 decoders are needed, each enabled by a distinct combination of the 2 high-order bits.

Answer: 4 decoders.

Common misconception. Answering 8 by dividing 32 by 4, or 5 by confusing input bits with decoder count. The count is 2^(input bits − 3) = 2^2 = 4.

DL-U2-Q13MCQmedium

A 3-to-8 decoder has active-high outputs O0 … O7 and inputs A B C with A the most significant bit. A single OR gate is used to realise f(A,B,C) = Σm(1,2,6,7). Which decoder outputs must feed the OR gate?

  1. O1, O2, O6, O7
  2. O1, O2, O5, O6
  3. O0, O3, O6, O7
  4. O1, O4, O6, O7
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A decoder generates every minterm; OR-ing the outputs for the minterms of a function realises its canonical sum-of-products.

Step by step.

  1. The decoder output Oi is 1 exactly when the input equals the binary value i, i.e. Oi is minterm mi.
  2. The function is the sum of minterms 1, 2, 6 and 7.
  3. A sum of minterms is realised by OR-ing precisely those decoder outputs: f = O1 + O2 + O6 + O7.

Answer: O1, O2, O6, O7 (option A).

DL-U2-Q14MSQhard

Which of the following statements about priority encoders are TRUE?

  1. An 8-to-3 priority encoder produces a 3-bit output code and, in a complete design, a valid-output indicator V.
  2. In a 4-to-2 priority encoder in which I3 has the highest priority, the input I3 I2 I1 I0 = 1001 produces the output 11.
  3. A priority encoder produces a valid output only when exactly one input line is asserted.
  4. A plain (non-priority) 8-to-3 encoder has undefined behaviour when more than one input line is asserted.
Show answer & solution

Answer: Options (A), (B), (D)

Detailed solution

Concept. A priority encoder resolves simultaneous assertions by encoding the highest-priority active input, so it is defined for every input combination.

Step by step.

  1. Statement A is true. The V line distinguishes the all-zero input from the case where I0 alone is asserted, since both would otherwise encode as 000.
  2. Statement B is true. I3 is the highest-priority line and it is asserted, so the output encodes index 3, which is 11; the asserted I0 is ignored.
  3. Statement C is false. That is the defining weakness of a plain encoder; a priority encoder is precisely the fix, and it accepts any number of asserted inputs.
  4. Statement D is true. A plain encoder assumes exactly one active input, so multiple assertions produce a meaningless combination of output bits.
  5. Correct set: A, B and D.

DL-U2-Q15NATmedium

An 8-to-3 priority encoder has inputs I7 … I0 with I7 the highest priority. If I6 = 1, I3 = 1 and I1 = 1 while every other input is 0, what is the decimal value of the 3-bit output?

Show answer & solution

Answer: 6

Detailed solution

Concept. A priority encoder outputs the index of the highest-numbered asserted input.

Step by step.

  1. The asserted inputs are I1, I3 and I6.
  2. Priority runs from I7 down to I0, so the highest-numbered asserted line wins: I6.
  3. The output encodes index 6 as a 3-bit binary value, 110, which is decimal 6.

DL-U2-Q16MCQeasy

The BCD digit 0101 is represented in excess-3 code as:

  1. 0111
  2. 1000
  3. 1001
  4. 1010
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Excess-3 adds 3 to the BCD value before encoding, so the code word equals the digit plus three.

Step by step.

  1. 0101 in BCD is the digit 5.
  2. Excess-3 code = BCD + 3 = 5 + 3 = 8.
  3. 8 in 4-bit binary is 1000.

Answer: 1000 (option B).

Common misconception. Subtracting 3 instead of adding it, which gives 0010. Excess-3 always adds, never subtracts.

DL-U2-Q17MCQmedium

The 4-bit binary number 1101 converted to Gray code is:

  1. 1011
  2. 1110
  3. 1010
  4. 1100
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Binary-to-Gray: keep the MSB unchanged and set each further Gray bit to the XOR of the adjacent binary bits.

Step by step.

  1. Write b3 b2 b1 b0 = 1 1 0 1.
  2. g3 = b3 = 1.
  3. g2 = b3 ⊕ b2 = 1 ⊕ 1 = 0.
  4. g1 = b2 ⊕ b1 = 1 ⊕ 0 = 1.
  5. g0 = b1 ⊕ b0 = 0 ⊕ 1 = 1.
  6. Gray code = 1011.

Answer: 1011 (option A).

Common misconception. XOR-ing the wrong neighbour (e.g. gi = bi ⊕ b(i−1) instead of bi ⊕ b(i+1)), which reverses the direction of the conversion and yields 1110.

DL-U2-Q18NATmedium

The 4-bit Gray code word 1110 represents which decimal value in binary?

Show answer & solution

Answer: 11

Detailed solution

Concept. Gray-to-binary: the MSB is copied, then each binary bit is the XOR of the previous binary bit with the current Gray bit.

Step by step.

  1. Write g3 g2 g1 g0 = 1 1 1 0.
  2. b3 = g3 = 1.
  3. b2 = b3 ⊕ g2 = 1 ⊕ 1 = 0.
  4. b1 = b2 ⊕ g1 = 0 ⊕ 1 = 1.
  5. b0 = b1 ⊕ g0 = 1 ⊕ 0 = 1.
  6. Binary = 1011, which is 8 + 2 + 1 = 11 in decimal.

Answer: 11 (binary 1011).

Common misconception. Applying the binary-to-Gray rule in the wrong direction, which would give 1001 = 9. The two conversions use opposite XOR neighbours and are not symmetric.

DL-U2-Q19MSQmedium

Which of the following decimal codes are self-complementing?

  1. 2421 code
  2. Excess-3 code
  3. 84-2-1 code
  4. 8421 BCD
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. A code is self-complementing when the 9's complement of a digit is obtained simply by complementing all four bits.

Step by step.

  1. 2421: digit d plus digit 9 − d sums bit-wise to 15 in every position, so complementing the bits gives the 9's complement. Self-complementing.
  2. Excess-3 is 8421 shifted by 3, so d + 3 and (9 − d) + 3 = 12 − d are bit-wise complements within 4 bits. Self-complementing.
  3. 84-2-1 weights satisfy the same condition, d and 9 − d giving bit-wise complementary patterns. Self-complementing.
  4. 8421 BCD is not self-complementing: complementing the bits of 0 (0000) gives 1111, which is not a valid BCD digit at all.
  5. Correct set: A, B and C.

Answer: Options A, B and C are correct; 8421 BCD is not self-complementing.

Common misconception. Assuming every weighted code is self-complementing. The property depends on the specific weight set, and plain 8421 fails it outright.

DL-U2-Q20MCQhard

In a 4-bit BCD-to-excess-3 converter with inputs A B C D (A most significant), the input combinations 1010 to 1111 are don't-cares. The minimal sum-of-products expression for the most significant output bit W is:

  1. A + BC + BD
  2. A + B + CD
  3. A + C + BD
  4. A + BC + CD
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Excess-3 adds 3 to the BCD digit, so the MSB of the result is 1 for every input of 5 or more, and the invalid inputs are don't-cares that can be grouped freely.

Step by step.

  1. W is the MSB of BCD + 3, so W = 1 for inputs 5, 6, 7, 8, 9; inputs 10 to 15 are don't-cares.
  2. Minterms of W: 5 (0101), 6 (0110), 7 (0111), 8 (1000), 9 (1001), plus don't-cares 10 to 15.

  1. a momentary 0 on an output that should remain 1 while a single input changes
  2. a momentary 1 on an output that should remain 0 while a single input changes

  4. a permanent incorrect steady-state value
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Hazards are classified by what the output does when it is supposed to stay put: static-1 dips, static-0 spikes.

Step by step.

  1. 'Static' means the steady-state value before and after the input change is the same.
  2. A static-1 hazard is a transient 0 while the output should hold at 1.
  3. Option B describes a static-0 hazard, option C a dynamic hazard, and option D a stuck-at fault rather than a hazard.

DL-U2-Q22MCQhard

The two-level sum-of-products realisation F = A'B' + AC' must be made free of static-1 hazards without changing the function. Which single additional product term achieves this?

  1. B'C'
  2. BC'
  3. A'C'
  4. No additional term is needed
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A static-1 hazard exists when two product terms are adjacent in the Karnaugh map but are covered by different implicants; adding their consensus term bridges the gap.

Step by step.

  1. A'B' covers minterms 0 (000) and 1 (001). AC' covers 4 (100) and 5 (101).
  2. Minterm 0 (000) and minterm 4 (100) are adjacent — they differ only in A — yet they lie in different implicants. When B = C = 0 and A switches, the output can dip: a static-1 hazard.
  3. The consensus of A'B' and AC' is obtained by dropping the complementary literal pair A/A' and keeping the rest: B'C'.
  4. B'C' covers 000, 001, 100, 101 — all already true minterms, so the function is unchanged and the hazard is removed.
  5. Hence the required term is B'C'.

Answer: B'C' (option A).

Common misconception. Adding BC' or A'C', which look symmetric but change the function or fail to bridge minterms 0 and 4. Only the consensus term preserves the function while covering the adjacency.

DL-U2-Q23MCQmedium

In a product-of-sums (POS) realisation, a static-0 hazard is eliminated by:

  1. adding a redundant sum term, namely the consensus of the two adjacent sum terms
  2. adding a redundant product term covering the two adjacent minterms
  3. adding inverters so that all paths have equal delay
  4. nothing — POS realisations cannot contain hazards
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Hazards are dual in the two standard forms: SOP needs a redundant product term, POS needs a redundant sum term.

Step by step.

  1. A static-0 hazard appears in a POS circuit when two adjacent sum terms are covered by different clauses.
  2. Adding the consensus of those two sum clauses keeps the function unchanged and holds the output at 0 across the transition.
  3. Adding a product term is the SOP remedy, not the POS one; delay matching is not a structural guarantee.
  4. Hence the remedy is the redundant consensus sum term.

DL-U2-Q24MSQeasy

DL-U2-Q25MCQeasy

A glitch in a combinational circuit is best described as:

  1. a temporary, unwanted output transition caused by unequal propagation delays along different paths
  2. a permanent stuck-at fault in a gate
  3. a race between two flip-flops in a sequential circuit
  4. a violation of the setup time of a flip-flop
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A glitch is a timing artefact of reconvergent paths, not a manufacturing or logical fault.

Step by step.

  1. A glitch is transient: it appears when an input changes and disappears once signals settle.
  2. It is caused by two paths from the changed input to the output having different delays, so the output briefly reflects an intermediate state.
