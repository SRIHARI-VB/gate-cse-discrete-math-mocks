Base conversions · 8
DL-U1-Q01MCQeasy

The octal number (756)8 is equal to which one of the following binary strings?

  1. 111101110
  2. 111110110
  3. 111101100
  4. 111011110
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Base 8 and base 2 are linked by 8 = 23, so each octal digit is replaced by exactly three bits, independently of its neighbours.

Step by step.

  1. Split the octal number into its digits: 7, 5, 6.
  2. Convert each digit on its own: 7 = 111, 5 = 101, 6 = 110.
  3. Concatenate without dropping zeros: 111 101 110.
  4. Check through decimal: (756)8 = 7×64 + 5×8 + 6 = 448 + 40 + 6 = 494, and 1111011102 = 256 + 128 + 64 + 32 + 8 + 4 + 2 = 494.

Answer: 1111011102

Common misconception. Converting through decimal and then writing the binary of each digit separately, which silently introduces decimal-to-binary errors; or grouping in four bits, which is the rule for hexadecimal, not octal.

Takeaway. Fix the group width before you start: 3 bits per octal digit, 4 bits per hex digit, and never drop a leading zero inside a group.

DL-U1-Q02MCQeasy

What is the minimum number of bits needed to represent the decimal number 1000 as an unsigned binary integer?

  1. 9
  2. 10
  3. 11
  4. 12
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. An unsigned binary number with n bits spans 0 to 2n − 1, so the requirement is 2n − 1 ≥ N, that is n ≥ ⌈log2(N + 1)⌉.

Step by step.

  1. Compute the powers around 1000: 29 = 512 and 210 = 1024.
  2. Nine bits reach only 511, which is below 1000.
  3. Ten bits reach 1023, and 1000 ≤ 1023, so ten bits suffice.

Answer: 10 bits

Common misconception. Answering 9 because 29 = 512 feels close to 1000, or using log10 instead of log2.

Takeaway. Count bits by the largest value the width can hold, not by the first power that looks large enough.

DL-U1-Q07MSQeasy

Which of the following represent the decimal value 255? (Select all that apply.)

  1. 0xFF in hexadecimal
  2. (377)8 in octal
  3. 11111111 in binary
  4. 0x1FF in hexadecimal
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. The same quantity has one representation per base, so each option must be converted to decimal and compared with 255.

Step by step.

  1. 0xFF = 15×16 + 15 = 255. True.
  2. (377)8 = 3×64 + 7×8 + 7 = 192 + 56 + 7 = 255. True.
  3. 111111112 = 28 − 1 = 255. True.
  4. 0x1FF = 1×256 + 15×16 + 15 = 511. False.

Answer: Options (A), (B) and (C) only.

Common misconception. Treating 0x1FF as "FF plus a bit" and assuming it is still 255; in hexadecimal each extra digit multiplies the value by 16.

Takeaway. 0xFF is the largest 8-bit value; adding a hex digit pushes the number into the 9-bit range.

DL-U1-Q09NATeasy

What is the decimal value of the unsigned binary number 1101011? (Enter an integer.)

Show answer & solution

Answer: 107

Detailed solution

Concept. Each bit contributes 2 raised to its position, counting positions from 0 at the right.

Step by step.

  1. Positions with a 1 are 6, 5, 3, 1 and 0.
  2. Add 26 + 25 + 23 + 21 + 20 = 64 + 32 + 8 + 2 + 1.
  3. The total is 107.

Answer: 107

Common misconception. Counting bit positions from the left, which turns 1101011 into 1 + 2 + 8 + 32 + 64 with the wrong weights.

Takeaway. Write the place values above the bits before adding; seven bits always end at 26 = 64.

DL-U1-Q11MCQmedium

The binary fraction (0.1101)2 equals which decimal value?

  1. 0.8125
  2. 0.6875
  3. 0.875
  4. 0.625
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Bits to the right of the point carry the weights 2−1, 2−2, 2−3, and so on, so the digits are summed as fractions, not as integers.

Step by step.

  1. 1 × 2−1 = 0.5
  2. 1 × 2−2 = 0.25
  3. 0 × 2−3 = 0
  4. 1 × 2−4 = 0.0625
  5. Sum: 0.5 + 0.25 + 0 + 0.0625 = 0.8125.

Answer: 0.8125

Common misconception. Reading the four bits as the integer 13 and writing 0.13, or reversing the weight order and getting 0.6875.

Takeaway. Fractional bits halve as they move right; four bits can express only multiples of 1/16.

DL-U1-Q12MCQmedium

In which base b is the numeral (121)b equal to the decimal number 100?

  1. 9
  2. 8
  3. 10
  4. 11
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A positional numeral is evaluated by expanding its digits against powers of the base, which turns the question into an equation in b.

Step by step.

  1. Expand: (121)b = 1·b2 + 2·b + 1.
  2. Recognise the perfect square: b2 + 2b + 1 = (b + 1)2.
  3. Set (b + 1)2 = 100, so b + 1 = 10 and b = 9.
  4. Verify: (121)9 = 81 + 18 + 1 = 100.

Answer: b = 9

Common misconception. Trying bases by eye and stopping at 10 because 121 looks familiar in decimal; the digit 2 is legal in every base above 2, so legality alone does not identify the base.

Takeaway. Whenever the digits form a symmetric pattern, look for a perfect-square or perfect-cube structure before expanding.

DL-U1-Q18MSQmedium

Which of the following conversions are correct? (Select all that apply.)

  1. 0x2F = 47
  2. (101110)2 = 46
  3. (64)8 = 52
  4. 0x100 = 255
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. Every claim of equality between bases is settled by expanding the numeral in powers of its own base.

Step by step.

  1. 0x2F = 2×16 + 15 = 47. Correct.
  2. (101110)2 = 32 + 8 + 4 + 2 = 46. Correct.
  3. (64)8 = 6×8 + 4 = 52. Correct.
  4. 0x100 = 1×256 = 256, not 255. Incorrect.

Answer: Options (A), (B) and (C) only.

Common misconception. Treating 0x100 as "the maximum three-digit hex value"; the maximum is 0xFF = 255, and 0x100 is one more.

Takeaway. A new digit position in base b multiplies the value by b, so 0x100 is 16 times 0x10.

DL-U1-Q25NAThard

What is the decimal value of the numeral (2026)7? (Enter an integer.)

Show answer & solution

Answer: 706

Detailed solution

Concept. A base-7 numeral is expanded against powers of 7, and the digit set is 0 to 6, so every digit here is legal.

Step by step.

  1. Positions from the right: 6×70, 2×71, 0×72, 2×73.
  2. Compute the powers: 70 = 1, 71 = 7, 72 = 49, 73 = 343.
  3. Sum: 2×343 + 0×49 + 2×7 + 6 = 686 + 0 + 14 + 6.
  4. The total is 706.

Answer: 706

Common misconception. Reading the numeral as decimal because the digits look familiar, or using powers of 10 for the higher positions.

Takeaway. Write the powers of the base first; a numeral's value depends only on its digits and its base, never on how it looks.

DL-U1-Q03MCQeasy

Which of the following is the 12-bit two's complement representation of the decimal number −21?

  1. 1111 1110 1011
  2. 1111 1110 1010
  3. 1000 0001 0101
  4. 1111 1111 1011
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Two's complement negation is invert-all-bits then add 1, and the width of the field must be fixed before the inversion.

Step by step.

  1. Write +21 in 12 bits: 0000 0001 0101.
  2. Invert every bit: 1111 1110 1010.
  3. Add 1: 1111 1110 1011.
  4. Check as an unsigned value: 1111 1110 1011 = 4096 − 21 = 4075, and 4075 − 4096 = −21.

Answer: 1111 1110 10112

Common misconception. Stopping at the inversion, which gives the one's complement (option B), or setting only the sign bit, which is sign-magnitude (option C).

Takeaway. This is a variation of GATE CSE 2019, Question 4 (−28 in 16-bit two's complement, official key option C). The width and the magnitude changed; the invert-and-add-one method did not.

DL-U1-Q04MCQeasy

The 8-bit two's complement pattern 1111 0000 represents which decimal integer?

  1. −16
  2. −15
  3. −112
  4. +240
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. For an n-bit pattern whose leading bit is 1, the two's complement value is the unsigned value minus 2n.

Step by step.

  1. Read the pattern as unsigned: 1111 0000 = 240.
  2. The leading bit is 1, so subtract 28 = 256: 240 − 256 = −16.
  3. Cross-check by negating: invert 1111 0000 to 0000 1111, add 1 to get 0001 0000 = 16, so the original is −16.

Answer: −16

Common misconception. Reading the pattern as the unsigned value 240, or inverting without adding 1 and reporting −15, which is the one's complement reading.

Takeaway. This is a variation of GATE CSE 2016, Set 1, Question 7 (the 16-bit pattern 1111 1111 1111 0101 has value −11). The subtraction of 2n is the whole method.

DL-U1-Q13MCQmedium

In 8-bit two's complement arithmetic, the operation 0110 1001 − 1101 0110 produces which result, and does signed overflow occur?

  1. 1001 0011, and overflow occurs
  2. 1001 0011, and no overflow occurs
  3. 0100 1011, and overflow occurs
  4. 0011 0111, and no overflow occurs
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Subtraction is implemented as addition of the two's complement of the subtrahend, and signed overflow is decided by the signs of the operands and the result, not by the carry out.

Step by step.

  1. Interpret the operands: 0110 1001 = 105 and 1101 0110 = 214 − 256 = −42.
  2. The operation is 105 − (−42) = 105 + 42 = 147.
  3. The 8-bit signed range is −128 to +127, and 147 lies outside it, so signed overflow occurs.
  4. The bit pattern produced is 147 − 256 = −109, that is 1001 0011.
  5. Consistency check: both operands were positive after negation, and the result has its sign bit set, which is exactly the overflow signature.

Answer: 1001 0011, with overflow

Common misconception. Assuming that subtracting a negative number cannot overflow, or reading the carry out of the sign bit as an overflow flag; that carry detects unsigned wraparound only.

Takeaway. Overflow is a property of the operands' signs: two like-signed operands producing an unlike-signed result.

DL-U1-Q14MCQmedium

In 8-bit one's complement arithmetic, what is the value of (−5) + (−3) after the end-around carry is applied?

  1. −8
  2. −7
  3. +8
  4. −9
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. One's complement addition adds the patterns and folds the carry out of the sign position back into the least significant bit; the result is a one's complement pattern, so a leading 1 means a negative number whose magnitude is the bitwise complement.

Step by step.

  1. −5 in 8-bit one's complement: 0000 0101 inverted = 1111 1010.
  2. −3: 0000 0011 inverted = 1111 1100.
  3. Add: 1111 1010 + 1111 1100 = 1 1111 0110, a 9-bit intermediate.
  4. Fold the carry back: 1111 0110 + 1 = 1111 0111.
  5. Read the pattern: leading bit 1, so negate by inverting: 0000 1000 = 8, giving −8.

Answer: −8

Common misconception. Dropping the end-around carry, which leaves 1111 0110 and gives −9; that is the classic one-bit error in one's complement.

Takeaway. One's complement needs the carry folded back; two's complement simply discards the carry. That difference is why two's complement is used in hardware.

DL-U1-Q17MSQmedium

Which of the following statements about n-bit two's complement numbers are TRUE? (Select all that apply.)

  1. The negation of a value is obtained by inverting all its bits and adding 1.
  2. The most negative value −2n−1 has no positive counterpart in the same width.
  3. −1 is represented as all ones.
  4. For every value x, the n-bit sum x + (−x) is 0 without overflow.
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. Two's complement is a modular code: patterns are integers modulo 2n, with the upper half read as negative.

Step by step.

  1. Inverting and adding 1 computes the additive inverse modulo 2n, so statement A is true.
  2. The range is −2n−1 to 2n−1 − 1, which contains 2n−1 negatives but only 2n−1 − 1 positives, so −2n−1 is unmatched. Statement B is true.
  3. −1 is 2n − 1, whose n bits are all 1. Statement C is true.
  4. Take x = −2n−1. Its negation overflows, and the n-bit sum of the pattern with itself is 0 by wraparound but is not a valid result. Statement D is false.

Answer: Options (A), (B) and (C) only.

Common misconception. Believing every number has an opposite; the asymmetry of the range makes the most negative value its own negation.

Takeaway. The single exception at −2n−1 explains why negating the smallest value in a machine is a real and commonly hit bug.

DL-U1-Q22MCQhard

What is the minimum number of bits in a two's complement register that can hold every integer from −1000 to +1000?

  1. 10
  2. 11
  3. 12
  4. 13
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. An n-bit two's complement register holds −2n−1 to 2n−1 − 1, so both ends of the required interval must be checked.

Step by step.

  1. With n = 10 the range is −512 to 511, which cannot hold 1000.
  2. With n = 11 the range is −1024 to 1023, which contains both −1000 and +1000.
  3. So 11 bits are necessary and sufficient.

Answer: 11 bits

Common misconception. Choosing 10 because 210 = 1024 exceeds 1000; that argument ignores the sign bit, which halves the positive range.

Takeaway. Solve the inequality 2n−1 ≥ 1001, not 2n ≥ 1000.

DL-U1-Q23MCQhard

In an 8-bit two's complement system, the value stored in a register is 1000 0000. The negation operation (invert all bits, then add 1) is applied to it. What is the resulting pattern?

  1. 1000 0000, the same pattern
  2. 0000 0000, because the value is negated
  3. 0111 1111, the inverted pattern without the increment
  4. 1000 0001, because the operation adds one twice
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Negation is addition of the additive inverse modulo 2n; when the value is the most negative one, its inverse does not exist in the same width and the operation wraps onto itself.

Step by step.

  1. 1000 0000 has value −128, the most negative 8-bit two's complement number.
  2. Invert: 0111 1111.
  3. Add 1: 1000 0000.
  4. The pattern is unchanged and still decodes to −128, so the negation silently failed to change the value; +128 is not representable in 8 bits.

Answer: 1000 0000, unchanged

Common misconception. Assuming negation always flips the sign; it does so except at the single most negative value, where it overflows.

Takeaway. This is why the absolute value of the most negative integer is itself in C and Java; the fix is to widen before negating.

DL-U1-Q06MCQeasy

In IEEE 754 single precision, the 8-bit exponent field is stored with which bias?

  1. 127
  2. 128
  3. 126
  4. 1023
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. IEEE 754 stores the exponent in excess-K form, where K = 2e−1 − 1 for an e-bit exponent field.

Step by step.

  1. Single precision uses an 8-bit exponent field, so the bias is 27 − 1 = 127.
  2. The stored field is the true exponent plus 127, so a stored 126 means the exponent is −1.
  3. Double precision uses an 11-bit field, whose bias is 210 − 1 = 1023.

Answer: 127

Common misconception. Using 128, the plain 27, which would shift every exponent by one; option D is the double-precision bias.

Takeaway. Bias = 2e−1 − 1, and the two reserved field values 0 and 255 are not ordinary exponents at all.

DL-U1-Q08MSQeasy

Which of the following statements about IEEE 754 formats are TRUE? (Select all that apply.)

  1. Single precision is laid out as 1 sign bit, 8 exponent bits and 23 fraction bits, 32 bits in all.
  2. The exponent is stored in excess-127 form.
  3. For normal numbers the leading 1 of the significand is not stored, giving an effective 24-bit significand.
  4. Double precision stores its exponent in an 8-bit field.
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. The IEEE 754 layout is a fixed field split whose widths decide precision and range; the significand is normalised so its leading bit need not be stored.

Step by step.

  1. Single precision: 1 + 8 + 23 = 32 bits. Statement A is true.
  2. The 8-bit exponent is biased by 127, so stored 127 means exponent 0. Statement B is true.
  3. Normalisation guarantees a leading 1, which is implied rather than stored, so 23 stored bits give 24 bits of significand. Statement C is true.
  4. Double precision is 1 + 11 + 52 = 64 bits, so its exponent field is 11 bits, not 8. Statement D is false.

Answer: Options (A), (B) and (C) only.

Common misconception. Believing the fraction field holds all the significand bits, or transferring the single-precision exponent width to double precision.

Takeaway. Learn the two layouts as the pairs (8, 23) and (11, 52); every other fact about IEEE 754 follows from them.

DL-U1-Q16MCQmedium

The IEEE 754 single precision bit pattern 0x3F000000 represents which value?

  1. 0.5
  2. 1.0
  3. 2.0
  4. 0.375
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Decoding a single-precision word means splitting it into sign, biased exponent and fraction, then applying (−1)s × 1.f × 2E−127.

Step by step.

  1. 0x3F000000 = 0011 1111 0000 0000 0000 0000 0000 0000.
  2. Sign bit 0, so the value is positive.
  3. Exponent field 0111 1110 = 126, so the true exponent is 126 − 127 = −1.
  4. Fraction field is all zeros, so the significand is 1.0.
  5. Value = 1.0 × 2−1 = 0.5.

Answer: 0.5

Common misconception. Subtracting 128 instead of 127, which shifts the answer by a factor of two and lands on 1.0 or 0.25.

Takeaway. Anchor yourself on three fixed words: 0x3F800000 is 1.0, 0x40000000 is 2.0, and halving subtracts one from the exponent field.

DL-U1-Q20NATmedium

The 32-bit word 0x41A00000 is an IEEE 754 single precision number. What decimal value does it represent? (Enter an integer.)

Show answer & solution

Answer: 20

Detailed solution

Concept. The value is (−1)s × (1 + f) × 2E−127, where f is the fraction field read as a binary fraction.

Step by step.

  1. 0x41A00000 = 0100 0001 1010 0000 0000 0000 0000 0000.
  2. Sign bit 0: positive.
  3. Exponent field 1000 0011 = 131, so the true exponent is 131 − 127 = 4.
  4. Fraction bits 010 followed by zeros: f = 0.25, so the significand is 1.25.
  5. Value = 1.25 × 24 = 1.25 × 16 = 20.

Answer: 20

Common misconception. Forgetting the implicit leading 1 and computing 0.25 × 16 = 4, or reading the fraction field as the integer 0xA0.

Takeaway. The implicit 1 is worth more than the whole fraction field: forgetting it is the most common single-precision decoding error.

DL-U1-Q21MCQhard

What is the smallest positive subnormal number representable in IEEE 754 single precision?

  1. 2−149
  2. 2−126
  3. 2−127
  4. 2−150
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A subnormal number has an all-zero exponent field, which is decoded as the minimum normal exponent 1 − 127 = −126 with no implicit leading 1; the fraction then contributes directly.

Step by step.

  1. Take the exponent field as 0, which decodes to 2−126 as the scale.
  2. With the implicit 1 suppressed, the value is f × 2−126.
  3. The smallest positive fraction is the last bit set: f = 2−23.
  4. Value = 2−23 × 2−126 = 2−149, about 1.4 × 10−45.

Answer: 2−149

Common misconception. Answering 2−126, which is the smallest positive normal number; subnormals exist precisely to go below it.

Takeaway. Subnormals trade significand precision for range: the exponent stops decreasing and the leading 1 is dropped instead.

DL-U1-Q05MCQeasy

Which range of integers can be stored in a 12-bit two's complement register?

  1. −2048 to +2047
  2. −2047 to +2047
  3. −4096 to +4095
  4. 0 to 4095
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. An n-bit two's complement field holds −2n−1 through 2n−1 − 1, because zero occupies one of the 2n patterns and there is no negative zero.

Step by step.

  1. With n = 12, the most negative value is −211 = −2048.
  2. The most positive value is 211 − 1 = 2047.
  3. Total patterns: 2048 + 2047 + 1 (for zero) = 4096 = 212.

Answer: −2048 to +2047

Common misconception. Assuming the range is symmetric, which is true of sign-magnitude and one's complement but false of two's complement; option C is the unsigned range reinterpreted.

Takeaway. Two's complement is asymmetric by exactly one: the negative side holds one extra value.

DL-U1-Q10NATeasy

How many distinct integer values can an 8-bit two's complement register hold? (Enter an integer.)

Show answer & solution

Answer: 256

Detailed solution

Concept. The number of distinct values a field can hold is 2n; what changes between representations is which values those are.

Step by step.

  1. An 8-bit field has 28 = 256 distinct bit patterns.
  2. Two's complement assigns each pattern a different integer: −128 through −1, zero, and 1 through 127.
  3. 128 + 1 + 127 = 256, so no pattern is wasted and none is duplicated.

Answer: 256

Common misconception. Answering 255 on the assumption that two patterns encode zero; that waste belongs to sign-magnitude and one's complement, which two's complement removes.

Takeaway. Two's complement covers all 2n patterns, which is exactly why its range is one wider on the negative side.

DL-U1-Q15MCQmedium

An 8-bit unsigned adder receives 1100 1000 and 0110 0100. What does it produce, and what is the carry out?

  1. 0010 1100 with carry-out 1
  2. 0010 1100 with carry-out 0
  3. 300 with carry-out 0
  4. 0010 1101 with carry-out 1
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. An unsigned adder works modulo 2n; the sum beyond the field width leaves through the carry-out, and the field keeps the remainder.

Step by step.

  1. Convert: 1100 1000 = 200 and 0110 0100 = 100.
  2. Exact sum: 300.
  3. 300 = 256 + 44, so the carry-out is 1 and the 8-bit field holds 44.
  4. 44 in binary is 0010 1100.

Answer: 0010 1100 with carry-out 1

Common misconception. Writing the mathematical answer 300, which an 8-bit field cannot hold; or calling the carry-out "overflow", which in unsigned arithmetic is simply the carry.

Takeaway. Unsigned: carry-out is the ninth bit. Signed: overflow is a sign anomaly. They are different flags.

DL-U1-Q19NATmedium

A 16-bit two's complement machine computes 30000 + 10000. The stored bit pattern is then read back as a 16-bit two's complement integer. What value is read? (Enter an integer, which may be negative.)

Show answer & solution

Answer: -25536

Detailed solution

Concept. Two's complement addition is addition modulo 2n; a result outside the representable range wraps by exactly 2n and the sign flips.

Step by step.

  1. The exact sum is 40000.
  2. The 16-bit signed range is −32768 to +32767, and 40000 exceeds it.
  3. Reduce modulo 65536: 40000 − 65536 = −25536.
  4. So the machine holds the pattern for −25536, which is 1001 1100 0100 0000.

Answer: −25536

Common misconception. Subtracting 32768 instead of 65536, which gives +7232; the modulus is the number of patterns, 216, not the magnitude of the most negative value.

Takeaway. When a signed sum overflows, the wrap amount is 2n, and the sign of the result flips from positive to negative.

DL-U1-Q24MSQhard

Which of the following statements about signed overflow in n-bit two's complement addition are TRUE? (Select all that apply.)

  1. Overflow occurs exactly when both operands have the same sign and the result has the opposite sign.
  2. Overflow cannot occur when the two operands have opposite signs.
  3. The carry out of the sign bit is by itself a correct signed overflow indicator.
  4. Overflow occurs exactly when the carry into the sign bit differs from the carry out of it.
Show answer & solution

Answer: Options (A), (B), (D)

Detailed solution

Concept. Signed overflow means the true sum lies outside −2n−1..2n−1−1; it is a statement about magnitudes, and it is equivalent to a mismatch between the two carries at the sign position.

Step by step.

  1. If the operands have the same sign, their magnitudes add; the sum can only leave the range on the far side, so the sign must flip. Statement A is true.
  2. With opposite signs the true sum lies strictly between the operands, hence inside the range. Statement B is true.
  3. The carry out of the sign bit is the unsigned carry; for example −1 + −1 produces a carry out of 1 while being perfectly valid, and 127 + 1 produces no carry out while overflowing. Statement C is false.
  4. Adding the carries into and out of the sign position: they agree exactly when no overflow occurred. Statement D is true.

Answer: Options (A), (B) and (D) only.

Common misconception. Confusing the unsigned carry flag with the signed overflow flag; hardware keeps them as two separate flags for exactly this reason.

Takeaway. The two-carry rule is the one a datapath can implement with a single XOR gate, and it is the definition to quote in an exam.

  • Base conversions.
