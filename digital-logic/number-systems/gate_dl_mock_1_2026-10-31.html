DL-U1-Q01MCQeasy

The octal number (756)8 is equal to which one of the following binary strings?

  1. 111101110
  2. 111110110
  3. 111101100
  4. 111011110
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Base 8 and base 2 are linked by 8 = 23, so each octal digit is replaced by exactly three bits, independently of its neighbours.

Step by step.

  1. Split the octal number into its digits: 7, 5, 6.
  2. Convert each digit on its own: 7 = 111, 5 = 101, 6 = 110.
  3. Concatenate without dropping zeros: 111 101 110.
  4. Check through decimal: (756)8 = 7×64 + 5×8 + 6 = 448 + 40 + 6 = 494, and 1111011102 = 256 + 128 + 64 + 32 + 8 + 4 + 2 = 494.

Answer: 1111011102

Common misconception. Converting through decimal and then writing the binary of each digit separately, which silently introduces decimal-to-binary errors; or grouping in four bits, which is the rule for hexadecimal, not octal.

Takeaway. Fix the group width before you start: 3 bits per octal digit, 4 bits per hex digit, and never drop a leading zero inside a group.

DL-U1-Q02MCQeasy

What is the minimum number of bits needed to represent the decimal number 1000 as an unsigned binary integer?

  1. 9
  2. 10
  3. 11
  4. 12
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. An unsigned binary number with n bits spans 0 to 2n − 1, so the requirement is 2n − 1 ≥ N, that is n ≥ ⌈log2(N + 1)⌉.

Step by step.

  1. Compute the powers around 1000: 29 = 512 and 210 = 1024.
  2. Nine bits reach only 511, which is below 1000.
  3. Ten bits reach 1023, and 1000 ≤ 1023, so ten bits suffice.

Answer: 10 bits

Common misconception. Answering 9 because 29 = 512 feels close to 1000, or using log10 instead of log2.

Takeaway. Count bits by the largest value the width can hold, not by the first power that looks large enough.

DL-U1-Q07MSQeasy

Which of the following represent the decimal value 255? (Select all that apply.)

  1. 0xFF in hexadecimal
  2. (377)8 in octal
  3. 11111111 in binary
  4. 0x1FF in hexadecimal
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. The same quantity has one representation per base, so each option must be converted to decimal and compared with 255.

Step by step.

  1. 0xFF = 15×16 + 15 = 255. True.
  2. (377)8 = 3×64 + 7×8 + 7 = 192 + 56 + 7 = 255. True.
  3. 111111112 = 28 − 1 = 255. True.
  4. 0x1FF = 1×256 + 15×16 + 15 = 511. False.

Answer: Options (A), (B) and (C) only.

Common misconception. Treating 0x1FF as "FF plus a bit" and assuming it is still 255; in hexadecimal each extra digit multiplies the value by 16.

Takeaway. 0xFF is the largest 8-bit value; adding a hex digit pushes the number into the 9-bit range.

DL-U1-Q09NATeasy

What is the decimal value of the unsigned binary number 1101011? (Enter an integer.)

    Show answer & solution

    Answer: 107

    Detailed solution

    Concept. Each bit contributes 2 raised to its position, counting positions from 0 at the right.

    Step by step.

    1. Positions with a 1 are 6, 5, 3, 1 and 0.
    2. Add 26 + 25 + 23 + 21 + 20 = 64 + 32 + 8 + 2 + 1.
    3. The total is 107.

    Answer: 107

    Common misconception. Counting bit positions from the left, which turns 1101011 into 1 + 2 + 8 + 32 + 64 with the wrong weights.

    DL-U1-Q11MCQmedium

    The binary fraction (0.1101)2 equals which decimal value?

    1. 0.8125
    2. 0.6875
    3. 0.875
    4. 0.625
    Show answer & solution

    Answer: Option (A)

    Detailed solution

    Concept. Bits to the right of the point carry the weights 2−1, 2−2, 2−3, and so on, so the digits are summed as fractions, not as integers.

    Step by step.

    1. 1 × 2−1 = 0.5
    2. 1 × 2−2 = 0.25
    3. 0 × 2−3 = 0
    4. 1 × 2−4 = 0.0625
    5. Sum: 0.5 + 0.25 + 0 + 0.0625 = 0.8125.

    Answer: 0.8125

    Common misconception. Reading the four bits as the integer 13 and writing 0.13, or reversing the weight order and getting 0.6875.

    Takeaway. Fractional bits halve as they move right; four bits can express only multiples of 1/16.

    DL-U1-Q12MCQmedium

    In which base b is the numeral (121)b equal to the decimal number 100?

    1. 9
    2. 8
    3. 10
    4. 11
    Show answer & solution

    Answer: Option (A)

    Detailed solution

    Concept. A positional numeral is evaluated by expanding its digits against powers of the base, which turns the question into an equation in b.

    Step by step.

    1. Expand: (121)b = 1·b2 + 2·b + 1.
    2. Recognise the perfect square: b2 + 2b + 1 = (b + 1)2.
    3. Set (b + 1)2 = 100, so b + 1 = 10 and b = 9.
    4. Verify: (121)9 = 81 + 18 + 1 = 100.

    Answer: b = 9

    Common misconception. Trying bases by eye and stopping at 10 because 121 looks familiar in decimal; the digit 2 is legal in every base above 2, so legality alone does not identify the base.

    Takeaway. Whenever the digits form a symmetric pattern, look for a perfect-square or perfect-cube structure before expanding.

    DL-U1-Q18MSQmedium

    Which of the following conversions are correct? (Select all that apply.)

    1. 0x2F = 47
    2. (101110)2 = 46
    3. (64)8 = 52
    4. 0x100 = 255
    Show answer & solution

    Answer: Options (A), (B), (C)

    Detailed solution

    Concept. Every claim of equality between bases is settled by expanding the numeral in powers of its own base.

    Step by step.

    1. 0x2F = 2×16 + 15 = 47. Correct.
    2. (101110)2 = 32 + 8 + 4 + 2 = 46. Correct.
    3. (64)8 = 6×8 + 4 = 52. Correct.
    4. 0x100 = 1×256 = 256, not 255. Incorrect.

    Answer: Options (A), (B) and (C) only.

    Common misconception. Treating 0x100 as "the maximum three-digit hex value"; the maximum is 0xFF = 255, and 0x100 is one more.

    Takeaway. A new digit position in base b multiplies the value by b, so 0x100 is 16 times 0x10.

      DL-U1-S2-Q03MCQmedium

      The octal sum (27)8 + (45)8 expressed in octal is

      1. (74)8
      2. (72)8
      3. (64)8
      4. (714)8
      Show answer & solution

      Answer: Option (A)

      Detailed solution

      Concept. Octal digits are added with a carry of 1 whenever a column reaches 8, exactly as decimal addition carries at 10.

      Step by step.

      1. Units column: 7 + 5 = 12 = 1×8 + 4, so write 4 and carry 1.
      2. Eights column: 2 + 4 + 1 = 7, which is below 8, so write 7 with no carry.
      3. Result: (74)8.
      4. Check in decimal: 23 + 37 = 60, and (74)8 = 7×8 + 4 = 60.

      Answer: (74)8

      Common misconception. Carrying at 10 out of habit gives (72)8 or (64)8; the carry point is the base, not the decimal ten.

      2. 0xD5F
      3. 0xED6
      4. 0xB6F

      Answer: Option (A)

      Concept. Hexadecimal and binary are linked by 16 = 24, so the bits are grouped in fours starting from the binary point.

      DL-U1-S2-Q05MSQmedium

      Which of the following statements about base conversion are TRUE? (Select all that apply.)

      1. Every octal digit expands to exactly three binary bits.
      2. Every hexadecimal digit expands to exactly four binary bits.
      3. Binary-to-octal conversion groups the bits in fours.
      4. For any base b > 1, the numeral (1000)b equals b3.
      Show answer & solution

      Answer: Options (A), (B), (D)

      Detailed solution

      Concept. Conversion between base 2 and base 2k is mechanical because each digit of the larger base is exactly k bits.

      Step by step.

      1. (A) 8 = 23, so one octal digit is three bits, including leading zeros inside the group: 1 = 001. True.
      2. (B) 16 = 24, so one hexadecimal digit is four bits: A = 1010. True.
      3. (C) Octal needs groups of three, not four; fours belong to hexadecimal. False.
      4. (D) In base b the numeral 1000 has value 1×b3 + 0 + 0 + 0 = b3. True.

      Answer: (A), (B) and (D)

      Common misconception. Option (C) is the standard slip: the group width must match the power of two that the base is, so three bits for octal and four for hexadecimal.

          Which of the following is the 12-bit two's complement representation of the decimal number -21?

          1. 1111 1110 1011
          2. 1111 1110 1010
          3. 1000 0001 0101
          4. 1111 1111 1011
          Show answer & solution

          Answer: Option (A)

          Detailed solution

          Concept. Two's complement negation is invert-all-bits then add 1, and the width of the field must be fixed before the inversion.

          Step by step.

          1. Write +21 in 12 bits: 0000 0001 0101.
          2. Invert every bit: 1111 1110 1010.
          3. Add 1: 1111 1110 1011.
          4. Check as an unsigned value: 1111 1110 1011 = 4096 − 21 = 4075, and 4075 − 4096 = −21.

          DL-U1-Q04MCQeasy

          The 8-bit two's complement pattern 1111 0000 represents which decimal integer?

          1. -16
          2. -15
          3. -112
          4. +240
          Show answer & solution

          Answer: Option (A)

          Detailed solution

          Concept. For an n-bit pattern whose leading bit is 1, the two's complement value is the unsigned value minus 2n.

          Step by step.

          1. Read the pattern as unsigned: 1111 0000 = 240.
          2. The leading bit is 1, so subtract 28 = 256: 240 − 256 = −16.
          3. Cross-check by negating: invert 1111 0000 to 0000 1111, add 1 to get 0001 0000 = 16, so the original is −16.

          Answer: −16

          Common misconception. Reading the pattern as the unsigned value 240, or inverting without adding 1 and reporting −15, which is the one's complement reading.

          Takeaway. This is a variation of GATE CSE 2016, Set 1, Question 7 (the 16-bit pattern 1111 1111 1111 0101 has value −11). The subtraction of 2n is the whole method.

          DL-U1-Q13MCQmedium

          In 8-bit two's complement arithmetic, the operation 0110 1001 - 1101 0110 produces which result, and does signed overflow occur?

          1. 1001 0011, and overflow occurs
          2. 1001 0011, and no overflow occurs
          3. 0100 1011, and overflow occurs
          4. 0011 0111, and no overflow occurs
          Show answer & solution

          Answer: Option (A)

          Detailed solution

          Concept. Subtraction is implemented as addition of the two's complement of the subtrahend, and signed overflow is decided by the signs of the operands and the result, not by the carry out.

          Step by step.

          1. Interpret the operands: 0110 1001 = 105 and 1101 0110 = 214 − 256 = −42.
          2. The operation is 105 − (−42) = 105 + 42 = 147.
          3. The 8-bit signed range is −128 to +127, and 147 lies outside it, so signed overflow occurs.
          4. The bit pattern produced is 147 − 256 = −109, that is 1001 0011.
          5. Consistency check: both operands were positive after negation, and the result has its sign bit set, which is exactly the overflow signature.

          Answer: 1001 0011, with overflow

          Common misconception. Assuming that subtracting a negative number cannot overflow, or reading the carry out of the sign bit as an overflow flag; that carry detects unsigned wraparound only.

          Takeaway. Overflow is a property of the operands' signs: two like-signed operands producing an unlike-signed result.

          DL-U1-Q14MCQmedium

          In 8-bit one's complement arithmetic, what is the value of (-5) + (-3) after the end-around carry is applied?

          1. -8
          2. -7
          3. +8
          4. -9
          Show answer & solution

          Answer: Option (A)

          Detailed solution

          Concept. One's complement addition adds the patterns and folds the carry out of the sign position back into the least significant bit; the result is a one's complement pattern, so a leading 1 means a negative number whose magnitude is the bitwise complement.

          Step by step.

          1. −5 in 8-bit one's complement: 0000 0101 inverted = 1111 1010.
          2. −3: 0000 0011 inverted = 1111 1100.
          3. Add: 1111 1010 + 1111 1100 = 1 1111 0110, a 9-bit intermediate.
          4. Fold the carry back: 1111 0110 + 1 = 1111 0111.
          5. Read the pattern: leading bit 1, so negate by inverting: 0000 1000 = 8, giving −8.

          Answer: −8

          Common misconception. Dropping the end-around carry, which leaves 1111 0110 and gives −9; that is the classic one-bit error in one's complement.

          Takeaway. One's complement needs the carry folded back; two's complement simply discards the carry. That difference is why two's complement is used in hardware.

          DL-U1-Q17MSQmedium

          Which of the following statements about n-bit two's complement numbers are TRUE? (Select all that apply.)

          1. The negation of a value is obtained by inverting all its bits and adding 1.
          2. The most negative value -2n-1 has no positive counterpart in the same width.
          3. -1 is represented as all ones.
          4. For every value x, the n-bit sum x + (-x) is 0 without overflow.
          Show answer & solution

          Answer: Options (A), (B), (C)

          Detailed solution

          Concept. Two's complement is a modular code: patterns are integers modulo 2n, with the upper half read as negative.

          Step by step.

          1. Inverting and adding 1 computes the additive inverse modulo 2n, so statement A is true.
          2. The range is −2n−1 to 2n−1 − 1, which contains 2n−1 negatives but only 2n−1 − 1 positives, so −2n−1 is unmatched. Statement B is true.
          3. −1 is 2n − 1, whose n bits are all 1. Statement C is true.
          4. Take x = −2n−1. Its negation overflows, and the n-bit sum of the pattern with itself is 0 by wraparound but is not a valid result. Statement D is false.

          Answer: Options (A), (B) and (C) only.

          Common misconception. Believing every number has an opposite; the asymmetry of the range makes the most negative value its own negation.

          Takeaway. The single exception at −2n−1 explains why negating the smallest value in a machine is a real and commonly hit bug.

          DL-U1-Q22MCQhard

          What is the minimum number of bits in a two's complement register that can hold every integer from -1000 to +1000?

          1. 10
          2. 11
          3. 12
          4. 13
          Show answer & solution

          Answer: Option (B)

          Detailed solution

          Concept. An n-bit two's complement register holds −2n−1 to 2n−1 − 1, so both ends of the required interval must be checked.

          Step by step.

          1. With n = 10 the range is −512 to 511, which cannot hold 1000.
          2. With n = 11 the range is −1024 to 1023, which contains both −1000 and +1000.
          3. So 11 bits are necessary and sufficient.

          Takeaway. Solve the inequality 2n−1 ≥ 1001, not 2n ≥ 1000.

          DL-U1-Q23MCQhard

          In an 8-bit two's complement system, the value stored in a register is 1000 0000. The negation operation (invert all bits, then add 1) is applied to it. What is the resulting pattern?

          1. 1000 0000, the same pattern
          2. 0000 0000, because the value is negated
          3. 0111 1111, the inverted pattern without the increment
          4. 1000 0001, because the operation adds one twice
          Show answer & solution

          Answer: Option (A)

          Detailed solution

          Concept. Negation is addition of the additive inverse modulo 2n; when the value is the most negative one, its inverse does not exist in the same width and the operation wraps onto itself.

          Step by step.

          1. 1000 0000 has value −128, the most negative 8-bit two's complement number.
          2. Invert: 0111 1111.
          3. Add 1: 1000 0000.
          4. The pattern is unchanged and still decodes to −128, so the negation silently failed to change the value; +128 is not representable in 8 bits.

          Answer: 1000 0000, unchanged

          Common misconception. Assuming negation always flips the sign; it does so except at the single most negative value, where it overflows.

          Takeaway. This is why the absolute value of the most negative integer is itself in C and Java; the fix is to widen before negating.

                                                                                1. Setup: tcq,max + tcomb,max + tsu ≤ T + δ, built from maximum delays, because a late arrival breaks it.
                                                                                2. Hold: tcq,min + tcomb,min ≥ th + δ, built from minimum delays, because an early change breaks it.
                                                                                3. The two checks therefore use different corners of the same path: slow corner for setup, fast corner for hold.

                                                                                Answer: The largest possible delay

                                                                                Common misconception. Using minimum delays for both checks, which silently assumes the logic is as fast as possible. Setup is decided by the slowest path, so minimum delays make the check look easier than it is.

                                                                                Takeaway. Setup is a race against the next edge and uses slow delays; hold is a race against the same edge and uses fast delays.

                                                                                DL-U4-S2-Q14MCQhard

                                                                                On a path between two flip-flops, tcq,min = 1.0 ns, tcomb,min = 0.8 ns and th = 1.2 ns. The setup check is already met at the operating frequency. What is the largest positive skew, that is the largest amount by which the destination clock may arrive later than the source clock, that does not create a hold violation?

                                                                                1. 0.4 ns
                                                                                2. 0.6 ns
                                                                                3. 1.8 ns
                                                                                4. 2.0 ns
                                                                                Show answer & solution

                                                                                Answer: Option (B)

                                                                                Detailed solution

                                                                                Concept. Positive skew delays the capturing edge, which gives the data more time for setup but less time before the capturing edge must stop sampling. The hold inequality is tcq,min + tcomb,min ≥ th + δ, so skew enters with a plus sign and shrinks the margin.

                                                                                Step by step.

                                                                                1. Earliest the data can change after the launching edge: 1.0 + 0.8 = 1.8 ns.
                                                                                2. The capturing edge must have finished sampling by th + δ = 1.2 + δ after the launching edge.
                                                                                3. Hold requires 1.2 + δ ≤ 1.8, so δ ≤ 0.6 ns.
                                                                                4. The largest positive skew that is still safe is 0.6 ns. Beyond that the data may change before the hold window closes.

                                                                                Answer: 0.6 ns

                                                                                Common misconception. Using the maximum delays in the hold inequality, or reversing the sign of the skew and answering 1.8 ns. Positive skew always hurts hold and always helps setup.

                                                                                Takeaway. Skew is a trade: every nanosecond of positive skew bought for setup is a nanosecond taken from hold.

                                                                                DL-U4-S2-Q15MCQmedium

                                                                                Two combinational paths run between the same pair of flip-flops. Path P has a delay between 3.5 ns and 5.0 ns; path Q has a delay between 0.5 ns and 4.0 ns. Which statement is correct?

                                                                                1. P sets the maximum clock frequency and Q is the path that can violate hold.
                                                                                2. Q sets the maximum clock frequency and P is the path that can violate hold.
                                                                                3. Both the maximum frequency and the hold check are decided by Q.
                                                                                4. Both the maximum frequency and the hold check are decided by P.
                                                                                Show answer & solution

                                                                                Answer: Option (A)

                                                                                Detailed solution

                                                                                Concept. Setup is limited by the slowest path and hold by the fastest, and these need not be the same path. With several paths between the same registers, each check is decided by its own worst case.

                                                                                Step by step.

                                                                                1. Setup uses the largest delay: 5.0 ns on P against 4.0 ns on Q, so P decides the period.
                                                                                2. Hold uses the smallest delay: 0.5 ns on Q against 3.5 ns on P, so Q is the path that can change too early.
                                                                                3. The two checks therefore point at different paths, which is exactly why a static timing report lists the setup critical path and the hold critical path separately.

                                                                                Answer: P decides setup, Q decides hold

                                                                                Common misconception. Assuming the path with the largest delay is also the path with the smallest delay, so that one "critical path" is reported for both checks. Long delay and short delay are independent properties.

                                                                                Takeaway. There is no single critical path. Setup has one, hold has another.

                                                                                DL-U4-S2-Q20MSQmedium

                                                                                Take positive skew to mean that the clock at the capturing flip-flop arrives later than the clock at the launching flip-flop. Which of the following statements are TRUE? (Select all that apply.)

                                                                                1. Positive skew relaxes the setup check.
                                                                                2. Positive skew tightens the hold check.
                                                                                3. Negative skew can turn a satisfied hold check into a violation.
                                                                                4. Adding delay on a very short path can repair a hold violation but reduces the setup margin on that path.
                                                                                Show answer & solution

                                                                                Answer: Options (A), (B), (D)

                                                                                Detailed solution

                                                                                Concept. Skew appears with a plus sign on the right of the setup inequality and with a plus sign on the right of the hold inequality as well, so the same skew helps one check and hurts the other.

                                                                                Step by step.

                                                                                1. Setup: tcq + tcomb,max + tsu ≤ T + δ. A larger δ gives the data more time, so positive skew relaxes setup.
                                                                                2. Hold: tcq,min + tcomb,min ≥ th + δ. A larger δ means the data must hold longer, so positive skew tightens hold.
                                                                                3. (C) False. Negative skew makes the hold right-hand side smaller, which makes hold easier to satisfy; it is setup that negative skew endangers.
                                                                                4. (D) True. A delay buffer slows the earliest arrival, which fixes hold, but it also slows the latest arrival, which eats setup margin.

                                                                                Answer: Options (A), (B) and (D) only

                                                                                Common misconception. Treating skew as unconditionally good or unconditionally bad. Skew is a shift of one edge relative to another, so it can only trade one check against the other.

                                                                                Takeaway. Positive skew: good for setup, bad for hold. Negative skew: the reverse.

                                                                                DL-U4-S2-Q25NATmedium

                                                                                A path has tcq = 1.0 ns, tcomb,max = 3.5 ns and tsu = 0.7 ns. The clock reaches the destination flip-flop 0.2 ns later than the source flip-flop. What is the maximum clock frequency, in MHz?

                                                                                  Show answer & solution

                                                                                  Answer: 200

                                                                                  Detailed solution

                                                                                  Concept. With positive skew the destination edge arrives later, so the setup inequality becomes tcq + tcomb,max + tsu ≤ T + δ, where δ is the capture-minus-launch skew. Skew therefore subtracts from the required period.

                                                                                  Step by step.

                                                                                  1. Data path delay: 1.0 + 3.5 + 0.7 = 5.2 ns.
                                                                                  2. Requirement: 5.2 ≤ T + 0.2, that is T ≥ 5.0 ns.
                                                                                  3. Maximum frequency 1 / 5.0 ns = 200 MHz.
                                                                                  4. Check: at 200 MHz the period is 5 ns and the destination edge is 5.2 ns after the launching edge, exactly the 5.2 ns the path needs.

                                                                                  Answer: 200 MHz

                                                                                  Common misconception. Adding the skew instead of subtracting it, which gives T ≥ 5.4 ns and 188.7 MHz, or dropping the skew altogether and giving 192.3 MHz.

                                                                                  Takeaway. Positive skew buys setup time: subtract it from the period requirement, and remember it costs hold margin.

                                                                                  Concept map used to build the questions

                                                                                  • Place value is the whole of base conversion. A digit in position k carries the weight bk. Hex and octal are read off binary in groups of four and three from the right, so no decimal step is needed; the decimal step is the check, not the method.
                                                                                  • Two complement systems, one difference. One’s complement inverts, two’s complement inverts and adds one. That single increment removes the double zero, makes subtraction a plain addition with the carry out discarded, and leaves one value, −2n−1, without a positive counterpart.
                                                                                  • Weight, not pattern. The leading bit of a signed pattern carries the weight −2n−1; every other bit keeps its positive weight. Reading the pattern as unsigned is a different data type, not an error of arithmetic.
                                                                                  • IEEE 754 is a field split. Sign, biased exponent and fraction; bias 2k−1−1; an implicit leading 1 for normal numbers; spacing 2e−23 inside a binade, which is why integers above 224 stop being exact and why ties round to even.
                                                                                  • Range is an interval, overflow is a departure from it. Unsigned runs from 0 to 2n−1 and reports a wrap through the carry-out; two’s complement runs from −2n−1 to 2n−1−1 and reports a wrap through the overflow flag, which is the exclusive-or of the carry into and out of the sign bit. The two flags answer different questions about the same adder.

                                                                                  Connections. The adder and its two flags reappear in combinational circuits (Unit 2); the complement patterns reappear in signed arithmetic and in the ALU of the datapath unit; and the exponent-field arithmetic of IEEE 754 returns in floating-point datapath questions.
