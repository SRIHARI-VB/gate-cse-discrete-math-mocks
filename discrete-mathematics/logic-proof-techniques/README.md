## Why the paper sits here and not in a subtopic folder

A paper covers a whole unit, so it is filed at unit level and exists in exactly one
place. It is not copied into subtopic folders and it is not copied to the repository
root — the dashboard links to this one file. Duplicating a 150 KB self-contained paper
means two files that must stay byte-identical with nothing enforcing it.
