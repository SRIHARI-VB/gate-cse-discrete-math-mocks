DM-PL1-Q01MCQeasy

Which one of the following is a proposition — that is, a declarative statement that has exactly one definite truth value?

  1. x + 1 = 5
  2. Is it raining outside?
  3. Every even integer greater than 2 is a sum of two primes.
  4. Close the door, please.
Show answer & detailed solution

Detailed solution

Concept. A proposition is a declarative sentence that is either true or false, but not both. Interrogatives, imperatives and sentences with free variables are not propositions.

Step by step.

  1. (A) contains the free variable x, so its truth value changes with x; it is an open sentence (a predicate), not a proposition.
  2. (B) is a question and (D) is a command; neither has a truth value at all.
  3. (C) is a declarative sentence. Whether or not anyone can prove it, it is objectively either true or false, so it is a proposition. (It is Goldbach's conjecture, still open — but openness is about our knowledge, not about the statement's form.)

Answer: Option (C).

Why the other options are wrong.

  • (A) is a predicate; it becomes a proposition only after x is given a value.
  • (B) is interrogative and (D) is imperative; truth values do not apply.

Common misconception. Students often reject (C) with “nobody knows if it is true, so it is not a proposition”. Being unknown is not the same as being truth-valueless: a proposition only needs a definite truth value, not a known one.

Faster method. Ask two questions: is it declarative, and does it contain a free variable? If yes-then-no, it is a proposition.

Takeaway. “Open sentence ≠ proposition” and “unknown ≠ not a proposition” are the two traps in this standard GATE opener.

DM-PL1-Q11MCQmedium

Which one of the following sets of connectives is functionally complete — that is, able to express every Boolean function?

  1. {∧, ∨}
  2. {¬, →}
  3. {∨, →}
  4. {¬, ↔}
Show answer & detailed solution

Detailed solution

Concept. A set of connectives is functionally complete if every truth function can be written using only those connectives. {¬, ∧}, {¬, ∨}, {¬, →}, {↑} and {↓} are complete.

Step by step.

  1. (B) {¬, →}: ¬ is available directly, and p ∨ q ≡ ¬p → q, so ∨ is definable; with {¬, ∨} we already have a complete set. Hence {¬, →} is complete.
  2. (A) {∧, ∨}: both are monotone — replacing a false input by true never makes the output false — so no formula built from them alone can express ¬p.
  3. (C) {∨, →}: exhaustively, only 6 of the 16 binary functions are expressible; for instance no formula in one variable built from ∨ and → can produce ¬p or the constant F.
  4. (D) {¬, ↔}: ↔ and ¬ preserve the property “f(x,x) = f(y,y) for all x, y”, so only 8 of the 16 functions are reachable; ∧ is not one of them.

Answer: Option (B).

Why the other options are wrong.

  • (A) cannot express negation (monotonicity).
  • (C) reaches only 6 of the 16 binary truth functions.
  • (D) reaches only 8 of the 16.

Common misconception. Assuming any “reasonably rich” pair works. Completeness is a strong condition; {∧, ∨} fails because negation is unavailable, which is easy to forget.

Faster method. If the set contains ¬ plus anything that can build ∨ (or ∧), it is complete. Without ¬ you need a single connective such as ↑ or ↓.

Takeaway. NAND and NOR are each complete on their own; {∧, ∨} and {¬, ↔} are the classic incomplete traps.

DM-PL1-Q16MSQeasy

Which of the following are propositions? (Select all that apply.)

  1. 2 + 2 = 5
  2. x > 3
  3. New Delhi is the capital of India.
  4. Please submit your answer sheet before 5 p.m.
Show answer & detailed solution

Detailed solution

Concept. A proposition is a declarative sentence with exactly one truth value. It may be false — falsity does not disqualify it.

Step by step.

  1. (A) is declarative and false; false propositions are still propositions.
  2. (B) has a free variable, so its truth value depends on x; it is a predicate, not a proposition.
  3. (C) is declarative and true.
  4. (D) is a request; it has no truth value.

Answer: Options (A) and (C).

Why the other options are wrong.

  • (B) is an open sentence.
  • (D) is an imperative sentence.

Common misconception. Excluding (A) because it is false. A proposition needs a definite truth value, not the value “true”.

Faster method. Declarative + no free variable = proposition, regardless of truth value.

Takeaway. “2 + 2 = 5” is a proposition (a false one); “x > 3” is not.

DM-PL1-Q21NATeasy

For how many of the four truth assignments to (p, q) is the implication p → q TRUE?
(Enter an integer.)

Show answer & detailed solution

Detailed solution

Concept. p → q is false only when p is true and q is false; the other three rows make it true.

Step by step.

  1. (T,T): T → T = T.
  2. (T,F): T → F = F — the only false row.
  3. (F,T): F → T = T.
  4. (F,F): F → F = T.

Answer: 3.

Common misconception. Counting (F,F) as false. A false hypothesis makes the implication vacuously true, which is exactly why 3 and not 2 is the answer.

Faster method. False rows of an implication = 1 for each pair of variables; so true rows = 2ⁿ − 2ⁿ⁻¹ = 2 for n = 2 ... here simply 4 − 1 = 3.

Takeaway. p → q is true on 3 of the 4 rows and false on exactly one.

DM-PL2-Q01MCQeasy

Which one of the following sentences is not a proposition?

  1. 7 is an odd integer.
  2. Every integer greater than 1 has a prime divisor.
  3. Let n be an even integer.
  4. No real number has square −1.
Show answer & detailed solution

Detailed solution

Concept. A proposition is a declarative sentence that has exactly one definite truth value. A sentence that merely introduces or stipulates a variable — “let n be …” — makes no claim, so it has no truth value.

Step by step.

  1. (A) is declarative and true; its truth value is definite.
  2. (B) is declarative and true (every integer > 1 has a prime factor); it is a proposition.
  3. (D) is declarative and true, since x² ≥ 0 for every real x.
  4. (C) is an instruction that fixes the value of n; nothing is asserted, so nothing is true or false. It is not a proposition.

Answer: Option (C).

Why the other options are wrong.

  • (A), (B) and (D) are all declarative sentences with definite truth values, so each is a proposition regardless of whether it is true.
  • Confusing “introduces a variable” with “is false”: a proposition may be false and still be a proposition.

Common misconception. Students accept (C) because it “looks mathematical”. The test is whether the sentence asserts something that is either true or false — “let …” asserts nothing.

Faster method. Ask one question: does the sentence make a claim? An instruction or a definition makes none.

Takeaway. Declarative claim ⇒ proposition. Questions, commands, requests and “let …” stipulations are not propositions, however mathematical they look.

DM-PL2-Q11MCQmedium

How many distinct binary (two-argument) truth functions are there?

  1. 4
  2. 8
  3. 16
  4. 256
Show answer & detailed solution

Detailed solution

Concept. A binary truth function is fixed by its output on each of the 2² = 4 input pairs, and each output can be chosen independently, giving 2^4 functions.

Step by step.

  1. The inputs are the four pairs (F,F), (F,T), (T,F), (T,T).
  2. An output value (0 or 1) is chosen for each pair: 2⁴ = 16 possible output columns.
  3. Each column is a distinct truth function — for example ∧, ∨, →, ⊕, ↔ and the two projections are among the 16.

Answer: Option (C).

Why the other options are wrong.

  • 4 counts the input pairs, not the functions.
  • 8 is 2³, the number of functions of one variable, or the number of commutative binary functions.
  • 256 is 2⁸, the number of truth functions of three variables.

Common misconception. Using the number of inputs as the base instead of the number of outputs. The count is 2^(2ⁿ) for n arguments.

Faster method. Functions of n variables: 2^(2ⁿ). Here 2⁴ = 16.

Takeaway. 1 variable → 4 functions, 2 variables → 16, 3 variables → 256. The double exponent is the point.

DM-PL2-Q12MCQhard

Of the 16 binary truth functions, how many are associative — that is, satisfy f(f(a, b), c) = f(a, f(b, c)) for all truth values a, b, c?

  1. 4
  2. 6
  3. 8
  4. 10
Show answer & detailed solution

Detailed solution

Concept. Associativity lets you drop the brackets. For binary connectives it is a property of the truth function, checked on the eight triples (a, b, c).

Step by step.

  1. The connectives ∧, ∨, ⊕ and ↔ are all associative — each is a Boolean operation (min, max, addition mod 2, equality) that is associative on {0,1}.
  2. The two projections f(a, b) = a and f(a, b) = b are associative: both sides reduce to the same one of a, b, c.
  3. The two constant functions (always T, always F) are associative, since both sides are the same constant.
  4. The remaining eight fail. Implication is the standard counterexample: at a = F, b = F, c = F we get (F → F) → F = T → F = F while F → (F → F) = F → T = T, so → is not associative; NAND, NOR and the four mixed functions fail similarly.
  5. Count: 4 + 2 + 2 = 8.

Answer: Option (C).

Why the other options are wrong.

  • 4 counts only the familiar AND, OR, XOR, IFF and forgets the projections and constants, which are also associative.
  • 6 or 10 come from testing associativity on a subset of the eight triples, typically only those with a = b or b = c.

Common misconception. Assuming every “reasonable-looking” connective is associative. Implication and NAND are the standard counterexamples, and the constant functions are the ones students never check.

Faster method. Group by structure: the 4 lattice/Boolean operations, the 2 projections, the 2 constants = 8. Every other binary function fails on some triple.

Takeaway. Associativity is a property of the function's table, not of the symbol. Constants and projections are associative too — do not forget them.

DM-PL2-Q16MSQeasy

Which of the following statements about functionally complete sets of connectives are TRUE? (Select all that apply.)

  1. NAND alone is functionally complete.
  2. {¬, ∨} is functionally complete.
  3. {∧, ↔} is functionally complete.
  4. {→} alone is functionally complete.
Show answer & detailed solution

Detailed solution

Concept. A set of connectives is functionally complete if every truth function can be written using only those connectives. NAND and NOR are each complete on their own; so is any set from which negation plus one of ∧, ∨ can be built.

Step by step.

  1. (A) True: ¬p ≡ p ↑ p and p ∧ q ≡ ¬(p ↑ q), so NAND builds everything.
  2. (B) True: with ¬ and ∨ we get p ∧ q ≡ ¬(¬p ∨ ¬q), and {¬, ∧, ∨} is complete.
  3. (C) False: using only ∧ and ↔ from variables p, q one can build just 8 of the 16 binary functions, and in particular no negation of a single variable; the set cannot be complete.
  4. (D) False: → is 1-preserving (a true consequent makes it true), so no formula built from → alone can express ¬p or the constant F.

Answer: Options (A) and (B).

Why the other options are wrong.

  • (C) is the standard “two connectives must be enough” trap; the pair generates only half the functions.
  • (D) confuses “can express ∧ and ∨” with “complete”. Without negation, completeness is impossible for → alone.

Common misconception. Assuming any pair of connectives is complete. Completeness needs a way to produce negation or a known complete single connective.

Faster method. If the set contains ¬ plus ∧ or ∨, it is complete. If it contains NAND or NOR alone, it is complete. Otherwise suspect incompleteness.

Takeaway. The complete single connectives are NAND and NOR. Among pairs, {¬, ∧}, {¬, ∨}, {¬, →} work; {∧, ∨}, {∧, ↔}, {∨, →} do not.

DM-PL2-Q23NATeasy

How many distinct truth functions of three propositional variables are there?
(Enter an integer.)

Show answer & detailed solution

Detailed solution

Concept. A truth function of n variables is determined by its output column, which has 2ⁿ entries; each entry can be 0 or 1 independently, giving 2^(2ⁿ) functions.

Step by step.

  1. Three variables give 2³ = 8 rows.
  2. Each of the 8 outputs is chosen freely as T or F: 2⁸ = 256 output columns.
  3. So there are 256 distinct truth functions of three variables.

Answer: 256.

Common misconception. Answering 2³ = 8 (the number of rows) or 2 × 3. The double exponent is what matters.

Faster method. Memorise the ladder: 1 variable → 4, 2 → 16, 3 → 256, 4 → 65536.

Takeaway. Truth functions of n variables: 2^(2ⁿ). The count grows doubly exponentially, which is why functional completeness matters.

DM-PL1-Q02MCQeasy

How many rows does a complete truth table for the compound proposition (p ∧ q) → (r ∨ ¬s) contain?

  1. 8
  2. 16
  3. 24
  4. 32
Show answer & detailed solution

Detailed solution

Concept. A truth table for a formula with n distinct propositional variables has 2ⁿ rows, one per assignment of truth values to those variables.

Step by step.

  1. List the distinct variables: p, q, r, s — four of them.
  2. So the number of rows is 2⁴ = 16.
  3. The number of connectives (three here) is irrelevant; only the variable count matters.

Answer: Option (B).

Why the other options are wrong.

  • (A) 8 would be right for three variables; here there are four.
  • (C) and (D) do not correspond to any power of two.

Common misconception. Counting occurrences instead of distinct variables — ¬s and r∨¬s both use s, but s still contributes one column, not two.

Faster method. Count distinct variable names, then take 2 to that power.

Takeaway. Rows = 2^(distinct variables); columns = distinct variables + one per subformula.

DM-PL1-Q07MCQmedium

For how many of the eight truth assignments to (p, q, r) is the proposition (p ∨ q) → r false?

  1. 1
  2. 2
  3. 3
  4. 4
Show answer & detailed solution

Detailed solution

Concept. An implication is false in exactly one situation: antecedent true and consequent false.

Step by step.

  1. (p ∨ q) → r is false iff (p ∨ q) is true and r is false.
  2. (p ∨ q) is true for three of the four assignments to (p, q): (T,T), (T,F), (F,T).
  3. Fix r = F for each of those three: (T,T,F), (T,F,T), (F,T,F) — three falsifying assignments.
  4. Equivalently, the formula is true on 8 − 3 = 5 of the eight rows.

Answer: Option (C).

Why the other options are wrong.

  • (A) 1 would be right only if the antecedent were a single variable.
  • (B) and (D) come from counting rows of (p, q) only, or from forgetting that r is free.

Common misconception. Counting the rows where r is false (four) instead of intersecting with the rows where the antecedent holds (three).

Faster method. False rows = (rows making the antecedent true) × (rows making the consequent false) = 3 × 1 = 3.

Takeaway. For a count of falsifying rows, count models of the antecedent and multiply by models of ¬consequent, then subtract any overlap.

DM-PL1-Q13MCQhard

Which one of the following formulas is TRUE exactly when an odd number of p, q, r are TRUE?

  1. (p ⊕ q) ⊕ r
  2. (p ⊕ q) ∧ r
  3. (p ∨ q ∨ r) ∧ ¬(p ∧ q ∧ r)
  4. p ⊕ q
Show answer & detailed solution

Detailed solution

Concept. XOR is addition modulo 2. Iterating it over three variables gives the parity function: true exactly when the number of TRUE inputs is odd.

Step by step.

  1. Check the four odd rows. One TRUE: (T,F,F) → T⊕F = T, T⊕F = T. Symmetric for the other two single-TRUE rows.
  2. Three TRUE: (T,T,T) → T⊕T = F, F⊕T = T. True, as parity requires.
  3. Check the even rows. Two TRUE: (T,T,F) → F⊕F = F. Zero TRUE: (F,F,F) → F⊕F = F. Correct.
  4. (B) is true only on rows with exactly two TRUE values and r = T, i.e. only (T,T,T) — wrong. (C) is true for one or two TRUE values, so it wrongly accepts the two-TRUE rows. (D) ignores r entirely.

Answer: Option (A).

Why the other options are wrong.

  • (B) collapses to (p ⊕ q) ∧ r, true on a single row.
  • (C) is the “at least one but not all” formula, which is not parity.
  • (D) is independent of r, so it cannot distinguish rows that differ only in r.

Common misconception. Assuming “odd number of TRUE” means “exactly one TRUE”. Parity also includes three TRUE, which is where (C) and (B) fail.

Faster method. Parity over n variables is the n-fold XOR. Write p ⊕ q ⊕ r and verify the two extreme rows (all false, all true).

Takeaway. This is a variation on the GATE CSE 2014 Set 1 Q53 pattern (formula true exactly when a given number of p, q, r are TRUE); the original asked for “exactly two”, this asks for odd parity. It is practice material, not the official question.

DM-PL1-Q17MSQmedium

Which of the following are tautologies? (Select all that apply.)

  1. p → (q → p)
  2. (p → q) → (q → p)
  3. (p ∧ (p → q)) → q
  4. (p ∨ q) → p
Show answer & detailed solution

Detailed solution

Concept. A tautology is true under every assignment. (A) and (C) are the two standard “absorption” tautologies; (B) and (D) are not.

Step by step.

  1. (A) p → (q → p) ≡ ¬p ∨ ¬q ∨ p ≡ T. Tautology.
  2. (B) p = F, q = T: (F → T) → (T → F) = T → F = F. Not a tautology.
  3. (C) p ∧ (p → q) → q is modus ponens as a formula: ≡ ¬(p ∧ (¬p ∨ q)) ∨ q ≡ (¬p ∨ (p ∧ ¬q)) ∨ q ≡ T. Tautology.
  4. (D) p = F, q = T: (F ∨ T) → F = F. Not a tautology.

Answer: Options (A) and (C).

Why the other options are wrong.

  • (B) fails at p = F, q = T — it is the converse-flavoured formula.
  • (D) fails at p = F, q = T.

Common misconception. Assuming every formula with the shape “implication between implications” is a tautology. Test p = F, q = T, the standard killer row.

Faster method. Convert to ¬/∨ form; a tautology becomes an expression that reduces to T for every assignment.

Takeaway. Modus ponens and “p implies (q implies p)” are tautologies; anything that reverses an arrow usually is not.

DM-PL1-Q22NATeasy

For how many of the eight truth assignments to (p, q, r) is the proposition p → (q ∧ r) TRUE?
(Enter an integer.)

Show answer & detailed solution

Detailed solution

Concept. Count the falsifying rows and subtract from 8: the implication fails only when p is true and q ∧ r is false.

Step by step.

  1. p = F: the implication is vacuously true for all four assignments of (q, r) — 4 rows.
  2. p = T: the implication is true only when q ∧ r is true, i.e. only (q, r) = (T, T) — 1 row.
  3. Total true rows = 4 + 1 = 5; the three false rows are (T,T,F), (T,F,T), (T,F,F).

Answer: 5.

Common misconception. Forgetting the four vacuous rows with p = F and answering 1 or 3.

Faster method. True rows = 2ⁿ⁻¹ (hypothesis false) + (rows with hypothesis true and conclusion true) = 4 + 1.

Takeaway. Split on the hypothesis first; the false-hypothesis half is always free.

DM-PL2-Q02MCQeasy

How many rows does a complete truth table for the proposition (p ∧ ¬q) ∨ (r ⊕ s) ∨ ¬t contain?

  1. 16
  2. 24
  3. 32
  4. 64
Show answer & detailed solution

Detailed solution

Concept. A complete truth table has one row per assignment of truth values to the distinct propositional variables, so 2ⁿ rows for n distinct variables.

Step by step.

  1. List the distinct variables: p, q, r, s, t — five of them.
  2. The number of assignments is 2⁵ = 32.
  3. The connectives (¬, ∧, ∨, ⊕) and how often a variable repeats do not change the row count.

Detailed solution

  • (A) is the negation of p ∧ q, not of p ∨ q.
  • (C) is true on exactly one row (p = q = T), the opposite corner.
  • (D) ¬p → q ≡ p ∨ q, which is the formula being negated.

Takeaway. De Morgan is applied to the connective that the ¬ meets first; nothing else changes.

  3. q ∧ r
  4. p ∨ q

Concept. A conclusion follows logically iff every assignment satisfying all the premises also satisfies the conclusion.

  2. invalid; it commits the fallacy of affirming the consequent.
  3. valid, by modus tollens.
  4. invalid; it commits the fallacy of denying the antecedent.
Show answer & detailed solution

Detailed solution

Concept. Modus ponens has the form `p → q, p ∴ q`. Modus tollens has `p → q, ¬q ∴ ¬p`. Affirming the consequent uses `p → q, q ∴ p`, which is not valid.

Step by step.

  1. Formalise: p = it rained last night, q = the ground is wet. The premises are p → q and q; the conclusion drawn is p.

  3. A concrete model: the sprinkler ran, so the ground is wet although it did not rain.
  4. Hence the argument is invalid, and the specific error is affirming the consequent.

Why the other options are wrong.

  • (A) modus ponens would need the second premise to be p, not q.

Takeaway. Modus ponens and modus tollens are the only two valid implication-elimination patterns.

For plane quadrilaterals let R(x) mean “x is a rhombus”, P(x) “x is a parallelogram”, Q(x) “x is a rectangle” and S(x) “x is a square”. Which of the following are true? (Select all that apply.)

  1. R(x) is sufficient for P(x).
  2. P(x) is necessary for R(x).
  3. P(x) is sufficient for Q(x).
  4. R(x) and Q(x) together are sufficient for S(x).
Show answer & detailed solution

Detailed solution

Concept. Sufficiency is implication from the condition to the conclusion; necessity is the reverse arrow. The quadrilateral hierarchy is rhombus ⊂ parallelogram and square = rhombus ∩ rectangle.

Step by step.

  1. Every rhombus is a parallelogram (both pairs of opposite sides parallel), so R → P. Hence R is sufficient for P — (A) true.
  2. The same implication read backwards says P is necessary for R: you cannot be a rhombus without being a parallelogram — (B) true.
  3. A parallelogram need not have a right angle (take a 60°-rhombus), so P → Q fails — (C) false.
  4. A quadrilateral that is both a rhombus (four equal sides) and a rectangle (four right angles) is a square, so R ∧ Q → S — (D) true.

Answer: Options (A), (B) and (D)..

Why the other options are wrong.

  • (C) confuses “parallelogram” with “rectangle”; the non-rectangular parallelogram is the counterexample.

Common misconception. (A) and (B) are treated as competing answers, though they are the same implication read from its two ends. Both can be, and here are, true together.

Faster method. Write the single arrow R → P. Tail is sufficient, head is necessary. One arrow, two true statements.

Takeaway. Wherever a genuine subset relation holds, both “A sufficient for B” and “B necessary for A” are true simultaneously.

DM-LPT3-N-22NATeasy

Over the reals, x² = 4 is necessary but not sufficient for x = 2. How many real numbers satisfy x² = 4? (Enter an integer.)

Show answer & detailed solution

Detailed solution

Concept. The number of solutions of the necessary condition measures how far it falls short of sufficiency. One solution means the two conditions are equivalent; more than one means the necessary condition is not sufficient.

Step by step.

  1. x² = 4 ⟺ x² − 4 = 0 ⟺ (x − 2)(x + 2) = 0.
  2. The solutions are x = 2 and x = −2: two real numbers.
  3. Since a second value (x = −2) satisfies the condition without satisfying x = 2, the condition cannot be sufficient for x = 2 — which matches the statement.

Answer: 2.

Common misconception. x² = 4 is read as x = 2 by taking the positive square root only. The negative root is what breaks sufficiency.

Faster method. x² = k with k > 0 always has two real solutions, ±√k.

Takeaway. A condition with more solutions than the conclusion can never be sufficient for it. Counting solutions is a quick necessity/sufficiency test.
