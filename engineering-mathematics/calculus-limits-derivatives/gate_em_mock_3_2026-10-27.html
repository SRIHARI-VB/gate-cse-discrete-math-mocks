EM-U1-Q01MCQeasy

Let A be a 3 × 2 matrix and B a 2 × 4 matrix. Which statement is TRUE?

  1. AB is defined and is a 3 × 4 matrix, while BA is not defined.
  2. BA is defined and is a 2 × 2 matrix, while AB is not defined.
  3. Both AB and BA are defined.
  4. Neither product is defined.
Show answer & solution

Detailed solution

Concept. The product XY is defined only when the number of columns of X equals the number of rows of Y, and the result then has the rows of X and the columns of Y.

Step by step.

  1. A is 3 × 2 and B is 2 × 4. For AB the inner dimensions are 2 = 2, so AB is defined and is 3 × 4.
  2. For BA the inner dimensions are 4 (columns of B) and 3 (rows of A). Since 4 ≠ 3, BA is not defined.
  3. Hence exactly one of the two products exists, and it is 3 × 4.

Answer: Option (A).

Common misconception. Students check only whether both matrices are non-square, or assume that if AB exists then BA must too. Matrix multiplication is not commutative and the two products can have different orders or fail to exist at all.

EM-U1-Q02MCQeasy

If A and B are n × n real matrices with AB = 0, which of the following must be TRUE?

  1. A = 0 or B = 0
  2. det(A) = 0 or det(B) = 0
  3. Both A and B are invertible
  4. A = B
Show answer & solution

Detailed solution

Concept. The determinant is multiplicative: det(AB) = det(A)·det(B).

Step by step.

  1. Suppose, for contradiction, that det(A) ≠ 0 and det(B) ≠ 0. Then both are invertible.
  2. Then AB is invertible, so det(AB) ≠ 0.
  3. But AB = 0 gives det(AB) = 0, a contradiction. So at least one determinant is zero.

Answer: Option (B).

Common misconception. The error is believing that a zero product forces a zero factor, as it does for real numbers. For matrices, AB = 0 can hold with both factors non-zero, e.g. A = [[1,0],[0,0]], B = [[0,0],[1,0]]. The correct conclusion is only singularity, not zero-ness.

EM-U1-Q03MCQeasy

For square matrices A and B of the same order, (A + B)² equals

  1. A² + 2AB + B²
  2. A² + AB + BA + B²
  3. A² + B²
  4. A² + 2BA + B²
Show answer & solution

Detailed solution

Concept. Expand the product and use distributivity; do not assume commutativity.

Step by step.

  1. (A + B)² = (A + B)(A + B) = A·A + A·B + B·A + B·B.
  2. That is A² + AB + BA + B².
  3. The two middle terms can be merged only when AB = BA, which is not given.

Answer: Option (B).

Common misconception. Writing A² + 2AB + B² by analogy with the scalar binomial expansion. That step silently assumes commutativity, which fails for general matrices.

EM-U1-Q04MCQmedium

Let A be a 3 × 3 matrix with det(A) = 2. Then det(adj A) equals

  1. 2
  2. 4
  3. 8
  4. 1/2
Show answer & solution

Detailed solution

Concept. For an n × n matrix, A · adj(A) = det(A) I, hence det(adj A) = det(A)^(n−1).

Step by step.

  1. Take determinants in A · adj(A) = det(A) I: det(A)·det(adj A) = det(A)ⁿ.
  2. With det(A) ≠ 0 this gives det(adj A) = det(A)^(n−1).
  3. Here n = 3 and det(A) = 2, so det(adj A) = 2² = 4.

Answer: Option (B) — 4.

Common misconception. Using the exponent n instead of n − 1, or applying the scalar rule det(kA) = k·det(A) here. The exponent depends on the order of the matrix, so for n = 3 the factor is det(A)².

EM-U1-Q05MCQmedium

Let A be a real 3 × 3 skew-symmetric matrix, i.e. Aᵀ = −A. Which of the following must hold?

  1. det(A) = 0
  2. det(A) > 0
  3. A is invertible
  4. trace(A) = 3
Show answer & solution

Detailed solution

Concept. Determinant under transpose, and the effect of a scalar multiple on a determinant of odd order.

Step by step.

  1. det(A) = det(Aᵀ) = det(−A).
  2. For a 3 × 3 matrix, det(−A) = (−1)³ det(A) = −det(A).
  3. So det(A) = −det(A), giving 2·det(A) = 0, i.e. det(A) = 0.

Answer: Option (A).

Common misconception. Assuming a skew-symmetric matrix is invertible because it looks 'structured'. In fact every real skew-symmetric matrix of odd order is singular; the determinant is zero because the eigenvalues are 0 or purely imaginary pairs. Also note trace(A) = 0 for any skew-symmetric matrix, not 3.

EM-U1-Q16MSQeasy

For real square matrices A and B of the same order, which statements are TRUE?

  1. (AB)ᵀ = BᵀAᵀ
  2. (A + B)ᵀ = Aᵀ + Bᵀ
  3. tr(AB) = tr(BA)
  4. If A and B are invertible then (AB)⁻¹ = A⁻¹B⁻¹
Show answer & solution

Detailed solution

Concept. Transpose reverses products but distributes over sums; trace is invariant under cyclic permutation; inverses reverse order.

Step by step.

  1. (AB)ᵀ = BᵀAᵀ — true: the (i,j) entry of (AB)ᵀ is the (j,i) entry of AB, which is (BᵀAᵀ)_ij.
  2. (A + B)ᵀ = Aᵀ + Bᵀ — true: transpose is additive.
  3. tr(AB) = Σᵢ (AB)_ii = Σᵢ Σ_k a_ik b_ki = tr(BA) — true.
  4. (AB)⁻¹ = B⁻¹A⁻¹, not A⁻¹B⁻¹ — false as written.

Answer: Options (A), (B) and (C).

Common misconception. Option (D) is the classic slip: order must be reversed for both transpose and inverse. Only when A and B commute does A⁻¹B⁻¹ happen to coincide with the correct inverse.

EM-U1-Q20MSQeasy

Which of the following statements are TRUE for real square matrices?

  1. If A is 2 × 2 and A² = I, then A = I or A = −I.
  2. If A is invertible, then Aᵀ is invertible.
  3. If A and B are invertible n × n matrices, then AB is invertible.
  4. The inverse of an invertible upper-triangular matrix with non-zero diagonal entries is upper-triangular.
Show answer & solution

Detailed solution

Concept. Invertibility under transpose and products, plus the triangular structure of inverses.

Step by step.

  1. (A) False: A = [[0, 1], [1, 0]] satisfies A² = I but is neither I nor −I.
  2. (B) True: det(Aᵀ) = det(A) ≠ 0.
  3. (C) True: det(AB) = det(A)det(B) ≠ 0, so AB is invertible with inverse B⁻¹A⁻¹.
  4. (D) True: if U is upper-triangular with non-zero diagonal, solving UX = I by back substitution gives an upper-triangular X = U⁻¹.

Answer: Options (B), (C) and (D).

Common misconception. Option (A) — treating matrix squares like scalar squares. Over the reals, A² = I gives (A − I)(A + I) = 0, which does not force either factor to vanish because matrices have zero divisors.

EM-U1-Q21NATeasy

Let A be a 3 × 3 real matrix with det(A) = 5. Find det(2A).

    Show answer & solution

    Detailed solution

    Concept. Scaling an n × n matrix by k multiplies the determinant by kⁿ, not by k.

    Step by step.

    1. Every one of the 3 rows is multiplied by 2, and each such multiplication scales the determinant by 2.
    2. Hence det(2A) = 2³ · det(A).
    3. det(2A) = 8 × 5 = 40.

    Answer: 40

    Common misconception. Writing det(2A) = 2·det(A) = 10. The factor 2 is applied to all n rows, so it is raised to the order of the matrix. Only for 1 × 1 matrices do the two rules coincide.

    EM-U1-Q26MCQeasy

    Let A be a 4 × 3 matrix, B a 3 × 5 matrix and C a 5 × 2 matrix. Which of the following products is defined, and what is its order?

    1. AC is defined and is 4 × 2.
    2. CB is defined and is 5 × 3.
    3. ABC is defined and is 4 × 2.
    4. BA is defined and is 3 × 3.
    Show answer & solution

    Detailed solution

    Concept. The product XY is defined exactly when the number of columns of X equals the number of rows of Y, and the result has the row count of X and the column count of Y. Conformability chains through a product of three matrices.

    Step by step.

    1. AC: A has 3 columns, C has 5 rows — not equal, so AC is undefined.
    2. CB: C has 2 columns, B has 3 rows — undefined.
    3. AB is defined, 4 × 5; the inner sizes agree: (4 × 3)(3 × 5).
    4. That product then multiplies C as (4 × 5)(5 × 2), which is conformable, so ABC is defined and is 4 × 2.
    5. BA: B has 5 columns, A has 4 rows — undefined.

    Answer: Option (C)

    Common misconception. Students check A against C and stop at the first mismatch, concluding that the triple product fails. The correct test is pairwise and left to right: A with B, then the result with C.

    EM-U1-Q27MCQeasy

    Let A be a 3 × 3 upper-triangular matrix whose diagonal entries are 2, −3, 4. Then det(A) equals

    1. −24
    2. 24
    3. 9
    4. 0
    Show answer & solution

    Detailed solution

    Concept. The determinant of a triangular matrix (upper or lower) is the product of its diagonal entries: all other terms of the Leibniz expansion contain a zero factor.

    Step by step.

    1. A is upper triangular, so every term of det(A) except the diagonal product contains an entry below the diagonal, which is 0.
    2. det(A) = 2 · (−3) · 4 = −24.

    Answer: Option (A)

    Common misconception. Adding the diagonal entries, 2 + (−3) + 4 = 3, and picking the nearest option. The rule is a product, not a sum — and the sign matters.

    EM-U1-Q28MCQmedium

    Let A be a 4 × 4 real matrix with det(A) = 3. Then det(2A⁻¹) equals

    1. 16/3
    2. 2/3
    3. 16
    4. 3/16
    Show answer & solution

    Detailed solution

    Concept. Two determinant rules compose here: det(A⁻¹) = 1/det(A) and det(kA) = kⁿ det(A) for an n × n matrix.

    Step by step.

    1. det(A⁻¹) = 1/3.
    2. Scaling A⁻¹ by 2 multiplies its determinant by 2⁴ = 16.
    3. det(2A⁻¹) = 16 · (1/3) = 16/3.

    Answer: Option (A)

    Common misconception. Applying the scaling to the inverse first, (2A)⁻¹ = A⁻¹/2, or using 2 instead of 2⁴. Write the order n down before applying kⁿ; with n = 4 the factor is 16, not 2.

    EM-U1-Q29MCQmedium

    Let A and B be invertible n × n matrices. Then (AᵀB)⁻¹ equals

    1. (A⁻¹)ᵀ B⁻¹
    2. B⁻¹ (A⁻¹)ᵀ
    3. B⁻¹ A⁻¹
    4. A⁻¹ B⁻¹
    Show answer & solution

    Detailed solution

    Concept. The inverse of a product reverses the order: (XY)⁻¹ = Y⁻¹X⁻¹. Also (Aᵀ)⁻¹ = (A⁻¹)ᵀ, so it does not matter whether the transpose or the inverse is taken first.

    Step by step.

    1. Put X = Aᵀ and Y = B. Then (XY)⁻¹ = Y⁻¹X⁻¹ = B⁻¹(Aᵀ)⁻¹.
    2. Since (Aᵀ)⁻¹ = (A⁻¹)ᵀ, this is B⁻¹(A⁻¹)ᵀ.
    3. Check: (AᵀB)·B⁻¹(A⁻¹)ᵀ = Aᵀ(BB⁻¹)(A⁻¹)ᵀ = Aᵀ(A⁻¹)ᵀ = (A⁻¹A)ᵀ = I.

    Answer: Option (B)

    Common misconception. Option (A) keeps the original order and option (D) forgets the transpose. Both fail the multiplication check above as soon as A and B do not commute.

    EM-U1-Q41MSQeasy

    Let A and B be 2 × 2 real matrices with det(A) = 2 and det(B) = 3. Which statements are TRUE?

    1. det(AB) = 6
    2. det(A + B) = 5
    3. det(A⁻¹) = 1/2
    4. det(Aᵀ) = 3
    Show answer & solution

    Detailed solution

    Concept. The determinant is multiplicative and invariant under transpose; it is additive in neither the matrix nor, in general, the scalar.

    Step by step.

    1. det(AB) = det(A)det(B) = 2 · 3 = 6 — true.
    2. det(A + B) has no rule in terms of det(A) and det(B); take A = I, B = 2I: det(A + B) = 9 ≠ 3 — false.
    3. det(A⁻¹) = 1/det(A) = 1/2 — true.
    4. det(Aᵀ) = det(A) = 2, not 3 — false.

    Answer: Options (A) and (C)

    Common misconception. Treating the determinant as linear, so that det(A + B) = det(A) + det(B). Linearity holds row by row, not for the whole matrix sum.

    EM-U1-Q45MSQmedium

    Let A, B, C be n × n real matrices. Which statements are TRUE?

    1. If A² = 0 then A is singular
    2. If A² = A then det(A) ∈ {0, 1}
    3. If A is invertible and AB = AC then B = C
    4. Every square matrix has an inverse
    Show answer & solution

    Detailed solution

    Concept. The determinant turns matrix multiplication into ordinary multiplication, so polynomial relations among matrices become relations among numbers.

    Step by step.

    1. A² = 0 gives det(A)² = 0, hence det(A) = 0 and A is singular — true.
    2. A² = A gives det(A)² = det(A), so det(A) is a real root of t² = t, namely 0 or 1 — true.
    3. Multiply AB = AC on the left by A⁻¹ to get B = C — true.
    4. A square matrix is invertible only if det(A) ≠ 0; the zero matrix is a counterexample — false.

    Answer: Options (A), (B) and (C)

    Common misconception. Cancelling A without invertibility. In (C) the hypothesis supplies A⁻¹; in general AB = AC does not imply B = C when A is singular.

    EM-U1-Q46NATeasy

    Let A = [[2, 1], [1, 1]]. Find the (1, 2) entry of A⁻¹. (Enter an integer; the value may be negative.)

      Show answer & solution

      Detailed solution

      Concept. For a 2 × 2 matrix [[a, b], [c, d]] with ad − bc ≠ 0, the inverse is (1/(ad − bc))·[[d, −b], [−c, a]] — the diagonal entries swap and the off-diagonal entries change sign.

      EM-U1-Q06MCQmedium

      A 4 × 6 real matrix A has rank 4. The nullity of A is

      1. 0
      2. 2
      3. 4
      4. 6
      Show answer & solution

      Detailed solution

      Concept. The rank–nullity theorem: for an m × n matrix, rank(A) + nullity(A) = n, the number of columns.

      Step by step.

      1. Here m = 4, n = 6.
      2. nullity(A) = n − rank(A) = 6 − 4 = 2.
      3. Equivalently the solution space of Ax = 0 has dimension 2.

      Answer: Option (B) — 2.

      Common misconception. Using the number of rows (4 − 4 = 0) instead of the number of columns. The rank–nullity theorem counts the domain dimension n, never m.

      EM-U1-Q07MCQeasy

      Every row of a 3 × 3 real matrix A equals the same non-zero vector. The rank of A is

      1. 0
      2. 1
      3. 2
      4. 3
      Show answer & solution

      Detailed solution

      Concept. The rank is the maximum number of linearly independent rows.

      Step by step.

      1. All three rows are equal to one non-zero vector v.
      2. Any two rows are scalar multiples of each other, so at most one row is independent.
      3. Since v ≠ 0, that one row is independent, so rank(A) = 1.

      Answer: Option (B) — 1.

      Common misconception. Answering 3 because the matrix 'has three rows', or 0 because the rows are repeated. Rank counts independent directions, not rows; repetition reduces rank to 1 but a non-zero vector still contributes rank 1.

      EM-U1-Q08MCQmedium

      Let A be a 5 × 5 real matrix with rank(A) = 3. Which statement is TRUE?

      1. rank(Aᵀ) = 3 and nullity(A) = 2
      2. rank(Aᵀ) = 2
      3. nullity(A) = 3
      4. A is invertible
      Show answer & solution

      Detailed solution

      Concept. Row rank equals column rank, so rank(Aᵀ) = rank(A); and rank + nullity = n.

      Step by step.

      1. rank(Aᵀ) = rank(A) = 3.
      2. nullity(A) = 5 − 3 = 2.
      3. A is singular because rank(A) = 3 < 5, so option (D) fails.

      Answer: Option (A).

      Common misconception. Believing rank(Aᵀ) may differ from rank(A) for non-symmetric matrices. Row rank and column rank are always equal, for every real matrix.

      EM-U1-Q09MCQhard

      Let A be 3 × 5 and B be 5 × 3 real matrices with AB = I₃. Which statement is TRUE?

      1. rank(A) = 3 and nullity(A) = 2
      2. rank(A) = 5
      3. nullity(B) = 2
      4. BA = I₅
      Show answer & solution

      Detailed solution

      Concept. Rank is submultiplicative: rank(XY) ≤ min(rank X, rank Y). Also rank(A) ≤ min(m, n).

      Step by step.

      1. rank(AB) = rank(I₃) = 3.
      2. 3 = rank(AB) ≤ rank(A), and rank(A) ≤ min(3, 5) = 3, so rank(A) = 3.
      3. Then nullity(A) = 5 − 3 = 2, which confirms option (A).
      4. Similarly rank(B) = 3 and nullity(B) = 3 − 3 = 0, so (C) fails. BA would be 5 × 5, not I₅ in general — only AB = I₃ is given, so (D) fails.

      Answer: Option (A).

      Common misconception. Concluding BA = I₅ from AB = I₃. A right inverse of a wide matrix is not a two-sided inverse; here B is a right inverse of A only, and BA is a non-identity projection of rank 3.

      EM-U1-Q17MSQmedium

      Let A be a 6 × 4 real matrix with rank(A) = 3. Which statements are TRUE?

      1. nullity(A) = 1
      2. The columns of A span ℝ³
      3. rank(Aᵀ) = 3
      4. The six rows of A are linearly dependent
      Show answer & solution

      Detailed solution

      Concept. Rank–nullity counts columns; row rank equals column rank; the column space lives in ℝ^m, not ℝ^r.

      Step by step.

      1. nullity(A) = 4 − 3 = 1 — (A) is true.
      2. The columns are vectors in ℝ⁶ (six entries each), spanning a 3-dimensional subspace of ℝ⁶. They do not span ℝ³ — (B) is false.
      3. Row rank equals column rank, so rank(Aᵀ) = 3 — (C) is true.
      4. Six rows live in ℝ⁴, so at most 4 can be independent; with rank 3 they are dependent — (D) is true.

      Answer: Options (A), (C) and (D).

      Common misconception. Option (B): students match the rank 3 with ℝ³. Rank gives the dimension of the column space; the ambient space is still ℝ⁶ because the matrix has six rows.

      A 5 × 8 real matrix A has rank 5. Find the nullity of A. (Enter an integer.)

        Show answer & solution

        Concept. Rank–nullity: rank(A) + nullity(A) = n, where n is the number of columns.

        2. nullity(A) = 8 − 5 = 3.

        EM-U1-Q25NAThard

        Let A be a 4 × 4 real matrix with A² = A and rank(A) = 3. Find trace(A). (Enter an integer.)

          Show answer & solution

          Detailed solution

          Concept. A matrix satisfying A² = A is a projection: it is diagonalisable with eigenvalues only 0 and 1, so its trace counts the eigenvalues equal to 1, i.e. the rank.

          Step by step.

          1. If λ is an eigenvalue with eigenvector v, then A²v = λ²v and also A²v = Av = λv, so λ² = λ, giving λ ∈ {0, 1}.

                                                EM-U3-Q04MCQeasy

                                                For f(x) = x² on the interval [0, 2], the point c whose existence is asserted by Lagrange's mean value theorem is

                                                1. 1/2
                                                2. 1
                                                3. 3/2
                                                4. √2
                                                Show answer & solution

                                                Detailed solution

                                                Concept. Lagrange's mean value theorem asserts a point c ∈ (a, b) with f′(c) = (f(b) − f(a))/(b − a), the slope of the chord.

                                                Step by step.

                                                1. The chord slope is (f(2) − f(0))/(2 − 0) = (4 − 0)/2 = 2.
                                                2. Set f′(c) = 2c = 2, giving c = 1.
                                                3. Check 1 ∈ (0, 2), so the asserted point exists and is unique here.

                                                Answer: 1 — option (B).

                                                Common misconception. Confusing the mean value theorem with the midpoint of the interval, or with the point where f attains its average value (f(0) + f(2))/2 = 2 — which would be c = √2, option (D). The theorem equates derivatives, not function values.

                                                EM-U3-Q09MCQmedium

                                                The number of points c in (−√3, √3) at which f′(c) = 0 for f(x) = x³ − 3x is

                                                1. 0
                                                2. 1
                                                3. 3
                                                4. 2
                                                Show answer & solution

                                                Detailed solution

                                                Concept. Rolle's theorem applies on [−√3, √3] because f is a polynomial (hence continuous and differentiable) and the endpoint values agree. Rolle guarantees at least one stationary point; counting them needs the derivative solved explicitly.

                                                Step by step.

                                                1. f(−√3) = −3√3 + 3√3 = 0 and f(√3) = 3√3 − 3√3 = 0, so Rolle's hypotheses hold.
                                                2. f′(x) = 3x² − 3 = 3(x − 1)(x + 1), vanishing at x = ±1.
                                                3. Both −1 and 1 lie inside (−√3, √3) since √3 ≈ 1.732, so there are exactly two such points.

                                                Answer: 2 — option (D).

                                                Common misconception. Answering 1 from Rolle's theorem as if it guaranteed exactly one point — it guarantees at least one. Answering 3 by also counting the endpoints ±√3, where the derivative is 3, not 0.

                                                Apply Cauchy's mean value theorem to f(x) = x² and g(x) = x³ on [1, 2]. The point c whose existence it asserts is

                                                1. 3/2
                                                2. 4/3
                                                3. 7/3
                                                4. 14/9

                                                Concept. Cauchy's mean value theorem asserts c ∈ (a, b) with f′(c)/g′(c) = (f(b) − f(a))/(g(b) − g(a)), a ratio of chord slopes rather than a single chord slope. It requires g′(x) ≠ 0 on (a, b).

                                                1. Chord ratio: (4 − 1)/(8 − 1) = 3/7.

                                                Which of the following statements about the mean value theorems are TRUE?

                                                1. Rolle's theorem is the special case of Lagrange's mean value theorem in which f(a) = f(b).
                                                2. Lagrange's theorem requires continuity on [a, b] and differentiability on (a, b).
                                                3. Lagrange's theorem requires differentiability at the endpoints a and b.
                                                4. If f′(x) = 0 at every point of an interval, then f is constant on that interval.
                                                Show answer & solution

                                                Detailed solution

                                                Concept. Rolle's theorem is Lagrange's with equal endpoint values, and the zero-derivative corollary is what makes the mean value theorem the main tool for proving identities between functions.

                                                Step by step.

                                                1. (A) With f(a) = f(b) the chord slope is 0, so Lagrange gives f′(c) = 0 — exactly Rolle.
                                                2. (B) These are the correct hypotheses: continuity on the closed interval, differentiability on the open one.
                                                3. (C) False: the theorem needs no one-sided derivative at the endpoints, only continuity there.
                                                4. (D) Apply Lagrange on any subinterval [x₁, x₂]: f(x₂) − f(x₁) = f′(c)(x₂ − x₁) = 0.

                                                Answer: (A), (B) and (D).

                                                Common misconception. Upgrading the hypothesis to differentiability on [a, b] (option C). Requiring a derivative at the endpoints would exclude functions like √x on [0, 1], for which the theorem still holds.

                                                Let f(x) = x(x − 1)(x − 2) on [0, 2]. Which of the following are TRUE?

                                                1. Rolle's theorem applies to f on [0, 2].
                                                2. f′(c) = 0 at exactly two points of (0, 2).
                                                3. The conclusion of Rolle's theorem is attained at exactly one point of (0, 2).
                                                4. There is a point c in (2, 3) with f′(c) = 0.
                                                Show answer & solution

                                                Concept. Rolle needs f continuous on [0, 2], differentiable on (0, 2) and f(0) = f(2). The number of stationary points is found by solving f′(x) = 0.

                                                1. f is a polynomial, and f(0) = 0 = f(2), so Rolle applies: (A) is true.

                                                  Partial derivatives 6
                                                  EM-U3-Q05MCQeasy

                                                  For f(x, y) = x²y + y³, the mixed partial derivative ∂²f/∂x∂y equals

                                                  1. 2x
                                                  2. 2y
                                                  3. 2x + 3y²
                                                  4. 6y
                                                  Show answer & solution

                                                  Detailed solution

                                                  Concept. Mixed partials are computed by differentiating in either order; by Clairaut's theorem the two orders agree whenever the second partials are continuous, which they are for a polynomial.

                                                  Step by step.

                                                  1. Differentiate with respect to x first: ∂f/∂x = 2xy.
                                                  2. Now differentiate that with respect to y: ∂/∂y (2xy) = 2x.
                                                  3. Reversing the order gives the same answer: ∂f/∂y = x² + 3y² and ∂/∂x (x² + 3y²) = 2x.

                                                  Answer: 2x — option (A).

                                                  Common misconception. Reporting ∂²f/∂x² = 2y (option B) or ∂²f/∂y² = 6y (option D), which are the pure second partials. The notation ∂²f/∂x∂y here means differentiate in x then y, and the mixed derivative of a polynomial is generally of lower degree than either pure one.

                                                  EM-U3-Q06MCQeasy

                                                  The tangent plane to the surface z = x² + y² at the point (1, 1, 2) is

                                                  1. z = x + y
                                                  2. z = 2x + 2y
                                                  3. z = 2x + 2y − 2
                                                  4. z = 2x + 2y + 2
                                                  Show answer & solution

                                                  Detailed solution

                                                  Concept. The tangent plane to z = f(x, y) at (a, b, f(a, b)) is z = f(a, b) + fx(a, b)(x − a) + fy(a, b)(y − b), a first-order Taylor expansion.

                                                  Step by step.

                                                  1. Here fx = 2x and fy = 2y, so at (1, 1) both slopes equal 2, and f(1, 1) = 2.
                                                  2. Substitute: z = 2 + 2(x − 1) + 2(y − 1).
                                                  3. Expand: z = 2x + 2y − 2.

                                                  Answer: z = 2x + 2y − 2 — option (C).

                                                  Common misconception. Dropping the constant: writing the plane as z = 2x + 2y (option B) ignores that the plane must pass through (1, 1, 2) — it would pass through the origin instead. Always substitute the point back to check.

                                                  3. 6
                                                  4. 0

                                                  Let w = x²y with x = 2t and y = t². Then dw/dt at t = 1 equals

                                                  1. 8
                                                  2. 16
                                                  3. 12
                                                  4. 24
                                                  Show answer & solution

                                                  Detailed solution

                                                  Concept. The chain rule for a composite of several variables: dw/dt = (∂w/∂x)(dx/dt) + (∂w/∂y)(dy/dt). Substituting first and differentiating the resulting one-variable function is an equally valid check.

                                                  Step by step.

                                                  1. Substituting: w = (2t)²(t²) = 4t⁴, so dw/dt = 16t³ and at t = 1 this is 16.

                                                  EM-U3-Q15MCQhard

                                                  For f(x, y) = x³ + y³ − 3xy, which statement about the critical points is TRUE?

                                                  1. (0, 0) is a saddle point and (1, 1) is a local minimum.
                                                  2. (0, 0) and (1, 1) are both saddle points.
                                                  3. (0, 0) is a local minimum and (1, 1) is a saddle point.
                                                  4. (1, 1) is a local maximum.
                                                  Show answer & solution

                                                  Detailed solution

                                                  Concept. Solve fx = fy = 0, then classify each critical point with the discriminant D = fxxfyy − fxy²: D < 0 is a saddle, D > 0 with fxx > 0 a minimum.

                                                  Step by step.

                                                  1. fx = 3x² − 3y = 0 gives y = x²; fy = 3y² − 3x = 0 gives x = y².
                                                  2. Combining, x = x⁴, so x = 0 or x = 1 (the roots of x³ = 1 are only x = 1 in the reals). The critical points are (0, 0) and (1, 1).
                                                  3. fxx = 6x, fyy = 6y, fxy = −3, so D = 36xy − 9.
                                                  4. At (0, 0): D = −9 < 0, a saddle. At (1, 1): D = 27 > 0 and fxx = 6 > 0, a local minimum.

                                                  Answer: saddle at (0, 0), local minimum at (1, 1) — option (A).

                                                  Common misconception. Classifying from the Hessian signs alone without the discriminant, which mislabels (0, 0) as a minimum because fyy = 0 is not negative. Also common: discarding (1, 1) as a maximum by analogy with x³, which has no critical point at all.

                                                  EM-U3-Q25NAThard

                                                  For f(x, y) = x²y³, the value of ∂⁴f/∂x²∂y² at (1, 1) is ____.

                                                    Show answer & solution

                                                    Detailed solution

                                                    Concept. For a product xmyn the mixed partial of order r in x and s in y is [m!/(m − r)!] · [n!/(n − s)!] · xm−r yn−s, and the order of differentiation does not matter for a polynomial.

                                                    Step by step.

                                                    1. Differentiate twice in y: ∂f/∂y = 3x²y², then ∂²f/∂y² = 6x²y.
                                                    2. Then twice in x: ∂/∂x (6x²y) = 12xy, then ∂²/∂x² (6x²y) = 12y.
                                                    3. At (1, 1): 12 · 1 = 12. Shortcut: 2!/(0!) · 3!/(1!) · x⁰y¹ = 2 · 6 · y = 12y.

                                                    Answer: 12

                                                    Common misconception. Counting the derivative as ∂²f/∂x∂y (order two) rather than order four, which gives 6xy² = 6 at (1, 1). The symbol ∂x² means 'twice in x', and ∂y² means 'twice in y', so four differentiations are performed in all.
