Matrix operations 8
EM-U1-Q01MCQeasy

Let A be a 3 × 2 matrix and B a 2 × 4 matrix. Which statement is TRUE?

  1. AB is defined and is a 3 × 4 matrix, while BA is not defined.
  2. BA is defined and is a 2 × 2 matrix, while AB is not defined.
  3. Both AB and BA are defined.
  4. Neither product is defined.
Show answer & solution

Detailed solution

Concept. The product XY is defined only when the number of columns of X equals the number of rows of Y, and the result then has the rows of X and the columns of Y.

Step by step.

  1. A is 3 × 2 and B is 2 × 4. For AB the inner dimensions are 2 = 2, so AB is defined and is 3 × 4.
  2. For BA the inner dimensions are 4 (columns of B) and 3 (rows of A). Since 4 ≠ 3, BA is not defined.
  3. Hence exactly one of the two products exists, and it is 3 × 4.

Answer: Option (A).

Common misconception. Students check only whether both matrices are non-square, or assume that if AB exists then BA must too. Matrix multiplication is not commutative and the two products can have different orders or fail to exist at all.

EM-U1-Q02MCQeasy

If A and B are n × n real matrices with AB = 0, which of the following must be TRUE?

  1. A = 0 or B = 0
  2. det(A) = 0 or det(B) = 0
  3. Both A and B are invertible
  4. A = B
Show answer & solution

Detailed solution

Concept. The determinant is multiplicative: det(AB) = det(A)·det(B).

Step by step.

  1. Suppose, for contradiction, that det(A) ≠ 0 and det(B) ≠ 0. Then both are invertible.
  2. Then AB is invertible, so det(AB) ≠ 0.
  3. But AB = 0 gives det(AB) = 0, a contradiction. So at least one determinant is zero.

Answer: Option (B).

Common misconception. The error is believing that a zero product forces a zero factor, as it does for real numbers. For matrices, AB = 0 can hold with both factors non-zero, e.g. A = [[1,0],[0,0]], B = [[0,0],[1,0]]. The correct conclusion is only singularity, not zero-ness.

EM-U1-Q03MCQeasy

For square matrices A and B of the same order, (A + B)² equals

  1. A² + 2AB + B²
  2. A² + AB + BA + B²
  3. A² + B²
  4. A² + 2BA + B²
Show answer & solution

Detailed solution

Concept. Expand the product and use distributivity; do not assume commutativity.

Step by step.

  1. (A + B)² = (A + B)(A + B) = A·A + A·B + B·A + B·B.
  2. That is A² + AB + BA + B².
  3. The two middle terms can be merged only when AB = BA, which is not given.

Answer: Option (B).

Common misconception. Writing A² + 2AB + B² by analogy with the scalar binomial expansion. That step silently assumes commutativity, which fails for general matrices.

EM-U1-Q04MCQmedium

Let A be a 3 × 3 matrix with det(A) = 2. Then det(adj A) equals

  1. 2
  2. 4
  3. 8
  4. 1/2
Show answer & solution

Detailed solution

Concept. For an n × n matrix, A · adj(A) = det(A) I, hence det(adj A) = det(A)^(n−1).

Step by step.

  1. Take determinants in A · adj(A) = det(A) I: det(A)·det(adj A) = det(A)ⁿ.
  2. With det(A) ≠ 0 this gives det(adj A) = det(A)^(n−1).
  3. Here n = 3 and det(A) = 2, so det(adj A) = 2² = 4.

Answer: Option (B) — 4.

Common misconception. Using the exponent n instead of n − 1, or applying the scalar rule det(kA) = k·det(A) here. The exponent depends on the order of the matrix, so for n = 3 the factor is det(A)².

EM-U1-Q05MCQmedium

Let A be a real 3 × 3 skew-symmetric matrix, i.e. Aᵀ = −A. Which of the following must hold?

  1. det(A) = 0
  2. det(A) > 0
  3. A is invertible
  4. trace(A) = 3
Show answer & solution

Detailed solution

Concept. Determinant under transpose, and the effect of a scalar multiple on a determinant of odd order.

Step by step.

  1. det(A) = det(Aᵀ) = det(−A).
  2. For a 3 × 3 matrix, det(−A) = (−1)³ det(A) = −det(A).
  3. So det(A) = −det(A), giving 2·det(A) = 0, i.e. det(A) = 0.

Answer: Option (A).

Common misconception. Assuming a skew-symmetric matrix is invertible because it looks 'structured'. In fact every real skew-symmetric matrix of odd order is singular; the determinant is zero because the eigenvalues are 0 or purely imaginary pairs. Also note trace(A) = 0 for any skew-symmetric matrix, not 3.

EM-U1-Q16MSQeasy

For real square matrices A and B of the same order, which statements are TRUE?

  1. (AB)ᵀ = BᵀAᵀ
  2. (A + B)ᵀ = Aᵀ + Bᵀ
  3. tr(AB) = tr(BA)
  4. If A and B are invertible then (AB)⁻¹ = A⁻¹B⁻¹
Show answer & solution

Detailed solution

Concept. Transpose reverses products but distributes over sums; trace is invariant under cyclic permutation; inverses reverse order.

Step by step.

  1. (AB)ᵀ = BᵀAᵀ — true: the (i,j) entry of (AB)ᵀ is the (j,i) entry of AB, which is (BᵀAᵀ)_ij.
  2. (A + B)ᵀ = Aᵀ + Bᵀ — true: transpose is additive.
  3. tr(AB) = Σᵢ (AB)_ii = Σᵢ Σ_k a_ik b_ki = tr(BA) — true.
  4. (AB)⁻¹ = B⁻¹A⁻¹, not A⁻¹B⁻¹ — false as written.

Answer: Options (A), (B) and (C).

Common misconception. Option (D) is the classic slip: order must be reversed for both transpose and inverse. Only when A and B commute does A⁻¹B⁻¹ happen to coincide with the correct inverse.

EM-U1-Q20MSQeasy

Which of the following statements are TRUE for real square matrices?

  1. If A is 2 × 2 and A² = I, then A = I or A = −I.
  2. If A is invertible, then Aᵀ is invertible.
  3. If A and B are invertible n × n matrices, then AB is invertible.
  4. The inverse of an invertible upper-triangular matrix with non-zero diagonal entries is upper-triangular.
Show answer & solution

Detailed solution

Concept. Invertibility under transpose and products, plus the triangular structure of inverses.

Step by step.

  1. (A) False: A = [[0, 1], [1, 0]] satisfies A² = I but is neither I nor −I.
  2. (B) True: det(Aᵀ) = det(A) ≠ 0.
  3. (C) True: det(AB) = det(A)det(B) ≠ 0, so AB is invertible with inverse B⁻¹A⁻¹.
  4. (D) True: if U is upper-triangular with non-zero diagonal, solving UX = I by back substitution gives an upper-triangular X = U⁻¹.

Answer: Options (B), (C) and (D).

Common misconception. Option (A) — treating matrix squares like scalar squares. Over the reals, A² = I gives (A − I)(A + I) = 0, which does not force either factor to vanish because matrices have zero divisors.

EM-U1-Q21NATeasy

Let A be a 3 × 3 real matrix with det(A) = 5. Find det(2A).

Answer format: a single integer.

Show answer & solution

Detailed solution

Concept. Scaling an n × n matrix by k multiplies the determinant by kⁿ, not by k.

Step by step.

  1. Every one of the 3 rows is multiplied by 2, and each such multiplication scales the determinant by 2.
  2. Hence det(2A) = 2³ · det(A).
  3. det(2A) = 8 × 5 = 40.

Answer: 40

Common misconception. Writing det(2A) = 2·det(A) = 10. The factor 2 is applied to all n rows, so it is raised to the order of the matrix. Only for 1 × 1 matrices do the two rules coincide.

Rank & nullity 7
EM-U1-Q06MCQmedium

A 4 × 6 real matrix A has rank 4. The nullity of A is

  1. 0
  2. 2
  3. 4
  4. 6
Show answer & solution

Detailed solution

Concept. The rank–nullity theorem: for an m × n matrix, rank(A) + nullity(A) = n, the number of columns.

Step by step.

  1. Here m = 4, n = 6.
  2. nullity(A) = n − rank(A) = 6 − 4 = 2.
  3. Equivalently the solution space of Ax = 0 has dimension 2.

Answer: Option (B) — 2.

Common misconception. Using the number of rows (4 − 4 = 0) instead of the number of columns. The rank–nullity theorem counts the domain dimension n, never m.

EM-U1-Q07MCQeasy

Every row of a 3 × 3 real matrix A equals the same non-zero vector. The rank of A is

  1. 0
  2. 1
  3. 2
  4. 3
Show answer & solution

Detailed solution

Concept. The rank is the maximum number of linearly independent rows.

Step by step.

  1. All three rows are equal to one non-zero vector v.
  2. Any two rows are scalar multiples of each other, so at most one row is independent.
  3. Since v ≠ 0, that one row is independent, so rank(A) = 1.

Answer: Option (B) — 1.

Common misconception. Answering 3 because the matrix 'has three rows', or 0 because the rows are repeated. Rank counts independent directions, not rows; repetition reduces rank to 1 but a non-zero vector still contributes rank 1.

EM-U1-Q08MCQmedium

Let A be a 5 × 5 real matrix with rank(A) = 3. Which statement is TRUE?

  1. rank(Aᵀ) = 3 and nullity(A) = 2
  2. rank(Aᵀ) = 2
  3. nullity(A) = 3
  4. A is invertible
Show answer & solution

Detailed solution

Concept. Row rank equals column rank, so rank(Aᵀ) = rank(A); and rank + nullity = n.

Step by step.

  1. rank(Aᵀ) = rank(A) = 3.
  2. nullity(A) = 5 − 3 = 2.
  3. A is singular because rank(A) = 3 < 5, so option (D) fails.

Answer: Option (A).

Common misconception. Believing rank(Aᵀ) may differ from rank(A) for non-symmetric matrices. Row rank and column rank are always equal, for every real matrix.

EM-U1-Q09MCQhard

Let A be 3 × 5 and B be 5 × 3 real matrices with AB = I₃. Which statement is TRUE?

  1. rank(A) = 3 and nullity(A) = 2
  2. rank(A) = 5
  3. nullity(B) = 2
  4. BA = I₅
Show answer & solution

Detailed solution

Concept. Rank is submultiplicative: rank(XY) ≤ min(rank X, rank Y). Also rank(A) ≤ min(m, n).

Step by step.

  1. rank(AB) = rank(I₃) = 3.
  2. 3 = rank(AB) ≤ rank(A), and rank(A) ≤ min(3, 5) = 3, so rank(A) = 3.
  3. Then nullity(A) = 5 − 3 = 2, which confirms option (A).
  4. Similarly rank(B) = 3 and nullity(B) = 3 − 3 = 0, so (C) fails. BA would be 5 × 5, not I₅ in general — only AB = I₃ is given, so (D) fails.

Answer: Option (A).

Common misconception. Concluding BA = I₅ from AB = I₃. A right inverse of a wide matrix is not a two-sided inverse; here B is a right inverse of A only, and BA is a non-identity projection of rank 3.

EM-U1-Q17MSQmedium

Let A be a 6 × 4 real matrix with rank(A) = 3. Which statements are TRUE?

  1. nullity(A) = 1
  2. The columns of A span ℝ³
  3. rank(Aᵀ) = 3
  4. The six rows of A are linearly dependent
Show answer & solution

Detailed solution

Concept. Rank–nullity counts columns; row rank equals column rank; the column space lives in ℝ^m, not ℝ^r.

Step by step.

  1. nullity(A) = 4 − 3 = 1 — (A) is true.
  2. The columns are vectors in ℝ⁶ (six entries each), spanning a 3-dimensional subspace of ℝ⁶. They do not span ℝ³ — (B) is false.
  3. Row rank equals column rank, so rank(Aᵀ) = 3 — (C) is true.
  4. Six rows live in ℝ⁴, so at most 4 can be independent; with rank 3 they are dependent — (D) is true.

Answer: Options (A), (C) and (D).

Common misconception. Option (B): students match the rank 3 with ℝ³. Rank gives the dimension of the column space; the ambient space is still ℝ⁶ because the matrix has six rows.

EM-U1-Q22NATeasy

A 5 × 8 real matrix A has rank 5. Find the nullity of A. (Enter an integer.)

Answer format: a single integer.

Show answer & solution

Detailed solution

Concept. Rank–nullity: rank(A) + nullity(A) = n, where n is the number of columns.

Step by step.

  1. m = 5, n = 8, rank(A) = 5.
  2. nullity(A) = 8 − 5 = 3.
  3. So the solution space of Ax = 0 has dimension 3.

Answer: 3

Common misconception. Reporting 0 because the rank already equals the number of rows. Full row rank does not force trivial null space; only full column rank does.

EM-U1-Q25NAThard

Let A be a 4 × 4 real matrix with A² = A and rank(A) = 3. Find trace(A). (Enter an integer.)

Answer format: a single integer.

Show answer & solution

Detailed solution

Concept. A matrix satisfying A² = A is a projection: it is diagonalisable with eigenvalues only 0 and 1, so its trace counts the eigenvalues equal to 1, i.e. the rank.

Step by step.

  1. If λ is an eigenvalue with eigenvector v, then A²v = λ²v and also A²v = Av = λv, so λ² = λ, giving λ ∈ {0, 1}.
  2. A² = A implies A is diagonalisable (its minimal polynomial x² − x has distinct roots), so the algebraic multiplicity of each eigenvalue equals its geometric multiplicity.
  3. The multiplicity of λ = 1 is dim(Col A) = rank(A) = 3; the multiplicity of λ = 0 is nullity(A) = 1.
  4. trace(A) = 3·1 + 1·0 = 3.

Answer: 3

Common misconception. Guessing the trace from the diagonal entries of a particular example, or assuming A² = A forces A = I. Projections onto a proper subspace satisfy A² = A with trace strictly less than the order — here 3 < 4, exactly as expected.

EM-U1-Q10MCQeasy

Let A be a 3 × 3 real matrix with det(A) = 0, and let b ≠ 0 lie in the column space of A. The system Ax = b has

  1. exactly one solution
  2. infinitely many solutions
  3. no solution
  4. exactly three solutions
Show answer & solution

Detailed solution

Concept. Consistency is decided by rank(A) = rank([A | b]); the number of solutions is decided by the nullity.

Step by step.

  1. b is in the column space, so the system is consistent and at least one solution exists.
  2. det(A) = 0 means rank(A) ≤ 2, so nullity(A) = 3 − rank(A) ≥ 1.
  3. A non-zero null vector v lets us add tv to any solution for every t ∈ ℝ, producing infinitely many distinct solutions.

Answer: Option (B).

Common misconception. Equating det(A) = 0 with inconsistency. A singular system is inconsistent only when the right-hand side lies outside the column space; when it lies inside, there are infinitely many solutions.

EM-U1-Q11MCQmedium

For the system x + y = 2, 2x + 2y = k to have infinitely many solutions, k must be

  1. 0
  2. 2
  3. 4
  4. any real number
Show answer & solution

Detailed solution

Concept. Two equations in two unknowns represent the same line exactly when one is a scalar multiple of the other, including the constant terms.

Step by step.

  1. The second equation is twice the left side of the first: 2(x + y) = 2x + 2y.
  2. For the two lines to coincide we need k = 2 × 2 = 4.
  3. If k = 4, the second equation carries no new information and y is free: x = 2 − y, infinitely many solutions.
  4. If k ≠ 4, the system is inconsistent (parallel distinct lines).

Answer: Option (C) — 4.

Common misconception. Matching only the coefficient rows and forgetting the augmented column. Consistency requires rank(A) = rank([A | b]), so the constant terms must scale together with the coefficients.

EM-U1-Q12MCQmedium

A homogeneous system of 3 linear equations in 5 unknowns over ℝ

  1. has only the trivial solution
  2. always has a non-trivial solution
  3. has exactly two solutions
  4. may have no solution at all
Show answer & solution

Detailed solution

Concept. A homogeneous system is always consistent (it has x = 0), and it has a non-trivial solution exactly when the coefficient matrix has a non-trivial null space.

Step by step.

  1. The coefficient matrix is 3 × 5, so rank(A) ≤ 3.
  2. nullity(A) = 5 − rank(A) ≥ 5 − 3 = 2 > 0.
  3. A positive nullity means non-zero solutions exist, in fact a whole 2-dimensional (or larger) family.

Answer: Option (B).

Common misconception. Confusing this with the case of more equations than unknowns. With more unknowns than equations the non-trivial solution is guaranteed; with 5 equations in 3 unknowns it is not.

EM-U1-Q13MCQhard

The system x + 2y + 3z = 1, 2x + 4y + 6z = 2, 3x + 6y + 9z = 4 is

  1. consistent with a unique solution
  2. consistent with infinitely many solutions
  3. inconsistent
  4. consistent with exactly two solutions
Show answer & solution

Detailed solution

Concept. Compare rank(A) with rank([A | b]): equality means consistent, inequality means inconsistent.

Step by step.

  1. Row 2 is 2 × Row 1, and Row 3 is 3 × Row 1 in the coefficient part. So rank(A) = 1.
  2. Row 3 of the augmented matrix is [3, 6, 9 | 4]. Subtracting 3 × Row 1 [1, 2, 3 | 1] leaves [0, 0, 0 | 1].
  3. That row reads 0 = 1, impossible. Hence rank([A | b]) = 2 > rank(A) = 1, and the system is inconsistent.

Answer: Option (C).

Common misconception. Seeing that the coefficient rows are proportional and concluding 'infinitely many solutions'. Proportional coefficients give rank(A) = 1, but the right-hand side must scale the same way; here 4 ≠ 3 × 1, which is exactly what makes it inconsistent.

EM-U1-Q18MSQmedium

Which of the following statements about linear systems are TRUE?

  1. A homogeneous system with 3 equations and 5 unknowns always has a non-trivial solution.
  2. A system with more equations than unknowns is always inconsistent.
  3. If A is 4 × 4 with det(A) = 0, then Ax = b either has no solution or infinitely many.
  4. For b ≠ 0, the solution set of Ax = b is a subspace of ℝⁿ
Show answer & solution

Detailed solution

Concept. Consistency of a homogeneous system, the rank test for general systems, and the affine (not linear) nature of a non-homogeneous solution set.

Step by step.

  1. (A) True: rank ≤ 3 < 5, so nullity ≥ 2 and non-trivial solutions exist.
  2. (B) False: an overdetermined system can be perfectly consistent, e.g. x = 1, 2x = 2, 3x = 3.
  3. (C) True: det(A) = 0 makes A singular, so either the system is inconsistent or the nullity is positive, giving infinitely many solutions. A unique solution is impossible.
  4. (D) False: the solution set of Ax = b with b ≠ 0 does not contain 0, so it cannot be a subspace. It is a translate of the null space.

Answer: Options (A) and (C).

Common misconception. Option (D) is a frequent error: the homogeneous solution set N(A) is a subspace, but a coset x₀ + N(A) is not, precisely because it misses the origin.

EM-U1-Q23NATmedium

The system x + y + z = 3, x + 2y + 3z = 4, x + 3y + kz = 5 has infinitely many solutions for exactly one integer value of k. Find that value. (Enter an integer.)

Answer format: a single integer.

Show answer & solution

Detailed solution

Concept. A square system has infinitely many solutions exactly when the coefficient matrix is singular and the system is consistent.

Step by step.

  1. R₂ ← R₂ − R₁: y + 2z = 1.
  2. R₃ ← R₃ − R₁: 2y + (k − 1)z = 2.
  3. Eliminate y using step 1: 2(1 − 2z) + (k − 1)z = 2, so (k − 5)z = 0.
  4. If k = 5 the last row vanishes and z is free: y = 1 − 2z, x = 2 + z, giving infinitely many solutions.
  5. If k ≠ 5, then z = 0, y = 1, x = 2: a unique solution.

Answer: 5

Common misconception. Solving for the determinant and reporting every root as 'infinitely many'. A zero determinant gives singularity, but one must also verify the system stays consistent — here it does, at k = 5.

Gauss elimination 4
EM-U1-Q14MCQeasy

Applying Gauss–Jordan elimination to a system whose coefficient matrix is invertible transforms that coefficient matrix into

  1. an upper-triangular matrix
  2. the identity matrix
  3. a diagonal matrix that is not the identity
  4. its own transpose
Show answer & solution

Detailed solution

Concept. Gauss–Jordan elimination continues forward elimination with backward elimination, reducing the augmented matrix to reduced row-echelon form.

Step by step.

  1. Forward elimination alone produces an upper-triangular U — that is plain Gaussian elimination.
  2. Gauss–Jordan then eliminates above each pivot and scales every pivot to 1.
  3. For an invertible matrix every column has a pivot, so the coefficient block becomes I.

Answer: Option (B).

Common misconception. Confusing the two methods. Gaussian elimination stops at upper-triangular form; only Gauss–Jordan reaches the identity, after which the solution is read directly from the transformed right-hand side.

EM-U1-Q15MCQhard

Gaussian elimination is applied to A = [[1, 2, 3], [2, 4, 7], [3, 6, 10]]. The rank of A is

  1. 1
  2. 2
  3. 3
  4. 0
Show answer & solution

Detailed solution

Concept. Row operations preserve the row space, so the number of non-zero rows in the echelon form is the rank.

Step by step.

  1. R₂ ← R₂ − 2R₁: [2, 4, 7] − [2, 4, 6] = [0, 0, 1].
  2. R₃ ← R₃ − 3R₁: [3, 6, 10] − [3, 6, 9] = [0, 0, 1].
  3. R₃ ← R₃ − R₂: [0, 0, 0].
  4. The echelon form is [[1, 2, 3], [0, 0, 1], [0, 0, 0]], with two non-zero rows, so rank(A) = 2.

Answer: Option (B) — 2.

Common misconception. Reading rank off the first column only, or stopping after one elimination step. Rank is the count of pivots across all columns, obtained only after the elimination is complete.

EM-U1-Q19MSQhard

Which of the following statements about Gaussian elimination are TRUE?

  1. Partial pivoting can reduce the growth of round-off error.
  2. For a dense n × n matrix, forward elimination costs about n³/3 multiplications.
  3. If a zero pivot appears while a non-zero entry remains below it in that column, a row interchange can continue the elimination.
  4. An LU decomposition without row interchanges exists for every non-singular matrix.
Show answer & solution

Detailed solution

Concept. Pivoting strategy, operation count, and the exact condition for a pivot-free LU factorisation.

Step by step.

  1. (A) True: choosing the largest-magnitude candidate as pivot keeps multipliers |l_ik| ≤ 1, bounding error growth.
  2. (B) True: the total is Σ_{k=1}^{n−1} (n−k)(n−k+1) ≈ n³/3 multiplications.
  3. (C) True: a zero pivot with a non-zero entry below is repairable by interchanging rows — this is exactly why partial pivoting is used.
  4. (D) False: LU without interchanges requires every leading principal minor to be non-zero. For example [[0, 1], [1, 0]] is non-singular but has no such factorisation.

Answer: Options (A), (B) and (C).

Common misconception. Believing non-singularity alone guarantees LU. It guarantees a factorisation only with row interchanges (PA = LU); without pivoting a zero pivot can appear even for an invertible matrix.

EM-U1-Q24NATmedium

Gaussian elimination without row interchange is applied to A = [[2, 1, 1], [4, 3, 3], [8, 7, 9]]. Find U₃₃, the (3, 3) entry of the resulting upper-triangular matrix U. (Enter an integer.)

Answer format: a single integer.

Show answer & solution

Detailed solution

Concept. Forward elimination annihilates entries below each pivot using multipliers l_ik = a_ik / a_kk.

Step by step.

  1. Pivot a₁₁ = 2. R₂ ← R₂ − 2R₁: [4,3,3] − [4,2,2] = [0,1,1].
  2. R₃ ← R₃ − 4R₁: [8,7,9] − [8,4,4] = [0,3,5].
  3. Pivot a₂₂ = 1. R₃ ← R₃ − 3R₂: [0,3,5] − [0,3,3] = [0,0,2].
  4. So U = [[2,1,1],[0,1,1],[0,0,2]] and U₃₃ = 2.

Answer: 2

Common misconception. Subtracting multiples of the original first row again in the third step instead of using the updated second row. Each elimination must use the current pivot row, not the original R₁.

Concept map used to build the questions

  • Matrix operations. Conformability of a chain of products, tested pairwise and left to right; the determinant of a triangular matrix as the product of its diagonal; the composition of det(kA) = kⁿ det(A) with det(A⁻¹) = 1/det(A); the inverse of a product with a transpose inside it, (AᵀB)⁻¹ = B⁻¹(A⁻¹)ᵀ; nilpotent and idempotent matrices, where A² = 0 forces singularity and A² = A forces det(A) ∈ {0, 1}; and cancellation, which needs invertibility.
  • Rank & nullity. The bound rank(A) ≤ min(m, n) and the resulting floor on the nullity of a wide matrix; the column space living inside ℝᵐ; rank(AB) ≤ min(rank A, rank B) and when the bound is attained; and the nilpotent chain argument col(A) ⊆ ker(A), which caps the rank at n/2. Rank–nullity is always counted over columns.
  • Systems of linear equations. A homogeneous system is always consistent, so rank alone decides between the trivial solution and infinitely many; the solution set of a consistent Ax = b is an affine subspace of dimension n − rank(A); Cramer's rule with the replacement column matched to the unknown; and uniqueness of a square system decided by the determinant, independent of the right-hand side.
  • Gauss elimination. The three elementary row operations and why scaling by zero is not one; the operation counts n³/3 for forward elimination and n³/2 for Gauss–Jordan; banded structure, where a tridiagonal system costs only Θ(n); and pivoting — partial, scaled partial and complete — which bounds the growth of round-off error without making finite-precision arithmetic exact.
