What this test contains

25 questions on Unit 1 (C Programming Foundations), Set 1 of 2. All four subtopics are covered: data types and operators, control structures, functions and parameter passing, and recursion with stack execution. Composition: 15 MCQ, 5 MSQ, 5 NAT; difficulty 10 easy, 10 medium, 5 hard; 60 minutes, 35 marks. MCQ carries 1 mark, MSQ and NAT carry 2 marks, there is no negative marking, and an MSQ scores only when the exact set of correct options is selected. This is a practice marking scheme, not the official GATE scheme.

Concept map used to build the questions

  • Data types & operators. Integer division truncating towards zero; character constants having type int; bitwise precedence & > ^ > |; unsigned arithmetic modulo 2ⁿ against undefined signed overflow; integer promotion before a shift; the comma operator; and implementation-defined signedness of plain char.
  • Control structures. Assignment inside an if; comma expressions in a for header; nested loops and arithmetic-series counts; switch fall-through and the scope of break and continue; and the two classic non-terminating loops — an unsigned counter tested with >= 0 and an equality test with a stride that never hits its target.
  • Functions & parameter passing. Call by value, and why a swap needs addresses; array parameters decaying to pointers, so sizeof and the element count are lost; static locals keeping state between calls; and which writes through a parameter are visible to the caller.
  • Recursion & stack execution. Unwinding order, so code before a recursive call runs on the way down and code after it runs on the way up; counting calls with C(n) = C(n−1) + C(n−2) + 1; per-frame copies of parameters and automatic locals; tail-call optimisation; and the finite stack depth that the standard does not bound.
