TOC-U1-Q01MCQeasy

Over the alphabet Σ = {a, b}, the minimal DFA that accepts exactly those strings which contain an even number of a's has how many states?

  1. 2
  2. 3
  3. 4
  4. Infinitely many
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. A DFA cannot count; it can only remember a finite amount of information. For the parity of the number of a's the only thing that matters is whether the count seen so far is even or odd — two facts, hence at most two states.

Step by step.

  1. Let E = "even number of a's so far" (start state, and final because the empty string has zero a's). Let O = "odd number so far".
  2. δ(E,a) = O, δ(E,b) = E — a b does not change the parity.
  3. δ(O,a) = E, δ(O,b) = O.
  4. Both states are reachable (ε reaches E, a reaches O) and distinguishable (E is final, O is not). So no further merging is possible.

Answer: Option (A) — 2 states.

Common misconception. Many candidates add a third "dead" state, imagining that a misplaced b must be rejected. It must not: b's are simply ignored, so the transition on b stays inside the two parity states. Equally wrong is "infinitely many", which forgets that a DFA only needs the parity, not the count.

TOC-U1-Q02MCQeasy

In DFA minimisation by the table-filling method, two states p and q of a complete DFA are distinguishable exactly when:

  1. there is a string w ∈ Σ* such that exactly one of δ̂(p,w) and δ̂(q,w) is a final state.
  2. p and q are both final states.
  3. p and q are both non-final states.
  4. no string takes p and q to different states.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. States are equivalent when no future input can tell them apart, i.e. when for every string w the two runs agree on acceptance. Distinguishable is the negation of that: some string w makes exactly one run end in a final state.

Step by step.

  1. Take w = ε. If one state is final and the other is not, they are already distinguishable.
  2. Otherwise try longer strings: p and q are distinguishable if for some symbol a the states δ(p,a) and δ(q,a) are distinguishable.
  3. Table filling propagates this rule until no new pair is marked; unmarked pairs are merged.

Answer: Option (A).

Common misconception. Options (B) and (C) are necessary conditions only for w = ε: two final states, or two non-final states, may still be told apart by a longer string. Option (D) describes equivalence, the opposite of distinguishability.

TOC-U1-Q09MCQmedium

Let L = {w ∈ {0,1}* : #₀(w) ≡ 0 (mod 3) and #₁(w) ≡ 0 (mod 2)}. The minimal DFA accepting L has how many states?

  1. 5
  2. 6
  3. 8
  4. 3
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. A conjunction of two independent modular conditions is recognised by the product of the two machines; the state count multiplies.

Step by step.

  1. The condition #₀ ≡ 0 mod 3 needs 3 states (the residues 0, 1, 2).
  2. The condition #₁ ≡ 0 mod 2 needs 2 states (even, odd).
  3. The product machine tracks the pair (i, j) with i = #₀ mod 3 and j = #₁ mod 2: 3 × 2 = 6 states, and every pair is reachable.
  4. All six are pairwise distinguishable (residue classes of a mod-3 counter and a mod-2 counter are distinct), so the product is already minimal.

Answer: Option (B) — 6 states.

Common misconception. Adding the counts (3 + 2 = 5) instead of multiplying them, or forgetting that the two conditions are independent and must be tracked simultaneously.

TOC-U1-Q12MCQhard

Consider the complete DFA below over Σ = {0,1}, start state A, final states {A, E}. The minimal DFA equivalent to it has how many states?

| 0 | 1 ------+-----+----- A* | B | C B | A | D C | D | E D | C | B E* | B | C

  1. 5
  2. 4
  3. 3
  4. 2
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Minimisation first deletes unreachable states, then merges states that are indistinguishable by every input string.

Step by step.

  1. All five states are reachable: A → B, C; C → E; B → D.
  2. Compare A and E. Both are final. δ(A,0) = B = δ(E,0) and δ(A,1) = C = δ(E,1), so no input can separate them: A ≡ E.
  3. Every other pair is separated by a short string: B and C are non-final but δ(B,0) = A is final while δ(C,0) = D is not; D is separated from B by 0 (to C, non-final) versus A (final); and the final state A is separated from every non-final state by ε.
  4. Merging A and E leaves {[A,E], B, C, D} = 4 states.
  5. As a check, the language is "even number of 0's and even number of 1's", whose product DFA has exactly 4 states.

Answer: Option (B) — 4 states.

Common misconception. Answering 5 by assuming that two distinct final states must be distinguishable, or answering 3 by merging the two non-final states B and C that differ on input 0. Merging is allowed only when no string separates the pair.

TOC-U1-Q16MSQmedium

Which of the following statements about DFA minimisation are TRUE?

  1. A state that is not reachable from the start state can always be deleted without changing the accepted language.
  2. Two states p, q are equivalent if and only if for every string w, δ̂(p,w) ∈ F exactly when δ̂(q,w) ∈ F.
  3. Merging equivalent states never changes the language accepted by the automaton.
  4. A DFA in which every state is reachable and every pair of states is distinguishable can still be reduced further.
Show answer & solution

Answer: Options (A), (B) and (C)

Detailed solution

Concept. Minimisation = remove unreachable states, then merge equivalent states; the result is the unique minimal DFA up to renaming.

Step by step.

  1. (A) true. An unreachable state is never entered on any input, so it can never affect acceptance.
  2. (B) true. This is exactly the definition of state equivalence (≡ is the right congruence).
  3. (C) true. Merging equivalent states preserves the run of every string up to equivalence, hence preserves acceptance.
  4. (D) false. Reachability plus pairwise distinguishability is precisely the definition of a minimal DFA; nothing is left to remove or merge.

Answer: Options (A), (B) and (C).

Common misconception. Believing that a "tidy-looking" DFA can always be squeezed further, or that merging states always risks changing the language — merging equivalent states cannot.

TOC-U1-Q21NATeasy

Count the states of the minimal DFA over {0,1} that accepts exactly the binary strings denoting a number divisible by 5. Take the usual convention: leading zeros are allowed and the empty string denotes 0, so ε is accepted.

Show answer & solution

Answer: 5

Detailed solution

Concept. Divisibility by k is decided by the remainder of the value read so far, and reading a bit b maps r ↦ (2r + b) mod 5. The remainder is the state.

Step by step.

  1. States q₀ … q₄, where q_r means "the number read so far leaves remainder r". Start q₀, final q₀.
  2. Transitions: δ(q_r, 0) = q_{2r mod 5} and δ(q_r, 1) = q_{(2r+1) mod 5}.
  3. All five remainders are reachable (q₀ by ε, then q₁ by 1, q₂ by 10, q₃ by 11, q₄ by 100).
  4. They are pairwise distinguishable: q_0 is the only final state, and from q_r, q_s one can always append digits to reach a multiple of 5 for one and not the other. So 5 is minimal.

Answer: 5.

Common misconception. Answering 6 by adding a separate "no input yet" start state; with the stated convention ε denotes 0 and is accepted, so q₀ doubles as the start state. Another trap is writing 4 or 10 by confusing divisor and radix.

TOC-U1-Q22NATmedium

How many states does the minimal complete DFA have for L = {a^n b^m : n ≥ 1, m ≥ 2} over Σ = {a,b}?

Show answer & solution

Answer: 5

Detailed solution

Concept. The machine must remember whether the initial a-block has started, and how many b's have been seen (0, 1, ≥2) — plus a dead state for violations.

Step by step.

  1. q₀ (start, non-final): no a yet. On a → q₁; on b → d (violates n ≥ 1).
  2. q₁ (non-final): at least one a. On a → q₁; on b → q₂.
  3. q₂ (non-final): exactly one b. On b → q₃; on a → d (an a after b is illegal).
  4. q₃ (final): at least two b's. On b → q₃; on a → d.
  5. d (dead, non-final): self-loops on both symbols.
  6. Five states, all reachable, pairwise distinguishable (q₃ is the only final state; d is the only one from which nothing final is reachable; q₀,q₁,q₂ differ in how many b's they still need) — so 5 is minimal.

Answer: 5.

Common misconception. Answering 4 by dropping the dead state — but the DFA must be complete, and a b before any a has to go somewhere. Answering 6 by counting a separate start state for q₀.

TOC-U1-Q26MCQeasy

Over Σ = {a, b}, how many states does the minimal complete DFA have that accepts exactly those strings which end in ab?

  1. 2
  2. 3
  3. 4
  4. 5
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. A DFA reads left to right and cannot look ahead, so "ends in ab" is decided by remembering only how much of the pattern has already been matched. The number of states equals the number of distinct residuals of the language.

Step by step.

  1. State q₀ — nothing of the pattern matched so far (also the start state, and the state reached after any symbol other than the one that advances the match).
  2. State q₁ — the last symbol read was a.
  3. State q₂ — the last two symbols read are ab; this is the only final state.
  4. Transitions: q₀ →a q₁, q₀ →b q₀, q₁ →a q₁, q₁ →b q₂, q₂ →a q₁, q₂ →b q₀.
  5. All three are reachable (ε, a, ab) and pairwise distinguishable: q₂ accepts ε while the others reject it; q₁ accepts b while q₀ rejects it. So no two states merge.

Answer: Option (B) — 3 states.

Why the other options are wrong.

  • (A) Two states cannot separate "ends in a" from "ends in ab"; the third residual is genuinely different.
  • (C) and (D) add a state for "ends in b", which is the same residual as "nothing matched" — the table-filling method merges them.

Common misconception. Candidates insert an extra start state distinct from "no partial match seen". Those two are the same residual, and a DFA has one state per residual, not one per event.

Takeaway. A language that constrains the last k symbols needs k + 1 states; the "ends in" pattern is the cheapest way GATE tests this.

TOC-U1-Q30MCQeasy

Which one of the following is TRUE of the minimal DFA of a regular language L?

  1. It is unique up to renaming of states.
  2. It always has strictly fewer states than every NFA that accepts L.
  3. Every one of its states must be a final state.
  4. It is never a complete DFA.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. By the Myhill–Nerode theorem the states of the minimal DFA are exactly the distinct residuals u⁻¹L = {v : uv ∈ L} of the language. A language determines its residuals uniquely, so it determines its minimal DFA uniquely.

Step by step.

  1. Every DFA for L assigns each state a residual: the set of suffixes accepted from it.
  2. Two states with the same residual are indistinguishable and can be merged.
  3. So every DFA for L has at least as many states as L has distinct residuals, and the minimal DFA has exactly that many.
  4. Two minimal DFAs for the same language therefore have the same states up to the naming of states and the choice of the start state's name.

Answer: Option (A) — unique up to renaming of states.

Why the other options are wrong.

  • (B) fails: for {w : the n-th symbol from the right is 1} an NFA with n + 1 states suffices while every DFA needs 2ⁿ states, so the minimal DFA can be exponentially larger than an NFA.
  • (C) fails for any language that is not Σ*; a DFA needs non-final states too.
  • (D) fails: the minimal DFA of a regular language is always complete — missing transitions would have to lead to an implicit rejecting sink, which is a state.

Common misconception. Believing that different constructions produce genuinely different minimal machines. They can differ while being built, but the end result is the same machine up to names.

Takeaway. One regular language, one minimal DFA. This uniqueness is what lets GATE ask for "the number of states" without further qualification.

TOC-U1-Q34MCQmedium

A complete DFA over Σ = {0, 1} has 6 states. Exactly 2 of them cannot be reached from the start state, and among the 4 reachable states exactly 2 are equivalent to each other. How many states does the minimal equivalent DFA have?

  1. 3
  2. 4
  3. 5
  4. 6
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Minimisation is two operations in a fixed order: first delete unreachable states (they can never affect the accepted language), then merge equivalent reachable states (they are indistinguishable by any suffix).

Step by step.

  1. Start with 6 states.
  2. Remove the 2 unreachable states: 6 − 2 = 4 remain.
  3. Among those 4, one pair is equivalent, so the pair collapses into a single state: 4 − 1 = 3.
  4. The remaining 3 states are reachable and pairwise distinguishable, so no further merging is possible.

Answer: Option (A) — 3 states.

Why the other options are wrong.

  • (B) 4 forgets to merge the equivalent pair.
  • (C) 5 removes only one unreachable state, or merges before pruning.
  • (D) 6 assumes no reduction at all.

Common misconception. Merging first and pruning afterwards. It happens to give the same count here, but it can go wrong: an unreachable state can be equivalent to a reachable one, and merging them before pruning can hide a real distinction. Prune, then merge.

Takeaway. Minimal states = (reachable states) − (merges among them). Do the two steps in that order, and never count a state that cannot be entered.

TOC-U1-Q38MCQhard

Consider the complete DFA over Σ = {0, 1} with start state A, final states {C, D} and the transition table below. The minimal DFA equivalent to it has how many states?

| 0 | 1 ------+-----+----- A | B | E B | D | C C* | F | A D* | A | C E | D | C F | B | F

  1. 4
  2. 5
  3. 6
  4. 7
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Minimality is decided by two tests: every state must be reachable from the start state, and no two states may be equivalent. States with identical rows and the same finality are equivalent and merge.

Step by step.

  1. Reachability. From A: A → {B, E}; from B: D, C; from C: F, A; from D: A, C; from E: D, C; from F: B, F. All six states are reachable, so nothing is deleted.
  2. First refinement. Split into final {C, D} and non-final {A, B, E, F}.
  3. Compare rows inside the non-final block. B and E both go to D on 0 and to C on 1, and both are non-final — the rows are identical, so B ≡ E. A (→B, E) and F (→B, F) differ from that and from each other, and they sit in different classes from {C, D}, so they stay separate.
  4. Compare inside the final block. C goes to F on 0 while D goes to A; A and F are already separated (they reach different classes), so C and D are distinguishable.
  5. Count. Classes are {A}, {B, E}, {C}, {D}, {F} — five states.

Answer: Option (B) — 5 states.

Why the other options are wrong.

  • (A) 4 would need a second merge, but no other pair shares both row and finality.
  • (C) 6 is the unminimised count: it misses B ≡ E.
  • (D) 7 exceeds the number of states in the given table, which is impossible for a minimal DFA.

Common misconception. Merging states with equal rows but different finality. Here B and E are both non-final, which is what licenses the merge; a final and a non-final state can never be equivalent because ε separates them.

Takeaway. Run table filling in order: split final from non-final, then refine by destination classes until nothing changes. Identical rows in the same block are an immediate merge.

TOC-U1-Q41MSQmedium

Which of the following languages over Σ = {a, b} have a minimal complete DFA with exactly 3 states? (Select all that apply.)

  1. {w : w ends in ab}
  2. {w : w has an even number of a's}
  3. {w : w contains aa as a substring}
  4. {w : |w| ≡ 1 (mod 3)}
Show answer & solution

Answer: Options (A), (C) and (D)

Detailed solution

Concept. The number of states of the minimal DFA equals the number of distinct residuals. Each option is checked by counting the residuals it forces.

Step by step.

  1. (A) ends in ab. Three residuals: "no partial match", "last symbol was a", "last two symbols are ab". All reachable, all distinguishable. 3 states ✓
  2. (B) even number of a's. Only the parity of the count matters, and b's change nothing. Two residuals. 2 states ✗
  3. (C) contains aa. Three residuals: no aa yet and last symbol not a; no aa yet and last symbol is a; aa already seen (absorbing, accepting). 3 states ✓
  4. (D) |w| ≡ 1 (mod 3). Three residuals, indexed by |w| mod 3, the one with residue 1 accepting. 3 states ✓

Answer: Options (A), (C) and (D).

Common misconception. Adding a separate dead state to (C) on the grounds that a wrong symbol must be rejected. After aa every further symbol is accepted, so the third state absorbs; and before aa there is no rejecting sink because every symbol keeps the run alive. Counting states "intuitively" instead of by residual is the usual slip.

Takeaway. Ask "what must be remembered?" For suffix patterns it is the matched prefix length; for counts it is the residue; for absorbing conditions it is a single flag state.

TOC-U1-Q46NATeasy

How many states does the minimal complete DFA over Σ = {a, b} have that accepts exactly those strings which contain aba as a substring?

Show answer & solution

Answer: 4

Detailed solution

Concept. "Contains aba" is decided by remembering the longest prefix of aba that is a suffix of what has been read. That gives one state per prefix length plus one absorbing accepting state.

Step by step.

  1. q₀ — no prefix of aba matched.
  2. q₁ — the last symbol is a, a prefix of length 1.
  3. q₂ — the last two symbols are ab, a prefix of length 2.
  4. q₃ — aba has been seen; absorbing and accepting.
  5. Transitions: q₀ →a q₁, q₀ →b q₀; q₁ →a q₁, q₁ →b q₂; q₂ →a q₃, q₂ →b q₀; q₃ →a q₃, q₃ →b q₃.
  6. The four residuals are distinct (ε separates q₃ from the rest; ba separates q₂; ba against b separates q₁), so no merging is possible.

Answer: 4.

Common misconception. Answering 3 by forgetting the accepting state, or 5 by adding a dead state for "wrong symbol". After aba every input is accepted, so the accepting state absorbs; and before aba no input kills the run, so no dead state is needed.

Takeaway. A pattern of length k needs k + 1 states when the matched state absorbs. The subtle part is the fallback transitions: q₂ →b q₀ because abb ends in bb, not in a prefix of aba.

TOC-U1-Q47NATeasy

How many states does the minimal complete DFA over Σ = {0, 1} have that accepts exactly those binary strings whose value is congruent to 2 modulo 3? Leading zeros are allowed and the empty string denotes 0.

Show answer & solution

Answer: 3

Detailed solution

Concept. Reading a binary string left to right, appending a bit b maps the value v to 2v + b. Modulo 3 only the residue of v matters, so three residues suffice — and are necessary.

Step by step.

  1. States r₀, r₁, r₂ meaning "value so far ≡ i (mod 3)". Start state r₀, because the empty string has value 0.
  2. Transitions follow r → (2r + b) mod 3.
  3. r₀ →0 r₀, r₀ →1 r₁; r₁ →0 r₂, r₁ →1 r₀; r₂ →0 r₁, r₂ →1 r₂.
  4. The single final state is r₂.
  5. Check: 10 = 2 → r₀ →1 r₁ →0 r₂ ✓ accepted; 11 = 3 ≡ 0 → r₁ →1 r₀ ✓ rejected.
  6. The three residues are pairwise distinguishable — from r₀ the string 10 is accepted, from r₁ the string 0 is accepted, from r₂ the empty string is accepted — so all three are needed.

Answer: 3.

Common misconception. Treating the number of bits as the state count, or forgetting that leading zeros are allowed so 010 and 10 must land in the same state. The state is the residue, not the length.

Takeaway. For "value mod k" languages the minimal DFA has exactly k states, with r → (2r + b) mod k. Moduli other than 2 need the general rule, not the parity shortcut.

TOC-U1-Q03MCQeasy

An NFA accepts a string w if and only if:

  1. at least one computation path labelled w leads from the start state to a final state.
  2. every computation path labelled w leads from the start state to a final state.
  3. the NFA has no ε-transitions on the path.
  4. exactly one computation path labelled w reaches a final state.
Show answer & solution

Answer: Option (A)

Detailed solution

Concept. Nondeterminism is existential acceptance: the NFA guesses, and one successful guess is enough.

Step by step.

  1. Running an NFA on w produces a set of reachable states rather than a single state.
  2. The string is accepted when that set meets the set of final states.
  3. Dead-end branches are simply abandoned; they do not veto acceptance.

Answer: Option (C)

Detailed solution

Step by step.

  1. The yield has n terminal leaves.
  2. Each leaf is the only child of the production that emitted it, so there are at most n terminal-production nodes — at most, because one production such as A → ab can emit two leaves at once.
  3. Let b be the number of branching nodes and u the number of terminal-production nodes. Counting edges: 2b + u = b + u + n − 1 when every branching node is binary, so b = n − 1. A ternary production would only reduce b, so n − 1 is the maximum.

  • (B) Quadratic growth needs unary chains, which the ban on unit productions removes.
  • (D) n + 1 is far too small for any tree with more than one branching node.

  3. Accept when the PDA accepts and the DFA state is final. Hence L ∩ R is context-free.
  4. The same construction fails for a second CFL, because two stacks cannot be simulated by one.

Answer: Option (C)

Why the other options are wrong.

  • (A) CFLs are not closed under complement.
  • (B) Two arbitrary CFLs can intersect to a non-CFL, e.g. {aⁿbⁿcᵐ} ∩ {aᵐbⁿcⁿ} = {aⁿbⁿcⁿ}.
  • (D) involves a complement, so it is not guaranteed to be context-free.

Common misconception. Believing that "regular is small, so intersecting with it must be fine for the other operand too" — the asymmetry is real: one side must be regular.

TOC-U2-Q22MSQmedium

Select every operation under which the class of context-free languages is closed.

  1. union
  2. intersection with a regular language
  3. homomorphism
  4. complement
Show answer & solution

Answer: Options (A), (B), (C)

Detailed solution

Concept. Closure holds when the operation can be simulated without a second stack. Union and homomorphism act on productions; intersection with a regular language acts on control states.

Step by step.

  1. Union: S → S₁ | S₂ with disjoint nonterminal sets. Closed.
  2. Intersection with a regular language: product of a PDA and a DFA, one stack only. Closed.
  3. Homomorphism: replace each terminal a in every production by the grammar of h(a); the result is again context-free. Closed.
  4. Complement: not closed. L = {aᵡbᵑcᵏ : i ≠ j or j ≠ k} is context-free but its complement {aⁿbⁿcⁿ} is not. Not closed.

Answer: (A), (B) and (C)

Common misconception. Assuming closure under complement because CFLs are closed under union. If CFLs were closed under both union and complement they would be closed under intersection, which they are not — a one-line contradiction worth remembering.

TOC-U2-Q23MSQmedium

Let L₁ and L₂ be context-free languages and R a regular language. Select every statement that is TRUE.

  1. L₁ − R is context-free.
  2. L₁ ∩ L₂ is context-free.
  3. L₁* is context-free.
  4. L₁ ∪ L₂ is context-free.
Show answer & solution

Answer: Options (A), (C), (D)

Detailed solution

Concept. Use the known closure properties and reduce each statement to one of them.

Step by step.

  1. (A) L₁ − R = L₁ ∩ R̄, and R̄ is regular, so this is a CFL intersected with a regular language. True.
  2. (B) The intersection of two CFLs need not be context-free: {aⁿbⁿcᵐ} ∩ {aᵐbⁿcⁿ} = {aⁿbⁿcⁿ}. False.
  3. (C) Kleene star is a basic closure property: add S → SS | ε. True.
  4. (D) Union is a basic closure property. True.

Answer: (A), (C) and (D)

Common misconception. Treating set difference as "removing something, so it must be safe" without checking. It is safe here only because the removed set is regular; L₁ − L₂ for two CFLs is not guaranteed context-free.

TOC-U2-Q24MCQhard

Let L₁ = {aⁿbⁿcᵐ : n, m ≥ 0} and L₂ = {aᵐbⁿcⁿ : m, n ≥ 0}. Which of the following is TRUE?

  1. Both are context-free and L₁ ∩ L₂ is context-free.
  2. Both are context-free, but L₁ ∩ L₂ = {aⁿbⁿcⁿ : n ≥ 0} is not context-free.
  3. L₁ is not context-free, though L₂ is.
  4. Both are context-free, but L₁ ∪ L₂ is not context-free.
Show answer & solution

Answer: Option (B)

Detailed solution

Concept. Each language has one matched pair and one free block, so a single stack suffices. The intersection forces two matched pairs at once, which needs two stacks.

Step by step.

  1. L₁ is generated by S → AB, A → aAb | ε, B → cB | ε. So it is context-free.
  2. L₂ is generated by S → AC, A → aA | ε, C → bCc | ε. Also context-free.
  3. In the intersection, a string must satisfy #a = #b (from L₁) and #b = #c (from L₂), so it is exactly {aⁿbⁿcⁿ}.
  4. By the pumping lemma for CFLs, {aⁿbⁿcⁿ} is not context-free: pumping any v, x pair disturbs at least one of the three equal counts.
  5. Union, on the other hand, is always context-free — just add S → S₁ | S₂ — so (D) is false.

Answer: Option (B)

Why the other options are wrong.

  • (A) contradicts the non-context-freeness of {aⁿbⁿcⁿ}.
  • (C) misreads the grammars: both have a single matched pair.
  • (D) ignores closure under union, which holds unconditionally for CFLs.

Common misconception. Assuming that a language with three symbols in a fixed order must be non-context-free. Ordering is irrelevant; the question is how many independent counts must be held at the same time.

TOC-U2-Q25MCQmedium

Which of the following languages is NOT context-free?

  1. {aⁿbⁿ : n ≥ 0}
  2. {aⁿbᵐ : n ≠ m}
  3. {w ∈ {a,b}* : #a(w) = #b(w)}
  4. {ww : w ∈ {a,b}*}
Show answer & solution

Answer: Option (D)

Detailed solution

Concept. A CFL can compare one pair of counts using its stack. Copying an arbitrary string requires remembering it in full, which a single stack cannot do while the second copy is read in the same left-to-right order.

Step by step.

  1. (A) is the model CFL: S → aSb | ε.
  2. (B) {aⁿbᵐ : n < m} ∪ {aⁿbᵐ : n > m}, a union of two CFLs, hence context-free.
  3. (C) #a = #b is generated by S → aSbS | bSaS | ε — context-free.
  4. (D) Suppose a PDA accepts {ww}. On aⁿbⁿaⁿbⁿ the stack must hold the first half and then match it, but the stack pops in reverse order, so the second half would have to be read backwards. The pumping lemma confirms the failure, so (D) is not context-free.

Answer: Option (D)

Why the other options are wrong.

  • (A), (B) and (C) each compare a fixed number of counts, which one stack handles.
  • Note that {wwᵀ} is context-free — the reversal is exactly what the stack provides. Only the non-reversed copy fails.

Common misconception. Confusing {ww} with {wwᵀ}. The single superscript R is the whole difference between a CFL and a non-CFL.
