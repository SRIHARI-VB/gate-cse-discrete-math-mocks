TOC-U1-Q01MCQeasy

Over the alphabet Σ = {a, b}, the minimal DFA that accepts exactly those strings which contain an even number of a's has how many states?

  1. 2
  2. 3
  3. 4
  4. Infinitely many
Show answer & solution

Detailed solution

Concept. A DFA cannot count; it can only remember a finite amount of information. For the parity of the number of a's the only thing that matters is whether the count seen so far is even or odd — two facts, hence at most two states.

Step by step.

  1. Let E = "even number of a's so far" (start state, and final because the empty string has zero a's). Let O = "odd number so far".
  2. δ(E,a) = O, δ(E,b) = E — a b does not change the parity.
  3. δ(O,a) = E, δ(O,b) = O.
  4. Both states are reachable (ε reaches E, a reaches O) and distinguishable (E is final, O is not). So no further merging is possible.

Answer: Option (A) — 2 states.

Common misconception. Many candidates add a third "dead" state, imagining that a misplaced b must be rejected. It must not: b's are simply ignored, so the transition on b stays inside the two parity states. Equally wrong is "infinitely many", which forgets that a DFA only needs the parity, not the count.

TOC-U1-Q02MCQeasy

In DFA minimisation by the table-filling method, two states p and q of a complete DFA are distinguishable exactly when:

  1. there is a string w ∈ Σ* such that exactly one of δ̂(p,w) and δ̂(q,w) is a final state.
  2. p and q are both final states.
  3. p and q are both non-final states.
  4. no string takes p and q to different states.
Show answer & solution

Detailed solution

Concept. States are equivalent when no future input can tell them apart, i.e. when for every string w the two runs agree on acceptance. Distinguishable is the negation of that: some string w makes exactly one run end in a final state.

Step by step.

  1. Take w = ε. If one state is final and the other is not, they are already distinguishable.
  2. Otherwise try longer strings: p and q are distinguishable if for some symbol a the states δ(p,a) and δ(q,a) are distinguishable.
  3. Table filling propagates this rule until no new pair is marked; unmarked pairs are merged.

Answer: Option (A).

Common misconception. Options (B) and (C) are necessary conditions only for w = ε: two final states, or two non-final states, may still be told apart by a longer string. Option (D) describes equivalence, the opposite of distinguishability.

TOC-U1-Q09MCQmedium

Let L = {w ∈ {0,1}* : #₀(w) ≡ 0 (mod 3) and #₁(w) ≡ 0 (mod 2)}. The minimal DFA accepting L has how many states?

  1. 5
  2. 6
  3. 8
  4. 3
Show answer & solution

Detailed solution

Concept. A conjunction of two independent modular conditions is recognised by the product of the two machines; the state count multiplies.

Step by step.

  1. The condition #₀ ≡ 0 mod 3 needs 3 states (the residues 0, 1, 2).
  2. The condition #₁ ≡ 0 mod 2 needs 2 states (even, odd).
  3. The product machine tracks the pair (i, j) with i = #₀ mod 3 and j = #₁ mod 2: 3 × 2 = 6 states, and every pair is reachable.
  4. All six are pairwise distinguishable (residue classes of a mod-3 counter and a mod-2 counter are distinct), so the product is already minimal.

Answer: Option (B) — 6 states.

Common misconception. Adding the counts (3 + 2 = 5) instead of multiplying them, or forgetting that the two conditions are independent and must be tracked simultaneously.

TOC-U1-Q12MCQhard

Consider the complete DFA below over Σ = {0,1}, start state A, final states {A, E}. The minimal DFA equivalent to it has how many states?

| 0 | 1 ------+-----+----- A* | B | C B | A | D C | D | E D | C | B E* | B | C

  1. 5
  2. 4
  3. 3
  4. 2
Show answer & solution

Detailed solution

Concept. Minimisation first deletes unreachable states, then merges states that are indistinguishable by every input string.

Step by step.

  1. All five states are reachable: A → B, C; C → E; B → D.
  2. Compare A and E. Both are final. δ(A,0) = B = δ(E,0) and δ(A,1) = C = δ(E,1), so no input can separate them: A ≡ E.
  3. Every other pair is separated by a short string: B and C are non-final but δ(B,0) = A is final while δ(C,0) = D is not; D is separated from B by 0 (to C, non-final) versus A (final); and the final state A is separated from every non-final state by ε.
  4. Merging A and E leaves {[A,E], B, C, D} = 4 states.
  5. As a check, the language is "even number of 0's and even number of 1's", whose product DFA has exactly 4 states.

Answer: Option (B) — 4 states.

Common misconception. Answering 5 by assuming that two distinct final states must be distinguishable, or answering 3 by merging the two non-final states B and C that differ on input 0. Merging is allowed only when no string separates the pair.

TOC-U1-Q16MSQmedium

Which of the following statements about DFA minimisation are TRUE?

  1. A state that is not reachable from the start state can always be deleted without changing the accepted language.
  2. Two states p, q are equivalent if and only if for every string w, δ̂(p,w) ∈ F exactly when δ̂(q,w) ∈ F.
  3. Merging equivalent states never changes the language accepted by the automaton.
  4. A DFA in which every state is reachable and every pair of states is distinguishable can still be reduced further.
Show answer & solution

Detailed solution

Concept. Minimisation = remove unreachable states, then merge equivalent states; the result is the unique minimal DFA up to renaming.

Step by step.

  1. (A) true. An unreachable state is never entered on any input, so it can never affect acceptance.
  2. (B) true. This is exactly the definition of state equivalence (≡ is the right congruence).
  3. (C) true. Merging equivalent states preserves the run of every string up to equivalence, hence preserves acceptance.
  4. (D) false. Reachability plus pairwise distinguishability is precisely the definition of a minimal DFA; nothing is left to remove or merge.

Answer: Options (A), (B) and (C).

Common misconception. Believing that a "tidy-looking" DFA can always be squeezed further, or that merging states always risks changing the language — merging equivalent states cannot.

TOC-U1-Q21NATeasy

Count the states of the minimal DFA over {0,1} that accepts exactly the binary strings denoting a number divisible by 5. Take the usual convention: leading zeros are allowed and the empty string denotes 0, so ε is accepted.

Show answer & solution

Detailed solution

Concept. Divisibility by k is decided by the remainder of the value read so far, and reading a bit b maps r ↦ (2r + b) mod 5. The remainder is the state.

Step by step.

  1. States q₀ … q₄, where q_r means "the number read so far leaves remainder r". Start q₀, final q₀.
  2. Transitions: δ(q_r, 0) = q_{2r mod 5} and δ(q_r, 1) = q_{(2r+1) mod 5}.
  3. All five remainders are reachable (q₀ by ε, then q₁ by 1, q₂ by 10, q₃ by 11, q₄ by 100).
  4. They are pairwise distinguishable: q_0 is the only final state, and from q_r, q_s one can always append digits to reach a multiple of 5 for one and not the other. So 5 is minimal.

Answer: 5.

Common misconception. Answering 6 by adding a separate "no input yet" start state; with the stated convention ε denotes 0 and is accepted, so q₀ doubles as the start state. Another trap is writing 4 or 10 by confusing divisor and radix.

TOC-U1-Q22NATmedium

How many states does the minimal complete DFA have for L = {a^n b^m : n ≥ 1, m ≥ 2} over Σ = {a,b}?

Show answer & solution

Detailed solution

Concept. The machine must remember whether the initial a-block has started, and how many b's have been seen (0, 1, ≥2) — plus a dead state for violations.

Step by step.

  1. q₀ (start, non-final): no a yet. On a → q₁; on b → d (violates n ≥ 1).
  2. q₁ (non-final): at least one a. On a → q₁; on b → q₂.
  3. q₂ (non-final): exactly one b. On b → q₃; on a → d (an a after b is illegal).
  4. q₃ (final): at least two b's. On b → q₃; on a → d.
  5. d (dead, non-final): self-loops on both symbols.
  6. Five states, all reachable, pairwise distinguishable (q₃ is the only final state; d is the only one from which nothing final is reachable; q₀,q₁,q₂ differ in how many b's they still need) — so 5 is minimal.

Answer: 5.

Common misconception. Answering 4 by dropping the dead state — but the DFA must be complete, and a b before any a has to go somewhere. Answering 6 by counting a separate start state for q₀.

TOC-U1-Q26MCQeasy

Over Σ = {a, b}, how many states does the minimal complete DFA have that accepts exactly those strings which end in ab?

  1. 2
  2. 3
  3. 4
  4. 5
Show answer & solution

Detailed solution

Concept. A DFA reads left to right and cannot look ahead, so "ends in ab" is decided by remembering only how much of the pattern has already been matched. The number of states equals the number of distinct residuals of the language.

Step by step.

  1. State q₀ — nothing of the pattern matched so far (also the start state, and the state reached after any symbol other than the one that advances the match).
  2. State q₁ — the last symbol read was a.
  3. State q₂ — the last two symbols read are ab; this is the only final state.
  4. Transitions: q₀ →a q₁, q₀ →b q₀, q₁ →a q₁, q₁ →b q₂, q₂ →a q₁, q₂ →b q₀.
  5. All three are reachable (ε, a, ab) and pairwise distinguishable: q₂ accepts ε while the others reject it; q₁ accepts b while q₀ rejects it. So no two states merge.

Answer: Option (B) — 3 states.

Why the other options are wrong.

  • (A) Two states cannot separate "ends in a" from "ends in ab"; the third residual is genuinely different.
  • (C) and (D) add a state for "ends in b", which is the same residual as "nothing matched" — the table-filling method merges them.

Common misconception. Candidates insert an extra start state distinct from "no partial match seen". Those two are the same residual, and a DFA has one state per residual, not one per event.

Takeaway. A language that constrains the last k symbols needs k + 1 states; the "ends in" pattern is the cheapest way GATE tests this.

TOC-U1-Q30MCQeasy

Which one of the following is TRUE of the minimal DFA of a regular language L?

  1. It is unique up to renaming of states.
  2. It always has strictly fewer states than every NFA that accepts L.
  3. Every one of its states must be a final state.
  4. It is never a complete DFA.
Show answer & solution

Detailed solution

Concept. By the Myhill–Nerode theorem the states of the minimal DFA are exactly the distinct residuals u⁻¹L = {v : uv ∈ L} of the language. A language determines its residuals uniquely, so it determines its minimal DFA uniquely.

Step by step.

  1. Every DFA for L assigns each state a residual: the set of suffixes accepted from it.
  2. Two states with the same residual are indistinguishable and can be merged.
  3. So every DFA for L has at least as many states as L has distinct residuals, and the minimal DFA has exactly that many.
  4. Two minimal DFAs for the same language therefore have the same states up to the naming of states and the choice of the start state's name.

Answer: Option (A) — unique up to renaming of states.

Why the other options are wrong.

  • (B) fails: for {w : the n-th symbol from the right is 1} an NFA with n + 1 states suffices while every DFA needs 2ⁿ states, so the minimal DFA can be exponentially larger than an NFA.
  • (C) fails for any language that is not Σ*; a DFA needs non-final states too.
  • (D) fails: the minimal DFA of a regular language is always complete — missing transitions would have to lead to an implicit rejecting sink, which is a state.

Common misconception. Believing that different constructions produce genuinely different minimal machines. They can differ while being built, but the end result is the same machine up to names.

Takeaway. One regular language, one minimal DFA. This uniqueness is what lets GATE ask for "the number of states" without further qualification.

TOC-U1-Q34MCQmedium

A complete DFA over Σ = {0, 1} has 6 states. Exactly 2 of them cannot be reached from the start state, and among the 4 reachable states exactly 2 are equivalent to each other. How many states does the minimal equivalent DFA have?

  1. 3
  2. 4
  3. 5
  4. 6
Show answer & solution

Detailed solution

Concept. Minimisation is two operations in a fixed order: first delete unreachable states (they can never affect the accepted language), then merge equivalent reachable states (they are indistinguishable by any suffix).

Step by step.

  1. Start with 6 states.
  2. Remove the 2 unreachable states: 6 − 2 = 4 remain.
  3. Among those 4, one pair is equivalent, so the pair collapses into a single state: 4 − 1 = 3.
  4. The remaining 3 states are reachable and pairwise distinguishable, so no further merging is possible.

Answer: Option (A) — 3 states.

Why the other options are wrong.

  • (B) 4 forgets to merge the equivalent pair.
  • (C) 5 removes only one unreachable state, or merges before pruning.
  • (D) 6 assumes no reduction at all.

Common misconception. Merging first and pruning afterwards. It happens to give the same count here, but it can go wrong: an unreachable state can be equivalent to a reachable one, and merging them before pruning can hide a real distinction. Prune, then merge.

Takeaway. Minimal states = (reachable states) − (merges among them). Do the two steps in that order, and never count a state that cannot be entered.

TOC-U1-Q38MCQhard

Consider the complete DFA over Σ = {0, 1} with start state A, final states {C, D} and the transition table below. The minimal DFA equivalent to it has how many states?

| 0 | 1 ------+-----+----- A | B | E B | D | C C* | F | A D* | A | C E | D | C F | B | F

  1. 4
  2. 5
  3. 6
  4. 7
Show answer & solution

Detailed solution

Concept. Minimality is decided by two tests: every state must be reachable from the start state, and no two states may be equivalent. States with identical rows and the same finality are equivalent and merge.

Step by step.

  1. Reachability. From A: A → {B, E}; from B: D, C; from C: F, A; from D: A, C; from E: D, C; from F: B, F. All six states are reachable, so nothing is deleted.
  2. First refinement. Split into final {C, D} and non-final {A, B, E, F}.
  3. Compare rows inside the non-final block. B and E both go to D on 0 and to C on 1, and both are non-final — the rows are identical, so B ≡ E. A (→B, E) and F (→B, F) differ from that and from each other, and they sit in different classes from {C, D}, so they stay separate.
  4. Compare inside the final block. C goes to F on 0 while D goes to A; A and F are already separated (they reach different classes), so C and D are distinguishable.
  5. Count. Classes are {A}, {B, E}, {C}, {D}, {F} — five states.

Answer: Option (B) — 5 states.

Why the other options are wrong.

  • (A) 4 would need a second merge, but no other pair shares both row and finality.
  • (C) 6 is the unminimised count: it misses B ≡ E.
  • (D) 7 exceeds the number of states in the given table, which is impossible for a minimal DFA.

Common misconception. Merging states with equal rows but different finality. Here B and E are both non-final, which is what licenses the merge; a final and a non-final state can never be equivalent because ε separates them.

Takeaway. Run table filling in order: split final from non-final, then refine by destination classes until nothing changes. Identical rows in the same block are an immediate merge.

TOC-U1-Q41MSQmedium

Which of the following languages over Σ = {a, b} have a minimal complete DFA with exactly 3 states? (Select all that apply.)

  1. {w : w ends in ab}
  2. {w : w has an even number of a's}
  3. {w : w contains aa as a substring}
  4. {w : |w| ≡ 1 (mod 3)}
Show answer & solution

Detailed solution

Concept. The number of states of the minimal DFA equals the number of distinct residuals. Each option is checked by counting the residuals it forces.

Step by step.

  1. (A) ends in ab. Three residuals: "no partial match", "last symbol was a", "last two symbols are ab". All reachable, all distinguishable. 3 states ✓
  2. (B) even number of a's. Only the parity of the count matters, and b's change nothing. Two residuals. 2 states ✗
  3. (C) contains aa. Three residuals: no aa yet and last symbol not a; no aa yet and last symbol is a; aa already seen (absorbing, accepting). 3 states ✓
  4. (D) |w| ≡ 1 (mod 3). Three residuals, indexed by |w| mod 3, the one with residue 1 accepting. 3 states ✓

Answer: Options (A), (C) and (D).

Common misconception. Adding a separate dead state to (C) on the grounds that a wrong symbol must be rejected. After aa every further symbol is accepted, so the third state absorbs; and before aa there is no rejecting sink because every symbol keeps the run alive. Counting states "intuitively" instead of by residual is the usual slip.

Takeaway. Ask "what must be remembered?" For suffix patterns it is the matched prefix length; for counts it is the residue; for absorbing conditions it is a single flag state.

TOC-U1-Q46NATeasy

How many states does the minimal complete DFA over Σ = {a, b} have that accepts exactly those strings which contain aba as a substring?

Show answer & solution

Detailed solution

Concept. "Contains aba" is decided by remembering the longest prefix of aba that is a suffix of what has been read. That gives one state per prefix length plus one absorbing accepting state.

Step by step.

  1. q₀ — no prefix of aba matched.
  2. q₁ — the last symbol is a, a prefix of length 1.
  3. q₂ — the last two symbols are ab, a prefix of length 2.
  4. q₃ — aba has been seen; absorbing and accepting.
  5. Transitions: q₀ →a q₁, q₀ →b q₀; q₁ →a q₁, q₁ →b q₂; q₂ →a q₃, q₂ →b q₀; q₃ →a q₃, q₃ →b q₃.
  6. The four residuals are distinct (ε separates q₃ from the rest; ba separates q₂; ba against b separates q₁), so no merging is possible.

Answer: 4.

Common misconception. Answering 3 by forgetting the accepting state, or 5 by adding a dead state for "wrong symbol". After aba every input is accepted, so the accepting state absorbs; and before aba no input kills the run, so no dead state is needed.

Takeaway. A pattern of length k needs k + 1 states when the matched state absorbs. The subtle part is the fallback transitions: q₂ →b q₀ because abb ends in bb, not in a prefix of aba.

TOC-U1-Q47NATeasy

How many states does the minimal complete DFA over Σ = {0, 1} have that accepts exactly those binary strings whose value is congruent to 2 modulo 3? Leading zeros are allowed and the empty string denotes 0.

Show answer & solution

Detailed solution

Concept. Reading a binary string left to right, appending a bit b maps the value v to 2v + b. Modulo 3 only the residue of v matters, so three residues suffice — and are necessary.

Step by step.

  1. States r₀, r₁, r₂ meaning "value so far ≡ i (mod 3)". Start state r₀, because the empty string has value 0.
  2. Transitions follow r → (2r + b) mod 3.
  3. r₀ →0 r₀, r₀ →1 r₁; r₁ →0 r₂, r₁ →1 r₀; r₂ →0 r₁, r₂ →1 r₂.
  4. The single final state is r₂.
  5. Check: 10 = 2 → r₀ →1 r₁ →0 r₂ ✓ accepted; 11 = 3 ≡ 0 → r₁ →1 r₀ ✓ rejected.
  6. The three residues are pairwise distinguishable — from r₀ the string 10 is accepted, from r₁ the string 0 is accepted, from r₂ the empty string is accepted — so all three are needed.

Answer: 3.

Common misconception. Treating the number of bits as the state count, or forgetting that leading zeros are allowed so 010 and 10 must land in the same state. The state is the residue, not the length.

Takeaway. For "value mod k" languages the minimal DFA has exactly k states, with r → (2r + b) mod k. Moduli other than 2 need the general rule, not the parity shortcut.

TOC-U1-Q03MCQeasy

An NFA accepts a string w if and only if:

  1. at least one computation path labelled w leads from the start state to a final state.
  2. every computation path labelled w leads from the start state to a final state.
  3. the NFA has no ε-transitions on the path.
  4. exactly one computation path labelled w reaches a final state.
Show answer & solution

Detailed solution

Concept. Nondeterminism is existential acceptance: the NFA guesses, and one successful guess is enough.

Concept. NPDAs are the machine model of the context-free languages. Nondeterminism is what gives them their power, and it is also what makes the two acceptance modes interchangeable.

Step by step.

  1. (A) true. Take a grammar in Greibach Normal Form and build the single-state NPDA that replaces the top nonterminal by a right-hand side and pops matching terminals; it accepts by empty stack.
  2. (B) true. That is the definition of nondeterminism: δ(q, a, X) may contain two or more elements, and an ε-move may coexist with an input move.
  3. (C) true. The triple construction [q, A, p] produces a grammar for the language of any PDA.
  4. (D) false. The empty string is accepted whenever the start configuration is already accepting — for instance a grammar with S → ε gives an NPDA that accepts ε by empty stack.

Answer: Options (A), (B) and (C).

Common misconception. Thinking that 'the stack must be emptied by reading input' rules out ε. ε-moves can empty the stack without consuming anything.

Takeaway. NPDA = CFG, nondeterministic by design, and perfectly able to accept ε.

TOC-U3-Q12MCQmedium

A grammar G = (V, T, P, S) is converted into an NPDA by the standard top-down construction: one state q, initial stack Z0S, acceptance by empty stack. Which move is added for the production A → X1 X2 … Xk?

  1. δ(q, X1, A) contains (q, X2 … Xk)
  2. δ(q, A, ε) contains (q, X1 … Xk)
  3. δ(q, ε, X1) contains (q, A)
  4. δ(q, ε, A) contains (q, X1 X2 … Xk)
Show answer & solution

Detailed solution

Concept. The construction simulates a leftmost derivation on the stack. The stack holds the unexpanded sentential form with the leftmost symbol on top, so expanding a nonterminal means replacing the top symbol by the right-hand side, in order.

Step by step.

  1. Expansion consumes no input, so the move must be on ε.
  2. The symbol being expanded is the stack top, so the move is keyed on A, giving δ(q, ε, A).
  3. The replacement is the whole right-hand side X1…Xk, written so that X1 becomes the new top.
  4. The other half of the construction is a move δ(q, a, a) = {(q, ε)} for each terminal a: when the top is a terminal that matches the input, both are consumed.
  5. Option (A) would consume X1 as input even when it is a nonterminal; option (B) has the arguments of δ in the wrong order; option (C) expands backwards.

Answer: Option (D).

Common misconception. Swapping the arguments: δ takes (state, input symbol or ε, stack top). The stack top is the last argument, and it is the nonterminal being expanded.

Takeaway. Nonterminal on top → ε-move that expands it; terminal on top → consume the matching input symbol.

TOC-U3-Q13MCQhard

Which one of the following languages is accepted by some nondeterministic PDA but by no deterministic PDA?

  1. { ai bj ck : i = j or j = k, i, j, k ≥ 0 }
  2. { an bn : n ≥ 0 }
  3. { w c wR : w ∈ {a, b}* }
  4. { an bm : n ≠ m, n, m ≥ 0 }
Show answer & solution

Detailed solution

Concept. An NPDA can guess; a DPDA cannot. The languages that separate the two classes are exactly the ones where the machine must commit to one of several matching rules before it has enough information.

Step by step.

  1. Option (A) is context-free: it is the union of {aibick} and {aibjcj}, each of which is context-free, and the CFLs are closed under union. An NPDA guesses at the start which of the two branches to follow.
  2. Option (A) is not a DCFL. A DPDA reading the a-block must decide whether it will compare the a-count with the b-count or the b-count with the c-count, and that decision cannot be made until the whole string has been seen. Whichever rule it commits to, the strings that satisfy only the other rule are rejected. This is the standard example of a CFL that is not deterministic.
  3. Options (B) and (C) are DCFLs — push the a-block and pop on b's; or push up to the visible c and pop after it.
  4. Option (D) is a DCFL too: it is the complement of {anbn} inside the regular set a*b*, and DCFLs are closed under complement and under intersection with a regular language.

Answer: Option (A).

Common misconception. Reading 'or' as automatically nondeterministic and '≠' as automatically nondeterministic. It is the other way round here: the union in (A) is the nondeterministic one, while the inequality in (D) is deterministic.

Takeaway. Two independent matching rules, chosen before the information arrives, is the signature of a CFL that is not deterministic.

Acceptance: empty store vs final state · 6
TOC-U3-Q14MCQeasy

A pushdown automaton is said to accept a string by empty stack when:

  1. it reaches a final state at some point while reading the string.
  2. the stack is empty at some point during the computation.
  3. after reading the whole string the stack is empty, whatever the state.
  4. it reaches a final state after reading the whole string and the stack is also empty.
Show answer & solution

Detailed solution

Concept. The two acceptance modes look at different things. Acceptance by final state looks at the state after the input is consumed; acceptance by empty stack looks at the stack after the input is consumed and ignores the state entirely.

Step by step.

  1. A computation must consume the whole input before it can accept — that rules out option (A).
  2. In empty-stack acceptance the set of final states is irrelevant, so option (D) imposes an extra condition that is not required.
  3. Option (B) drops the requirement that the input be exhausted: a machine may empty its stack halfway and then keep reading.
  4. The correct condition is: the whole input is consumed and the stack is empty, with no condition on the state.

Answer: Option (C).

Common misconception. Treating 'empty stack' as an event that can happen mid-string. Acceptance always requires the input to be finished first.

Takeaway. Final-state acceptance ignores the stack; empty-stack acceptance ignores the state. Both require the input to be exhausted.

TOC-U3-Q15NATmedium

A pushdown automaton has 2 states and stack alphabet {Z0, A}. A configuration is the current state together with the entire contents of the stack. How many distinct configurations does the automaton have in which the stack holds exactly one or two symbols?

Show answer & solution

Detailed solution

Concept. A configuration of a PDA is (state, remaining input, stack contents). Counting configurations of bounded stack height is a counting problem on the stack alphabet, multiplied by the number of states.

Step by step.

  1. Stacks of length 1: any single symbol of the stack alphabet, so 2 possibilities (Z0 and A).
  2. Stacks of length 2: two independent choices, so 22 = 4 possibilities (Z0Z0, Z0A, AZ0, AA).
  3. Stack contents altogether: 2 + 4 = 6.
  4. Multiply by the 2 states: 2 × 6 = 12 configurations.

Answer: 12.

Common misconception. Counting only stacks that respect the bottom marker, i.e. requiring Z0 to be at the bottom. That is a restriction on legal computations, not on configurations, and it would give 4 stacks instead of 6.

Takeaway. Configurations are state × stack, and the number of stacks of length L over a k-symbol alphabet is kL.

TOC-U3-Q16MCQeasy

For nondeterministic pushdown automata, which statement about the two acceptance modes is TRUE?

  1. Empty-stack acceptance is strictly weaker than final-state acceptance.
  2. A language is accepted by some NPDA by final state if and only if it is accepted by some NPDA by empty stack.
  3. Final-state acceptance is strictly weaker than empty-stack acceptance.
  4. Neither mode can accept the empty string.
Show answer & solution

Detailed solution

Concept. For NPDAs the two acceptance modes are interchangeable: each can simulate the other, so they define the same class of languages, the context-free languages.

Step by step.

  1. Final state → empty stack. Add a new bottom marker below the old one and a new single final state; from every old final state add ε-moves that empty the stack. The new machine accepts by empty stack exactly when the old one reached a final state.
  2. Empty stack → final state. Add a new bottom marker and a new single final state; whenever the old stack would empty, move on ε to the new final state instead. Acceptance by empty stack becomes acceptance by final state.
  3. Both simulations are language-preserving, so neither mode is weaker.
  4. Option (D) is false: ε is accepted whenever the start configuration already satisfies the acceptance condition.

Answer: Option (B).

Common misconception. Importing the deterministic picture, where the two modes really are not interchangeable. The equivalence is a property of nondeterministic machines.

Takeaway. NPDA: the two modes are equivalent. DPDA: they are not, and that asymmetry is a favourite exam point.

TOC-U3-Q17MSQmedium

Select every statement about the two acceptance modes of pushdown automata that is TRUE.

  1. Every NPDA that accepts by final state can be converted into an NPDA that accepts the same language by empty stack.
  2. Every DPDA that accepts by final state can be converted into a DPDA that accepts the same language by empty stack.
  3. In a PDA that accepts by empty stack, acceptance depends only on the stack and not on the state.
  4. If a DPDA accepts a language by empty stack, then no proper prefix of a word of the language belongs to the language.
Show answer & solution

Detailed solution

Concept. The conversion between acceptance modes is free for NPDAs and is not free for DPDAs, because the conversion has to empty the stack at the right instant and a deterministic machine cannot postpone or duplicate that decision.

Step by step.

  1. (A) true. Add a fresh bottom marker and a fresh single final state, and from each old final state add ε-moves that pop the stack away. Nothing here needs a choice, so the construction works for NPDAs.
  2. (B) false. A DPDA may reach a final state while input still remains. Emptying the stack at that moment would also accept every longer string with that prefix, which changes the language. Since the machine is deterministic it cannot keep the stack and empty it 'later instead'. The classic witness is L = {anbn} ∪ {anbnc}.
  3. (C) true. That is the definition: the final-state set plays no part.
  4. (D) true. Suppose x ∈ L and x is a proper prefix of y ∈ L. After reading x the stack is empty, and with an empty stack no further move is possible, so y could never be accepted. This is the prefix property.

Answer: Options (A), (C) and (D).

Common misconception. Assuming the NPDA equivalence carries over to DPDAs. It does not: only DCFLs with the prefix property can be accepted by a DPDA by empty stack.

Takeaway. Empty-stack acceptance forces the prefix property; final-state acceptance does not. That is the whole difference.

TOC-U3-Q18MCQmedium

Why can a DPDA that accepts by final state not always be turned into a DPDA that accepts the same language by empty stack?

  1. Because a DPDA has no final states to remove.
  2. Because determinism forbids ε-moves, which such a conversion needs.
  3. Because the empty stack cannot be represented in a DPDA.
  4. Because the machine may reach a final state while input remains, so emptying the stack there would also accept every longer string having that prefix.
Show answer & solution

Detailed solution

Concept. Empty-stack acceptance is a strictly stronger requirement: the stack must empty at the exact instant the last input symbol is read. A deterministic machine cannot arrange that if it was designed to stop at an earlier moment.

Step by step.

  1. Take a DPDA M accepting by final state and a word x ∈ L(M). In many DPDAs the machine enters a final state with input still unread — nothing forbids that.
  2. The natural conversion adds ε-moves that empty the stack on entering a final state. Applied at that moment, the stack empties before the input is finished.
  3. With an empty stack no move is possible, so the machine stops and the rest of the input is never read. Under the convention that acceptance requires the whole input to be consumed, it rejects; but under the naive reading it would accept every extension xy as well.
  4. Because the machine is deterministic it cannot both keep the stack and empty it 'later', so there is no way to delay the emptying until the input ends. Hence the conversion can fail.
  5. Options (A), (B) and (C) are all false: DPDAs do have final states (which the conversion simply stops using), DPDAs may use ε-moves, and the empty stack is of course representable — it is the acceptance condition itself.

Answer: Option (D).

Common misconception. Believing the conversion is always safe because it is safe for NPDAs. Nondeterminism lets the NPDA keep both options open; a DPDA must commit.

Takeaway. A DPDA accepting by empty stack accepts a language with the prefix property. Languages without it can be accepted by final state only.

TOC-U3-Q19MCQhard

Let L be a language accepted by some DPDA by empty stack. Which property must L necessarily have?

  1. No word of L is a proper prefix of another word of L.
  2. L is regular.
  3. L is closed under reversal.
  4. L is finite.
Show answer & solution

Detailed solution

Concept. Once a stack is empty there is no symbol left to consult, so no further move is possible. That single observation forces the prefix property.

Step by step.

  1. Suppose x, y ∈ L with x a proper prefix of y, so y = xz for some non-empty z.
  2. The accepting computation on y must, after reading x, still have consumed only the prefix x. Since the machine is deterministic it is in the same configuration as it would be after reading x alone — and that configuration accepts x, so the stack is empty.
  3. With an empty stack, δ has no stack top to read, so no move exists and the remaining input z can never be consumed. Contradiction.
  4. So no word of L can be a proper prefix of another — the prefix property.
  5. The other options are far too strong: {anbn : n ≥ 1} is accepted by a DPDA by empty stack, is not regular, is not closed under reversal ({bnan} is not even deterministic in the required sense) and is infinite.

Answer: Option (A).

Common misconception. Confusing the prefix property with 'prefix-closed'. The prefix property says the language contains no word together with a proper prefix of it — the exact opposite of prefix-closed.

Takeaway. Empty-stack acceptance ⇒ prefix property. Conversely, a language with the prefix property that is accepted by a DPDA by final state can be accepted by empty stack as well.

TOC-U3-Q20MCQeasy

Which statement about context-free grammars and pushdown automata is TRUE?

  1. Every context-free grammar has an equivalent deterministic pushdown automaton.
  2. Every context-free grammar has an equivalent nondeterministic pushdown automaton, and every NPDA has an equivalent context-free grammar.
  3. Every NPDA has an equivalent regular expression.
  4. A context-free grammar can generate only regular languages.
Show answer & solution

Detailed solution

Concept. CFGs and NPDAs are two presentations of one class: the context-free languages. The equivalence fails as soon as 'nondeterministic' is replaced by 'deterministic'.

Step by step.

  1. CFG → NPDA. The top-down construction: one state, initial stack Z0S, an ε-move per production and a pop per matching terminal.
  2. NPDA → CFG. The triple construction with variables [q, A, p].
  3. Option (A) is false: {w wR} is context-free but no DPDA accepts it.
  4. Options (C) and (D) confuse the context-free class with the regular class; the regular languages are a proper subclass.

Answer: Option (B).

Common misconception. Writing 'PDA' when 'NPDA' is meant. The default reading of 'PDA' in most textbooks is nondeterministic; determinism must be stated explicitly.

Takeaway. CFG ≡ NPDA, strictly weaker than nothing and strictly stronger than regular expressions.

TOC-U3-Q21NATmedium

While the automaton accepts the string aabb, what is the largest number of symbols the stack ever holds, counting the bottom marker Z0?

Show answer & solution

Detailed solution

Concept. The stack of the top-down NPDA holds the unexpanded part of the sentential form, with the leftmost symbol on top. Its height therefore tracks how much of the derivation is still outstanding.

Step by step.

  1. Start: stack Z0S — height 2.
  2. Expand S → AB: Z0AB — height 3.
  3. Expand A → aA: Z0aAB — height 4. This is the maximum.
  4. Pop the matched a: Z0AB — height 3.
  5. Expand A → a: Z0aB — height 3; pop: Z0B — height 2.
  6. Expand B → bB: Z0bB — height 3; pop: Z0B — height 2.
  7. Expand B → b: Z0b — height 2; pop: Z0 — height 1, stack empty of everything but the marker, input exhausted, accepted.
  8. The largest height reached on this (the only accepting) computation is 4.

Answer: 4.

Common misconception. Counting only nonterminals, or forgetting that expanding A → aA momentarily puts the terminal a on the stack as well. That terminal is a real stack symbol until it is matched.

TOC-U3-Q22MCQmedium

In the standard construction of a context-free grammar from a pushdown automaton, the variables are triples [q, A, p]. What does the variable [q, A, p] generate?

  1. All strings accepted by the automaton when it starts in state q.
  2. All strings whose length is at most the stack height reached in state p.
  3. All strings w such that the automaton, starting in state q with A on top of the stack, can read w and end in state p having popped A, never inspecting the symbols below A.
  4. All strings that take the automaton from its start state to a final state.
Show answer & solution

Detailed solution

Concept. The triple construction records a whole sub-computation: from a state with a particular symbol on top, to another state with that symbol gone.

Step by step.

  1. The automaton's behaviour depends on the state and on the top stack symbol only — the symbols below it are invisible until the top is popped. That is why a variable needs exactly three pieces of information.
  2. [q, A, p] describes a computation that starts in q with A on top, ends in p with A removed, and never looks below A in between.
  3. Productions encode single moves: for a move that replaces A by B1…Bk and steps from q to r, add [q, A, p] → a [r, B1, r1] … [rk−1, Bk, p].
  4. The start variable is [q0, Z0, p] for each final state p — the whole computation is one such triple with the bottom marker.
  5. Options (A) and (D) drop the stack symbol and the end state, which the construction needs; option (B) is not a language-theoretic notion at all.

Answer: Option (C).

Common misconception. Thinking that [q, A, p] generates a string of the language. Only the start triples do; the others generate fragments of the computation.

Takeaway. Three pieces of information — start state, stack top, end state — because the rest of the stack is hidden.

TOC-U3-Q23NATeasy

A grammar has 5 productions and terminal alphabet {a, b}. In the standard single-state NPDA construction, one move is added for each production and one for each terminal symbol. How many moves does the resulting NPDA have?

Show answer & solution

Detailed solution

Concept. The construction mirrors the grammar piece by piece: one ε-move per production (expand a nonterminal) and one input-consuming move per terminal (match and pop).

Step by step.

  1. Production moves: 5, each of the form δ(q, ε, A) ∋ (q, α).
  2. Terminal moves: 2, namely δ(q, a, a) = {(q, ε)} and δ(q, b, b) = {(q, ε)}.
  3. Total: 5 + 2 = 7 moves.
  4. No move is needed for the start-up step: the initial stack is simply defined to be Z0S.

Answer: 7.

Common misconception. Adding an extra move for the start symbol or for the bottom marker. Neither is a move — both are part of the initial configuration.

Takeaway. Moves = |P| + |T| for the single-state construction.

TOC-U3-Q24MCQhard

  1. 3
  2. 4
  3. 5
  4. 6
Show answer & solution

Detailed solution

Concept. Each application of S → aSb adds two symbols to the sentential form; each matched terminal removes one. The peak comes just after an expansion, before the terminal is matched.

Step by step.

  1. Start: Z0S — height 2.
  2. Expand S → aSb: Z0aSb — height 4.
  3. Match the first a: Z0Sb — height 3.
  4. Expand S → aSb again: Z0aSbb — height 5. This is the maximum.
  5. Match the second a: Z0Sbb — height 4.
  6. Expand S → ε: Z0bb — height 3.
  7. Match both b's: height 2, then 1. Input exhausted, only Z0 left, accepted by empty stack.
  8. Maximum height: 5.

TOC-U3-Q25MSQmedium

Select every statement about the equivalence of context-free grammars and pushdown automata that is TRUE.

  1. A grammar in Greibach Normal Form is simulated by an NPDA that has a single state and accepts by empty stack.
  2. The class of languages accepted by nondeterministic pushdown automata is exactly the class of context-free languages.
  3. Every context-free grammar has an equivalent deterministic pushdown automaton.
  4. If an NPDA accepts a language by empty stack, then some context-free grammar generates that language.
Show answer & solution

Detailed solution

Concept. The equivalence CFG ≡ NPDA is exact, and it has a concrete constructive form on each side. The single-state simulation works especially cleanly for Greibach Normal Form, where every production begins with a terminal.

Step by step.

  1. (A) true. In GNF every production is A → aα. The single-state automaton reads a from the input and replaces A by α in one move; after |w| moves the stack is empty exactly when w has been generated.
  2. (B) true. This is the standard equivalence, proved by the top-down and triple constructions.
  3. (C) false. {w wR} has a context-free grammar but no DPDA, because the midpoint is unmarked.
  4. (D) true. That is the direction of the equivalence that converts a machine into a grammar.
