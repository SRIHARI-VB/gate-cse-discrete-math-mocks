DFA construction & minimisation 7
TOC-U1-Q01MCQeasy

Over the alphabet Σ = {a, b}, the minimal DFA that accepts exactly those strings which contain an even number of a's has how many states?

  1. 2
  2. 3
  3. 4
  4. Infinitely many
Show answer & solution

Detailed solution

Concept. A DFA cannot count; it can only remember a finite amount of information. For the parity of the number of a's the only thing that matters is whether the count seen so far is even or odd — two facts, hence at most two states.

Step by step.

  1. Let E = "even number of a's so far" (start state, and final because the empty string has zero a's). Let O = "odd number so far".
  2. δ(E,a) = O, δ(E,b) = E — a b does not change the parity.
  3. δ(O,a) = E, δ(O,b) = O.
  4. Both states are reachable (ε reaches E, a reaches O) and distinguishable (E is final, O is not). So no further merging is possible.

Answer: Option (A) — 2 states.

Common misconception. Many candidates add a third "dead" state, imagining that a misplaced b must be rejected. It must not: b's are simply ignored, so the transition on b stays inside the two parity states. Equally wrong is "infinitely many", which forgets that a DFA only needs the parity, not the count.

TOC-U1-Q02MCQeasy

In DFA minimisation by the table-filling method, two states p and q of a complete DFA are distinguishable exactly when:

  1. there is a string w ∈ Σ* such that exactly one of δ̂(p,w) and δ̂(q,w) is a final state.
  2. p and q are both final states.
  3. p and q are both non-final states.
  4. no string takes p and q to different states.
Show answer & solution

Detailed solution

Concept. States are equivalent when no future input can tell them apart, i.e. when for every string w the two runs agree on acceptance. Distinguishable is the negation of that: some string w makes exactly one run end in a final state.

Step by step.

  1. Take w = ε. If one state is final and the other is not, they are already distinguishable.
  2. Otherwise try longer strings: p and q are distinguishable if for some symbol a the states δ(p,a) and δ(q,a) are distinguishable.
  3. Table filling propagates this rule until no new pair is marked; unmarked pairs are merged.

Answer: Option (A).

Common misconception. Options (B) and (C) are necessary conditions only for w = ε: two final states, or two non-final states, may still be told apart by a longer string. Option (D) describes equivalence, the opposite of distinguishability.

TOC-U1-Q09MCQmedium

Let L = {w ∈ {0,1}* : #₀(w) ≡ 0 (mod 3) and #₁(w) ≡ 0 (mod 2)}. The minimal DFA accepting L has how many states?

  1. 5
  2. 6
  3. 8
  4. 3
Show answer & solution

Detailed solution

Concept. A conjunction of two independent modular conditions is recognised by the product of the two machines; the state count multiplies.

Step by step.

  1. The condition #₀ ≡ 0 mod 3 needs 3 states (the residues 0, 1, 2).
  2. The condition #₁ ≡ 0 mod 2 needs 2 states (even, odd).
  3. The product machine tracks the pair (i, j) with i = #₀ mod 3 and j = #₁ mod 2: 3 × 2 = 6 states, and every pair is reachable.
  4. All six are pairwise distinguishable (residue classes of a mod-3 counter and a mod-2 counter are distinct), so the product is already minimal.

Answer: Option (B) — 6 states.

Common misconception. Adding the counts (3 + 2 = 5) instead of multiplying them, or forgetting that the two conditions are independent and must be tracked simultaneously.

TOC-U1-Q12MCQhard

Consider the complete DFA below over Σ = {0,1}, start state A, final states {A, E}. The minimal DFA equivalent to it has how many states?

| 0 | 1 ------+-----+----- A* | B | C B | A | D C | D | E D | C | B E* | B | C
  1. 5
  2. 4
  3. 3
  4. 2
Show answer & solution

Detailed solution

Concept. Minimisation first deletes unreachable states, then merges states that are indistinguishable by every input string.

Step by step.

  1. All five states are reachable: A → B, C; C → E; B → D.
  2. Compare A and E. Both are final. δ(A,0) = B = δ(E,0) and δ(A,1) = C = δ(E,1), so no input can separate them: A ≡ E.
  3. Every other pair is separated by a short string: B and C are non-final but δ(B,0) = A is final while δ(C,0) = D is not; D is separated from B by 0 (to C, non-final) versus A (final); and the final state A is separated from every non-final state by ε.
  4. Merging A and E leaves {[A,E], B, C, D} = 4 states.
  5. As a check, the language is "even number of 0's and even number of 1's", whose product DFA has exactly 4 states.

Answer: Option (B) — 4 states.

Common misconception. Answering 5 by assuming that two distinct final states must be distinguishable, or answering 3 by merging the two non-final states B and C that differ on input 0. Merging is allowed only when no string separates the pair.

TOC-U1-Q16MSQmedium

Which of the following statements about DFA minimisation are TRUE?

  1. A state that is not reachable from the start state can always be deleted without changing the accepted language.
  2. Two states p, q are equivalent if and only if for every string w, δ̂(p,w) ∈ F exactly when δ̂(q,w) ∈ F.
  3. Merging equivalent states never changes the language accepted by the automaton.
  4. A DFA in which every state is reachable and every pair of states is distinguishable can still be reduced further.
Show answer & solution

Detailed solution

Concept. Minimisation = remove unreachable states, then merge equivalent states; the result is the unique minimal DFA up to renaming.

Step by step.

  1. (A) true. An unreachable state is never entered on any input, so it can never affect acceptance.
  2. (B) true. This is exactly the definition of state equivalence (≡ is the right congruence).
  3. (C) true. Merging equivalent states preserves the run of every string up to equivalence, hence preserves acceptance.
  4. (D) false. Reachability plus pairwise distinguishability is precisely the definition of a minimal DFA; nothing is left to remove or merge.

Answer: Options (A), (B) and (C).

Common misconception. Believing that a "tidy-looking" DFA can always be squeezed further, or that merging states always risks changing the language — merging equivalent states cannot.

TOC-U1-Q21NATeasy

Count the states of the minimal DFA over {0,1} that accepts exactly the binary strings denoting a number divisible by 5. Take the usual convention: leading zeros are allowed and the empty string denotes 0, so ε is accepted.

Show answer & solution

Detailed solution

Concept. Divisibility by k is decided by the remainder of the value read so far, and reading a bit b maps r ↦ (2r + b) mod 5. The remainder is the state.

Step by step.

  1. States q₀ … q₄, where q_r means "the number read so far leaves remainder r". Start q₀, final q₀.
  2. Transitions: δ(q_r, 0) = q_{2r mod 5} and δ(q_r, 1) = q_{(2r+1) mod 5}.
  3. All five remainders are reachable (q₀ by ε, then q₁ by 1, q₂ by 10, q₃ by 11, q₄ by 100).
  4. They are pairwise distinguishable: q_0 is the only final state, and from q_r, q_s one can always append digits to reach a multiple of 5 for one and not the other. So 5 is minimal.

Answer: 5.

Common misconception. Answering 6 by adding a separate "no input yet" start state; with the stated convention ε denotes 0 and is accepted, so q₀ doubles as the start state. Another trap is writing 4 or 10 by confusing divisor and radix.

TOC-U1-Q22NATmedium

How many states does the minimal complete DFA have for L = {a^n b^m : n ≥ 1, m ≥ 2} over Σ = {a,b}?

Show answer & solution

Detailed solution

Concept. The machine must remember whether the initial a-block has started, and how many b's have been seen (0, 1, ≥2) — plus a dead state for violations.

Step by step.

  1. q₀ (start, non-final): no a yet. On a → q₁; on b → d (violates n ≥ 1).
  2. q₁ (non-final): at least one a. On a → q₁; on b → q₂.
  3. q₂ (non-final): exactly one b. On b → q₃; on a → d (an a after b is illegal).
  4. q₃ (final): at least two b's. On b → q₃; on a → d.
  5. d (dead, non-final): self-loops on both symbols.
  6. Five states, all reachable, pairwise distinguishable (q₃ is the only final state; d is the only one from which nothing final is reachable; q₀,q₁,q₂ differ in how many b's they still need) — so 5 is minimal.

Answer: 5.

Common misconception. Answering 4 by dropping the dead state — but the DFA must be complete, and a b before any a has to go somewhere. Answering 6 by counting a separate start state for q₀.

NFA to DFA (subset construction) 6
TOC-U1-Q03MCQeasy

An NFA accepts a string w if and only if:

  1. at least one computation path labelled w leads from the start state to a final state.
  2. every computation path labelled w leads from the start state to a final state.
  3. the NFA has no ε-transitions on the path.
  4. exactly one computation path labelled w reaches a final state.
Show answer & solution

Detailed solution

Concept. Nondeterminism is existential acceptance: the NFA guesses, and one successful guess is enough.

Step by step.

  1. Running an NFA on w produces a set of reachable states rather than a single state.
  2. The string is accepted when that set meets the set of final states.
  3. Dead-end branches are simply abandoned; they do not veto acceptance.

Answer: Option (A).

Common misconception. Option (B) is universal acceptance, which is not how an NFA accepts — an NFA with one accepting and one dead branch still accepts. Option (D) confuses "at least one" with "exactly one".

TOC-U1-Q04MCQeasy

An NFA with n states over Σ is converted to an equivalent DFA by the subset construction. The number of states of the resulting DFA is at most:

  1. 2^n
  2. n²
  3. n
  4. n + 1
Show answer & solution

Detailed solution

Concept. In the subset construction each DFA state is a set of NFA states, and there are 2^n such sets.

Step by step.

  1. The start state of the DFA is ε-closure(q₀).
  2. For a DFA state S and symbol a, the successor is the ε-closure of the union of δ(p,a) over all p ∈ S.
  3. Every DFA state is a subset of the n NFA states, so there can be no more than 2^n of them; only the reachable subsets actually appear.

Answer: Option (A) — at most 2^n states.

Common misconception. 2^n is an upper bound, not the usual size: most NFAs produce far fewer reachable subsets, and the DFA can then be minimised further. Candidates who read the bound as "exactly 2^n" lose the question.

TOC-U1-Q07MCQeasy

Which of the following statements is FALSE?

  1. Every NFA has an equivalent DFA.
  2. Every DFA is a special case of an NFA.
  3. A language accepted by an NFA with ε-transitions need not be regular.
  4. NFAs and DFAs accept exactly the same class of languages.
Show answer & solution

Detailed solution

Concept. Adding nondeterminism and ε-moves does not add expressive power: both machines characterise the regular languages.

Step by step.

  1. ε-transitions are eliminated by taking ε-closures; the subset construction then yields a DFA for the same language.
  2. Hence every ε-NFA language is regular — statement (C) is false, and it is the required answer.
  3. (A), (B) and (D) are the standard equivalences.

Answer: Option (C) — the false statement.

Common misconception. Students expect that ε-moves buy extra power, because they look like spontaneous computation. They only shorten the description; the accepted class is unchanged.

TOC-U1-Q13MCQhard

An NFA over Σ = {0,1} has states {0,1,2,3}, start state 0, final state {3} and the transitions below (∅ means no move). The minimal DFA equivalent to this NFA has how many states?

| 0 | 1 ------+---------+-------- 0 | {0} | {0, 1} 1 | {2} | {2} 2 | {3} | {3} 3 | ∅ | ∅
  1. 4
  2. 5
  3. 8
  4. 16
Show answer & solution

Detailed solution

Concept. Two steps are needed: subset construction to get a DFA, then minimisation. Skipping either step gives a wrong count.

Step by step.

  1. The NFA accepts w exactly when w has a 1 in the third position from the end — state 0 waits, guesses with 1 that the third-from-last symbol has been seen, and states 1, 2 count the remaining two symbols.
  2. Subset construction from {0}: {0} --1--> {0,1} --1--> {0,1,2} --1--> {0,1,2,3}, while 0-moves add 2, then 3: {0} --0--> {0}, {0,1} --0--> {0,2} --0--> {0,3}. Closing the table gives exactly {0}, {0,1}, {0,2}, {0,3}, {0,1,2}, {0,1,3}, {0,2,3}, {0,1,2,3} — 8 reachable subsets, so the 2³ bound is met.
  3. Minimisation cannot help: four of the eight subsets are accepting (those containing 3) and four are not, and the Myhill–Nerode argument for "third symbol from the right is 1" separates the 2³ strings 000, 001, …, 111 pairwise. So all 8 states survive.

Answer: Option (C) — 8 states.

Common misconception. Answering 4 (the NFA's own state count) forgets that determinisation is mandatory. Answering 16 assumes that all 2⁴ subsets are reachable, but this NFA reaches only 8. Answering 5 or 6 comes from dropping a subset state that is in fact reachable — check the table before deciding which subsets never appear.

TOC-U1-Q17MSQmedium

For an NFA with ε-transitions and ε-closure(q) written for the set of states reachable from q using only ε-moves, which statements are TRUE?

  1. q ∈ ε-closure(q) for every state q.
  2. ε-closure(q) is the set of states reachable from q by a path of ε-moves only, including q itself.
  3. In the subset construction, the start state of the DFA is ε-closure(q₀).
  4. ε-closure(q) can be empty when q has no ε-transitions.
Show answer & solution

Detailed solution

Concept. ε-closure is a reflexive, transitive closure: it always contains its argument and is closed under taking ε-steps again.

Step by step.

  1. (A) true. The empty path of length 0 reaches q, so q is always included.
  2. (B) true. That is the definition, made explicit about the empty path.
  3. (C) true. Before reading any symbol the NFA may slide along ε-moves, so the DFA starts at the whole closure.
  4. (D) false. Even with no ε-transitions the closure is {q}, never ∅.

Answer: Options (A), (B) and (C).

Common misconception. Writing ε-closure(q) = ∅ for a state with no ε-moves. The closure of a single state always contains at least that state; only a closure of the empty set is empty.

TOC-U1-Q23NATmedium

An NFA has states {p, q, r}, start state p, final state {r} and the transitions below. Counting only the reachable subset states, how many states does the DFA produced by the subset construction have?

| 0 | 1 ------+---------+------ p | {p, q} | {p} q | ∅ | {r} r | {r} | {r}
Show answer & solution

Detailed solution

Concept. Subset construction: each DFA state is a set of NFA states, and the successor of a set is the union of the successors of its members.

Step by step.

  1. Start: {p}.
  2. {p} on 0 → {p,q}; on 1 → {p}.
  3. {p,q} on 0 → {p,q}; on 1 → {p} ∪ {r} = {p,r}.
  4. {p,r} on 0 → {p,q} ∪ {r} = {p,q,r}; on 1 → {p} ∪ {r} = {p,r}.
  5. {p,q,r} on 0 → {p,q,r}; on 1 → {p,r}. No new sets appear.
  6. Reachable subsets: {p}, {p,q}, {p,r}, {p,q,r} — four. (The ∅ state is never reached, since p is in every subset.)

Answer: 4.

Common misconception. Answering 3 (the NFA's state count) or 8 (the full 2³ bound). Only reachable subsets count, and here p survives every transition, so exactly four of the eight subsets appear.

Regular expressions 6
TOC-U1-Q05MCQeasy

The language denoted by the regular expression (a+b)*abb is:

  1. the set of all strings over {a,b} that end in abb.
  2. the set of all strings over {a,b} that contain abb as a substring.
  3. the set of all strings over {a,b} that begin with abb.
  4. the set of all strings over {a,b} that contain exactly one occurrence of abb.
Show answer & solution

Detailed solution

Concept. Concatenation in a regular expression fixes order: (a+b)* consumes an arbitrary prefix, and the trailing abb must be the last three symbols of the string.

Step by step.

  1. Any string of the form x·abb with x ∈ {a,b}* is generated: choose x from (a+b)* and append abb.
  2. Conversely, every generated string literally ends in abb.
  3. So the language is exactly the strings with suffix abb, e.g. abb, aabb, abbabb.

Answer: Option (A).

Common misconception. (a+b)*abb(a+b)* — with the trailing star — is the "contains" language (option B). Dropping the final (a+b)* pins abb to the end.

TOC-U1-Q06MCQeasy

Which regular expression denotes exactly the set of all strings over {a,b} that contain at least one a?

  1. (a+b)*a(a+b)*
  2. a*
  3. (a+b)*
  4. b*ab*
Show answer & solution

Detailed solution

Concept. "At least one a" is expressed by isolating one required a and letting arbitrary text surround it.

Step by step.

  1. (a+b)* before the required a generates any prefix.
  2. The single a is the witness that at least one a occurs.
  3. (a+b)* after it generates any suffix, including more a's.
  4. So (a+b)*a(a+b)* accepts a, ba, ab, aab, bbaab … and rejects only b*.

Answer: Option (A).

Common misconception. Option (D) b*ab* allows only one a; option (C) allows strings with no a at all; option (B) a* forces every symbol to be a.

TOC-U1-Q10MCQmedium

Taking a DFA to be complete (a transition is defined for every state and symbol), the minimal DFA accepting L(a(a+b)*) has how many states?

  1. 2
  2. 3
  3. 4
  4. 5
Show answer & solution

Detailed solution

Concept. a(a+b)* is "every string that starts with a". Three facts must be remembered: nothing read yet, a good prefix, a hopeless prefix.

Step by step.

  1. q₀ (start, non-final): on a go to q₁, on b go to q_d.
  2. q₁ (final): the first symbol was a; every later symbol keeps the string valid, so δ(q₁,a) = δ(q₁,b) = q₁.
  3. q_d (dead, non-final): the first symbol was b; nothing can repair it, so δ(q_d,a) = δ(q_d,b) = q_d.
  4. The three states are reachable and pairwise distinguishable (q₀ and q_d differ on a; q₁ is the only final state), so 3 is minimal.

Answer: Option (B) — 3 states.

Common misconception. Answering 2, which is correct only for an incomplete transition graph where q_d is simply omitted. GATE convention uses complete DFAs, and the minimal complete DFA has 3 states.

TOC-U1-Q14MCQhard

Which regular expression denotes exactly the strings over {a,b} that contain an odd number of a's?

  1. b*(ab*ab*)*ab*
  2. b*(ab*a)*b*
  3. (a+b)*a(a+b)*
  4. a(a+b)*
Show answer & solution

Detailed solution

Concept. Read a regular expression as a machine: the part ab*ab* contains exactly two a's, so repeating it adds an even number of a's; a final a outside the loop makes the total odd.

Step by step.

  1. b* before the loop and b* inside it absorb all b's anywhere.
  2. Each iteration of (ab*ab*) contributes exactly two a's.
  3. The trailing ab* contributes exactly one a.
  4. Total = 2k + 1, odd — and every odd-a string can be parsed this way, so the expression is exact.

Answer: Option (A).

Common misconception. Option (B) b*(ab*a)*b* generates an even number of a's (including none), i.e. it is the parity-dual language. Options (C) and (D) only say "at least one a".

TOC-U1-Q18MSQmedium

Which of the following regular-expression identities hold for all strings over {a,b}?

  1. (a+b)* = (a*b*)*
  2. (ab)* = a*b*
  3. (a+b)* = (a*+b*)*
  4. a*b* = (a+b)*
Show answer & solution

Detailed solution

Concept. Identities are settled by proving both inclusions, or by producing one string that separates the two sides.

Step by step.

  1. (A) true. (a*b*)* contains every string: write it as blocks of a's then blocks of b's, e.g. ba = (ε)(b)·(a)(ε) is two iterations. Conversely every generated string is over {a,b}.
  2. (B) false. a ∈ a*b* but a ∉ (ab)*; equally b ∈ a*b* ∖ (ab)*.
  3. (C) true. a* ⊆ (a*+b*)* and b* ⊆ (a*+b*)*, and the star of a union of subsets of {a,b}* stays inside (a+b)*; so both sides equal {a,b}*.
  4. (D) false. ba ∈ (a+b)* but ba ∉ a*b*, since a*b* forces all a's before all b's.

Answer: Options (A) and (C).

Common misconception. Assuming that (ab)* and a*b* are interchangeable because both "use only a and b". Order matters: a*b* is closed under concatenation in a fixed shape, (ab)* alternates.

TOC-U1-Q24NATmedium

How many strings of length exactly 4 over {a,b} belong to L((a+b)*ab(a+b)*)?

Show answer & solution

Detailed solution

Concept. (a+b)*ab(a+b)* is the set of strings containing ab. Counting the complement is faster than listing members.

Step by step.

  1. There are 2⁴ = 16 strings of length 4 in total.
  2. A string avoids ab exactly when no a is ever followed by a b, i.e. the string has the shape b*a*: all b's first, then all a's.
  3. The b*a* strings of length 4 are bbbb, bbba, bbaa, baaa, aaaa — five of them.
  4. So the count is 16 − 5 = 11. Check by listing: abab, abba, abbb, aabb, aaba, baab — every length-4 string except the five listed above.

Answer: 11.

Common misconception. Counting strings that end in ab (which gives 4), or forgetting that ab may occur more than once and must not be double-counted — the complement count avoids both traps.

Pumping lemma for regular languages 6
TOC-U1-Q08MCQeasy

The pumping lemma for regular languages is used to:

  1. prove that certain languages are not regular.
  2. prove that a given language is regular.
  3. minimise a given DFA.
  4. convert an NFA into an equivalent DFA.
Show answer & solution

Detailed solution

Concept. The lemma is a necessary condition: every regular language satisfies it. Therefore failing it proves non-regularity, while satisfying it proves nothing.

Step by step.

  1. If L is regular with a DFA of p states, every w ∈ L with |w| ≥ p can be split w = xyz with |xy| ≤ p, |y| ≥ 1 and xy^i z ∈ L for all i ≥ 0.
  2. So a language that violates this for every valid split is not regular.
  3. No converse is available: {a^n b^n : n ≥ 0} fails it, but a non-regular language can still satisfy it.

Answer: Option (A).

Common misconception. Using the pumping lemma to claim a language is regular (option B). To prove regularity you must exhibit a DFA, an NFA or a regular expression.

TOC-U1-Q11MCQmedium

To prove that L = {a^n b^n : n ≥ 0} is not regular using the pumping lemma, which argument is correct?

  1. Assume the pumping length is p and take w = a^p b^p. Then |xy| ≤ p forces y = a^k with k ≥ 1, so xy²z = a^{p+k} b^p ∉ L.
  2. Assume the pumping length is p and take w = (ab)^p. Pumping y = ab gives (ab)^{p+1} ∉ L.
  3. Assume the pumping length is p and take w = a^p b^p. Then y must contain both an a and a b, so xy²z ∉ L.
  4. Assume the pumping length is p and take w = b^p a^p. Then y = a^k gives xy²z ∉ L.
Show answer & solution

Detailed solution

Concept. A valid pumping-lemma proof must pick one string w ∈ L with |w| ≥ p such that every legal split w = xyz yields a pumped string outside L.

Step by step.

  1. Choose w = a^p b^p ∈ L; |w| = 2p ≥ p.
  2. |xy| ≤ p confines xy to the leading block of a's, so y = a^k for some k ≥ 1.
  3. Then xy²z = a^{p+k} b^p, which has more a's than b's and is not in L — contradiction for every legal split.

Answer: Option (A).

Common misconception. Option (B) fails because the lemma does not let you choose y: with w = (ab)^p a legal split may take y = a, which pumps into a string still in L. Option (C) misreads |xy| ≤ p: y cannot cross into the b block. Option (D) uses a string of the wrong shape (b^p a^p ∉ L).

TOC-U1-Q15MCQhard

For L = {a^i b^j : i > j ≥ 0}, a pumping-lemma proof takes w = a^{p+1} b^p. With w = xyz, |xy| ≤ p, |y| ≥ 1, the contradiction appears for which choice of the pump count i in xy^i z?

  1. i = 0
  2. i = 2
  3. i = 3
  4. every i ≥ 0 gives a contradiction
Show answer & solution

Detailed solution

Concept. L only requires more a's than b's, so pumping up preserves membership; only pumping down can break it.

Step by step.

  1. w = a^{p+1} b^p ∈ L because p+1 > p; also |w| ≥ p.
  2. |xy| ≤ p forces y = a^k with 1 ≤ k ≤ p, so no b is inside y.
  3. For i ≥ 1: xy^i z = a^{p+1+(i-1)k} b^p, which still has more a's than b's and lies in L — no contradiction.
  4. For i = 0: xy⁰z = a^{p+1-k} b^p with p+1-k ≤ p, so the number of a's no longer exceeds the number of b's and xy⁰z ∉ L — contradiction.

Answer: Option (A) — pump down, i = 0.

Common misconception. Pumping up by reflex (i = 2) is the standard habit for {a^n b^n} and fails here, because this language tolerates extra a's. When a language is one-sided, always check whether pumping down is the move that breaks it.

TOC-U1-Q19MSQeasy

Using the Myhill–Nerode theorem, which statements are TRUE?

  1. L is regular if and only if ≡_L has finitely many equivalence classes.
  2. If ≡_L has infinitely many equivalence classes, then L is not regular.
  3. The index of ≡_L equals the number of states of every DFA that accepts L.
  4. Every finite language is regular, so its ≡_L has finitely many classes.
Show answer & solution

Detailed solution

Concept. Myhill–Nerode turns a language into a right-invariant equivalence: x ≡_L y iff for every z, xz ∈ L ⇔ yz ∈ L. The number of classes is the index.

Step by step.

  1. (A) true. This is the theorem: a finite-index right congruence yields a DFA whose states are the classes, and a DFA with n states yields at most n classes.
  2. (B) true. The contrapositive of the forward direction of (A).
  3. (C) false. The index equals the number of states of the minimal DFA only. A non-minimal DFA has more states and the same index.
  4. (D) true. A finite language is accepted by a finite trie-like DFA, so it is regular, and by (A) its index is finite.

Answer: Options (A), (B) and (D).

Common misconception. Reading (C) as "some DFA" — the index is an invariant of the language, so it can only match the minimal machine.

TOC-U1-Q20MSQhard

Which of the following languages over {a,b} are NOT regular?

  1. {a^n b^n : n ≥ 0}
  2. {a^n b^m : n, m ≥ 0}
  3. {ww : w ∈ {a,b}*}
  4. {a^n : n is prime}
Show answer & solution

Detailed solution

Concept. A language that needs an unbounded counter — equal counts, a duplicated block, or primality — is not regular; a language needing only a bounded amount of state is.

Step by step.

  1. (A) not regular. w = a^p b^p with y = a^k pumps to a^{p+k}b^p ∉ L.
  2. (B) regular. a*b* describes it exactly — the two counts are independent, so no counter is needed.
  3. (C) not regular. Take w = a^p b a^p b; a legal split keeps y inside the first a^p block, and xy²z no longer has two identical halves.
  4. (D) not regular. Take w = a^p with p prime; y = a^k gives a^{p + (i-1)k}, which for i = p+1 equals a^{p(1+k)} — composite. (Myhill–Nerode gives the same answer: the strings a^n with n prime are pairwise inequivalent.)

Answer: Options (A), (C) and (D) — three non-regular languages.

Common misconception. Treating (C) as regular because it "looks like a star", or treating (B) as non-regular because it mentions two letters. Independence of the two counts is the deciding point.

TOC-U1-Q25NATmedium

How many of the following six languages over {a,b} are NOT regular?

(i) { a^n b^n : n >= 0 } (ii) { w : #a(w) = #b(w) } (iii) { a^n b^m : n, m >= 0 } (iv) { ww : w in {a,b}* } (v) { w : w = w^R } (palindromes) (vi) { w : #a(w) is even }
Show answer & solution

Detailed solution

Concept. Regular languages cannot compare two unbounded counts, cannot remember an arbitrary block in order to repeat it, and cannot test arithmetic properties such as primality. Parity, however, is a bounded amount of state.

Step by step.

  1. (i) not regular. a^n b^n needs an unbounded counter; the pumping lemma with w = a^p b^p gives a^{p+k}b^p ∉ L.
  2. (ii) not regular. #a = #b again compares two unbounded counts; pump w = a^p b^p.
  3. (iii) regular. The expression a*b* describes it exactly.
  4. (iv) not regular. The copy language ww needs unbounded memory of the first half.
  5. (v) not regular. Palindromes need unbounded memory to compare the two halves.
  6. (vi) regular. Two states remember the parity of the number of a's.

Answer: 4 — the non-regular ones are (i), (ii), (iv) and (v).

Common misconception. Marking (iii) as non-regular because it "looks like" (i); the difference is that n and m are independent, so no comparison is required. Others mark (vi) non-regular, forgetting that parity needs only two states.
