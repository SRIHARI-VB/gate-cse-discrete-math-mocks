TOC-U1-Q01MCQeasy

Over the alphabet Σ = {a, b}, the minimal DFA that accepts exactly those strings which contain an even number of a's has how many states?

  1. 2
  2. 3
  3. 4
  4. Infinitely many
Show answer & solution

Detailed solution

Concept. A DFA cannot count; it can only remember a finite amount of information. For the parity of the number of a's the only thing that matters is whether the count seen so far is even or odd — two facts, hence at most two states.

Step by step.

  1. Let E = "even number of a's so far" (start state, and final because the empty string has zero a's). Let O = "odd number so far".
  2. δ(E,a) = O, δ(E,b) = E — a b does not change the parity.
  3. δ(O,a) = E, δ(O,b) = O.
  4. Both states are reachable (ε reaches E, a reaches O) and distinguishable (E is final, O is not). So no further merging is possible.

Answer: Option (A) — 2 states.

Common misconception. Many candidates add a third "dead" state, imagining that a misplaced b must be rejected. It must not: b's are simply ignored, so the transition on b stays inside the two parity states. Equally wrong is "infinitely many", which forgets that a DFA only needs the parity, not the count.

TOC-U1-Q02MCQeasy

In DFA minimisation by the table-filling method, two states p and q of a complete DFA are distinguishable exactly when:

  1. there is a string w ∈ Σ* such that exactly one of δ̂(p,w) and δ̂(q,w) is a final state.
  2. p and q are both final states.
  3. p and q are both non-final states.
  4. no string takes p and q to different states.
Show answer & solution

Detailed solution

Concept. States are equivalent when no future input can tell them apart, i.e. when for every string w the two runs agree on acceptance. Distinguishable is the negation of that: some string w makes exactly one run end in a final state.

Step by step.

  1. Take w = ε. If one state is final and the other is not, they are already distinguishable.
  2. Otherwise try longer strings: p and q are distinguishable if for some symbol a the states δ(p,a) and δ(q,a) are distinguishable.
  3. Table filling propagates this rule until no new pair is marked; unmarked pairs are merged.

Answer: Option (A).

Common misconception. Options (B) and (C) are necessary conditions only for w = ε: two final states, or two non-final states, may still be told apart by a longer string. Option (D) describes equivalence, the opposite of distinguishability.

TOC-U1-Q09MCQmedium

Let L = {w ∈ {0,1}* : #₀(w) ≡ 0 (mod 3) and #₁(w) ≡ 0 (mod 2)}. The minimal DFA accepting L has how many states?

  1. 5
  2. 6
  3. 8
  4. 3
Show answer & solution

Detailed solution

Concept. A conjunction of two independent modular conditions is recognised by the product of the two machines; the state count multiplies.

Step by step.

  1. The condition #₀ ≡ 0 mod 3 needs 3 states (the residues 0, 1, 2).
  2. The condition #₁ ≡ 0 mod 2 needs 2 states (even, odd).
  3. The product machine tracks the pair (i, j) with i = #₀ mod 3 and j = #₁ mod 2: 3 × 2 = 6 states, and every pair is reachable.
  4. All six are pairwise distinguishable (residue classes of a mod-3 counter and a mod-2 counter are distinct), so the product is already minimal.

Answer: Option (B) — 6 states.

Common misconception. Adding the counts (3 + 2 = 5) instead of multiplying them, or forgetting that the two conditions are independent and must be tracked simultaneously.

TOC-U1-Q12MCQhard

Consider the complete DFA below over Σ = {0,1}, start state A, final states {A, E}. The minimal DFA equivalent to it has how many states?

| 0 | 1 ------+-----+----- A* | B | C B | A | D C | D | E D | C | B E* | B | C

  1. 5
  2. 4
  3. 3
  4. 2
Show answer & solution

Detailed solution

Concept. Minimisation first deletes unreachable states, then merges states that are indistinguishable by every input string.

Step by step.

  1. All five states are reachable: A → B, C; C → E; B → D.
  2. Compare A and E. Both are final. δ(A,0) = B = δ(E,0) and δ(A,1) = C = δ(E,1), so no input can separate them: A ≡ E.
  3. Every other pair is separated by a short string: B and C are non-final but δ(B,0) = A is final while δ(C,0) = D is not; D is separated from B by 0 (to C, non-final) versus A (final); and the final state A is separated from every non-final state by ε.
  4. Merging A and E leaves {[A,E], B, C, D} = 4 states.
  5. As a check, the language is "even number of 0's and even number of 1's", whose product DFA has exactly 4 states.

Answer: Option (B) — 4 states.

Common misconception. Answering 5 by assuming that two distinct final states must be distinguishable, or answering 3 by merging the two non-final states B and C that differ on input 0. Merging is allowed only when no string separates the pair.

TOC-U1-Q16MSQmedium

Which of the following statements about DFA minimisation are TRUE?

  1. A state that is not reachable from the start state can always be deleted without changing the accepted language.
  2. Two states p, q are equivalent if and only if for every string w, δ̂(p,w) ∈ F exactly when δ̂(q,w) ∈ F.
  3. Merging equivalent states never changes the language accepted by the automaton.
  4. A DFA in which every state is reachable and every pair of states is distinguishable can still be reduced further.
Show answer & solution

Detailed solution

Concept. Minimisation = remove unreachable states, then merge equivalent states; the result is the unique minimal DFA up to renaming.

Step by step.

  1. (A) true. An unreachable state is never entered on any input, so it can never affect acceptance.
  2. (B) true. This is exactly the definition of state equivalence (≡ is the right congruence).
  3. (C) true. Merging equivalent states preserves the run of every string up to equivalence, hence preserves acceptance.
  4. (D) false. Reachability plus pairwise distinguishability is precisely the definition of a minimal DFA; nothing is left to remove or merge.

Answer: Options (A), (B) and (C).

Common misconception. Believing that a "tidy-looking" DFA can always be squeezed further, or that merging states always risks changing the language — merging equivalent states cannot.

TOC-U1-Q21NATeasy

Count the states of the minimal DFA over {0,1} that accepts exactly the binary strings denoting a number divisible by 5. Take the usual convention: leading zeros are allowed and the empty string denotes 0, so ε is accepted.

Show answer & solution

Detailed solution

Concept. Divisibility by k is decided by the remainder of the value read so far, and reading a bit b maps r ↦ (2r + b) mod 5. The remainder is the state.

Step by step.

  1. States q₀ … q₄, where q_r means "the number read so far leaves remainder r". Start q₀, final q₀.
  2. Transitions: δ(q_r, 0) = q_{2r mod 5} and δ(q_r, 1) = q_{(2r+1) mod 5}.
  3. All five remainders are reachable (q₀ by ε, then q₁ by 1, q₂ by 10, q₃ by 11, q₄ by 100).
  4. They are pairwise distinguishable: q_0 is the only final state, and from q_r, q_s one can always append digits to reach a multiple of 5 for one and not the other. So 5 is minimal.

Answer: 5.

Common misconception. Answering 6 by adding a separate "no input yet" start state; with the stated convention ε denotes 0 and is accepted, so q₀ doubles as the start state. Another trap is writing 4 or 10 by confusing divisor and radix.

TOC-U1-Q22NATmedium

How many states does the minimal complete DFA have for L = {a^n b^m : n ≥ 1, m ≥ 2} over Σ = {a,b}?

Show answer & solution

Detailed solution

Concept. The machine must remember whether the initial a-block has started, and how many b's have been seen (0, 1, ≥2) — plus a dead state for violations.

Step by step.

  1. q₀ (start, non-final): no a yet. On a → q₁; on b → d (violates n ≥ 1).
  2. q₁ (non-final): at least one a. On a → q₁; on b → q₂.
  3. q₂ (non-final): exactly one b. On b → q₃; on a → d (an a after b is illegal).
  4. q₃ (final): at least two b's. On b → q₃; on a → d.
  5. d (dead, non-final): self-loops on both symbols.
  6. Five states, all reachable, pairwise distinguishable (q₃ is the only final state; d is the only one from which nothing final is reachable; q₀,q₁,q₂ differ in how many b's they still need) — so 5 is minimal.

Answer: 5.

Common misconception. Answering 4 by dropping the dead state — but the DFA must be complete, and a b before any a has to go somewhere. Answering 6 by counting a separate start state for q₀.

TOC-U1-Q26MCQeasy

Over Σ = {a, b}, how many states does the minimal complete DFA have that accepts exactly those strings which end in ab?

  1. 2
  2. 3
  3. 4
  4. 5
Show answer & solution

Detailed solution

Concept. A DFA reads left to right and cannot look ahead, so "ends in ab" is decided by remembering only how much of the pattern has already been matched. The number of states equals the number of distinct residuals of the language.

Step by step.

  1. State q₀ — nothing of the pattern matched so far (also the start state, and the state reached after any symbol other than the one that advances the match).
  2. State q₁ — the last symbol read was a.
  3. State q₂ — the last two symbols read are ab; this is the only final state.
  4. Transitions: q₀ →a q₁, q₀ →b q₀, q₁ →a q₁, q₁ →b q₂, q₂ →a q₁, q₂ →b q₀.
  5. All three are reachable (ε, a, ab) and pairwise distinguishable: q₂ accepts ε while the others reject it; q₁ accepts b while q₀ rejects it. So no two states merge.

Answer: Option (B) — 3 states.

Why the other options are wrong.

  • (A) Two states cannot separate "ends in a" from "ends in ab"; the third residual is genuinely different.
  • (C) and (D) add a state for "ends in b", which is the same residual as "nothing matched" — the table-filling method merges them.

Common misconception. Candidates insert an extra start state distinct from "no partial match seen". Those two are the same residual, and a DFA has one state per residual, not one per event.

Takeaway. A language that constrains the last k symbols needs k + 1 states; the "ends in" pattern is the cheapest way GATE tests this.

TOC-U1-Q30MCQeasy

Which one of the following is TRUE of the minimal DFA of a regular language L?

  1. It is unique up to renaming of states.
  2. It always has strictly fewer states than every NFA that accepts L.
  3. Every one of its states must be a final state.
  4. It is never a complete DFA.
Show answer & solution

Detailed solution

Concept. By the Myhill–Nerode theorem the states of the minimal DFA are exactly the distinct residuals u⁻¹L = {v : uv ∈ L} of the language. A language determines its residuals uniquely, so it determines its minimal DFA uniquely.

Step by step.

  1. Every DFA for L assigns each state a residual: the set of suffixes accepted from it.
  2. Two states with the same residual are indistinguishable and can be merged.
  3. So every DFA for L has at least as many states as L has distinct residuals, and the minimal DFA has exactly that many.
  4. Two minimal DFAs for the same language therefore have the same states up to the naming of states and the choice of the start state's name.

Answer: Option (A) — unique up to renaming of states.

Why the other options are wrong.

  • (B) fails: for {w : the n-th symbol from the right is 1} an NFA with n + 1 states suffices while every DFA needs 2ⁿ states, so the minimal DFA can be exponentially larger than an NFA.
  • (C) fails for any language that is not Σ*; a DFA needs non-final states too.
  • (D) fails: the minimal DFA of a regular language is always complete — missing transitions would have to lead to an implicit rejecting sink, which is a state.

Common misconception. Believing that different constructions produce genuinely different minimal machines. They can differ while being built, but the end result is the same machine up to names.

Takeaway. One regular language, one minimal DFA. This uniqueness is what lets GATE ask for "the number of states" without further qualification.

TOC-U1-Q34MCQmedium

A complete DFA over Σ = {0, 1} has 6 states. Exactly 2 of them cannot be reached from the start state, and among the 4 reachable states exactly 2 are equivalent to each other. How many states does the minimal equivalent DFA have?

  1. 3
  2. 4
  3. 5
  4. 6
Show answer & solution

Detailed solution

Concept. Minimisation is two operations in a fixed order: first delete unreachable states (they can never affect the accepted language), then merge equivalent reachable states (they are indistinguishable by any suffix).

Step by step.

  1. Start with 6 states.
  2. Remove the 2 unreachable states: 6 − 2 = 4 remain.
  3. Among those 4, one pair is equivalent, so the pair collapses into a single state: 4 − 1 = 3.
  4. The remaining 3 states are reachable and pairwise distinguishable, so no further merging is possible.

Answer: Option (A) — 3 states.

Why the other options are wrong.

  • (B) 4 forgets to merge the equivalent pair.
  • (C) 5 removes only one unreachable state, or merges before pruning.
  • (D) 6 assumes no reduction at all.

Common misconception. Merging first and pruning afterwards. It happens to give the same count here, but it can go wrong: an unreachable state can be equivalent to a reachable one, and merging them before pruning can hide a real distinction. Prune, then merge.

Takeaway. Minimal states = (reachable states) − (merges among them). Do the two steps in that order, and never count a state that cannot be entered.

TOC-U1-Q38MCQhard

Consider the complete DFA over Σ = {0, 1} with start state A, final states {C, D} and the transition table below. The minimal DFA equivalent to it has how many states?

| 0 | 1 ------+-----+----- A | B | E B | D | C C* | F | A D* | A | C E | D | C F | B | F

  1. 4
  2. 5
  3. 6
  4. 7
Show answer & solution

Detailed solution

Concept. Minimality is decided by two tests: every state must be reachable from the start state, and no two states may be equivalent. States with identical rows and the same finality are equivalent and merge.

Step by step.

  1. Reachability. From A: A → {B, E}; from B: D, C; from C: F, A; from D: A, C; from E: D, C; from F: B, F. All six states are reachable, so nothing is deleted.
  2. First refinement. Split into final {C, D} and non-final {A, B, E, F}.
  3. Compare rows inside the non-final block. B and E both go to D on 0 and to C on 1, and both are non-final — the rows are identical, so B ≡ E. A (→B, E) and F (→B, F) differ from that and from each other, and they sit in different classes from {C, D}, so they stay separate.
  4. Compare inside the final block. C goes to F on 0 while D goes to A; A and F are already separated (they reach different classes), so C and D are distinguishable.
  5. Count. Classes are {A}, {B, E}, {C}, {D}, {F} — five states.

Answer: Option (B) — 5 states.

Why the other options are wrong.

  • (A) 4 would need a second merge, but no other pair shares both row and finality.
  • (C) 6 is the unminimised count: it misses B ≡ E.
  • (D) 7 exceeds the number of states in the given table, which is impossible for a minimal DFA.

Common misconception. Merging states with equal rows but different finality. Here B and E are both non-final, which is what licenses the merge; a final and a non-final state can never be equivalent because ε separates them.

Takeaway. Run table filling in order: split final from non-final, then refine by destination classes until nothing changes. Identical rows in the same block are an immediate merge.

TOC-U1-Q41MSQmedium

Which of the following languages over Σ = {a, b} have a minimal complete DFA with exactly 3 states? (Select all that apply.)

  1. {w : w ends in ab}
  2. {w : w has an even number of a's}
  3. {w : w contains aa as a substring}
  4. {w : |w| ≡ 1 (mod 3)}
Show answer & solution

Detailed solution

Concept. The number of states of the minimal DFA equals the number of distinct residuals. Each option is checked by counting the residuals it forces.

Step by step.

  1. (A) ends in ab. Three residuals: "no partial match", "last symbol was a", "last two symbols are ab". All reachable, all distinguishable. 3 states ✓
  2. (B) even number of a's. Only the parity of the count matters, and b's change nothing. Two residuals. 2 states ✗
  3. (C) contains aa. Three residuals: no aa yet and last symbol not a; no aa yet and last symbol is a; aa already seen (absorbing, accepting). 3 states ✓
  4. (D) |w| ≡ 1 (mod 3). Three residuals, indexed by |w| mod 3, the one with residue 1 accepting. 3 states ✓

Answer: Options (A), (C) and (D).

Common misconception. Adding a separate dead state to (C) on the grounds that a wrong symbol must be rejected. After aa every further symbol is accepted, so the third state absorbs; and before aa there is no rejecting sink because every symbol keeps the run alive. Counting states "intuitively" instead of by residual is the usual slip.

Takeaway. Ask "what must be remembered?" For suffix patterns it is the matched prefix length; for counts it is the residue; for absorbing conditions it is a single flag state.

TOC-U1-Q46NATeasy

How many states does the minimal complete DFA over Σ = {a, b} have that accepts exactly those strings which contain aba as a substring?

Show answer & solution

Detailed solution

Concept. "Contains aba" is decided by remembering the longest prefix of aba that is a suffix of what has been read. That gives one state per prefix length plus one absorbing accepting state.

Step by step.

  1. q₀ — no prefix of aba matched.
  2. q₁ — the last symbol is a, a prefix of length 1.
  3. q₂ — the last two symbols are ab, a prefix of length 2.
  4. q₃ — aba has been seen; absorbing and accepting.
  5. Transitions: q₀ →a q₁, q₀ →b q₀; q₁ →a q₁, q₁ →b q₂; q₂ →a q₃, q₂ →b q₀; q₃ →a q₃, q₃ →b q₃.
  6. The four residuals are distinct (ε separates q₃ from the rest; ba separates q₂; ba against b separates q₁), so no merging is possible.

Answer: 4.

Common misconception. Answering 3 by forgetting the accepting state, or 5 by adding a dead state for "wrong symbol". After aba every input is accepted, so the accepting state absorbs; and before aba no input kills the run, so no dead state is needed.

Takeaway. A pattern of length k needs k + 1 states when the matched state absorbs. The subtle part is the fallback transitions: q₂ →b q₀ because abb ends in bb, not in a prefix of aba.

TOC-U1-Q47NATeasy

How many states does the minimal complete DFA over Σ = {0, 1} have that accepts exactly those binary strings whose value is congruent to 2 modulo 3? Leading zeros are allowed and the empty string denotes 0.

Show answer & solution

Detailed solution

Concept. Reading a binary string left to right, appending a bit b maps the value v to 2v + b. Modulo 3 only the residue of v matters, so three residues suffice — and are necessary.

Step by step.

  1. States r₀, r₁, r₂ meaning "value so far ≡ i (mod 3)". Start state r₀, because the empty string has value 0.
  2. Transitions follow r → (2r + b) mod 3.
  3. r₀ →0 r₀, r₀ →1 r₁; r₁ →0 r₂, r₁ →1 r₀; r₂ →0 r₁, r₂ →1 r₂.
  4. The single final state is r₂.
  5. Check: 10 = 2 → r₀ →1 r₁ →0 r₂ ✓ accepted; 11 = 3 ≡ 0 → r₁ →1 r₀ ✓ rejected.
  6. The three residues are pairwise distinguishable — from r₀ the string 10 is accepted, from r₁ the string 0 is accepted, from r₂ the empty string is accepted — so all three are needed.

Answer: 3.

Common misconception. Treating the number of bits as the state count, or forgetting that leading zeros are allowed so 010 and 10 must land in the same state. The state is the residue, not the length.

TOC-U4-Q01MCQeasy

Which one of the following statements about variants of the Turing machine is TRUE?

  1. A Turing machine whose tape is infinite in both directions accepts strictly more languages than a Turing machine whose tape is infinite in only one direction.
  2. A Turing machine with k work tapes accepts strictly more languages than a single-tape Turing machine.
  3. A tape infinite in both directions and a tape infinite in one direction accept exactly the same class of languages; only the running time may change.
  4. A nondeterministic Turing machine accepts strictly more languages than a deterministic Turing machine.
Show answer & solution

Detailed solution

Concept. All the usual variants — a two-way infinite tape, several tapes, a stay-put head, a two-dimensional tape, nondeterminism — accept exactly the class of recursively enumerable languages. They differ in time and space complexity, never in recognition power.

Step by step.

  1. A one-way infinite tape simulates a two-way infinite tape by folding it: cells to the left of the origin are stored in a second track, in reverse order, with an end marker. Each simulated move costs O(1) real moves.
  2. A single tape simulates k tapes by storing all k tapes on one tape, separated by markers, and carrying a "virtual head" mark on each track. One simulated move costs O(k) real moves, so t simulated steps cost O(k·t²).
  3. A deterministic machine simulates a nondeterministic one by a breadth-first search over the tree of configurations (equivalently, by a 3-tape machine that enumerates and tests). This is slower — exponential in the worst case — but it recognises the same language.
  4. So every variant in the options recognises exactly the r.e. languages, and only the options that claim a strictly larger class are false.

Answer: Option (C).

Why the other options are wrong.

  • (A) and (B) both claim extra recognition power. The fold construction and the multi-tape simulation above show there is none.
  • (D) confuses nondeterminism with extra power. Nondeterminism gives at most an exponential speed-up and is conjectured not to enlarge the class at all: a deterministic machine can search the whole computation tree, so it still accepts only r.e. languages.

Common misconception. "More hardware means more power." The model is already maximal: every reasonable extension is simulated with a slowdown, and the class of accepted languages never grows. Extra tapes buy time, not languages.

Takeaway. Variants of the Turing machine are equivalent in recognition power; the Church–Turing thesis is what makes this the definition of "computable" rather than a coincidence.

TOC-U4-Q06MCQeasy

Let L be a language over a finite alphabet and let L̄ be its complement. Which one of the following statements is TRUE?

  1. If L is recursively enumerable then L̄ is recursively enumerable.
  2. Every recursively enumerable language is recursive.
  3. If both L and L̄ are recursively enumerable then L is recursive.
  4. If L is recursive then L̄ is not recursively enumerable.
Show answer & solution

Detailed solution

Concept. Recursive means "there is a decider — an algorithm that always halts with yes or no". Recursively enumerable means "there is a recogniser — an algorithm that halts with yes on members and may run forever on non-members". Two recognisers, one for L and one for L̄, combine into a decider by running them in parallel.

Step by step.

  1. Assume L is recognised by M₁ and L̄ by M₂.
  2. On input w, run M₁ and M₂ alternately, one step each, in a dovetail.
  3. Every string lies in exactly one of L, L̄, so exactly one of the two machines eventually says yes.
  4. When it does, halt and answer accordingly. The combined procedure always halts, so L is recursive.
  5. Conversely, if L is recursive then L̄ is recursive too (swap the accepting and rejecting states), so both are r.e. Hence "both r.e." and "recursive" coincide for a language and its complement.

Answer: Option (C).

Why the other options are wrong.

  • (A) is false: the halting set K = {⟨M, w⟩ : M halts on w} is r.e. while its complement is not r.e. at all.
  • (B) is false: K is the standard example of an r.e. language that is not recursive.
  • (D) is false: every recursive language is r.e. — a decider is in particular a recogniser.

Common misconception. Thinking r.e. and recursive are the same because both have "an algorithm". The difference is whether the algorithm must halt on every input. A recogniser may loop forever on strings outside the language, and that is precisely the gap.

Takeaway. Recursive ⊂ RE, and the inclusion is strict. Equivalently, L is recursive iff both L and L̄ are r.e.

  2. (B) undecidable. Given ⟨M, w⟩, build M′ that simulates M and enters a fresh state q only when that simulation halts. Then M′ enters q iff M halts on w.
  3. (C) decidable. Do a reachability search from the start state of A over its finitely many states, and accept iff some final state is reachable. The graph is finite, so the search terminates.
  4. (D) undecidable. Given ⟨M, w⟩, build M′ that simulates M and writes 1 only when the simulation halts. Then M′ ever writes 1 iff M halts on w.

Answer: Options (A), (B) and (D).

Why (C) survives. A DFA has finitely many states, so "is a final state reachable?" is a finite graph question with a terminating algorithm. Emptiness, finiteness and universality of a DFA are decidable for the same reason.

Common misconception. Believing that a "simple" question about a Turing machine must be decidable. "Does it ever enter state q?" and "does it ever write 1?" look local, but the answer may depend on an unbounded computation, and unbounded is what makes it undecidable.

Takeaway. Undecidability is about the quantifier structure: a question of the form "does there exist a time t at which ..." over an unbounded t is undecidable, while the same question over a finite object is decidable.

Consider the deterministic Turing machine with states q₀, q₁, q₂, q₃, q_f, tape alphabet {0, 1, X, Y, ␣} (␣ is the blank) and the transition function below. X and Y are "crossed-off" marks; every pair not listed sends the machine to the halting reject state q_r.

Detailed solution

Concept. The machine is the standard "cross off one 0 at the left and one 1 at the right" decider for {0ⁿ1ⁿ : n ≥ 1}. Counting its moves is a matter of walking the head across the tape; nothing has to be guessed.

Step by step.

  1. Write the tape as 0 0 1 1 ␣ ␣ … with the head on the first cell, and run the table literally.
  2. Moves 1–3: (q₀,0)→(q₁,X,R) crosses the first 0; (q₁,0)→(q₁,0,R) skips the second 0; (q₁,1)→(q₂,Y,L) crosses the second 1 and turns left. Tape: X 0 Y 1.

The machine was executed step by step and the transition count recorded at each move; the 13 moves above are the complete computation, ending when δ(q₃,␣) is applied to the blank. Takeaway. A Turing machine is a completely explicit object: given the table, the computation and its length are determined. This is why "does it halt within k steps" is decidable — the trace is computable — while "does it halt at all" is not.

TOC-U4-Q15MCQhard

Let ≤m denote mapping reducibility. Which one of the following statements is TRUE for all languages A and B?

  1. If A ≤m B and B is undecidable, then A is undecidable.
  2. If A ≤m B and A is r.e., then B is r.e.
  3. If A ≤m B and B is decidable, then A is undecidable.
  4. If A ≤m B and A is undecidable, then B is undecidable.
Show answer & solution

Detailed solution

Concept. A ≤m B means: there is a computable f with x ∈ A ⟺ f(x) ∈ B. So A is at most as hard as B. Hardness therefore flows backwards along the arrow, and decidability flows forwards.

Step by step.

  1. Assume A ≤m B via f.
  2. If B were decidable with decider N, then N ∘ f would decide A: compute f(x), then run N. Since f is computable and N always halts, the composite always halts.
  3. So decidability of B gives decidability of A. In contrapositive form: if A is undecidable then B is undecidable. That is statement (D).
  4. The same argument with "recognisable" in place of "decidable" shows: if A is r.e. then B is r.e.
  5. The converses all fail, because an easy language reduces to a hard one: ∅ reduces to every language, including the undecidable ones.

Answer: Option (D).

Why the other options are wrong.

  • (A) reverses the arrow. A ≤m B says nothing about A when B is the hard one: ∅ reduces to any language, yet ∅ is decidable.
  • (B) has the same defect: r.e.-ness of the left side does not transfer to the right side.
  • (C) contradicts the transfer of decidability proved above.

Common misconception. Reading A ≤m B as "equally hard". It is a one-way statement: the left side is no harder than the right. Hardness of B says nothing about A.

Takeaway. To prove B undecidable, reduce a known undecidable language to B. To prove A decidable, reduce A to a known decidable language. Both are applications of the single composition rule above.

Rice’s theorem & reductions · 5
TOC-U4-Q16MCQeasy

By Rice's theorem, which one of the following languages is undecidable?

  1. {⟨M⟩ : M has at least three states}
  2. {⟨M⟩ : the transition table of M contains the symbol 0}
  3. {⟨M⟩ : L(M) is regular}
  4. {⟨M⟩ : M halts on ε within 100 steps}
Show answer & solution

Detailed solution

Concept. Rice's theorem: every non-trivial semantic property of L(M) is undecidable. Non-trivial means some r.e. language has the property and some does not; semantic means the property depends only on which strings the machine accepts, not on how the machine is built.

Step by step.

  1. Check the four options against the two conditions.
  2. (A) and (B) are syntactic: they are decided by inspecting the description of M — count its states, scan its table. Both are decidable.
  3. (D) is bounded: simulate for 100 steps and report. Decidable.
  4. (C) is semantic — it speaks only of L(M) — and non-trivial: ∅ is regular, while {aⁿbⁿ : n ≥ 0} is not. Rice's theorem therefore makes it undecidable.
  5. So exactly one option is undecidable.

Answer: Option (C).

Why the other options are decidable. Each is answered by a finite inspection: count the states, search the transition table, or run a clocked simulation. None requires knowing the language the machine accepts.

Common misconception. Applying Rice's theorem to any question about Turing machines. It applies only to properties of L(M). "Has three states" and "contains the symbol 0" are properties of the program text, and program text is a finite string that can be examined directly.

Takeaway. The test is always: does the property change if I replace M by an equivalent machine? If yes, it is semantic; if it is also non-trivial, it is undecidable.

TOC-U4-Q17MCQmedium

Rice's theorem applies only to properties of the language L(M), and only to non-trivial ones. To which one of the following languages does Rice's theorem NOT apply?

  1. {⟨M⟩ : M has an even number of states}
  2. {⟨M⟩ : L(M) = ∅}
  3. {⟨M⟩ : L(M) is infinite}
  4. {⟨M⟩ : L(M) contains at least one palindrome}
Show answer & solution

Detailed solution

Concept. Rice's theorem is a statement about properties of L(M). A property of the machine's description — its number of states, its alphabet, the length of its encoding — is outside its scope, and such properties are usually decidable outright.

Step by step.

  1. Option (A) counts the states of M. Two machines accepting the same language may have different state counts, and an equivalent machine can always be padded with unreachable states. So the property is not semantic, and Rice's theorem says nothing about it.
  2. In fact (A) is decidable: read the description, count the states, test parity.
  3. Options (B), (C) and (D) are each properties of L(M) alone, and each is non-trivial: ∅ satisfies (B) but not (C); Σ* satisfies (C) but not (B); and Σ* satisfies (D) while {ab} does not.
  4. So Rice's theorem applies to (B), (C) and (D) and makes them undecidable, and it does not apply to (A).

Answer: Option (A).

Why the others are covered. Emptiness, infiniteness and "contains a palindrome" all speak only about which strings are accepted. Each holds for some machines and fails for others, so each is a non-trivial semantic property and Rice's theorem applies.

Common misconception. Thinking a syntactic property must be trivial. Syntactic properties can be interesting — "uses more than 10 states", "has a transition on the blank" — but because the description is a finite string they are all decidable by inspection. Rice's theorem is silent about them, not permissive.

Takeaway. Semantic properties are undecidable by Rice; syntactic properties are decidable by inspection. When a question mixes the two, split them before reaching for the theorem.

TOC-U4-Q18MSQmedium

Which of the following are non-trivial properties of the language L(M), and therefore undecidable by Rice's theorem?

  1. L(M) is finite.
  2. L(M) = Σ*.
  3. L(M) contains at least one string of length 5.
  4. M uses at most 50 tape cells on every input.
Show answer & solution

Detailed solution

Concept. A property qualifies for Rice's theorem when (i) it is decided by L(M) alone and (ii) it is neither always true nor always false over the r.e. languages. The first three pass both tests; the fourth speaks about the machine's space usage.

Step by step.

  1. (A) qualifies. Finiteness depends only on L(M). Non-trivial: ∅ is finite, Σ* is infinite.
  2. (B) qualifies. Non-trivial: Σ* has L(M) = Σ* while ∅ has not. Undecidable by Rice's theorem.
  3. (C) qualifies. The set Σ⁵ is fixed and finite (32 strings over a binary alphabet), so "does M accept one of them" is a property of L(M). Non-trivial: ∅ accepts none, Σ* accepts all.
  4. (D) does not qualify. Space usage is a property of the computation, not of the accepted language: two machines accepting the same language can use very different space. It is still undecidable — by a reduction from halting — but not by Rice's theorem.

Answer: Options (A), (B) and (C).

Why (D) is excluded. Rice's theorem is about the extensional object L(M). Whether a machine stays within 50 cells is intensional: a wasteful machine and a frugal one may accept exactly the same language. The theorem has no purchase on it.

Common misconception. Treating "undecidable" and "undecidable by Rice's theorem" as the same thing. (D) is undecidable, yet Rice's theorem is not the reason; the correct tool is a direct reduction, since a halting computation can be encoded by making the machine write far out on the tape.

Takeaway. Read the property literally: if it mentions cells, steps, states or tape usage, Rice does not apply. If it mentions only the set of accepted strings, and some language has it while another does not, it does.

TOC-U4-Q19MCQmedium

The standard reduction proving that NE = {⟨M⟩ : L(M) ≠ ∅} is undecidable maps ⟨M, w⟩ to ⟨M′⟩, where M′ on input x ignores x, simulates M on w and accepts if that simulation halts. Which one of the following statements about this construction is correct?

  1. It is not a valid reduction, because M′ ignores its input x.
  2. ⟨M, w⟩ ∈ HALT ⟺ L(M′) ≠ ∅, so HALT ≤m NE and NE is undecidable.
  3. ⟨M, w⟩ ∈ HALT ⟺ L(M′) = ∅, so HALT ≤m NE.
  4. It shows only that NE is r.e., not that it is undecidable.
Show answer & solution

Detailed solution

Concept. The construction makes M′ a "witness machine": it accepts every input if M halts on w, and no input otherwise. That turns a question about one computation into a question about emptiness of a language.

Step by step.

  1. Case 1: M halts on w. Then M′ accepts every x it is given, so L(M′) = Σ*, in particular L(M′) ≠ ∅.
  2. Case 2: M does not halt on w. Then M′ loops on every input and accepts nothing, so L(M′) = ∅.
  3. Hence ⟨M, w⟩ ∈ HALT ⟺ L(M′) ≠ ∅, which is exactly the biconditional a reduction from HALT to NE requires. The map is computable: from the descriptions of M and w one writes down the description of M′ mechanically.
  4. If NE were decidable, composing its decider with this map would decide HALT, which is impossible. So NE is undecidable.

Answer: Option (B).

Why the other options are wrong.

  • (A) misreads the technique. Ignoring the input is the whole point: it makes acceptance independent of x, so the only remaining question is whether the simulation of M on w halts.
  • (C) has the biconditional inverted. If M halts on w then M′ accepts everything, so L(M′) is not empty.
  • (D) understates the result. The reduction transfers undecidability, not merely r.e.-ness — though NE does happen to be r.e. as well.

Common misconception. Forgetting to check both directions of the biconditional. A reduction must map yes-instances to yes-instances and no-instances to no-instances; case 2 supplies the second half.

Takeaway. The "ignore the input, simulate, then accept" gadget is the workhorse of undecidability proofs. Rice's theorem packages it once and for all: any non-trivial property of L(M) can be forced to hold or fail by choosing whether the simulated computation halts.

(iv) L(M) is co-finite, that is Σ* \ L(M) is finite
(v) L(M) ⊆ Σ*
(vi) |L(M)| ≤ 3

Detailed solution

Concept. Rice's theorem needs two things of a property: it must be a property of L(M), and it must be non-trivial — true for at least one r.e. language and false for at least one. Five of the six pass both tests; the exception is trivially true.

Step by step.

  1. (i) undecidable. Non-trivial (∅ has it, Σ* does not) and semantic. Rice applies.
  2. (ii) undecidable. Regularity depends only on L(M); ∅ is regular and {aⁿbⁿ : n ≥ 0} is not. Rice applies.
  3. (iii) undecidable. Membership of one fixed string is a semantic property; Σ* contains 0101, ∅ does not. Rice applies.
  4. (iv) undecidable. Co-finiteness is semantic and non-trivial: Σ* is co-finite, ∅ is not. Rice applies.
  5. (v) decidable. Every language over Σ satisfies L(M) ⊆ Σ*, so the property is trivial and the language in question is all of Σ*; a decider simply accepts everything. Rice's theorem requires non-triviality and therefore does not apply.
  6. (vi) undecidable. Bounded cardinality is semantic and non-trivial: ∅ satisfies it, Σ* does not. Rice applies.

How the answer was checked. Each of the six was tested against the two conditions rather than judged by feel. For every one of (i), (ii), (iii), (iv) and (vi) a witness pair was produced — a language with the property and a language without it — which is exactly the non-triviality certificate Rice's theorem needs. Property (v) has no such pair, because it holds for every language over Σ.

The theorem excludes the two trivial properties — always true and always false — and those are decidable precisely because a decider can ignore its input. It also excludes properties of the machine rather than of its language.

Takeaway. Before invoking Rice, ask: can I name a language with the property and a language without it? If yes, the property is non-trivial and undecidable. If no, it is trivial, and trivially decidable.

Chomsky hierarchy summary · 5
TOC-U4-Q21MCQeasy

Which one of the following statements about the classes of the Chomsky hierarchy is TRUE?

  1. Every recursive language is context-sensitive.
  2. Every context-sensitive language is recursive.
  3. Every recursively enumerable language is context-sensitive.
  4. The class of context-free languages equals the class of context-sensitive languages.
Show answer & solution

Detailed solution

Concept. The Chomsky hierarchy is a chain of strict inclusions: Regular ⊂ CFL ⊂ CSL ⊂ RE. Each step up adds a more powerful machine, and each step up keeps everything the level below can do.

Step by step.

  1. A context-sensitive language is accepted by a linear-bounded automaton, whose tape is bounded by the input length n. With |Q| states and n cells there are only |Q| · n · |Γ|ⁿ configurations — finitely many — so a brute-force search of the configuration graph decides membership.
  2. A total decision procedure therefore exists, so every CSL is recursive. Option (B) is true.
  3. The inclusion is strict at the top: the halting set K is r.e. and not recursive, hence not context-sensitive. Option (C) is false.
  4. The inclusion is strict at the bottom too: there are recursive languages that no non-contracting grammar generates, so some recursive languages are not context-sensitive. Option (A) is false.
  5. And {aⁿbⁿcⁿ : n ≥ 1} is context-sensitive but not context-free, so the two classes differ. Option (D) is false.

Answer: Option (B).

Why the other options are wrong.

  • (A) reverses a strict inclusion: recursion is above context-sensitivity, not below it.
  • (C) ignores the top of the hierarchy; Type 0 is strictly larger than Type 1.
  • (D) contradicts the standard witness {aⁿbⁿcⁿ : n ≥ 1}, which an LBA accepts but no PDA does.

Common misconception. Reading the hierarchy as "bigger type number, bigger class" and then assuming every level is decidable. Only Type 0 escapes decidability: Types 1, 2 and 3 are all recursive.

Takeaway. Type 3 ⊂ Type 2 ⊂ Type 1 ⊂ Type 0. Decidability is lost exactly once, between Type 1 and Type 0, when the tape bound is removed.

TOC-U4-Q22MCQeasy

The class of languages accepted by a linear-bounded automaton is exactly the class of:

  1. regular languages
  2. context-free languages
  3. recursive languages
  4. context-sensitive languages
Show answer & solution

Detailed solution

Concept. The Chomsky hierarchy pairs each language class with a machine: finite automaton with regular, pushdown automaton with context-free, linear-bounded automaton with context-sensitive, Turing machine with recursively enumerable.

Step by step.

  1. A linear-bounded automaton is a Turing machine whose tape is confined to the input cells. That restriction is exactly what a non-contracting grammar describes: every production either keeps the length or increases it, never shrinks it.
  2. By the standard equivalence, a language is context-sensitive iff some LBA accepts it — the tape bound on the machine matches the non-shrinking condition on the grammar.
  3. The class is strictly larger than the context-free languages ({aⁿbⁿcⁿ : n ≥ 1} is accepted by an LBA but by no PDA) and strictly smaller than the recursive languages.
  4. So the answer is the context-sensitive class.

Answer: Option (D) — the context-sensitive languages.

Why the other options are wrong.

  • (A) belongs to the one-way finite automaton and (B) to the pushdown automaton; both machines have strictly less storage than an LBA.
  • (C) is the class of languages decided by a Turing machine with no tape bound; every CSL is recursive, but not conversely.

Common misconception. Confusing "bounded tape" with "no tape". An LBA can still scan and rewrite its whole input many times; it simply cannot run off the end. That is why it reaches beyond the context-free languages.

Takeaway. Machine to language class: DFA gives regular, PDA gives context-free, LBA gives context-sensitive, TM gives recursively enumerable.

TOC-U4-Q23MSQeasy

Which of the following statements about the Chomsky hierarchy and its machine models are TRUE?

  1. Every regular language is context-free.
  2. Every context-free language is recursive.
  3. The membership problem for context-sensitive languages is decidable.
  4. Every recursively enumerable language is recursive.
Show answer & solution

Detailed solution

Concept. Climbing the hierarchy never loses a language, and the first three levels are decidable. Only Type 0 is undecidable.

Step by step.

  1. (A) true. A DFA is a pushdown automaton that never uses its stack, so every regular language has a PDA and hence a context-free grammar.
  2. (B) true. The CYK algorithm decides membership in a context-free language in O(n³) time given the grammar in Chomsky normal form, and it always halts.
  3. (C) true. An LBA has finitely many configurations — at most |Q| · n · |Γ|ⁿ — so membership is decided by exploring the configuration graph and testing whether an accepting configuration is reachable. The search is finite, hence terminating.
  4. (D) false. The halting set is r.e. and not recursive; the inclusion Recursive ⊂ RE is strict.

Answer: Options (A), (B) and (C).

Why (D) fails. If every r.e. language were recursive, the halting problem would be decidable, which the diagonal argument rules out. R.e. means recognisable, not decidable.

Common misconception. Believing context-sensitive membership is undecidable because the grammar is complicated. Complexity is not the issue: the configuration space of an LBA is finite, so even a crude search terminates. It may take exponential time, but decidability asks only for termination.

Takeaway. Types 1, 2 and 3 are decidable; Type 0 is not. The dividing line is the tape bound: bounded space makes the configuration graph finite.

TOC-U4-Q24MCQmedium

Which one of the following languages is context-sensitive but NOT context-free?

  1. {aⁿbⁿ : n ≥ 1}
  2. {w wᴿ : w ∈ {a, b}*}
  3. {aⁿbᵐ : n ≠ m}
  4. {aⁿbⁿcⁿ : n ≥ 1}
Show answer & solution

Detailed solution

Concept. A context-free language is recognised by a pushdown automaton, whose single stack can match one nested pair of counts. Three counts that must all agree need two independent comparisons, which one stack cannot make.

Step by step.

  1. Option (A) is context-free: S → aSb | ab generates it, and the stack counts the a's and matches them with the b's.
  2. Option (B) is context-free: guess the midpoint nondeterministically, then match the second half against the stack in reverse.
  3. Option (C) is context-free: it is the union {aⁿbᵐ : n > m} ∪ {aⁿbᵐ : n < m}, and context-free languages are closed under union.
  4. Option (D) is not context-free. By the pumping lemma, pumping any sufficiently long string of {aⁿbⁿcⁿ} produces a string that must still be in the language; but pumping changes one block while leaving the others fixed, so the three counts disagree.
  5. It is context-sensitive: the grammar with S → aSBC | aBC, CB → BC, aB → ab, bB → bb, bC → bc, cC → cc is non-contracting, so an LBA accepts the language.

Answer: Option (D) — {aⁿbⁿcⁿ : n ≥ 1}.

Why the others are context-free. Each of (A), (B) and (C) can be recognised with one stack: (A) and (B) by matching symbols against the stack, (C) by a nondeterministic union of two one-stack machines.

Common misconception. Assuming {aⁿbⁿcⁿ} is context-free because it "looks like" {aⁿbⁿ}. Adding a third block that must equal the first two is exactly what one stack cannot do — the stack is popped while reading the b's, so no record of n remains to check the c's against.

Takeaway. One stack handles one nesting depth. {aⁿbⁿcⁿ} is the standard witness separating context-free from context-sensitive, exactly as {aⁿbⁿ} separates regular from context-free.

TOC-U4-Q25NAThard

Consider the following six languages over Σ = {a, b, c}.
(i) {aⁿbⁿcⁿ : n ≥ 1}
(ii) {aⁿbⁿ : n ≥ 1}
(iii) {w w : w ∈ {a, b}*}
(iv) {w wᴿ : w ∈ {a, b}*}
(v) {aⁿbⁿcⁿdⁿ : n ≥ 1}
(vi) {aⁱbʲcᵏ : i = j or j = k}
How many of these six are context-free?

Show answer & solution

Detailed solution

Concept. A pushdown automaton has one stack, so it can enforce one "counted" equality. Languages demanding two independent equalities among three or more blocks are outside the class; languages that are a union of two one-equality conditions are inside it, because context-free languages are closed under union.

Step by step.

  1. (i) not context-free. Three blocks must agree; one stack cannot remember n while checking b's against it and also check c's. This is the standard pumping-lemma counterexample.
  2. (ii) context-free. Generated by S → aSb | ab.
  3. (iii) not context-free. Copy languages need to compare two halves without a marker at the midpoint; a PDA must guess where the middle is, and a wrong guess cannot be recovered from because the stack has been consumed. The pumping lemma confirms it.
  4. (iv) context-free. Generated by S → aSa | bSb | ε: guess the midpoint nondeterministically and match the second half against the stack in reverse. The reversal is what makes it fit one stack.
  5. (v) not context-free. Four blocks and three independent equalities — even further outside the class.
  6. (vi) context-free. It is {aⁱbʲcᵏ : i = j} ∪ {aⁱbʲcᵏ : j = k}, a union of two context-free languages, and context-free languages are closed under union.
  7. Counting: (ii), (iv) and (vi) are context-free, so the answer is 3.

Answer: 3

How the answer was checked. The three members were exhibited by grammar or construction, not merely asserted: S → aSb | ab for (ii), S → aSa | bSb | ε for (iv), and the union decomposition for (vi). The three non-members each require two independent equalities — (i) and (v) directly, (iii) through the midpoint argument — which one stack cannot supply.

Common misconception. Counting (iii) {w w} as context-free because {w wᴿ} is. The reversal in (iv) is what a stack can do; plain copying is not, since the machine would have to remember the first half in order and compare it forwards, but a stack returns symbols in reverse.

Takeaway. Context-free means "one counted comparison". Unions of such conditions stay context-free; conjunctions of two independent ones generally do not.

Concept map used to build the questions

  • The model. Finite control, one head, an unbounded tape; halting states as undefined transitions; a configuration as (state, head position, tape contents) and the count |Q| · n · |Γ|ⁿ that follows from it; the universal machine as a simulator that inherits loops; and the simulations that leave the accepted class alone — extra tapes, a two-way tape, a two-dimensional tape, nondeterminism — each with its own time cost.
  • Recursive versus r.e. Decider against recogniser; enumerators and the dovetail that turns one into the other; the r.e. class as the ranges of total computable functions; closure under union and intersection but not complement; and the two-line argument that a set recursive together with its complement forces the set to be recursive.
  • Undecidability. The diagonal argument for the halting problem; the direction of a mapping reduction HALT ≤m L; bounded halting as the decidable counterpart, including bounds that are functions of the input; existential questions that are r.e. against universal questions that are not; and K = {⟨M⟩ : M halts on ⟨M⟩} as the complete r.e. set.
  • Rice’s theorem. Semantic against syntactic properties; non-triviality as the condition that some r.e. language has the property and another does not; triviality as the trap; the “ignore the input, simulate, then accept” gadget and the budget that grows with the input, which is what turns a halting question into a question about an infinite language; and the properties — space usage, number of states — that lie outside the theorem.
  • Chomsky hierarchy. Regular ⊂ CFL ⊂ CSL ⊂ RE with the machine that matches each level; non-shortening productions as the definition of a context-sensitive grammar; membership and emptiness as the decidability dividing lines; and the closure facts that refuse to follow the chain — complementation holds for CFL and CSL but not for RE, while intersection fails already at CFL.
  • Connections. The counting argument behind the decidability of LBA acceptance is the same one that bounds a simulation, and it returns in every question about context-sensitive membership; the reduction gadget of this unit reappears whenever a language is shown hard by translating one problem into another.

Source categories

Each question carries a data-source tag. STANDARD_TEXTBOOK marks questions built on the standard treatment of computability (Sipser, Hopcroft–Motwani–Ullman), written in original wording. ORIGINAL_SYNTHESIS marks independently designed GATE-style practice, including all five numerical items. GATE_PYQ_VARIATION would mark a question built from a verified previous-year question; this set contains none, because no Turing-machine or decidability previous-year question has been verified against an official paper and key for this run.
